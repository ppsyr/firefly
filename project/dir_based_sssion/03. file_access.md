# 功能：文件访问权限（sandbox）+ `@目录` / `@文件名` 引用

## 0. 本部分实现的功能（一览）

> **本部分 = "让会话只能访问绑定 thread 的 dir（+ 追加目录）下的文件 + 用 `@目录` / `@文件名` 把文件塞进本轮上下文"**。
>
> **实现了**：
> 1. **sandbox 根 = `thread.cwd`** —— 从"隐式 `Path.cwd()`"改为"显式绑定 thread 的 dir"；
> 2. **`@目录` 引用** —— 把该目录下文本文件清单塞进本轮上下文；
> 3. **`@文件名` 引用** —— 在 `dir`（+ 追加目录）下搜索同名文件，命中后通过下栏选择；
> 4. **下栏文件选择器** —— `↑`/`↓` 选择，回车确认，`Esc` 取消（复用 `thread_picker` 模式）；
> 5. **路径越界拒绝** —— 必须在 `thread.cwd`（或 `/add-dir` 追加目录）下，不允许 `../` 穿越；
> 6. **大小 / 类型约束** —— 单文件 ≤ 100KB；二进制拒绝；`@目录` 展开总量受限；
> 7. **注入到本轮消息** —— 走现有 `context_engineering` 预算 / 截断；
> 8. **`AppRuntime.thread_cwd`** —— 作为 sandbox 根的来源。
>
> **不做**：
> - ❌ 文件写入（`@` 只读；写走工具）—— 另开；
> - ❌ 文件实时监听（引用一次，不追变）；
> - ❌ 多模态（图片 / 音视频注入）；
> - ❌ 跨 cwd 引用；
> - ❌ 模糊搜索 / 分页 / 多选（多命中只做单选）；
> - ❌ 跨进程会话恢复（功能 1 已覆盖）；
> - ❌ `/add-dir` / `/cd` 本身（消费其产物，不重造）。

## 1. 定义

### 是什么

把 **sandbox 的访问边界**从"隐式 `Path.cwd()`"改为"**显式绑定 thread 的 `cwd`**（+ 会话级追加目录）"，并提供 **`@目录` / `@文件名`** 两种引用语法，把目录下的文本文件内容**塞进本轮上下文**发给 LLM。

**`@文件名` 命中多个同名文件时**：弹**下栏选择器**，`↑`/`↓` + 回车决定选哪个。

### 为什么

- **功能 2 留了缺口** —— "沙箱根仍是 `Path.cwd()`，隐式"，`poirot --dir /path/a` 从别处启动时行为未定义；
- **coding agent 的刚需** —— 没有 `@文件`，无法把项目文件塞进上下文；
- **`@目录` 让"看一个模块"成为一步操作**；
- **多命中选择** —— 同名文件（`config.yaml` / `main.py`）必须能区分，否则注入错文件；
- **地基** —— 不做它，"以文件夹为基础的工作流"是空谈；`@thread-id` / `/cd` 也依赖它。

### 成功标准

1. `poirot --dir /path/a` 从 `/path/b` 启动 → 工具只能访问 `/path/a` 下；
2. `@main.py 帮我看看` → 单命中 → 文件内容进上下文；
3. `@config.yaml` → 多命中 → 下栏列出相对路径 → `↑`/`↓`/回车选中 / `Esc` 取消；
4. `@src 看看这个目录` → 目录下文本文件清单进上下文；二进制跳过；超限提示；
5. `@../etc/passwd` → 拒绝；
6. `@huge.log`（>100KB）→ 提示不注入；
7. `@image.png` → 提示拒绝（二进制）；
8. `/add-dir /lib` 后 `@foo.py` → 能在 `/lib` 命中。

### 不做什么

- ❌ 不做文件写入（`@` 只读）；
- ❌ 不做实时监听；
- ❌ 不做多模态；
- ❌ 不做跨 cwd 引用；
- ❌ 不做模糊搜索 / 分页 / 多选；
- ❌ 不做 `/add-dir` / `/cd` 本身（消费其产物）；
- ❌ 不做多进程文件锁（MVP 阶段 `threading.Lock` 足够）。
