# 功能：文件访问权限（sandbox）+ `@目录` / `@文件名` 引用

## 0. 本部分实现的功能（一览）

> **本部分 = "让会话只能访问绑定 thread 的 dir（+ 追加目录）下的文件 + 用 `@目录` / `@文件名` 把文件塞进本轮上下文"**。
>
> **实现了**：
> 1. **sandbox 根 = `thread.cwd`** —— 从"隐式 `Path.cwd()`"改为"显式绑定 thread 的 dir"；
> 2. **`@目录` 引用** —— 把该目录下文本文件清单塞进本轮上下文；
> 3. **`@文件名` 引用** —— 在 `dir`（+ 追加目录）下搜索同名文件，命中 1 个直接注入，命中多个下栏选择；
> 4. **下栏文件选择器** —— `↑`/`↓` 选择，回车确认，`Esc` 取消（复用 `thread_picker` 模式）；
> 5. **路径越界拒绝** —— 必须在 `thread.cwd`（或 `/add-dir` 追加目录）下，不允许 `../` 穿越；
> 6. **大小 / 类型约束** —— 单文件 ≤ 100KB；二进制拒绝；`@目录` 展开总量受限；
> 7. **注入到本轮消息** —— 走现有 `context_engineering` 预算 / 截断；
> 8. **`AppRuntime.thread_cwd`** —— 作为 sandbox 根的来源。
>
> **不做**：
> - ❌ 文件写入（`@` 只读；写走工具）—— 另开；
> - ❌ 文件实时监听（引用一次，不追变）；
> - ❌ 多模态（图片 / 音视频注入）；
> - ❌ 跨 cwd 引用；
> - ❌ 模糊搜索 / 分页 / 多选（多命中只做单选）；
> - ❌ 跨进程会话恢复（功能 1 已覆盖）；
> - ❌ `/add-dir` / `/cd` 本身（消费其产物，不重造）。

## 1. 定义

### 是什么

把 **sandbox 的访问边界**从"隐式 `Path.cwd()`"改为"**显式绑定 thread 的 `cwd`**（+ 会话级追加目录）"，并提供 **`@目录` / `@文件名`** 两种引用语法，把目录下的文本文件内容**塞进本轮上下文**发给 LLM。

**`@文件名` 命中多个同名文件时**：弹**下栏选择器**，`↑`/`↓` + 回车决定选哪个。

### 为什么

- **功能 2 留了缺口** —— "沙箱根仍是 `Path.cwd()`，隐式"，`poirot --dir /path/a` 从别处启动时行为未定义；
- **coding agent 的刚需** —— 没有 `@文件`，无法把项目文件塞进上下文；
- **`@目录` 让"看一个模块"成为一步操作**；
- **多命中选择** —— 同名文件（`config.yaml` / `main.py`）必须能区分，否则注入错文件；
- **地基** —— 不做它，"以文件夹为基础的工作流"是空谈；`@thread-id` / `/cd` 也依赖它。

### 成功标准

1. `poirot --dir /path/a` 从 `/path/b` 启动 → 工具只能访问 `/path/a` 下；
2. `@main.py 帮我看看` → 单命中 → 文件内容进上下文；
3. `@config.yaml` → 多命中 → 下栏列出相对路径 → `↑`/`↓`/回车选中 / `Esc` 取消；
4. `@src 看看这个目录` → 目录下文本文件清单进上下文；二进制跳过；超限提示；
5. `@../etc/passwd` → 拒绝；
6. `@huge.log`（>100KB）→ 提示不注入；
7. `@image.png` → 提示拒绝（二进制）；
8. `/add-dir /lib` 后 `@foo.py` → 能在 `/lib` 命中。

### 不做什么

- ❌ 不做文件写入（`@` 只读）；
- ❌ 不做实时监听；
- ❌ 不做多模态；
- ❌ 不做跨 cwd 引用；
- ❌ 不做模糊搜索 / 分页 / 多选；
- ❌ 不做 `/add-dir` / `/cd` 本身（消费其产物）；
- ❌ 不做多进程文件锁（MVP 阶段 `threading.Lock` 足够）。

## 4. 设计

### 接口

```python
# app/cli/at_parser.py（新）
@dataclass
class AtToken:
    raw: str            # 原文 token，如 "@src/main.py"
    kind: str           # "file" | "dir" | "thread"
    value: str          # "src/main.py" / "src" / "abc"

def parse_at_tokens(text: str) -> list[AtToken]: ...
def strip_at_tokens(text: str, tokens: list[AtToken]) -> str: ...

# sandbox/contracts/file_resolver.py（新）
def resolve_file(name: str, cwd: Path, extra_dirs: list[Path]) -> list[Path]: ...
    # 返回所有命中（相对路径优先 cwd，再追加目录）
def resolve_dir(path: str, cwd: Path, extra_dirs: list[Path]) -> Path | None: ...

# sandbox/contracts/file_reader.py（新）
def is_binary(path: Path, probe_bytes: int = 8192) -> bool: ...
def read_text_file(path: Path, max_bytes: int = 100 * 1024) -> str: ...
def read_dir_manifest(path: Path, max_files: int = 50,
                      max_total_bytes: int = 200 * 1024) -> str: ...

# app/cli/file_picker.py（新）
def pick_file_interactive(matches: list[Path], cwd: Path) -> Path | None: ...

# app/cli/at_injector.py（新）
def inject_at_tokens(tokens: list[AtToken],
                     cwd: Path,
                     extra_dirs: list[Path]) -> str: ...
    # 返回注入片段（供 _run_chat_async 拼进本轮消息）

# app/bootstrap.py::AppRuntime（扩展）
@property
def thread_cwd(self) -> Path: ...      # 来自 ThreadRegistry.get(thread_id).cwd
def add_dir(self, path: Path) -> None: ...
def remove_dir(self, path: Path) -> None: ...
def extra_dirs(self) -> list[Path]: ...

# app/cli/commands.py（新增命令，设 pending_*）
/add-dir <path>          → pending_add_dir = path
/add-dir --remove <path> → pending_remove_dir = path

# app/cli/main.py::_run_chat_async（消费）
pending_add_dir / pending_remove_dir → runtime.add_dir / remove_dir
用户输入含 @            → parse_at_tokens → inject_at_tokens → 拼进本轮
```

### 数据

```python
# 无新增持久化文件；追加目录为 AppRuntime 会话态
# thread.cwd 已由功能 2 写入 ~/.poirot/threads/{thread_id}.json

# 注入片段格式（示例，走 context_engineering）
"""
<file path="src/main.py">
...文件内容（截断后）...
</file>

<dir path="src">
- src/main.py (2.1KB)
- src/utils.py (1.4KB)
...
</dir>
"""
```

### 流程

```
_run_chat_async 主循环
    │
    ├─ 用户输入 "@config.yaml 看看"
    │     │
    │     ▼
    │   parse_at_tokens → [AtToken(kind="file", value="config.yaml")]
    │     │
    │     ▼
    │   resolve_file("config.yaml", cwd, extra_dirs)
    │     ├─ 命中 0 → 提示"未找到"
    │     ├─ 命中 1 → read_text_file → 注入片段
    │     └─ 命中 N → pick_file_interactive → 选中 → read_text_file → 注入片段
    │     │
    │     ▼
    │   strip_at_tokens(原输入) + 注入片段 → 本轮消息
    │     │
    │     ▼
    │   create_run(thread_id, user_input=本轮消息)
    │         └─ context_engineering 走预算 / 截断
    │
    ├─ 用户输入 "@src 看看目录"
    │     └─ parse_at_tokens(kind="dir") → resolve_dir → read_dir_manifest → 注入
    │
    └─ /add-dir /lib → pending_add_dir → runtime.add_dir(Path("/lib"))
```

## 7. 关键决策

| 决策 | 建议 |
|---|---|
| sandbox 根来源 | **`thread.cwd`**（显式，来自 `ThreadRegistry.get`） |
| `@` 语法区分 | **`@目录`（末尾无扩展名或存在同名目录）/ `@文件名`（有扩展名）；`@thread-<id>` 前缀区分** |
| 同名搜索范围 | **cwd 优先，再追加目录** |
| 多命中处理 | **下栏选择器**（`↑`/`↓`/回车/`Esc`） |
| 路径展示 | **相对 cwd**（区分同名） |
| 单文件上限 | **100KB**（可配） |
| `@目录` 展开上限 | **条数 ≤ 50 / 总大小 ≤ 200KB**（可配） |
| 二进制处理 | **拒绝 + 提示** |
| 注入时机 | **本轮一次性**（不监听变化） |
| 注入格式 | **`<file path="...">` / `<dir path="...">` 标签块**（走 `context_engineering`） |
| 追加目录作用域 | **会话级**（存 `AppRuntime`） |
| 并发 | **`threading.Lock`** |
| 迁移 | **不做** |
