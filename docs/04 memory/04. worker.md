---

name: MemoryWorker — 后台异步抽取 episodic + consolidate（L5）。

description:

【整体职责】
daemon 线程消费队列，异步做「抽取 episodic + 合并 semantic」。
主链「写路径」的执行体：
ConsolidationMW.aafter_model → worker.submit(task) → worker 异步处理。

【核心机制】
- daemon 线程 + threading.Queue。
- LLM 构造注入（不反向依赖 app）。
- aafter_model 非阻塞 submit，worker 异步处理。
- 工具里无 LLM 原则不变：worker 在 middleware 层调 LLM，
  manager 仍只接受外部传入 content。

【职责边界】
- 本模块只负责「异步执行」，不负责何时触发（那是 ConsolidationMW 的事）。
- 不生成记忆：抽取靠 LLM prompt；合并靠 LLM prompt；manager 只负责落库。
- LLM 失败 log + 跳过，不重试，不影响主流程。
- 队列无界（L5 MVP，L6 加 maxsize）。

【INVARIANT】
- daemon 线程（进程退出自动结束）。
- 队列无界（L5 MVP）。
- 无重试（LLM 失败 log + 跳过）。
- set_turn_id 标 actor = "worker:{thread_id}:{turn_count}"。
- 工具里无 LLM 原则不变（worker 在 middleware 层调 LLM）。

## 1. 消费循环与任务处理

```
start()
    └── Thread(target=_run, daemon=True).start()
            │
            ▼
_run() 循环
    │
    ├── _stop.set()? → 退出
    │
    ├── _queue.get(timeout=1.0)
    │       Empty → 继续循环
    │
    └── _process(task)
            │
            ├── set_turn_id("worker:{thread_id}:{turn_count}")  ← traceability C
            │
            ├── _extract_and_encode(task)
            │       ├── _format_messages(task.messages)
            │       ├── _EXTRACT_PROMPT → llm.invoke → JSON 解析
            │       └── 逐条 manager.encode
            │
            ├── _maybe_consolidate(task)
            │       ├── get_memory_config() → threshold
            │       ├── store.list_by_type(EPISODIC) 过滤 forgotten
            │       ├── 取最旧 max=10 条
            │       ├── _CONSOLIDATE_PROMPT → llm.invoke → merged
            │       └── manager.consolidate(ids, merged)
            │
            └── finally: set_turn_id(None)  ← 清理 actor
```

## 2. 两阶段处理

```
阶段 1：抽取（_extract_and_encode）
    │   目的：把对话里的值得记住的 episodic 落库。
    │
    ├── 输入：task.messages（最近 N*2 条）
    ├── LLM：_EXTRACT_PROMPT → JSON 数组
    ├── 逐条：manager.encode（同内容同 type 幂等）
    └── 输出：encoded trace id 列表（失败 / 无结果 → []）


阶段 2：合并（_maybe_consolidate）
    │   目的：episodic 积累到阈值时合并成 semantic。
    │
    ├── 触发条件：store 中非 forgotten episodic 总量 ≥ threshold
    ├── 输入：最旧 max=10 条 episodic
    ├── LLM：_CONSOLIDATE_PROMPT → merged 文本
    └── 输出：manager.consolidate → 新 semantic + 旧标 forgotten
```

## 4. 总览

```
MemoryTask             = 任务结构（thread_id + messages + turn_count）
MemoryWorker           = daemon 线程消费队列，异步处理沉淀任务
__init__               = 注入 manager + llm，初始化队列
start / submit / shutdown = 生命周期（启 / 丢 / 关）
_run                   = 消费循环（取任务，异常不崩）
_process               = 单任务处理（抽 + 合并，finally 清 actor）
_extract_and_encode    = LLM 抽取 + manager.encode（幂等）
_maybe_consolidate     = 查总量 + LLM 合并 + manager.consolidate
_format_messages       = 消息拼文本
```
