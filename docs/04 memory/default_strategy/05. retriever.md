---

name: HybridRetriever — 纯 BM25 检索（无 vector/graph）。

description:

【整体职责】
实现 Retriever Protocol，提供记忆的检索后端。
是 memory 模块唯一的检索实现，被 MemoryMiddleware（读路径）调用。
构造时全量建索引（冷启动），store 变更时增量维护。

【核心机制】
1. BM25 召回：从倒排索引算相似度。
2. retrieve 强化写回（1A）：命中后算 strength + with_strength + store.update。
3. forgotten 过滤（3B）：retrieve 时排除 metadata.forgotten=True。
4. 增量索引（5B）：构造全量建 + on_trace_* 增量维护。
5. 复合分数：score = similarity × 0.7 + strength × 0.3。

【职责边界】
- 本模块只做检索 + 强化写回，不感知遗忘判定（forget_policy 的事）。
- 纯 BM25，不依赖 vector/graph（adapters 是 Layer 6 预留）。
- forgotten 过滤在 Retriever（store 不感知）。
- 1A 强化写回在 retrieve 内部完成，caller 不负责。

【INVARIANT】
- 纯 BM25，无 vector/graph 依赖。
- forgotten 过滤在 Retriever（store 不感知）。
- 增量索引：构造全量建 + on_trace_* 增量维护。
- retrieve 强化写回：命中后 store.update，caller 不负责。

## 1. 索引维护（5B）

```
冷启动（构造时）
    __init__
        └── _build_index_from_store()
                └── store.list_all() → 逐条 _index_trace（排除 forgotten）

增量维护（运行时，由 bootstrap._wrap_store 挂载）
    store.add(trace)      → retriever.on_trace_added(trace)    → _index_trace
    store.update(trace)   → retriever.on_trace_updated(trace)  → _remove + _index_trace
    store.batch_update    → retriever.on_trace_updated（逐条）
    store.remove(id)      → retriever.on_trace_removed(id)     → _remove_trace_from_index
```

## 2. retrieve 流程

```
retrieve(query)
    │
    ├── 1. now = time.time() + query 分词
    │
    ├── 2. 3B forgotten 过滤
    │       candidates = [t for t in store.list_all() if not t.metadata["forgotten"]]
    │
    ├── 3. type_filter 过滤（若有）
    │
    ├── 4. avgdl + BM25 参数（k1 / b）
    │
    ├── 5. 对每个候选
    │       ├── _bm25_score → similarity
    │       │       similarity ≤ 0 → 跳过
    │       ├── decay_policy.compute_strength → current_strength
    │       │       current_strength < query.min_strength → 跳过
    │       └── RetrievalResult.compute_score → score
    │
    ├── 6. 按 score 降序排序 + top_k 截断
    │
    └── 7. 1A 强化写回（对 top 命中逐条）
            ├── decay_policy.compute_strength → new_strength
            ├── trace.with_strength(new_strength, now)
            ├── store.update(strengthened)
            └── RetrievalResult.compute_score(strengthened, ...) → 入结果列表
```

## 4. 总览

```
HybridRetriever         = Retriever 的默认实现，纯 BM25
__init__ / _build_...   = 冷启动全量建索引
_index_trace / _remove_trace_from_index = 增量索引维护
```
