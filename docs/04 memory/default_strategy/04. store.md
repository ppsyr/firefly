---

name: MarkdownFileStore — Markdown 持久化 truth source。

description:

【整体职责】
实现 MemoryStore Protocol，提供记忆的持久化后端。
traces.md 是 truth source，内存索引是 derived（可重建）。
是 memory 模块唯一的持久化实现，被 manager / retriever / worker 共用。

【存储模型】
- 单文件：所有 trace 存于 traces.md。
- 分隔符：`<!-- trace: {id} -->`（方案 B）。
- 每条 trace：YAML frontmatter（除 content 外所有字段）+ content 正文。
- 内存索引：dict[str, MemoryTrace]，启动加载 + 增量维护。

【职责边界】
- 本模块只负责持久化与内存索引维护，不感知 forgotten / strength 精算
  （forgotten 过滤在 Retriever，strength 精算由调用方）。
- 无事务（2A）：逐个操作，失败 log，接受最终一致（Phase 2 cron 修复）。
- 文件锁（6B）：threading.Lock 保护写操作（单进程）；跨进程锁留后续。
- 解析容错（2A）：frontmatter 损坏 log + 跳过，不崩。

【INVARIANT】
- Markdown-as-Truth：traces.md 是 truth source，内存索引是 derived（可重建）。
- 单文件 + 分隔符：所有 trace 在 traces.md，用 `<!-- trace: {id} -->` 分隔。
- storage_path 锚定：相对路径用 cwd fallback
  （Layer 4 bootstrap 传绝对路径锚定 _PROJECT_ROOT）。
- 写操作由 threading.Lock 保护（单进程）。

## 1. 写操作与锁

```
写操作（全部加 _lock，单进程串行）
│
├── add(trace)
│       ├── 检查 id 冲突 → MemoryConflictError
│       ├── 写内存索引
│       └── _append_to_file（增量写）
│
├── update(trace)
│       ├── 检查 id 存在 → MemoryNotFoundError
│       ├── 替换内存索引
│       └── _rewrite_file（全量重写）
│
├── batch_update(traces)
│       ├── 先全量校验（原子性）
│       ├── 逐条替换内存索引
│       └── _rewrite_file（一次，避免 O(N²)）
│
└── remove(trace_id)
        ├── id 存在 → 删除 + _rewrite_file
        └── 不存在 → 静默（幂等）
```

## 2. 序列化 / 反序列化

```
_serialize_trace（写盘）
    │   MemoryTrace → frontmatter + content
    │
    ├── MemoryType → value string
    ├── associations / operation_log tuple → list
    ├── embedding tuple → list 或 None
    └── diff tuple → list（_diff_to_serializable）
         │
         ▼
    YAML frontmatter + content
         │
         ▼
    `---\n{frontmatter}\n---\n{content}`


_parse_trace（读盘）
    │   frontmatter + content → MemoryTrace
    │
    ├── MemoryType string → 枚举
    ├── associations / operation_log list → tuple
    └── embedding list → tuple 或 None
         │
         ▼
    MemoryTrace（构造）
```

## 4. 总览

```
MarkdownFileStore       = MemoryStore 的默认实现，单文件 traces.md + 内存索引
__init__ / _load        = 启动加载 + 解析容错
_parse_trace / _serialize_trace = 序列化 / 反序列化（tuple ↔ list 转换）
add / update / batch_update / remove = 写操作（全部加锁）
get / list_by_type / list_by_filter / list_all = 读操作
_resolve_storage_path   = 路径解析（cwd fallback）
_append_to_file         = 增量写
_rewrite_file           = 全量重写
```
