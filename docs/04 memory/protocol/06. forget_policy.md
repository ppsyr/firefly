---

name: ForgetPolicy Protocol — 遗忘策略契约。

description:

【整体职责】
定义遗忘策略必须提供的接口。
是 memory 模块的 7 个 Protocol 之一，约束 forget 实现（默认 CompositeForgetPolicy）。

【两规则组合】
should_forget 检查两条规则，命中任一即应遗忘：
1. TTL 过期：long time no access → forget。
2. strength 阈值：衰减到 strength_threshold 以下 → forget。

【职责边界】
- 本模块只定义接口签名，零实现（Protocol 纯契约）。
- 只判 should_forget，不做实际删除（那是 store / manager 的事）。
- 不含矛盾解决（B3 决策）：矛盾解决走 reconsolidate（单条内容更新）或
  consolidate（多条合并 + 旧标记 forgotten），由 manager 调用。
- 默认实现：CompositeForgetPolicy（strategies/default/forget.py，Layer 2）。
- 可替换：TTLOnly / StrengthOnly。

【INVARIANT】
- Protocol 纯契约零实现，可 mock 可替换。
- 两规则遗忘：should_forget 检查 TTL + strength；无 resolve_conflict。
