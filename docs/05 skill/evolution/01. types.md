---

name: Skill 自进化层值对象 — frozen dataclass + Literal 枚举。

description: 

【整体职责】
定义 evolution（L2 进化层）的数据契约（全部为不可变值对象 + Literal 枚举）。
覆盖进化的全链路类型：
- 触发与上下文：EvolutionContext
- 聚焦证据：FailureEvidence
- 评估契约：EvalContext / EvalEvidence / EvalResult
- 门控决策：GateDecision
- 实验记录：EvolutionRecord

这些类型是 trigger / focuser / mutator / gate 之间，以及与 L3 eval、L1 store
之间的共同语言。承接 37.md §4.1 接口签名。

【内容摘要】
Literal 枚举：
- TriggerType        : METRIC / CAPTURE / PERIODIC / TOOL_DEGRADATION / ANALYSIS。
- EvolutionType      : FIX / DERIVED / CAPTURED。
- FailureClass       : FUNDAMENTAL / IMPLEMENTATION。
- GateRecommendation : accept_new_best / accept / reject / pending_human。
- EvalMetric         : hard / soft / mixed。
- EvalEvidenceKind   : programmatic_rule / longitudinal_pair / judge_reason。

值对象：
- FailureEvidence   : 聚焦后的单条失败证据（IVEFocuser 产出）。
- EvolutionContext  : 进化统一上下文（Trigger 产出，Focuser 增强，Mutator 消费）。
- EvalContext       : eval 调用上下文（第二层传给 EvalBridge）。
- EvalEvidence      : eval 证据链（2a 仅 programmatic_rule）。
- EvalResult        : eval 结果（EvalBridge 返回，PromotionGate 消费）。
- GateDecision      : PromotionGate 决策。
- EvolutionRecord   : 实验记录（写 store.skill_evolutions 表，可审计）。

【职责边界】
- 只负责：定义数据契约（字段 + 枚举）。
- 不负责：触发逻辑（triggers）、聚焦（focuser）、变异（mutator）、门控（gates）、
  评估（eval 层）、持久化（store）。
- 不持有可变状态：全部 frozen，构造后字段不可改。
- 不做 LLM 推理：本模块只声明结构（推理在 mutator / analyzer 里）。

## 0. 结构树

### 0.1. 静态结构树

```
skill/evolution/types.py — Skill 自进化层值对象（frozen dataclass + Literal 枚举）
│
├─ Literal 枚举
│   ├─ TriggerType        = METRIC | CAPTURE | PERIODIC | TOOL_DEGRADATION | ANALYSIS
│   ├─ EvolutionType      = FIX | DERIVED | CAPTURED
│   ├─ FailureClass       = FUNDAMENTAL | IMPLEMENTATION
│   ├─ GateRecommendation = accept_new_best | accept | reject | pending_human
│   ├─ EvalMetric         = hard | soft | mixed
│   └─ EvalEvidenceKind   = programmatic_rule | longitudinal_pair | judge_reason
│
├─ class FailureEvidence(frozen)               ← 聚焦后的单条失败证据（IVEFocuser 产出）
│   ├─ turn_index: int | None                  ← 失败 turn（PERIODIC/METRIC 为 None）
│   ├─ tool_name: str | None                   ← 失败工具
│   ├─ failure_class: FailureClass             ← IVE 分类
│   ├─ description: str                        ← 失败描述
│   └─ impl_fail_count: int = 0                ← implementation 累计（≥3 升级 fundamental）
│
├─ class EvolutionContext(frozen)              ← 进化统一上下文（Trigger 产 / Focuser 增 / Mutator 消）
│   ├─ trigger: TriggerType
│   ├─ evolution_type: EvolutionType
│   ├─ target_skill: SkillRecord | None        ← FIX/DERIVED 有；CAPTURED 无
│   ├─ failure_evidence: tuple[FailureEvidence, ...] = ()
│   ├─ fix_direction: str = ""                 ← IVE 第 5 问给的修复方向
│   ├─ capture_pattern: str = ""               ← CAPTURED：可复用模式描述
│   ├─ suggested_name: str = ""                ← CAPTURED：建议 skill name
│   └─ recent_analyses: tuple[str, ...] = ()   ← 历史分析摘要（防重复）
│
├─ class EvalContext(frozen)                   ← eval 调用上下文（第二层传给 EvalBridge）
│   ├─ baseline: SkillRecord                   ← 当前激活版（CAPTURED 时占位）
│   ├─ candidate: SkillRecord                  ← 变异后候选（is_active=False）
│   ├─ metrics_baseline: SkillMetrics | None = None
│   ├─ replay_samples: tuple[Any, ...] = ()    ← MVP 空（longitudinal 留 L3）
│   └─ task_domain: str | None = None
│
├─ class EvalEvidence(frozen)                  ← eval 证据链（2a 仅 programmatic_rule）
│   ├─ kind: EvalEvidenceKind
│   ├─ rule_name: str                          ← 如 "nonempty" / "semantic_density"
│   ├─ baseline_pass: bool
│   ├─ candidate_pass: bool
│   └─ detail: str = ""
│
├─ class EvalResult(frozen)                    ← eval 结果（EvalBridge 返，PromotionGate 消）
│   ├─ score: float                            ← [0,1] programmatic 通过率
│   ├─ metric: EvalMetric = "hard"
│   ├─ hard_failures: tuple[str, ...] = ()     ← 关键失败 rule 名
│   ├─ evidence: tuple[EvalEvidence, ...] = ()
│   ├─ confidence: float = 0.7                 ← programmatic ~0.7
│   └─ recommendation: GateRecommendation = "reject"
│
├─ class GateDecision(frozen)                  ← PromotionGate 决策
│   ├─ recommendation: GateRecommendation
│   ├─ reason: str
│   └─ new_version_id: str | None = None       ← accept 时的新 skill_id
│
└─ class EvolutionRecord(frozen)               ← 实验记录（写 store.skill_evolutions）
    ├─ evolution_id: str
    ├─ skill_name: str
    ├─ evolution_type: EvolutionType
    ├─ trigger: TriggerType
    ├─ baseline_id: str | None                 ← FIX/DERIVED 有；CAPTURED 无
    ├─ candidate_id: str
    ├─ failure_focus: str                      ← IVE 诊断摘要 / CAPTURED 模式描述
    ├─ mutation_diff: str                      ← Mutator 产出的 diff
    ├─ eval_score: float
    ├─ gate_decision: GateRecommendation
    ├─ created_version_id: str | None = None   ← accept 时的新 skill_id
    └─ timestamp: str = ""
```

### 0.2. 运行时调用树（类型在进化链路中的流转）

```
① 触发（Triggers）
    metric_monitor / capture_trigger
        └─ 产出 EvolutionContext（trigger + evolution_type + target_skill）

② 聚焦（Focuser）
    ive_focuser
        └─ 增强 EvolutionContext
              ├─ failure_evidence: tuple[FailureEvidence, ...]
              └─ fix_direction

③ 变异（Mutator）
    llm_mutator
        └─ 消费 EvolutionContext → 产 candidate SkillRecord + mutation_diff

④ 评估（EvalBridge / L3）
    RegistryEvalBridge.evaluate(EvalContext)
        ├─ EvalContext(baseline, candidate, metrics_baseline, ...)
        └─ 返回 EvalResult(score, hard_failures, evidence, confidence, recommendation)

⑤ 门控（Gates）
    score_delta_gate / git_ratchet
        └─ 消费 EvalResult → 产 GateDecision(recommendation, reason, new_version_id)

⑥ 落库（store）
    ├─ record_evolution(EvolutionRecord)        → skill_evolutions 表
    └─ create_version(...)                      → 新版本进 version DAG（accept 时）
```

## 1. 补充

- **`EvolutionContext.target_skill` 是三类进化的分水岭**：FIX/DERIVED 有值；CAPTURED 为 None（新技能），靠 `capture_pattern` + `suggested_name` 描述。
- **`EvalResult` 是 L3 → L2 的桥**：L3 的 `ResponseContractChecker` 产它，L2 的 `PromotionGate` 消费它。
- **`EvolutionRecord` 是审计记录**：与 L1 的 `skill_evolutions` 表一一对应；`created_version_id` 只有 accept 时才有值。
- **本模块不 import eval/types**：`EvolutionSuggestion`（eval/types）反过来依赖这里的 `EvolutionType`——依赖方向是 eval → evolution/types，不是反向。
