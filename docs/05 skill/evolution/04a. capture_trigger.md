---

name: CaptureTrigger — CAPTURED 主动沉淀触发（补 Hermes 式）。

description: 

【整体职责】
CAPTURED 类进化的触发器：把"可复用的成功模式"沉淀为新 skill。
2a 仅支持手动 `/skill capture`（manual_capture）；
自动信号（重复成功模式 / agent 自评）留 2b。

【内容摘要】
- should_trigger(store)                     : 2a 自动信号未实现，返空列表。
- manual_capture(pattern, suggested_name)   : 手动沉淀入口，产 CAPTURED 上下文。

【职责边界】
- 只负责：产 EvolutionContext（CAPTURED 类型）——不聚焦、不变异、不评估、不门控。
- 不负责：聚焦（focuser）、变异（mutator）、评估（eval_bridge）、门控（gate）、
  持久化（store）、编排（EvolutionManager）。
- 2a 不做自动识别：should_trigger 恒返空；自动模式识别留 2b。

---

## 0. 结构树

### 0.1. 静态结构树

```
skill/evolution/triggers/capture_trigger.py — CAPTURED 主动沉淀触发
│
└─ class CaptureTrigger
    ├─ should_trigger(store) -> list[EvolutionContext]        ← 【自动信号】2a 恒返空
    │   └─ 2b 计划：post-execution 模式识别 + agent 自评
    │
    └─ manual_capture(pattern, suggested_name)                ← 【手动入口】/skill capture
        -> EvolutionContext
        └─ 产 CAPTURED：
              trigger="CAPTURE"
              evolution_type="CAPTURED"
              target_skill=None（新 skill）
              capture_pattern=pattern
              suggested_name=suggested_name
```

---

### 0.2. 运行时调用树

```
① 手动 CAPTURED（/skill capture）
    EvolutionManager.capture_skill(pattern, name)
        └─ 遍历 triggers 找 CaptureTrigger
              └─ trigger.manual_capture(pattern, name)
                    └─ 返回 EvolutionContext(CAPTURE / CAPTURED / target_skill=None)
                          └─ EvolutionManager._run_evolution(ctx)

② 自动触发（2a 不生效）
    EvolutionManager.run_cycle()
        └─ trigger.should_trigger(store)
              └─ 返回 []（2a 无自动信号；2b 补模式识别 + agent 自评）
```

---

## 1. 补充

- **它是 `EvolutionManager.capture_skill` 的默认搭档**：manager 遍历 triggers，遇到 `CaptureTrigger` 就调 `manual_capture` 产上下文；未注册时 manager 自造等价上下文。
- **`should_trigger` 恒返空**：2a 的 CAPTURED 完全靠手动；`run_cycle` 里它不会产生任何上下文。
- **产出的上下文特点**：`target_skill=None`（无基线）——这正是 FIX / DERIVED 与 CAPTURED 的分水岭，后续 `_run_evolution` 会以 candidate 占位 baseline 构造 `EvalContext`。
