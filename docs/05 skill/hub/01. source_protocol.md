---

name: SkillSource Protocol + SkillMeta — skill 发现抽象。

description: 

【整体职责】
定义 hub（技能中心）的"技能源"抽象与元数据契约：
- SkillSource : 每种 source 的 adapter 接口（search / fetch / preview）。
- SkillMeta   : source 返回的轻量元数据（搜索结果的统一格式）。

设计目标（design_docs/46 §2.3）：
- 每种 source（builtin / github / well-known / claude-marketplace）写一个 adapter。
- 新增 source = 新增 adapter + 注册，不动核心 search / install 逻辑。

【内容摘要】
- SkillMeta(frozen)      : source 返回的 skill 元数据。
- SkillSource(Protocol)  : source adapter 接口。
    - name                       : 源名（类属性）。
    - search(query, limit)       : 搜索 skill，返 list[SkillMeta]。
    - fetch(identifier, dest_dir): 下载/克隆到 dest_dir，返 skill 目录路径。
    - preview(identifier)        : 预览 SKILL.md 内容（不安装），可选。

【职责边界】
- 只负责：定义 source 抽象 + 元数据契约。
- 不负责：具体 source 实现（在 sources/ 下）、搜索编排（search.py）、
  安装流程（installer.py）、中心存储（hub_store.py）。
- 不做持久化：SkillMeta 是轻量元数据，不落库；已安装状态由 store 管理。
- 不管理版本/指标：不含 metrics / version lineage（install 后由 SkillStore 管理）。

## 0. 结构树

### 0.1. 静态结构树

```
skill/hub/source.py — SkillSource Protocol + SkillMeta（skill 发现抽象）
│
├─ class SkillMeta(frozen)                  ← source 返回的轻量元数据
│   ├─ name: str                            ← 技能名
│   ├─ description: str                     ← 技能描述
│   ├─ category: str                        ← 类别（core / research / ...）
│   ├─ source: str                          ← "builtin" / "github" / "well-known" / "claude-marketplace"
│   ├─ identifier: str                      ← 安装时传给 installer 的唯一标识
│   ├─ install_path: str | None = None      ← 已安装时的路径（未安装 None）
│   ├─ preview_url: str | None = None       ← SKILL.md 预览 URL（远程 source）
│   └─ is_installed: bool = False           ← 是否已安装
│
└─ class SkillSource(Protocol)              ← source adapter 接口
    ├─ name: str                            ← 源名（类属性）
    ├─ search(query, limit=10) -> list[SkillMeta]   ← 搜索 skill
    ├─ fetch(identifier, dest_dir) -> Path          ← 下载/克隆到 dest_dir
    └─ preview(identifier) -> str | None            ← 预览 SKILL.md（可选）
```

---

### 0.2. 运行时调用树

```
① 装配期（bootstrap）
    构造各 source adapter（BuiltinSource / GitHubSource / WellKnownSource /
    ClaudeMarketplaceSource）→ 注册到 hub（search / installer）

② 搜索（search.py 编排）
    search(query, limit)
        └─ for source in sources:
              └─ source.search(query, limit)          ← 本模块 Protocol 方法
                    └─ 返回 list[SkillMeta]

③ 预览（CLI / TUI 按需）
    source.preview(identifier)
        └─ 返回 SKILL.md 文本 或 None（不支持预览）

④ 安装（installer.py 编排）
    installer.install(meta)
        ├─ source.fetch(meta.identifier, dest_dir)    ← 本模块 Protocol 方法
        │     └─ 返回 skill 目录路径
        ├─ parser.parse_skill_file(SKILL.md)
        └─ store.register(SkillRecord)                → skills.db
```

## 1. 补充

- **它是 hub 的抽象基座**：`SkillSource` 定义"源"的统一能力（search / fetch / preview）；4 个具体源（builtin / github / well-known / claude-marketplace）各自实现。
- **`SkillMeta` 是搜索结果的统一格式**：跨源搜索时，所有源都返回同一种 `SkillMeta`，search.py 无需关心具体源。
- **`SkillMeta` 与 `SkillRecord` 的区别**：
  - `SkillMeta`：source 返回的轻量元数据，不含 metrics / version lineage，**不落库**。
  - `SkillRecord`：install 后由 `SkillStore` 管理的完整记录，含计数器、血缘、rate。
- **`identifier` 是 source 特定的**：如 `github:owner/repo@skill-name`；安装时传给 `installer`，由它分发给对应 source 的 `fetch`。
- **`preview` 是可选能力**：不支持的源返 None，调用方需容错。
- **扩展方式**：新增 source = 新增一个 adapter 实现 + 注册，`search.py` / `installer.py` 核心逻辑不动。
