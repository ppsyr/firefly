name: WellKnownSource — HTTP GET /.well-known/skills/index.json 安装 skill。

description: 

【整体职责】
hub 的远程技能源之一：从任意网站的 /.well-known/skills/index.json 发现技能。
- 任何网站可暴露 skill 索引（约定路径 /.well-known/skills/index.json）。
- HTTP GET index.json，关键词匹配 name / description。
- endpoint 不可达时降级为返空（不抛异常）。

设计（design_docs/46 §2.4）：
- 任何网站可暴露 skill 索引（/.well-known/skills/index.json）。
- HTTP GET index.json，关键词匹配 name/description。
- endpoint 不可达时降级为返空（不抛异常）。
- identifier 格式：well-known:https://example.com 或 well-known:example.com。

【内容摘要】
类方法：
- __init__(endpoints)                       : 保存 well-known endpoint 列表。
- search(query, limit) -> list[SkillMeta]   : 遍历 endpoints，拉 index 匹配。
- fetch(identifier, dest_dir) -> Path       : 下载 skill（MVP 占位）。
- preview(identifier) -> str | None         : 预览 SKILL.md（MVP 返 None）。
- _fetch_index(endpoint) -> list[dict] | None : HTTP GET index.json。

【职责边界】
- 只负责：拉各 endpoint 的 index.json + 关键词匹配 + 转 SkillMeta。
- 不负责：搜索编排（search.py）、安装流程（installer.py）、中心存储（hub_store.py）、
  技能解析（parser）、持久化（store）。
- MVP 未实现 fetch / preview：fetch 只占位返 dest_dir，preview 恒返 None。

## 0. 结构树

### 0.1. 静态结构树

```
skill/hub/sources/well_known_source.py — WellKnownSource（HTTP GET /.well-known/skills/index.json）
│
└─ class WellKnownSource
    ├─ name = "well-known"                              ← 源标识（类属性）
    │
    ├─ __init__(endpoints=None)                         ← 保存 endpoint 列表（缺省 []）
    │   └─ self._endpoints = endpoints or []
    │
    ├─ search(query, limit=10) -> list[SkillMeta]       ← 【对外主入口】遍历 endpoints
    │   ├─ for endpoint in endpoints:
    │   │     ├─ _fetch_index(endpoint)（失败/空 → 跳过）
    │   │     ├─ 大小写不敏感匹配 name / description
    │   │     ├─ 命中 → SkillMeta(source="well-known",
    │   │     │                 identifier=f"well-known:{endpoint}@{name}",
    │   │     │                 is_installed=False)
    │   │     ├─ 达 limit → 提前返回
    │   │     └─ 异常 → 跳过该 endpoint（降级）
    │   └─ return results（跨 endpoint 累积）
    │
    ├─ fetch(identifier, dest_dir) -> Path              ← 【占位】MVP：返 dest_dir
    │   └─ 完整 HTTP 下载留后续
    │
    ├─ preview(identifier) -> str | None                ← 【占位】MVP：恒返 None
    │
    └─ _fetch_index(endpoint) -> list[dict] | None      ← 【内部】HTTP GET index.json
        ├─ url = f"{endpoint.rstrip('/')}/.well-known/skills/index.json"
        ├─ httpx.get(url, timeout=10, follow_redirects=True)
        ├─ status != 200 → None
        ├─ JSON list → 直接返回
        ├─ JSON dict 含 "skills" → 返回 data["skills"]
        └─ 其他 / 异常 → None
```

### 0.2. 运行时调用树

```
① 装配期（bootstrap）
    WellKnownSource(endpoints=["https://example.com", ...])
        └─ 注册到 hub 的 sources 列表

② 搜索（search.py 编排）
    search(query, limit)
        └─ for source in sources:
              └─ WellKnownSource.search(query, limit)        ← 本模块主入口
                    ├─ for endpoint in self._endpoints:
                    │     ├─ _fetch_index(endpoint)
                    │     │     └─ httpx.get(url) → JSON → list[dict]
                    │     ├─ 匹配 name / description
                    │     └─ 命中 → SkillMeta
                    └─ 跨 endpoint 累积结果

③ 安装（installer.py 编排）
    installer.install(meta)
        ├─ WellKnownSource.fetch(identifier, dest_dir)       ← 占位，返 dest_dir
        ├─ parser.parse_skill_file(SKILL.md)
        └─ store.register(SkillRecord)                       → skills.db

④ 预览（CLI / TUI 按需）
    WellKnownSource.preview(identifier)                      ← 占位，恒返 None
```

## 1. 补充

- **多 endpoint 设计**：与其他 source 不同，`WellKnownSource` 持有**一个 endpoint 列表**，`search` 会遍历所有 endpoint 累积结果——因为它对应的不是单一站点，而是"任何遵循 well-known 约定的网站"。
- **约定路径**：`{endpoint}/.well-known/skills/index.json`（endpoint 会先去尾斜杠）。这是模仿 `.well-known/` 标准（如 `security.txt`）的设计。
- **降级最彻底**：单个 endpoint 不可达 / 非 200 / JSON 坏 / 结构不符 → 跳过该 endpoint，继续下一个；`search` 整体不抛异常。
- **`fetch` / `preview` 是 MVP 占位**：与 `ClaudeMarketplaceSource` 一样——`search` 可用，`fetch` 只返 `dest_dir`，`preview` 恒返 `None`。
- **`identifier` 三元组**：`well-known:<endpoint>@<skill-name>`——比别的 source 多一个 endpoint 维度，因为同名 skill 可能来自不同站点。
- **四种 source 的 MVP 完成度对比**：

| Source | search | fetch | preview |
|--------|:---:|:---:|:---:|
| `BuiltinSource` | ✅（复用 SkillManager） | ✅（返本地路径） | ✅（读文件） |
| `GitHubSource` | ❌ 占位 | ✅（git clone） | ❌ 占位 |
| `ClaudeMarketplaceSource` | ✅（拉 registry） | ❌ 占位 | ❌ 占位 |
| `WellKnownSource` | ✅（拉多 endpoint） | ❌ 占位 | ❌ 占位 |

**要点**：只有 `BuiltinSource` 三个方法都可用；`GitHubSource` 的 `fetch` 可用但 `search` 不行；`ClaudeMarketplaceSource` 和 `WellKnownSource` 都只能 `search`，下载尚未实现。
