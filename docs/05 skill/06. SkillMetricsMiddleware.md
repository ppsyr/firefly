---

name: SkillMetricsMiddleware — applied 打点 + completions/fallbacks 归因。

description: 
【整体职责】
承接 SkillInjectionMiddleware 写下的 provenance 锚点，完成 skill 效果的「应用打点」与「结果归因」：
1. awrap_tool_call：工具真正被调用时，判断它属于哪个 active skill 的allowed_tools，命中就把该 skill 标为 applied=True，并写 journal。
2. after_agent：在 run 结束时，对每个 active skill 做归因（record_outcome），并判定本次 run 是否任务完成。

【INVARIANT（必须保持的不变量）】
- awrap_tool_call：
· 若 tool_name ∈ 某个 active skill 的 allowed_tools，则 _applied_ctx[sid] = True，并 journal.append("skill.apply", ...)。
- after_agent：
· 先做 run 级 task_completed 判定（与单个 skill 正交，不属于某个 skill）。
· 再对每个 active skill 调 store.record_outcome 做归因：
- tool-skill（有 allowed_tools）未命中工具 → applied=False（有能力用但没用）。
- guidance-skill（无 allowed_tools）→ applied=None（不强判）。
- applied=None → 只算「选中」，不归因 completion / fallback（INV#9）。
- provenance 通过 _ctx 里的 ContextVar 桥接：
awrap_tool_call 拿不到 state，只能靠 ContextVar 读 provenance。
- 无 _applied_ctx（即没有 injection middleware 写入）→ 降级处理：
after_agent 跳过归因（§6.6）。
- 无 store / journal 时静默不报错（INV#13，容忍运行环境缺件）。
- aafter_agent 直接委托同步版，保证同步/异步行为一致。

## 0. 结构树

### 0.1. 静态结构树（模块 → 类 → 方法）

```
SkillMetricsMiddleware — applied 打点 + completions/fallbacks 归因
│
├─ 模块级 INVARIANT（注释约定，非代码）
│   ├─ awrap_tool_call：tool ∈ allowed_tools → _applied_ctx[sid]=True + journal skill.apply
│   ├─ after_agent：判 task_completed（run 级，与 skill 正交）+ 对 active skill 归因
│   │   ├─ tool-skill 未命中工具 → applied=False
│   │   ├─ guidance-skill（无 allowed_tools）→ applied=None（不强判）
│   │   └─ applied=None → 只 selections 已打，不归因 completion/fallback（INV#9）
│   ├─ provenance 经 _ctx ContextVar 桥接（awrap_tool_call 无 state）
│   ├─ 无 _applied_ctx（无 injection middleware）→ 降级，after_agent 跳过归因（§6.6）
│   ├─ 无 store/journal → 静默不报错（INV#13）
│   └─ aafter_agent 委托同步
│
├─ _is_success_error(e)                        ← errors 条目是否 success 类（非硬失败）
│   ├─ dict          → e.get("kind") == "success"
│   └─ 其他对象      → getattr(e, "kind", None) == "success"
│
└─ class SkillMetricsMiddleware(AgentMiddleware)
    ├─ __init__(store)                         ← 持有 store（回退用）
    │
    ├─ awrap_tool_call(request, handler)       ← 异步：命中 allowed_tools 标 applied + 写 journal
    │   ├─ tool_name = request.tool_call["name"]
    │   ├─ active_list = _active_skills_ctx.get()
    │   ├─ applied_map = _applied_ctx.get()
    │   ├─ [for (sid, allowed_tools)] 命中 tool_name → applied_map[sid]=True + journal
    │   ├─ _applied_ctx.set(applied_map)
    │   └─ return await handler(request)
    │
    ├─ after_agent(state, runtime)             ← 同步：判 task_completed + 逐 skill record_outcome
    │   ├─ store = runtime.skill_store or self._store
    │   ├─ run_id = runtime.run_id
    │   ├─ active_ids = state.metadata.active_skills
    │   ├─ applied_map = _applied_ctx.get()
    │   ├─ task_completed = _judge_task_completed(state)
    │   └─ [for sid in active_ids] record_outcome(sid, run_id, applied, task_completed)
    │       ├─ rec = store.get(sid)
    │       ├─ applied = applied_map.get(sid)
    │       └─ tool-skill 未命中 → applied=False
    │
    ├─ aafter_agent(state, runtime)            ← 异步：直接转调同步版
    │
    └─ _judge_task_completed(state)  [static]  ← run 级完成判定（近似代理信号，INV#8）
        ├─ hard_failures = errors 中非 success 类
        ├─ 有 final_report（run 模式）→ 无硬失败即 True
        └─ 无 final_report（chat 模式）→ 无硬失败即 True（宽松）
```

### 0.2. 运行时调用树（按执行阶段分：工具命中 → 应用打点；run 结束 → 结果归因）

```
【阶段 A：工具调用时】

agent 调用工具
│
└─ SkillMetricsMiddleware.awrap_tool_call(request, handler)
    ├─ tool_name = request.tool_call["name"]
    ├─ active_list = _active_skills_ctx.get()      ← SkillInjectionMiddleware 写入
    ├─ applied_map = _applied_ctx.get()            ← SkillInjectionMiddleware 写入
    │
    ├─ if active_list and applied_map is not None and tool_name:
    │   ├─ journal = runtime.journal（可为 None）
    │   ├─ for sid, allowed_tools in active_list:
    │   │   └─ if tool_name in allowed_tools:
    │   │       ├─ applied_map[sid] = True                    ← 标 applied
    │   │       └─ journal.append("skill.apply", {...})       ← try/except
    │   └─ _applied_ctx.set(applied_map)                      ← 写回 ContextVar
    │
    └─ return await handler(request)                          ← 不改请求/结果，仅打点

【阶段 B：run 结束时】

LangGraph 进入 after_agent 阶段
│
└─ SkillMetricsMiddleware.after_agent(state, runtime)
    ├─ store = runtime.skill_store or self._store
    │   └─ if store is None: return None                      ← 短路：无法归因
    ├─ run_id = runtime.run_id
    ├─ active_ids = state.metadata.active_skills
    │   └─ if not active_ids: return None                     ← 短路：无 active skill
    ├─ applied_map = _applied_ctx.get()
    ├─ task_completed = _judge_task_completed(state)
    │   ├─ hard_failures = [e for e in errors if not _is_success_error(e)]
    │   └─ return len(hard_failures) == 0
    │
    └─ for sid in active_ids:
        ├─ rec = store.get(sid)                               ← try/except
        ├─ applied = applied_map.get(sid) if applied_map else None
        ├─ if rec and rec.allowed_tools and applied is None:
        │     applied = False                                 ← tool-skill 未命中
        └─ store.record_outcome(sid, run_id, applied, task_completed)  ← try/except
```

### 0.3. 与上下游的衔接（本文件之外，仅示意）

```
SkillInjectionMiddleware.before_model（上游）
│
├─ 写 _active_skills_ctx  ← [(skill_id, allowed_tools), ...]
├─ 写 _applied_ctx        ← {skill_id: None}
└─ 写 state.metadata      ← active_skills / skill_applied
      │
      ▼
SkillMetricsMiddleware（本文件）
│
├─ awrap_tool_call：命中 allowed_tools → _applied_ctx[sid] = True
│                                        + journal "skill.apply"
│
└─ after_agent：读 metadata.active_skills + _applied_ctx
               → 判 task_completed
               → 逐 skill record_outcome(applied, task_completed)
      │
      ▼
最终语义：
  选中/注入 = metadata.active_skills
  应用     = _applied_ctx 中标 True 的子集
  未用     = tool-skill 有 allowed_tools 但未命中 → False
  不强判   = guidance-skill（无 allowed_tools）→ None
```
