---

name: LLMMutator — LLM 推理变异（FIX 编辑 + CAPTURED 生成）。

description: 

【整体职责】
evolution 闭环的第三环：把 EvolutionContext 变成 candidate（新 skill 记录）+ diff。
- FIX      ：LLM 编辑现有 SKILL.md 的 body（保留 frontmatter）。
- CAPTURED ：LLM 生成全新 SKILL.md。
产出的 candidate 一律 is_active=False（champion 隔离），写 staging 路径。

约束（防"凭感觉自由改"）：
- budget：单次最多改 max_changed_lines 行（超则截断，partial apply 前 N 改动）。
- 单维度：LLM prompt 指示一次只改一个 section。
- 保留 frontmatter：不改 name / allowed-tools（FIX 重新附加原 frontmatter）。
- diff 输出：difflib.unified_diff，返 (candidate, diff)。
- max_steps：迭代上限（调用方 EvolutionManager 控制，本类单次 mutate）。

设计约束：
- 进化逻辑唯一 LLM 推理（RL / 计算式不适用，37.md D-L2-3）。
- LLM 可自主调既有 web_search 工具。
- candidate is_active=False（champion 隔离），写 staging 路径
  （.poirot/skills_staging/）。

【内容摘要】
模块常量：
- _STAGING_ROOT : staging 根目录（.poirot/skills_staging）。

类方法：
- __init__(max_changed_lines, max_steps, llm)     : 保存约束与 llm。
- mutate(ctx, llm) -> (SkillRecord, str)          : 对外主入口，按 type 分发。
- _mutate_fix(ctx, llm) -> (candidate, diff)      : FIX 路径。
- _mutate_capture(ctx, llm) -> (candidate, diff)  : CAPTURED 路径。
- _llm_edit_body(body, ctx, llm) -> str           : LLM 编辑 body。
- _llm_generate_skill(ctx, llm) -> str            : LLM 生成完整 SKILL.md。
- _enforce_budget(orig, new, budget) -> str       : budget 截断（partial apply）。
- _split_frontmatter(content) -> (fm, body)       : 切分 frontmatter / body。
- _extract_frontmatter_name(fm) -> str | None     : 从 frontmatter 取 name。
- _extract_frontmatter_desc(fm) -> str            : 从 frontmatter 取 description。
- _compute_diff(orig, new) -> str                 : unified_diff。
- _staging_path(name) -> Path                     : 生成 staging 文件路径。

【职责边界】
- 只负责：产 candidate + diff（写 staging），不做评估、门控、晋升、持久化。
- 不负责：触发（triggers）、聚焦（focuser）、评估（eval_bridge）、门控（gate）、
  落库（store）、编排（EvolutionManager）。
- 不决定是否晋升：只产 candidate，是否 accept 由 gate 决定。
- 不改 frontmatter：FIX 保留原 frontmatter；CAPTURED 由 LLM 生成但校验 name 合法性。
- 不直接写 version DAG：create_version 由 EvolutionManager 在 accept 时调。

## 0. 结构树

### 0.1. 静态结构树

```
skill/evolution/mutators/llm_mutator.py — LLMMutator（LLM 推理变异）
│
├─ 模块常量
│   └─ _STAGING_ROOT = Path(".poirot/skills_staging")    ← staging 根目录
│
└─ class LLMMutator
    ├─ __init__(max_changed_lines=20, max_steps=5, llm=None)  ← 保存约束 + llm
    │
    ├─ mutate(ctx, llm=None) -> (SkillRecord, str)            ← 【对外主入口】按 type 分发
    │   ├─ FIX      → _mutate_fix(ctx, llm)
    │   ├─ CAPTURED → _mutate_capture(ctx, llm)
    │   └─ 其他     → raise ValueError
    │
    ├─ _mutate_fix(ctx, llm) -> (candidate, diff)             ← 【FIX 路径】
    │   ├─ 读原文件 → _split_frontmatter → (frontmatter, body)
    │   ├─ _llm_edit_body(body, ctx, llm)                     ← LLM 编辑 body
    │   ├─ _enforce_budget(body, new_body, max_changed_lines) ← budget 截断
    │   ├─ _compute_diff(body, new_body)
    │   ├─ frontmatter + new_body → 写 staging
    │   └─ candidate(lineage: origin="FIXED", generation+1, parent=baseline)
    │
    ├─ _mutate_capture(ctx, llm) -> (candidate, diff)         ← 【CAPTURED 路径】
    │   ├─ _llm_generate_skill(ctx, llm)                      ← LLM 生成全文
    │   ├─ _split_frontmatter → _extract_frontmatter_name
    │   ├─ 校验 name（[a-z0-9-]+，否则 ValueError）
    │   ├─ 写 staging
    │   └─ candidate(lineage: origin="CAPTURED", generation=0, parent=())
    │
    ├─ _llm_edit_body(body, ctx, llm) -> str                  ← 【LLM 编辑】单维度 + budget 指令
    │   ├─ llm None → 返原 body
    │   ├─ prompt（fix_direction + body + 约束）
    │   ├─ llm.invoke([HumanMessage])
    │   └─ 异常 → 返原 body（不变异）
    │
    ├─ _llm_generate_skill(ctx, llm) -> str                   ← 【LLM 生成】CAPTURED 全文
    │   ├─ llm None → raise ValueError
    │   ├─ prompt（capture_pattern + suggested_name）
    │   └─ llm.invoke([HumanMessage])
    │
    ├─ _enforce_budget(orig, new, budget) -> str              ← 【budget 截断】
    │   ├─ SequenceMatcher opcodes → 统计改动行数
    │   ├─ changed <= budget → 返 new
    │   └─ 超出 → partial apply 前 N 改动，剩余回退原
    │
    ├─ _split_frontmatter(content) -> (fm, body)              ← 【切分】
    ├─ _extract_frontmatter_name(fm) -> str | None            ← 【提取】name
    ├─ _extract_frontmatter_desc(fm) -> str                   ← 【提取】description
    ├─ _compute_diff(orig, new) -> str                        ← 【diff】unified_diff
    └─ _staging_path(name) -> Path                            ← 【路径】staging/SKILL.md
```

### 0.2. 运行时调用树

```
① 装配期（bootstrap）
    LLMMutator(max_changed_lines, max_steps, llm)
        └─ 注入 EvolutionManager(mutator=...)

② run_cycle / evolve_skill / capture_skill → _run_evolution
    EvolutionManager._run_evolution(ctx)
        └─ mutator.mutate(ctx, llm)                     ← 本模块主入口
              ├─ FIX → _mutate_fix
              │     ├─ Path(baseline.path).read_text
              │     ├─ _split_frontmatter
              │     ├─ _llm_edit_body → llm.invoke
              │     ├─ _enforce_budget（超 max_changed_lines 截断）
              │     ├─ _compute_diff
              │     ├─ staging_path.write_text
              │     └─ return candidate(is_active=False)
              └─ CAPTURED → _mutate_capture
                    ├─ _llm_generate_skill → llm.invoke
                    ├─ _split_frontmatter + _extract_frontmatter_name
                    ├─ name 校验
                    ├─ staging_path.write_text
                    └─ return candidate(is_active=False)
        └─ 产出的 candidate 交给 eval_bridge.evaluate / gate.decide
```

## 1. 补充

- **两条路径的分岔**：`mutate` 按 `ctx.evolution_type` 分发；FIX 编辑现有 skill 的 body，CAPTURED 生成全新 SKILL.md。
- **candidate 的 lineage 差异**：
  - FIX：`parent_skill_ids=(baseline.skill_id,)`，`generation=baseline+1`，`origin="FIXED"`。
  - CAPTURED：`parent_skill_ids=()`，`generation=0`，`origin="CAPTURED"`。
- **candidate 隔离**：一律 `is_active=False`，写 staging 路径（`.poirot/skills_staging/`），不直接进 version DAG。
- **budget 机制**：`_enforce_budget` 用 `SequenceMatcher` 统计改动行数；超 `max_changed_lines` 时 partial apply 前 N 改动，剩余回退原 body——防"凭感觉自由改"。
- **失败降级不对称**：
  - FIX：LLM 失败 → 返原 body（不变异，不抛）。
  - CAPTURED：必须有 LLM，`llm=None` 直接 `raise ValueError`。
- **frontmatter 保护**：FIX 重新附加原 frontmatter（不改 name / allowed-tools）；CAPTURED 从生成内容里提取 name 并校验 `[a-z0-9-]+`。
