---

name: ContractCompiler — 从 skill 文本自动编译 contract 规则（AutoSkill EvalCompiler 模型）。

description: 

【整体职责】
响应层 eval 的"规则编译器"：读取 skill 文本，自动决定要跑哪些 contract 规则，
产出一份 list[ContractRule] 供 ResponseContractChecker 执行。
- 外部 skill 零改造：不要求 frontmatter 声明，扫描 skill 自身文本关键词即可。
- 替代 L2a 的固定 7 mode：规则按 skill 内容动态编译。

【内容摘要】
模块常量：
- _RE_PARAGRAPH_LIMIT : 段落数限制的提取正则（中英文表达 + 数字 + 单位）。

类方法：
- compile(skill_content)      : 编译规则清单（对外主入口）。
- _mentions_sources(corpus)   : 文本是否提到"引用来源"。
- _mentions_conclusion_first(corpus) : 文本是否提到"先给结论"。
- _paragraph_limit(corpus)    : 文本是否声明段落数限制，返回上限值（0 表示未声明）。

【职责边界】
- 只负责：从 skill 文本编译出规则清单（哪些规则要跑）。
- 不负责：规则检查（checks.py）、打分与汇总（ResponseContractChecker）、
  LLM 评估（analyzer / judge）、持久化（store）。
- 不做检查：只产 ContractRule，不执行。

## 0. 结构树

### 0.1. 静态结构树

```
eval/analyzers/contract_compiler.py — 从 skill 文本编译 contract 规则
│
├─ 模块常量
│   └─ _RE_PARAGRAPH_LIMIT   ← 段落数限制提取正则（中英表达 + 数字 + 单位）
│
└─ class ContractCompiler
    ├─ compile(skill_content) -> list[ContractRule]      ← 【对外主入口】
    │   ├─ 始终加硬规则：nonempty / json_parseable（hard=True）
    │   ├─ corpus = skill_content.lower()
    │   ├─ _mentions_sources → 加 must_cite（hard=False）
    │   ├─ _mentions_conclusion_first → 加 lead_with_conclusion（hard=False）
    │   ├─ _paragraph_limit > 0 → 加 paragraph_limit（hard=False，params.max）
    │   └─ 始终加 soft 规则：no_unfounded_claims / semantic_density（hard=False）
    │
    ├─ _mentions_sources(corpus) -> bool           ← 【关键词】文本是否提到"引用来源"
    ├─ _mentions_conclusion_first(corpus) -> bool  ← 【关键词】文本是否提到"先给结论"
    └─ _paragraph_limit(corpus) -> int             ← 【提取】段落数上限；未声明返 0
```

---

### 0.2. 运行时调用树

```
① 装配期（bootstrap）
    build_default_registry()
        └─ ContractCompiler()
              └─ ResponseContractChecker(compiler)
                    └─ EvalRegistry(checker)
                          └─ RegistryEvalBridge → 注入 L2

② 候选晋升前 —— 响应层（同步）
    L2 → RegistryEvalBridge.evaluate(ctx)
            └─ ResponseContractChecker.check(candidate, baseline)
                  ├─ compiler.compile(candidate_content)   ← 本模块主入口
                  │     ├─ 硬规则：nonempty / json_parseable
                  │     ├─ contract 规则（按文本关键词）
                  │     │     ├─ _mentions_sources → must_cite
                  │     │     ├─ _mentions_conclusion_first → lead_with_conclusion
                  │     │     └─ _paragraph_limit > 0 → paragraph_limit
                  │     └─ soft 规则：no_unfounded_claims / semantic_density
                  ├─ for rule: _run_rule → checks.check_*(...)
                  └─ EvalResult → L2
```

## 1. 补充

- **只编译、不检查**：`compile` 只产出 `list[ContractRule]`；真正执行在 `ResponseContractChecker` + `checks.py`。
- **三层规则**：
  - 硬规则（始终跑，hard=True）：`nonempty` / `json_parseable`
  - contract 规则（文本命中才跑，hard=False）：`must_cite` / `lead_with_conclusion` / `paragraph_limit`
  - soft 规则（始终跑，hard=False）：`no_unfounded_claims` / `semantic_density`
- **零改造**：不读 frontmatter 声明，只扫 skill 文本关键词决定编译哪些规则（D-L3-4）。
- **输出顺序固定**：硬 → contract → soft，`ResponseContractChecker` 按此顺序执行。
