---

name: Skill eval 确定性检查函数 — 纯函数，无类，无循环依赖。

description: 

【整体职责】
提供 eval 层的所有"确定性检查"能力（纯函数），是检查逻辑的单一真相源。
被 ResponseContractChecker 与 ProgrammaticEvalBridge（facade）共同复用；
check 逻辑只在本模块定义，其他模块不重复实现。

【内容摘要】
模块常量：
- HARD_MODES        : 硬失败模式（触发即 reject 倾向）：nonempty / json_parseable。
- DIRECTIVE_WORDS   : 指令性词（用于 semantic_density 计算）。
- UNFOUNDED_WORDS   : 无据绝对化词（用于 no_unfounded_claims）。
- CONCLUSION_WORDS  : 结论词（用于 lead_with_conclusion）。
- CITE_PATTERN      : 引用标记正则（URL / @mention / 来源词）。
- YAML_FRONTMATTER  : frontmatter 正则（---\\n{yaml}\\n---\\n）。
- PARAGRAPH_LIMIT   : 段落数上限（默认 20）。
- SEMANTIC_DENSITY_MIN / MAX : 指令性词密度的合理区间。

纯函数：
- read_content(record)             : 读 SKILL.md 全文；失败返 ""。
- split_body(content)              : 去 frontmatter，返 body。
- check_nonempty(content)          : body 非空。
- check_json_parseable(content)    : frontmatter YAML 可解析（无 frontmatter 也算 pass）。
- check_must_cite(content)         : 含引用标记。
- check_paragraph_limit(content)   : 段落数 <= 上限。
- check_lead_with_conclusion(content): 前 3 段含结论词。
- check_no_unfounded_claims(content): 无绝对化无据词。
- semantic_density(content)        : 指令性词密度（供区间判定）。

【职责边界】
- 只负责：确定性检查 + 文本读取与切分。
- 不负责：规则编译（contract_compiler）、规则分发与打分（response_contract_checker）、
  LLM 评估（analyzer / judge）、持久化（store）。
- 无状态、无类、无副作用（除读文件）。

## 0. 结构树

### 0.1. 静态结构树（含用途 / 层级 / 判定条件标注）

```
eval/analyzers/checks.py — eval 确定性检查函数库（纯函数，单一真相源）
│
├─ 模块常量
│   ├─ HARD_MODES = ("nonempty", "json_parseable")   ← 硬失败模式（触发即 reject 倾向）
│   ├─ DIRECTIVE_WORDS                               ← 指令性词表（semantic_density 用）
│   ├─ UNFOUNDED_WORDS                               ← 绝对化无据词表（no_unfounded_claims 用）
│   ├─ CONCLUSION_WORDS                              ← 结论词表（lead_with_conclusion 用）
│   ├─ CITE_PATTERN                                  ← 引用标记正则（must_cite 用）
│   ├─ YAML_FRONTMATTER                              ← frontmatter 正则（多处复用）
│   ├─ PARAGRAPH_LIMIT = 20                          ← 段落数上限
│   └─ SEMANTIC_DENSITY_MIN / MAX = 0.005 / 0.15     ← 指令密度合理区间
│
├─ read_content(record) -> str                       ← 【IO】读 SKILL.md 全文；失败返 ""
│
├─ split_body(content) -> str                        ← 【切分】去 frontmatter 返 body；被 3 个 check 复用
│
├─ check_nonempty(content) -> bool                   ← 【硬规则】body 非空 → True
│
├─ check_json_parseable(content) -> bool             ← 【硬规则】frontmatter YAML 可解析；
│                                                       无 frontmatter 也算 pass
│
├─ check_must_cite(content) -> bool                  ← 【contract】含引用标记（URL/@mention/来源词）
│
├─ check_paragraph_limit(content) -> bool            ← 【contract】段落数 ≤ 20（空行分隔，空段不计）
│
├─ check_lead_with_conclusion(content) -> bool       ← 【contract】前 3 段含结论词（大小写不敏感）
│
├─ check_no_unfounded_claims(content) -> bool        ← 【soft】无绝对化无据词
│
└─ semantic_density(content) -> float                ← 【soft】指令词数 / 总词数；
                                                        空串/无词 → 0.0
```

### 0.2. 运行时调用树（谁调它、它调谁）

```
① 响应层（ResponseContractChecker._run_rule 按 rule_id 分发）
    _run_rule(rule_id, content, params)
        ├─ "nonempty"             → check_nonempty(content)
        ├─ "json_parseable"       → check_json_parseable(content)
        ├─ "must_cite"            → check_must_cite(content)
        ├─ "lead_with_conclusion" → check_lead_with_conclusion(content)
        ├─ "paragraph_limit"      → check_paragraph_limit(content)
        ├─ "no_unfounded_claims"  → check_no_unfounded_claims(content)
        ├─ "semantic_density"     → semantic_density(content) → 区间判定
        └─ 未知 rule_id            → True（默认 pass）

② RegistryEvalBridge.evaluate
    ├─ read_content(ctx.candidate)         ← 读候选文件
    └─ read_content(ctx.baseline)          ← 读基线文件（无则 ""）

③ 模块内复用关系
    split_body ──被调用──► check_nonempty
                        check_paragraph_limit
                        check_lead_with_conclusion
    YAML_FRONTMATTER ──被使用──► split_body
                                 check_json_parseable
    DIRECTIVE_WORDS ──被使用──► semantic_density
    UNFOUNDED_WORDS ──被使用──► check_no_unfounded_claims
    CONCLUSION_WORDS ──被使用──► check_lead_with_conclusion
    CITE_PATTERN ──被使用──► check_must_cite
    PARAGRAPH_LIMIT ──被使用──► check_paragraph_limit
    SEMANTIC_DENSITY_MIN/MAX ──被使用──► ResponseContractChecker._run_rule
                                          （checks 只返 density 值，区间判定在调用方）
```
