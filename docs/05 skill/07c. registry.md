---

name: EvalRegistry + RegistryEvalBridge — L2 唯一看见的 L3 实现。

description: 

【整体职责】
向 L2（evolution）暴露 L3 评估层的唯一入口。
- EvalRegistry        ：实例级注册表，持有评估组件（当前是 contract checker）。
- RegistryEvalBridge  ：实现 L2 的 EvalBridge Protocol，内部调 ResponseContractChecker。
- build_default_registry：默认装配工厂（bootstrap 用）。

设计约束：
- D-L3-2：EvalBridge Protocol 是 L2 已有约定；RegistryEvalBridge 替换旧的
  ProgrammaticEvalBridge，L2 不感知 L3 内部变化。
- D-L3-8：fail-closed —— registry 为空 / checker 抛异常 → 返回 reject 的
  EvalResult，绝不"裸跑"（D8 安全原则）。
- 注册是实例级（不做 class-level 全局注册），由 bootstrap 装配。

【内容摘要】
- EvalRegistry              : 实例级注册表，持有 ResponseContractChecker。
    - __init__(contract_checker)
    - get_contract_checker() -> ResponseContractChecker
- RegistryEvalBridge        : L2 唯一可见的 L3 实现（EvalBridge Protocol）。
    - __init__(registry)
    - evaluate(ctx) -> EvalResult    : 主入口；异常 fail-closed reject。
- build_default_registry()  : 装配默认 registry（ContractCompiler + Checker）。

【职责边界】
- 只负责：向 L2 暴露评估入口、分发到 contract checker、异常 fail-closed。
- 不负责：具体规则编译（ContractCompiler）、规则检查逻辑（ResponseContractChecker）、
  其他层评估（judgment / task judge / tracker 不由本桥调用）。
- 不做全局状态：registry 为实例级，避免 class-level 全局注册。
- L2 不需要知道 L3 的实现类：只通过 EvalBridge Protocol 调 evaluate。

## 0. 结构树

### 0.1. 静态结构树（含用途标注）

```
eval/registry.py — EvalRegistry + RegistryEvalBridge（L2 唯一看见的 L3 实现）
│
├─ class EvalRegistry                                 ← 【注册表】实例级，bootstrap 装配
│   ├─ __init__(contract_checker)                     ← 保存唯一注册组件
│   │     └─ self._contract_checker: ResponseContractChecker
│   └─ get_contract_checker() -> ResponseContractChecker   ← 供 Bridge 取用
│
├─ class RegistryEvalBridge                           ← 【L2↔L3 桥】实现 EvalBridge Protocol
│   ├─ __init__(registry)                             ← 保存 registry
│   │     └─ self._registry: EvalRegistry
│   └─ evaluate(ctx: EvalContext) -> EvalResult       ← 主入口
│         ├─ 取 checker（registry.get_contract_checker）
│         ├─ 读 candidate 内容（checks.read_content）
│         ├─ 读 baseline 内容（无则空串）
│         ├─ checker.check(candidate, baseline) → EvalResult
│         └─ except → fail-closed reject
│               └─ EvalResult(score=0.0, metric="hard",
│                            hard_failures=("eval_exception",),
│                            confidence=0.0, recommendation="reject")
│
└─ build_default_registry() -> EvalRegistry           ← 【工厂】默认装配
      └─ ResponseContractChecker(ContractCompiler()) → EvalRegistry(...)
```

---

### 0.2. 运行时调用树（在进化流程的哪一步）

```
① 装配期（bootstrap，一次性）
    build_default_registry()
        ├─ ContractCompiler()
        ├─ ResponseContractChecker(compiler)
        └─ EvalRegistry(checker)
              │
              ▼
    RegistryEvalBridge(registry)
        └─ 作为 EvalBridge 注入 L2（替换 ProgrammaticEvalBridge，D-L3-2）

② 候选晋升前（L2 调 L3 的唯一入口）
    L2 ScoreDeltaGate
        └─ RegistryEvalBridge.evaluate(ctx)
              ├─ registry.get_contract_checker()
              ├─ checks.read_content(ctx.candidate)
              ├─ checks.read_content(ctx.baseline)（无 baseline → ""）
              └─ checker.check(candidate, baseline)
                    └─ EvalResult → 回到 L2（score / recommendation）

③ 异常路径（fail-closed，D-L3-8 / D8）
    任何异常（registry 空、文件读失败、checker 抛错）
        └─ return EvalResult(recommendation="reject")
              └─ L2 据此拒绝晋升，绝不"裸跑"
```

### 0.3. 三个组件的角色与关系

| 组件 | 角色 | 谁构造 | 谁调用 |
|------|------|--------|--------|
| `EvalRegistry` | 实例级注册表，持有 checker | `build_default_registry` | `RegistryEvalBridge` |
| `RegistryEvalBridge` | L2 唯一可见的 L3 实现（EvalBridge） | bootstrap | L2 ScoreDeltaGate |
| `build_default_registry` | 默认装配工厂 | bootstrap | bootstrap |

**关系图：**

```
build_default_registry()
        │
        ├─ ContractCompiler
        ├─ ResponseContractChecker(compiler)
        └─ EvalRegistry(checker)
                │
                ▼
        RegistryEvalBridge(registry)
                │
                │ 实现 EvalBridge Protocol
                ▼
        L2 ScoreDeltaGate ── evaluate(ctx) ──► EvalResult
```

### 0.4. 与相邻模块的对应关系

| `evolution/`（L2） | **调用方**：通过 EvalBridge Protocol 调 `evaluate`。 |

### 0.5. 总结

```
eval/registry.py
   ├─ EvalRegistry         ← 实例级注册表（当前只注册 contract checker）
   ├─ RegistryEvalBridge   ← L2 唯一可见的 L3 实现（EvalBridge Protocol）
   └─ build_default_registry ← 默认装配工厂
```

**本模块 = L2 与 L3 之间的唯一桥梁**：向上实现 `EvalBridge` Protocol（L2 零改动），向下分发到 `ResponseContractChecker`；任何异常都 fail-closed 返回 reject。
