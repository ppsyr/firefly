### 0.2. 运行时调用树（搜索 + 安装 + 卸载）

```
① 装配期（bootstrap，一次性）
    ├─ BuiltinSource(skill_manager)
    ├─ GitHubSource()
    ├─ ClaudeMarketplaceSource(registry_url)
    ├─ WellKnownSource(endpoints)
    ├─ HubLockFile() / SkillsGuard() / AuditLog()
    └─ Installer(sources={"builtin": ..., "github": ..., ...},
                  lock_file, guard, audit_log, dest_root)
          └─ 挂到 CLI / Agent 工具

        ═══════════ 运行期 ═══════════

② 搜索（CLI / TUI / Agent 工具）
    unified_search(query, sources, limit)
        ├─ sources 空 → 降级 [BuiltinSource()]
        ├─ for source in sources:
        │     ├─ source.search(query, limit)
        │     │     ├─ BuiltinSource  → SkillManager.search_builtin_skills
        │     │     ├─ GitHubSource   → []
        │     │     ├─ ClaudeMarketplaceSource → registry
        │     │     └─ WellKnownSource → 多 endpoint
        │     ├─ 按 name 去重
        │     └─ source 异常 → warning + 跳过
        ├─ 排序 (not is_installed, name)
        └─ limit 截断

③ 安装（CLI / Agent 工具）
    installer.install(identifier, name=None)
        ├─ 1. _resolve_source(identifier)
        ├─ 2. name None → _derive_name(identifier)
        ├─ 3. source.fetch(identifier, dest_dir)
        ├─ 4. guard.scan(skill_dir, source.name, identifier)
        │     ├─ 无 SKILL.md → allowed
        │     ├─ _is_trusted → allowed
        │     ├─ 模式匹配 → reasons
        │     └─ 命中 → _quarantine + allowed=False → ValueError
        ├─ 5. parser.install(skill_dir, name, dest_root) → skill_id
        ├─ 6. _compute_hash(skill_dir)
        ├─ 7. lock_file.add(HubLockEntry)
        └─ 8. audit_log.append("install", ...)

④ 卸载（CLI / Agent 工具）
    installer.uninstall(name)
        ├─ lock_file.get(name)
        ├─ shutil.rmtree(install_path)
        ├─ lock_file.remove(name)
        └─ audit_log.append("uninstall", ...)

⑤ 更新（MVP 占位）
    installer.update(name) → []
```

### 0.3. 与相邻模块的接口

```
hub → parser / store：
    installer.install → parser.install → store.register

hub → config：
    hub_enabled / hub_quarantine_enabled / hub_audit_log

hub ← CLI / agent_tools：
    /skill search  → unified_search
    /skill install → installer.install
    /skill list    → hub_lock.list_installed
    skill_search 工具 → unified_search

hub 文件落点：
    ~/.poirot/skills/                    （安装目标根）
    ~/.poirot/skills/.hub/lock.json      （provenance）
    ~/.poirot/skills/.hub/audit.log      （审计）
    ~/.poirot/skills/.hub/quarantine/    （隔离区）
```

- **它是 skill 的输入侧**：负责"技能从哪来、怎么找、怎么装"，不参与运行期的选择 / 注入 / 打点 / 评估 / 进化。
- **四源能力差异**：只有 `BuiltinSource` 三方法全可用；`GitHubSource` 能装不能搜；`ClaudeMarketplaceSource` / `WellKnownSource` 能搜不能装（fetch 是 MVP 占位）。
- **`sources` 字典的 key 是 identifier 前缀**：`Installer._resolve_source` 靠它分发到对应源。
- **`SkillsGuard` 是 install 的守门人**：正则匹配三类风险 + `TRUSTED_REPOS` 白名单；命中则进 quarantine 并拒装。
- **两条留痕路径**：`HubLockFile`（provenance，用于 update 检查）+ `AuditLog`（每次操作一条 JSON）。
- **降级原则**：搜索层 silent（尽量给结果）；安装层抛 `ValueError`（让用户知道）；文件层容错（读写不抛）。
- **MVP 边界**：`GitHubSource.search`、`ClaudeMarketplaceSource.fetch`、`WellKnownSource.fetch`、`Installer.update` 均为占位，留待后续实现。

## 3. 几种源怎么加载

### 3.1. 源的统一接口（`SkillSource` Protocol）

```python
class SkillSource(Protocol):
    name: str
    def search(query, limit) -> list[SkillMeta]: ...
    def fetch(identifier, dest_dir) -> Path: ...
    def preview(identifier) -> str | None: ...
```

四个源各自实现；`unified_search` 和 `Installer` 只认接口，不认具体类型。

### 3.2. 四个源的加载与能力

| 源 | 加载方式 | search | fetch | preview |
|----|---------|:---:|:---:|:---:|
| `BuiltinSource` | 零网络；延迟调 `SkillManager.search_builtin_skills` | ✅ | ✅（返本地路径） | ✅ |
| `GitHubSource` | `git clone --depth 1`；`GITHUB_TOKEN` 提权 | ❌ 占位 | ✅ | ❌ 占位 |
| `ClaudeMarketplaceSource` | HTTP GET registry（`httpx`） | ✅ | ❌ 占位 | ❌ 占位 |
| `WellKnownSource` | HTTP GET 多 endpoint 的 `/.well-known/skills/index.json` | ✅ | ❌ 占位 | ❌ 占位 |

**能力差异**：
- **Builtin 全可用**（本地技能，无需下载）。
- **GitHub 能装不能搜**（用户用 identifier 直接 install）。
- **Marketplace / WellKnown 能搜不能装**（fetch 是 MVP 占位）。

### 3.3. 源的注册方式

```
sources = {
    "builtin":             BuiltinSource(skill_manager),
    "github":              GitHubSource(),
    "claude-marketplace":  ClaudeMarketplaceSource(registry_url),
    "well-known":          WellKnownSource(endpoints),
}
```

字典的 **key 是 identifier 前缀**——`Installer._resolve_source` 靠它分发：
- `github:owner/repo@skill` → `GitHubSource`
- `builtin:name` → `BuiltinSource`
- `well-known:https://...@name` → `WellKnownSource`
- `claude-marketplace:name` → `ClaudeMarketplaceSource`

## 5. 调用的内部流程

### 5.1. 搜索流程（`unified_search`）

```
1. sources 为空 → 降级为 [BuiltinSource()]
2. for source in sources:
     ├─ source.search(query, limit)
     ├─ 按 name 去重（先到先得）
     └─ source 异常 → warning + 跳过
3. 排序：(not is_installed, name)  ← 已安装优先
4. limit 截断
```

**要点**：
- **顺序非并行**（设计文档说并行，实现是顺序）。
- **单源容错**：一个源失败不影响其他。
- **去重按 name**，顺序影响结果。

### 5.2. 安装流程（`Installer.install`）

```
1. _resolve_source(identifier)         ← 按前缀找 source
2. name 推导（None → _derive_name）
3. source.fetch(identifier, dest_dir)  ← 下载
4. SkillsGuard.scan(skill_dir, ...)    ← 安全扫描
     └─ allowed=False → ValueError（skill 已隔离）
5. parser.install(skill_dir, name, dest_root)  → skill_id
6. _compute_hash(skill_dir)            → content_hash
7. HubLockFile.add(HubLockEntry)       ← 记 provenance
8. AuditLog.append("install", ...)     ← 留痕
```

**要点**：
- **`SkillsGuard` 在落盘前拦截**：可疑 skill 被移到 quarantine，install 抛 `ValueError`。
- **`HubLockFile` 记录 provenance**：`source` / `identifier` / `install_path` / `content_hash` / `upstream_url`。
- **`AuditLog` 留痕**：每次 install 一条 JSON 记录。

### 5.3. 卸载流程（`Installer.uninstall`）

```
1. HubLockFile.get(name)（无记录 → ValueError）
2. shutil.rmtree(install_path)
3. HubLockFile.remove(name)
4. AuditLog.append("uninstall", ...)
```

### 5.4. 更新流程（`Installer.update`，MVP 占位）

```
1. 对比 upstream_url hash 与本地 content_hash
2. 返有更新的 skill name 列表
当前：恒返 []（未实现）
```

### 5.5. 安全扫描流程（`SkillsGuard.scan`）

```
1. 无 SKILL.md → allowed=True（skip）
2. _is_trusted（TRUSTED_REPOS 或 builtin）→ allowed=True
3. 模式匹配：
     _SENSITIVE_PATTERNS          （rm -rf / / mkfs / dd of=/dev/）
     _PROMPT_INJECTION_PATTERNS   （curl|bash / wget|sh / eval / exec）
     _SUSPICIOUS_URL_PATTERNS     （.exe / .bat / .sh 下载）
4. 命中任一 → _quarantine + allowed=False
5. 无命中 → allowed=True
```

**要点**：
- **正则匹配，非 AST**：可扩展，误报靠 `TRUSTED_REPOS` 白名单缓解。
- **三条短路**：无 SKILL.md / 信任源 / 命中风险。

## 7. 异常与降级

| 组件 | 触发 | 行为 |
|------|------|------|
| `unified_search` | sources 空 | 降级 builtin |
| `unified_search` | 单 source 异常 | warning + 跳过 |
| `BuiltinSource` | `SkillManager` 不可用 | 返 `[]` |
| `GitHubSource.fetch` | identifier 非法 | `ValueError` |
| `GitHubSource.fetch` | git clone 失败 | `CalledProcessError` |
| `ClaudeMarketplaceSource.search` | registry 不可达 | 返 `[]` |
| `WellKnownSource.search` | endpoint 不可达 | 跳过该 endpoint |
| `SkillsGuard.scan` | 命中风险 | quarantine + `allowed=False` |
| `Installer.install` | source 解析失败 | `ValueError` |
| `Installer.install` | SkillsGuard 拒绝 | `ValueError` |
| `Installer.uninstall` | lock 无记录 | `ValueError` |
| `HubLockFile._load` | 文件坏 | 返 `[]` |
| `AuditLog.read` | 坏行 | 跳过 |

**原则**：
- **搜索层**：全 silent，尽量给结果。
- **安装层**：参数错 / 安全拒绝 → `ValueError`（让用户知道）。
- **文件层**：读写容错，不抛。

## 8. 一句话总结

| 层面 | 内容 |
|------|------|
| **初始化** | bootstrap 构造 4 个 source + 三件套 → 打包 `Installer`；挂到 CLI / Agent 工具。 |
| **源加载** | `sources` 字典 key=identifier 前缀；`Installer._resolve_source` 靠前缀分发。 |
| **调用点** | 搜索：`unified_search`；安装/卸载/更新：`Installer`；由 CLI / Agent 工具触发。 |
| **内部流程** | 搜索：聚合 + 去重 + 排序 + 截断；安装：fetch → scan → install → lock → audit。 |
| **安全** | `SkillsGuard` 在落盘前扫（正则 + 白名单），可疑进 quarantine。 |
| **留痕** | `HubLockFile` 记 provenance；`AuditLog` 记每次操作。 |
| **降级** | 搜索层 silent；安装层抛 `ValueError`；文件层容错。 |

**hub 的本质**：它是 skill 的"输入侧"——从外部来源（builtin / GitHub / Marketplace / Well-known）发现与安装技能，通过 `SkillsGuard` 把关安全，通过 `HubLockFile` / `AuditLog` 留痕；装进来的技能交给 parser / store，此后进入 selector / injector / eval / evolution 的运行链路。
