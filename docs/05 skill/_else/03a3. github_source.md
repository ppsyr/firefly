---

name: GitHubSource — git clone owner/repo 安装 skill。

description: 

【整体职责】
hub 的远程技能源之一：通过 git clone 从 GitHub 安装 skill。
- 搜索：MVP 未实现（需 GitHub Search API + token）。
- 获取：git clone --depth 1 owner/repo 到 dest_dir。
- 预览：MVP 未实现（需 GitHub Contents API + token）。
- 缓存：search 结果按 repo URL 缓存 1 小时（hermes 模式）。

设计（design_docs/46 §2.4）：
- git clone --depth 1 owner/repo 到 ~/.poirot/skills/<name>/。
- 支持 GITHUB_TOKEN env var 提升限速。
- cache index 1 小时（hermes 模式）。
- identifier 格式：github:owner/repo@skill-name 或 github:owner/repo。

【内容摘要】
模块常量：
- _search_cache : dict[str, tuple[float, list[SkillMeta]]]，repo URL → (时间戳, 结果)。
- _CACHE_TTL    : 缓存有效期（3600 秒 = 1 小时）。

类方法：
- search(query, limit) -> list[SkillMeta]           : MVP 返空。
- fetch(identifier, dest_dir) -> Path               : git clone + 返回 skill 路径。
- preview(identifier) -> str | None                 : MVP 返 None。
- _parse_identifier(identifier) -> (owner, repo, skill_name) : 解析 identifier。
- _build_clone_url(owner, repo) -> str              : 构造 clone URL（可带 token）。
- _get_cached(repo_url) -> list[SkillMeta] | None   : 读 cache（TTL 1h）。
- _set_cached(repo_url, results)                    : 写 cache。

【职责边界】
- 只负责：git clone 安装 + identifier 解析 + clone URL 构造 + 缓存。
- 不负责：搜索编排（search.py）、安装后处理（installer 负责解析 + 落库）、
  中心存储（hub_store.py）、技能解析（parser）、持久化（store）。
- MVP 未实现 search / preview：search 恒返空，preview 恒返 None。
- 不做 GitHub API 调用：fetch 用 git 命令而非 API。

## 0. 结构树

### 0.1. 静态结构树

```
skill/hub/sources/github_source.py — GitHubSource（git clone owner/repo）
│
├─ 模块常量
│   ├─ _search_cache : dict[str, tuple[float, list[SkillMeta]]]   ← repo URL → (ts, 结果)
│   └─ _CACHE_TTL    = 3600                                        ← 缓存有效期 1 小时
│
└─ class GitHubSource
    ├─ name = "github"                                ← 源标识（类属性）
    │
    ├─ search(query, limit=10) -> list[SkillMeta]     ← 【MVP 占位】恒返空
    │
    ├─ fetch(identifier, dest_dir) -> Path            ← 【对外主入口】git clone
    │   ├─ _parse_identifier(identifier) → (owner, repo, skill_name)
    │   ├─ _build_clone_url(owner, repo)              ← 可带 GITHUB_TOKEN
    │   ├─ dest_dir.mkdir(parents=True, exist_ok=True)
    │   ├─ subprocess.run(["git", "clone", "--depth", "1", url, dest_dir],
    │   │                  capture_output=True, text=True, check=True)
    │   ├─ skill_name 且 dest_dir/skill_name 存在 → 返子目录
    │   └─ 否则 → 返 dest_dir
    │
    ├─ preview(identifier) -> str | None              ← 【MVP 占位】恒返 None
    │
    ├─ _parse_identifier(identifier)                  ← 【解析】identifier → (owner, repo, skill_name)
    │   -> tuple[str, str, str | None]
    │   ├─ 去 "github:" 前缀（若有）
    │   ├─ "@" 存在 → rsplit("@", 1) 分离 skill_name
    │   ├─ "/" 分割 → owner / repo（少于 2 段 → ValueError）
    │   └─ 支持 4 种格式
    │
    ├─ _build_clone_url(owner, repo) -> str           ← 【构造 URL】
    │   ├─ GITHUB_TOKEN 存在 → https://<token>@github.com/owner/repo.git
    │   └─ 否则 → https://github.com/owner/repo.git
    │
    ├─ _get_cached(repo_url) -> list[SkillMeta] | None ← 【读缓存】TTL 1h
    │
    └─ _set_cached(repo_url, results)                  ← 【写缓存】
```

### 0.2. 运行时调用树

```
① 装配期（bootstrap）
    GitHubSource()
        └─ 注册到 hub 的 sources 列表

② 搜索（search.py 编排）
    search(query, limit)
        └─ for source in sources:
              └─ GitHubSource.search(query, limit)      ← MVP 返空
                    （进阶：GitHub Search API）

③ 安装（installer.py 编排）
    installer.install(meta)
        └─ GitHubSource.fetch(identifier, dest_dir)    ← 本模块主入口
              ├─ _parse_identifier
              │     ├─ 去前缀 → 分离 @skill → 分 owner/repo
              │     └─ 非法 → ValueError
              ├─ _build_clone_url（可带 GITHUB_TOKEN）
              ├─ subprocess.run(["git", "clone", "--depth", "1", ...])
              ├─ skill_name 存在且子目录存在 → 返子目录
              └─ 否则 → 返 dest_dir
        ├─ parser.parse_skill_file(SKILL.md)
        └─ store.register(SkillRecord)                  → skills.db

④ 预览（CLI / TUI 按需）
    GitHubSource.preview(identifier)                    ← MVP 恒返 None

⑤ 缓存（供未来 search 用）
    _get_cached(repo_url) / _set_cached(repo_url, results)
        （当前 search 未实现，缓存读写尚无调用方）
```

## 1. 补充

- **`fetch` 是真正可用的**：`git clone --depth 1` 已实现，支持 `GITHUB_TOKEN` 提权；`search` / `preview` 才是 MVP 占位。
- **identifier 兼容四种格式**：
  - `github:owner/repo`
  - `github:owner/repo@skill-name`
  - `owner/repo`
  - `owner/repo@skill-name`
- **返回路径的两分支**：带 `@skill-name` 且子目录存在 → 返子目录；否则返整个 `dest_dir`。
- **Token 处理方式**：直接拼进 clone URL（`https://<token>@github.com/...`），依赖 git 自身认证。
- **缓存目前是"待用"状态**：`_get_cached` / `_set_cached` 已实现，但 `search` 未实现，所以**暂时没有调用方**——为将来接入 GitHub Search API 预留。
- **与 `BuiltinSource` / `ClaudeMarketplaceSource` 的对比**：
  - Builtin：零网络，`fetch` 返本地路径。
  - ClaudeMarketplace：网络源，`search` 可用、`fetch` 占位。
  - GitHub：网络源，`fetch` 可用、`search` / `preview` 占位。
- **错误处理**：identifier 非法 → `ValueError`；`git clone` 失败 → `subprocess.CalledProcessError`（`check=True`）——这两个会向上抛，由 installer / CLI 决定如何提示用户。
