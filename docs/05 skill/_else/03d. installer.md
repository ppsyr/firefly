---

name: Installer — install/uninstall/update 编排。

description: 

【整体职责】
hub 的安装编排器：把"下载 → 安全扫描 → 落盘注册 → 记录 provenance → 审计"
串成一条流程，并负责反向的 uninstall 与未来的 update。
- install   : source.fetch → SkillsGuard.scan → parser.install
              → HubLockFile.add → AuditLog.append。
- uninstall : HubLockFile.get → 删目录 → HubLockFile.remove → AuditLog.append。
- update    : 对比 upstream hash 与本地 content_hash（MVP 占位）。

设计（design_docs/46 §2.6）：
- source.fetch → SkillsGuard.scan → parser.install → HubLockFile.add → AuditLog.append。
- uninstall 反向流程。
- update 对比 upstream hash 与本地 content_hash。

【内容摘要】
- __init__(sources, lock_file, guard, audit_log, dest_root)
      注入 sources 字典 + 三件套（缺省用默认构造）+ 目标根目录。
- install(identifier, name=None) -> str        : 对外主入口，编排安装六步。
- uninstall(name) -> None                      : 反向流程。
- update(name=None) -> list[str]               : MVP 占位，返空。
- _resolve_source(identifier) -> SkillSource | None : 按前缀匹配 source。
- _derive_name(identifier) -> str              : 从 identifier 推导 name。
- _compute_hash(skill_dir) -> str              : 算 SKILL.md sha256。
- _now_iso() -> str                            : UTC ISO 时间戳。
- _derive_upstream_url(source, identifier) -> str | None : MVP 返 None。

【职责边界】
- 只负责：编排安装 / 卸载 / 更新流程，调 source / guard / parser / lock / audit。
- 不负责：搜索（unified_search）、具体 source 实现（sources/）、安全规则（SkillsGuard）、
  provenance 存储（HubLockFile）、审计格式（AuditLog）、技能解析（parser）。
- 不下载：下载由 source.fetch 负责，本类只调它。
- 不扫描：安全规则在 SkillsGuard，本类只调它。
- 不做 update 实现：MVP 占位，返空列表。

## 0. 结构树

### 0.1. 静态结构树

```
skill/hub/installer.py — Installer（install/uninstall/update 编排）
│
└─ class Installer
    ├─ __init__(sources, lock_file=None, guard=None,       ← 注入 sources 字典 + 三件套
    │           audit_log=None, dest_root=None)
    │   ├─ self._sources   = sources
    │   ├─ self._lock_file = lock_file or HubLockFile()
    │   ├─ self._guard     = guard or SkillsGuard()
    │   ├─ self._audit_log = audit_log or AuditLog()
    │   └─ self._dest_root = dest_root or ~/.poirot/skills
    │
    ├─ install(identifier, name=None) -> str               ← 【对外主入口】六步编排
    │   ├─ 1. _resolve_source(identifier)（失败 → ValueError）
    │   ├─ 2. name None → _derive_name(identifier)（空 → ValueError）
    │   ├─ 3. source.fetch(identifier, dest_dir)           ← 下载
    │   ├─ 4. _guard.scan(skill_dir, source.name, identifier)
    │   │     └─ allowed=False → warning + ValueError（已隔离）
    │   ├─ 5. parser.install(skill_dir, name, dest_root)   → skill_id
    │   ├─ 6. _compute_hash(skill_dir)                     → content_hash
    │   ├─ 7. _lock_file.add(HubLockEntry)                 ← 记 provenance
    │   └─ 8. _audit_log.append("install", ...)            ← 留痕
    │
    ├─ uninstall(name) -> None                             ← 【反向流程】
    │   ├─ _lock_file.get(name)（无记录 → ValueError）
    │   ├─ Path(entry.install_path).rmtree
    │   ├─ _lock_file.remove(name)
    │   └─ _audit_log.append("uninstall", ...)
    │
    ├─ update(name=None) -> list[str]                      ← 【MVP 占位】恒返 []
    │
    ├─ _resolve_source(identifier) -> SkillSource | None   ← 【前缀匹配】identifier → source
    │   └─ for prefix, source in self._sources.items():
    │         identifier 以 "<prefix>:" 或 "<prefix>" 开头 → 返回 source
    │
    ├─ _derive_name(identifier) -> str                     ← 【推导 name】
    │   ├─ "@" 后部分          （github:owner/repo@skill-name → skill-name）
    │   ├─ "/" 末段            （github:owner/repo → repo）
    │   ├─ ":" 后部分          （builtin:name → name）
    │   └─ 原 identifier
    │
    ├─ _compute_hash(skill_dir) -> str                     ← 【哈希】SKILL.md sha256
    │   └─ 无 SKILL.md → ""
    │
    ├─ _now_iso() -> str                                   ← 【时间】UTC ISO
    │
    └─ _derive_upstream_url(source, identifier) -> str | None  ← 【MVP 占位】返 None
```

### 0.2. 运行时调用树

```
① 装配期（bootstrap）
    Installer(
        sources = {"builtin": BuiltinSource(), "github": GitHubSource(), ...},
        lock_file = HubLockFile(),
        guard     = SkillsGuard(),
        audit_log = AuditLog(),
        dest_root = ~/.poirot/skills,
    )

② 安装（CLI / Agent 工具 / installer 被调）
    installer.install("github:owner/repo@skill-name")
        ├─ _resolve_source → GitHubSource
        ├─ _derive_name → "skill-name"
        ├─ source.fetch(identifier, dest_dir)              ← git clone
        ├─ guard.scan(skill_dir, "github", identifier)
        │     ├─ _is_trusted → allowed
        │     ├─ 模式匹配 → allowed=False → quarantine
        │     └─ allowed=False → raise ValueError
        ├─ parser.install(...) → skill_id
        ├─ _compute_hash
        ├─ lock_file.add(HubLockEntry)
        └─ audit_log.append("install", ...)

③ 卸载（CLI / Agent 工具）
    installer.uninstall("skill-name")
        ├─ lock_file.get(name)
        ├─ shutil.rmtree(install_path)
        ├─ lock_file.remove(name)
        └─ audit_log.append("uninstall", ...)

④ 更新（CLI / 周期任务；MVP 占位）
    installer.update(name)
        └─ 返 []（未实现）
```

## 1. 补充

- **它是 hub 的安装编排器**：把 source / guard / parser / lock / audit 五个组件串起来，本身不做下载、不做扫描、不做解析。
- **安装六步固定顺序**：`fetch → scan → install → hash → lock.add → audit.append`；`SkillsGuard` 是守门人，在落盘前拦截。
- **`source` 解析靠前缀匹配**：`sources` 字典的 key 是前缀（`"github"` / `"builtin"` / `"well-known"` / `"claude-marketplace"`），`_resolve_source` 按前缀分发。
- **`name` 推导有优先级**：`@` 后部分 > `/` 末段 > `:` 后部分 > 原 identifier；保证 `github:owner/repo@skill-name` 能推出 `skill-name`。
- **失败处理分两类**：
  - source 无法解析 / name 推导失败 → `ValueError`（参数问题）。
  - SkillsGuard 拒绝 → `logger.warning` + `ValueError`（安全拦截，skill 已被隔离）。
- **`uninstall` 是对称流程**：查 lock → 删目录 → 删记录 → 写审计。
- **`update` 与 `_derive_upstream_url` 都是 MVP 占位**：`update` 恒返 `[]`，`_derive_upstream_url` 恒返 `None`；进阶版需要"重新 fetch + hash 对比"。
- **与 config 开关的关系**：`hub_enabled` 控制是否装配 `Installer`；`hub_quarantine_enabled` 控制 `SkillsGuard` 是否真隔离；`hub_audit_log` 控制 `AuditLog` 是否写。
- **它在整个 hub 流程中的位置**：
  ```
  unified_search（找）→ 用户/LLM 选 → installer.install（装）
      → source.fetch → SkillsGuard.scan → parser.install
      → HubLockFile.add + AuditLog.append
  ```
