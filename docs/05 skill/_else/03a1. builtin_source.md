---

name: BuiltinSource — 扫 builtin_skills/ 树（零网络）。

description: 

【整体职责】
hub 的内置技能源：扫 builtin_skills/ 目录树，把内置技能转成 SkillMeta。
- 零网络：内置技能随包提交，全部在本地。
- 复用既有能力：调 SkillManager.search_builtin_skills 完成实际搜索。
- 已激活的技能标 is_installed=True。

设计（design_docs/46 §2.4）：
- 调既有 SkillManager.search_builtin_skills，转 SkillMeta。
- 已激活的 skill 标 is_installed=True。
- source="builtin"。

【内容摘要】
- name = "builtin"                                      : 源标识。
- __init__(skill_manager)                              : 保存 SkillManager（可 None）。
- search(query, limit) -> list[SkillMeta]              : 搜 builtin_skills/ 树。
- fetch(identifier, dest_dir) -> Path                  : 返 builtin skill 路径（不下载）。
- preview(identifier) -> str | None                    : 预览 SKILL.md 内容。

【职责边界】
- 只负责：扫本地 builtin_skills/ 树 + 转 SkillMeta。
- 不负责：搜索编排（search.py）、安装流程（installer.py）、中心存储（hub_store.py）、
  技能解析（parser）、持久化（store）。
- 不做网络访问：零网络。
- 不做下载：builtin skill 已在本地，fetch 直接返路径。

## 0. 结构树

### 0.1. 静态结构树

```
skill/hub/sources/builtin_source.py — BuiltinSource（扫 builtin_skills/ 树，零网络）
│
└─ class BuiltinSource
    ├─ name = "builtin"                                    ← 源标识（类属性）
    │
    ├─ __init__(skill_manager=None)                        ← 保存 SkillManager（可 None）
    │
    ├─ search(query, limit=10) -> list[SkillMeta]          ← 【对外主入口】搜 builtin_skills/
    │   ├─ mgr None → 延迟 build_skill_manager()
    │   ├─ mgr 仍 None → []
    │   ├─ mgr.search_builtin_skills(query)
    │   └─ 转 SkillMeta（source="builtin"，identifier=f"builtin:{name}"，
    │        is_installed 取自 is_active）→ 取前 limit 条
    │
    ├─ fetch(identifier, dest_dir) -> Path                 ← 【协议兼容】返 builtin 路径
    │   ├─ 解析 identifier："builtin:<name>" → name
    │   ├─ mgr.search_builtin_skills(name)
    │   ├─ 匹配 name → Path(r["path"])
    │   └─ 未找到 → dest_dir
    │
    └─ preview(identifier) -> str | None                   ← 【预览】读 SKILL.md
        ├─ path = fetch(identifier, Path("."))
        ├─ path.exists() → read_text()
        └─ 不存在 → None
```

---

### 0.2. 运行时调用树

```
① 装配期（bootstrap）
    BuiltinSource(skill_manager)（可 None，延迟加载）
        └─ 注册到 hub 的 sources 列表

② 搜索（search.py 编排）
    search(query, limit)
        └─ for source in sources:
              └─ BuiltinSource.search(query, limit)      ← 本模块主入口
                    ├─ 延迟 build_skill_manager()（首次）
                    ├─ mgr.search_builtin_skills(query)
                    └─ 转 list[SkillMeta]

③ 预览（CLI / TUI 按需）
    BuiltinSource.preview(identifier)
        └─ fetch(identifier) → read_text()

④ 安装（installer.py 编排）
    installer.install(meta)
        ├─ 优先用 meta.install_path（builtin 已在本地）
        └─ 兜底 BuiltinSource.fetch(identifier, dest_dir)
```

## 1. 补充

- **零网络、零下载**：内置技能随包提交，全部在本地；`fetch` 只是"协议兼容"——真实路径在 `search` 时已通过 `install_path` 返回，`installer` 应优先用它。
- **延迟加载 `SkillManager`**：`build_skill_manager()` 在 `search` / `fetch` 内 import，避免 `hub → skill/__init__` 的循环 import。
- **复用既有能力**：实际搜索逻辑不在本模块，而在 `SkillManager.search_builtin_skills`（只扫 `builtin_skills/` 全树，含未加载的非 core 技能）。
- **`is_installed` 的来源**：取自 `search_builtin_skills` 返回的 `is_active`——已激活（core 自动 discover）的标 True。
- **`identifier` 格式固定**：`builtin:<name>`；`fetch` 会解析出 `<name>` 再回查路径。
- **4 个 source 中最简单的一个**：无网络、无认证、无分页；github / well-known / claude-marketplace 会复杂得多。
