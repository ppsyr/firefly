---

name: HubLockFile + SkillsGuard + AuditLog — provenance + 安全 + 留痕。

description: 

【整体职责】
hub 的"安全与留痕"三件套：
- HubLockFile : 记录已安装 skill 的来源（provenance），支持 update 检查。
- SkillsGuard : install 前安全扫描（prompt injection / 敏感路径 / 可疑 URL）。
- AuditLog    : 记录每次 install / uninstall / update。

设计（design_docs/46 §2.5）：
- HubLockFile：~/.poirot/skills/.hub/lock.json，跟踪 hub 安装的 skill provenance。
- SkillsGuard：install 前安全扫描（prompt injection + 敏感路径 + 可疑 URL）。
- AuditLog：~/.poirot/skills/.hub/audit.log，记录每次 install/uninstall/update。

【内容摘要】
值对象：
- HubLockEntry(frozen) : hub 安装的 skill provenance 记录。
- ScanResult(frozen)   : SkillsGuard 扫描结果（allowed / reasons / quarantine_path）。

类与模块常量：
- HubLockFile : lock.json 读写（add / remove / list_installed / get）。
- SkillsGuard : 安全扫描（scan / _is_trusted / _quarantine）。
    - 模块常量：_SENSITIVE_PATTERNS / _PROMPT_INJECTION_PATTERNS /
      _SUSPICIOUS_URL_PATTERNS / TRUSTED_REPOS。
- AuditLog    : 审计日志（append / read）。

【职责边界】
- 只负责：provenance 记录（lock.json）、安全扫描（正则匹配）、审计日志（append/read）。
- 不负责：搜索（search.py）、安装流程编排（installer.py）、中心存储（hub_store.py）、
  技能解析（parser）、持久化（store）。
- 不做深度静态分析：SkillsGuard 用正则模式匹配，非 AST / 语义分析。
- 不做网络：三件套全部本地文件操作。

## 0. 结构树

### 0.1. 静态结构树

```
skill/hub/hub_store.py — HubLockFile + SkillsGuard + AuditLog（provenance + 安全 + 留痕）
│
├─ class HubLockEntry(frozen)                    ← hub 安装的 provenance 记录
│   ├─ name: str                                 ← 技能名
│   ├─ source: str                               ← "github" / "well-known" / "claude-marketplace"
│   ├─ identifier: str                           ← 安装时用的 identifier
│   ├─ install_path: str                         ← ~/.poirot/skills/<name>/
│   ├─ installed_at: str                         ← ISO timestamp
│   ├─ content_hash: str                         ← SKILL.md sha256
│   └─ upstream_url: str | None = None           ← 用于 update 检查
│
├─ class ScanResult(frozen)                      ← SkillsGuard 扫描结果
│   ├─ allowed: bool                             ← True 可安装；False 进 quarantine
│   ├─ reasons: list[str] = []                   ← 检测到的风险描述
│   └─ quarantine_path: str | None = None        ← 隔离路径（allowed=False 时填）
│
├─ class HubLockFile                             ← lock.json 读写
│   ├─ __init__(lock_path=None)                  ← 缺省 ~/.poirot/skills/.hub/lock.json
│   ├─ add(entry)                                ← 添加（同名覆盖）
│   ├─ remove(name)                              ← 按 name 删除
│   ├─ list_installed() -> list[HubLockEntry]    ← 列出全部
│   ├─ get(name) -> HubLockEntry | None          ← 按 name 查
│   ├─ _load() -> list[dict]                     ← 读（坏 / 缺 → []）
│   ├─ _save(entries)                            ← 写（indent=2, ensure_ascii=False）
│   ├─ _entry_to_dict(entry) -> dict             ← 序列化
│   └─ _dict_to_entry(d) -> HubLockEntry         ← 反序列化
│
├─ 模块常量（SkillsGuard 扫描模式）
│   ├─ _SENSITIVE_PATTERNS          ← 敏感路径（rm -rf / / mkfs / dd / chmod 777）
│   ├─ _PROMPT_INJECTION_PATTERNS   ← 注入模式（curl|bash / wget|sh / eval / exec）
│   ├─ _SUSPICIOUS_URL_PATTERNS     ← 可疑下载 URL（.exe / .bat / .cmd / .ps1 / .sh）
│   └─ TRUSTED_REPOS                ← 信任 repo 集合（自动放行）
│
├─ class SkillsGuard                             ← install 前安全扫描
│   ├─ __init__(quarantine_dir=None)             ← 缺省 ~/.poirot/skills/.hub/quarantine
│   ├─ scan(skill_dir, source, identifier)       ← 对外主入口
│   │   -> ScanResult
│   │   ├─ 无 SKILL.md → allowed=True（skip）
│   │   ├─ _is_trusted → allowed=True
│   │   ├─ 逐类模式匹配 → reasons
│   │   ├─ 命中 → _quarantine + allowed=False
│   │   └─ 无命中 → allowed=True
│   ├─ _is_trusted(source, identifier) -> bool   ← TRUSTED_REPOS / builtin
│   └─ _quarantine(skill_dir) -> Path            ← 移动到隔离目录（同名先 rmtree）
│
└─ class AuditLog                                ← audit.log 读写
    ├─ __init__(log_path=None)                   ← 缺省 ~/.poirot/skills/.hub/audit.log
    ├─ append(action, skill_name, source, **extra) ← 追加一条（UTC ISO 时间戳）
    └─ read() -> list[dict]                      ← 读全部（坏行跳过）
```

### 0.2. 运行时调用树

```
① 装配期（bootstrap）
    ├─ HubLockFile()      （缺省路径）
    ├─ SkillsGuard()      （缺省隔离目录）
    └─ AuditLog()         （缺省日志路径）

② install 流程（installer.py 编排）
    installer.install(meta)
        ├─ source.fetch(identifier, dest_dir)          ← 先下载
        ├─ skills_guard.scan(dest_dir, source, identifier)   ← 再扫描
        │     ├─ 无 SKILL.md → allowed=True
        │     ├─ _is_trusted → allowed=True
        │     ├─ 模式匹配 → reasons
        │     └─ 命中 → _quarantine（移到隔离目录）+ allowed=False
        ├─ allowed=False → 拒 install，写 audit log
        ├─ allowed=True  → 继续：
        │     ├─ parser.parse_skill_file(SKILL.md)
        │     ├─ store.register(SkillRecord)
        │     ├─ hub_lock.add(HubLockEntry)
        │     └─ audit_log.append("install", ...)

③ uninstall 流程
    ├─ hub_lock.remove(name)
    └─ audit_log.append("uninstall", ...)

④ update 流程
    ├─ hub_lock.get(name) → upstream_url
    ├─ 重新 fetch / scan / install
    └─ audit_log.append("update", ...)

⑤ 查询
    ├─ hub_lock.list_installed() / get(name)
    └─ audit_log.read()
```

## 1. 补充

- **三件套分工**：
  - `HubLockFile` 管 **provenance**（从哪来、什么版本、怎么更新）。
  - `SkillsGuard` 管 **安全**（install 前的最后一道闸）。
  - `AuditLog` 管 **留痕**（谁在什么时候装/卸/更新了什么）。
- **`SkillsGuard` 的三条短路**：
  1. 无 `SKILL.md` → 跳过扫描（allowed=True）。
  2. `_is_trusted`（TRUSTED_REPOS 或 builtin）→ 直接放行。
  3. 命中任一风险模式 → `_quarantine` + allowed=False。
- **扫描是正则匹配，不是 AST / 语义分析**：规则集中在四组模块常量里，可扩展；误报靠 `TRUSTED_REPOS` 白名单缓解。
- **quarantine 是"移动"而非"复制"**：命中风险的 skill 目录被 `shutil.move` 到隔离区；同名先 `rmtree` 再 move。
- **三个组件都容错**：
  - `HubLockFile._load`：文件缺失 / JSON 坏 / OSError → 返 `[]`。
  - `AuditLog.read`：坏行跳过。
  - `AuditLog.append`：父目录自动创建。
- **它们在 install 流程里的顺序**：`fetch` → **`scan`** → `parse` → `register` → `hub_lock.add` → `audit_log.append`——`SkillsGuard` 是 install 的守门人，`HubLockFile` / `AuditLog` 是安装后记录。
- **与 config 的开关对应**：`hub_enabled`（总开关）/ `hub_quarantine_enabled`（是否启用隔离）/ `hub_audit_log`（是否记审计）——分别控制这三件套是否生效。
