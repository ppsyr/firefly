---

name: ResponseContractChecker — 响应层 eval（pre-promotion，检查 candidate SKILL.md）。

description: 

【整体职责】
响应层评估器：在 candidate 晋升前，用 ContractCompiler 编译出适用规则，
跑在 candidate 上，汇总为 EvalResult（score + hard_failures + recommendation）。
- 规则来源：ContractCompiler.compile(candidate_content)（按 skill 文本动态编译）。
- 检查执行：_run_rule 分发到 checks 模块的确定性检查函数。
- 结论：有 hard 规则失败 → reject；否则 accept。

【内容摘要】
类方法：
- __init__(compiler)                          : 保存 compiler（缺省新建）。
- check(candidate_content, baseline_content)  : 对外主入口，产 EvalResult。
- _run_rule(rule_id, content, params)         : 按 rule_id 分发到 checks 检查函数。

【职责边界】
- 只负责：编译规则 → 逐条执行 → 汇总打分 → 产 EvalResult。
- 不负责：规则编译逻辑（ContractCompiler）、具体检查实现（checks.py）、
  LLM 评估（analyzer / judge）、持久化（store）。
- 不做 hard 判定以外的决策：是否晋升由 L2 消费 EvalResult 决定。
- 不 short-circuit：逐条跑完所有规则再汇总（hard_failures 只记录，不提前返回）。

## 0. 结构树

### 0.1. 静态结构树

```
eval/analyzers/response_contract_checker.py — 响应层 eval（pre-promotion）
│
└─ class ResponseContractChecker
    ├─ __init__(compiler)                                ← 保存 compiler（缺省新建）
    │
    ├─ check(candidate_content, baseline_content)        ← 【对外主入口】
    │   -> EvalResult
    │   ├─ rules = compiler.compile(candidate_content)
    │   ├─ for rule in rules:
    │   │     ├─ cand_pass = _run_rule(rule_id, candidate, params)
    │   │     ├─ base_pass = _run_rule(rule_id, baseline, params)
    │   │     │     （baseline 空 → True）
    │   │     ├─ cand_pass → passed += 1
    │   │     ├─ rule.hard 且 not cand_pass → hard_failures.append(rule_id)
    │   │     └─ evidence.append(EvalEvidence(...))
    │   ├─ score = passed / total（total=0 → 0.0）
    │   ├─ recommendation = "reject" if hard_failures else "accept"
    │   └─ return EvalResult(score, metric="hard", hard_failures,
    │                        evidence, confidence=0.7, recommendation)
    │
    └─ _run_rule(rule_id, content, params) -> bool       ← 【分发】rule_id → checks 函数
        ├─ "nonempty"             → checks.check_nonempty
        ├─ "json_parseable"       → checks.check_json_parseable
        ├─ "must_cite"            → checks.check_must_cite
        ├─ "lead_with_conclusion" → checks.check_lead_with_conclusion
        ├─ "paragraph_limit"      → checks.check_paragraph_limit
        ├─ "no_unfounded_claims"  → checks.check_no_unfounded_claims
        ├─ "semantic_density"     → checks.semantic_density + 区间判定
        │                           （content 空 → False）
        └─ 未知 rule_id           → True（默认 pass）
```

---

### 0.2. 运行时调用树

```
① 装配期（bootstrap）
    build_default_registry()
        ├─ ContractCompiler()
        ├─ ResponseContractChecker(compiler)
        └─ EvalRegistry(checker)
              └─ RegistryEvalBridge → 注入 L2

② 候选晋升前 —— 响应层（同步）
    L2 → RegistryEvalBridge.evaluate(ctx)
            ├─ checks.read_content(ctx.candidate)
            ├─ checks.read_content(ctx.baseline)
            └─ ResponseContractChecker.check(candidate, baseline)   ← 本模块主入口
                  ├─ compiler.compile(candidate)         ← 编译规则
                  ├─ for rule:
                  │     ├─ _run_rule → checks.check_*    ← 执行检查
                  │     ├─ 累加 passed / hard_failures
                  │     └─ evidence.append(...)
                  ├─ score = passed / total
                  ├─ recommendation = reject / accept
                  └─ EvalResult → 回到 L2
```

## 1. 补充

- **hard 失败不 short-circuit**：逐条跑完所有规则再汇总，`hard_failures` 只记录不提前返回。
- **`semantic_density` 是唯一区间判定**：`checks.semantic_density` 只返 float，区间比较在此模块内做。
- **baseline 空视为 pass**：`base_pass=True`，仅作对照记录，不影响 candidate 判定。
- **未知规则默认 pass**：向前兼容——compiler 未来新增规则时，老 checker 不会误判失败。
