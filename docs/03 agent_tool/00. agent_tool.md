
## 0. 结构树

### 0.1. 静态结构树（包 → 模块 → 函数）

```
agent_tools — 工具定义、汇总、装配与来源标记
│
├─ __init__.py                                    ← 包初始化
│
├─ available.py                                   ← 工具装配主入口
│   ├─ 模块级常量
│   │   ├─ CORE_TOOL_NAMES = {web_search, browse_page,
│   │   │                     read_snapshot, skill_search}     ← core 白名单
│   │   └─ SANDBOX_TOOL_NAMES = {bash, read_file, write_file,
│   │                            list_dir, str_replace,
│   │                            present_files}                ← sandbox 白名单
│   │
│   ├─ _tool_group(name)                          ← 工具名 → group 判定
│   │   ├─ 命中 CORE_TOOL_NAMES    → "core"
│   │   ├─ 命中 SANDBOX_TOOL_NAMES → "sandbox"
│   │   └─ 其余                    → "deferred"
│   │
│   ├─ dedupe_by_name(tools)                      ← 按 name 去重（保留首次）
│   │
│   ├─ select_search_tool(tools)                  ← 挑第一个名含 "search" 的工具
│   │
│   └─ get_available_tools(groups, include_mcp)   ← 对外主入口
│       ├─ get_builtin_tools() → dedupe_by_name()
│       ├─ groups=None        → 返回全部
│       └─ 指定 groups        → 按 _tool_group 过滤 + info 日志
│
├─ mcp_metadata.py                                ← MCP 工具来源标记
│   ├─ MCP_TOOL_METADATA_KEY = "poirot_mcp"       ← metadata 约定 key
│   ├─ tag_mcp_tool(tool)                         ← 写入 MCP 标记（in-place）
│   └─ is_mcp_tool(tool)                          ← 读取 MCP 标记（bool）
│
└─ builtin/                                        ← 内置工具目录
    ├─ __init__.py                                 ← builtin 汇总
    │   └─ get_builtin_tools()                     ← 收集 4 个工具（不去重）
    │       └─ [web_search_tool, read_snapshot,
    │            ask_help_tool, skill_search]
    │
    ├─ ddg_search.py                               ← DDG 直调搜索
    │   ├─ DEFAULT_MAX_RESULTS / DEFAULT_REGION /
    │   │  DEFAULT_SAFESEARCH / DEFAULT_BACKEND    ← 搜索默认参数
    │   └─ web_search_tool(query, max_results)     ← @tool("web_search")
    │
    ├─ read_snapshot.py                            ← 读压缩前快照
    │   └─ read_snapshot(snapshot_path)            ← @tool（名 = 函数名）
    │
    ├─ ask_help.py                                 ← 求助入口（空壳）
    │   └─ ask_help_tool(question, help_type,
    │                    context, options)         ← @tool("ask_help",
    │                                                  return_direct=True)
    │
    └─ skill_search.py                             ← 技能搜索
        └─ skill_search(query, limit)              ← @tool("skill_search")
```

### 0.2. 运行时调用树（按执行阶段分：装配加载 → 分组过滤 → 工具执行）

```
【阶段 A：装配加载（谁调谁）】

上层 Agent / bootstrap
│
└─ available.get_available_tools(groups, include_mcp)
    ├─ builtin.get_builtin_tools()                ← builtin 汇总
    │   └─ return [web_search_tool, read_snapshot,
    │              ask_help_tool, skill_search]
    ├─ available.dedupe_by_name(tools)            ← 按 name 去重
    └─ （若 groups 非 None）按 _tool_group 过滤

【阶段 A 的旁路来源（不走 available 这条链）】

MCP 工具     ← McpManager（build_mcp_manager）
                └─ mcp_metadata.tag_mcp_tool / is_mcp_tool 打标区分
sandbox 工具 ← Stage 4 bootstrap：config.sandbox 配了 provider
                └─ make_sandbox_tools(provider) → registry.tools

【阶段 B：分组过滤（get_available_tools 内部）】

get_available_tools(groups, include_mcp)
│
├─ tools = get_builtin_tools()
├─ all_tools = dedupe_by_name(tools)
│
├─ if groups is None:
│   └─ return all_tools                        ← 不过滤
│
└─ groups_set = set(groups)
    ├─ filtered = [t for t in all_tools
    │              if _tool_group(t.name) in groups_set]
    ├─ skipped  = [t.name for t in all_tools
    │              if _tool_group(t.name) not in groups_set]
    ├─ if skipped: logger.info(...)            ← 记录被过滤项
    └─ return filtered

【阶段 C：工具执行（各 builtin 工具被 LLM 调用时）】

web_search_tool(query, max_results)
├─ try: from ddgs import DDGS
├─ except ImportError → return error JSON
├─ DDGS(timeout=30) → ddgs.text(...) → list(...)
├─ except Exception → logger.error + return error JSON
├─ if not results → return error JSON
└─ normalized → json.dumps({query, total_results, results})

read_snapshot(snapshot_path)
├─ try: open(path, encoding="utf-8") → f.read()
└─ except OSError → return "读取快照失败：{path}"

ask_help_tool(question, help_type, context, options)
└─ return "Help request processed by HelpRequestMiddleware"
    （真正拦截/暂停由 HelpRequestMiddleware 负责，函数体是空壳）

skill_search(query, limit)
├─ build_skill_manager() → if None: return "[]"
├─ mgr.search_builtin_skills(query)          ← builtin 搜索
├─ try: unified_search(query, limit)         ← hub 搜索
│   ├─ except ImportError → pass（静默降级）
│   └─ except Exception   → warning（降级）
└─ 合并 + 去重(name) + 补 source + json.dumps(...[:limit])
```

### 0.3. 模块级 INVARIANT（约定，非代码）

```
agent_tools — 不变量 / 约定
│
├─ INV#1  builtin 工具优先于 MCP 工具（同名去重时优先保留 builtin）
├─ INV#2  去重按 tool.name，保留首次出现，顺序不变
├─ INV#3  get_builtin_tools() 只收集、不去重、不含 sandbox / MCP
├─ INV#4  sandbox 工具由 Stage 4 bootstrap 注入 registry.tools，不在此加载
├─ INV#5  MCP 工具由 McpManager 管理，include_mcp 为保留参数（当前无加载逻辑）
├─ INV#6  SANDBOX_TOOL_NAMES 在此仅用于「分组判定」，不触发加载
├─ INV#7  每个 builtin 工具只做一件事、返回字符串、不抛异常
├─ INV#8  ask_help 函数体是空壳，真正逻辑在 HelpRequestMiddleware
├─ INV#9  skill_search 归 core group（default + expert 都加载）
└─ INV#10 工具名以 @tool("名") 显式指定时 ≠ 函数名
```

## 2. 三个层次

### 层次一：单个工具定义（builtin/*.py）
每个文件定义一个 `@tool` 装饰的工具，只负责**自己那一件事**：

| 文件 | 工具名 | 作用 | 职责边界 |
|---|---|---|---|
| `ddg_search.py` | `web_search` | DDG 直调搜索，返回规范化 JSON | 只搜+规范化；3 类失败返回 error JSON 不抛 |
| `read_snapshot.py` | `read_snapshot` | 按路径读压缩前快照 | 只读文件；OSError 转错误串 |
| `ask_help.py` | `ask_help` | 向用户求助入口 | **空壳**，真正拦截在 middleware |
| `skill_search.py` | `skill_search` | 搜 builtin + hub 技能 | 只搜+合并+返回；hub 不可用降级 |

共同点：**都返回字符串**（JSON 或文本），都**不抛异常**，都不做跨工具编排。

### 层次二：builtin 汇总（builtin/__init__.py）
```python
def get_builtin_tools() -> list[BaseTool]:
    return [web_search_tool, read_snapshot, ask_help_tool, skill_search]
```
- 只做**收集**，返回 4 个工具对象。
- **不去重**（去重交给上层）。
- **不含 sandbox 工具**（由 Stage 4 bootstrap 注入）和 **MCP 工具**（由 McpManager 管）。

### 层次三：装配与过滤（available.py）
```python
get_available_tools(groups=None, include_mcp=True)
```
- 调 `get_builtin_tools()` → `dedupe_by_name()` 去重。
- `groups=None` → 返回全部；否则按 `_tool_group()` 过滤。
- 分组规则：
  - `core`     = `{web_search, browse_page, read_snapshot, skill_search}`
  - `sandbox`  = `{bash, read_file, write_file, list_dir, str_replace, present_files}`
  - 其余       → `deferred`
- 被过滤掉的工具名打 info 日志。

### 旁支：MCP 打标（mcp_metadata.py）
- `tag_mcp_tool(tool)` / `is_mcp_tool(tool)`，靠 metadata 的 `poirot_mcp` key 标识来源。
- 与 `available.py` 的 `include_mcp` 参数呼应：**MCP 工具另有来源，不在 builtin 里**。

## 3. 数据流（谁调谁）

```
上层 Agent / bootstrap
        │
        ▼
get_available_tools(groups=["core"])          ← available.py
        │
        ├─ get_builtin_tools()                ← builtin/__init__.py
        │       └─ [web_search, read_snapshot, ask_help, skill_search]
        │

```

其余来源并行注入，不走这条链：

```
MCP 工具     ← McpManager（build_mcp_manager）
sandbox 工具 ← Stage 4 bootstrap：make_sandbox_tools(provider) → registry.tools
```

## 4. 三条设计主线

**主线一：按 group 省上下文**
`core` 白名单工具 default + expert 都加载；`deferred` 只在 expert 加载；`sandbox` 仅用于分类判定（实际由 bootstrap 注入）。目的：**按模式裁剪注入 prompt 的工具数量**。

**主线二：来源分离 + 统一入口**
- builtin：`available.py` 这条链。
- MCP：McpManager，用 `mcp_metadata` 打标区分。
- sandbox：bootstrap 注入 registry。
三者最终都汇聚成 `list[BaseTool]` 交给 Agent，但**加载路径彼此独立**。

**主线三：工具本身「薄」，编排在外**
每个 builtin 工具只做一件事、只返回字符串、不抛异常。复杂逻辑（拦截、暂停、激活、归因）全在 **middleware / registry / bootstrap**，工具只是 LLM 的「可调用入口」。

## 6. 几个值得注意的点

1. **`include_mcp` 是保留参数**：`get_available_tools` 里没有 MCP 加载逻辑，MCP 由 McpManager 管。
2. **`SANDBOX_TOOL_NAMES` 只用于分类**：它不代表这里会加载 sandbox 工具。
3. **同名优先 builtin**：`get_builtin_tools` docstring 明说「优先于 MCP」，去重在上层按 name 做。
4. **`ask_help` 是特例**：函数体是空壳，真正逻辑在 `HelpRequestMiddleware`，配合 `return_direct=True` 暂停 graph。
5. **工具名 ≠ 函数名**：`web_search_tool` → `web_search`，`ask_help_tool` → `ask_help`，都以 `@tool("名")` 显式指定。

## 7. agent_tools 与 graph middleware 的关系

**没有直接关系。** 它们是两条独立的注入路径，只在「建图（build graph）」这一刻汇合。

text

agent_tools（本包）              graph middleware
     │                                │
     │ 产出 list[BaseTool]            │ 产出 list[Middleware]
     ▼                                ▼
     └──────────► build graph ◄───────┘
                    │
                    ▼
              Agent / LangGraph

- `agent_tools` 负责**工具**：产出 `list[BaseTool]`。
    
- `middlewares/` 负责**中间件**：产出 `list[Middleware]`（含你之前看的 `SkillMetricsMiddleware`、`TaggedContextMiddleware` 等）。
    
- 两者**互不 import**，各自被 bootstrap / 建图逻辑收集。
