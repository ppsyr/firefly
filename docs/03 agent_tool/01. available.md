---

name: 工具装配构建器（builtin 工具加载 + group 过滤）。

description:

【整体职责】
把 builtin 工具加载出来，并可选地按 group 白名单过滤，交给上层 Agent 使用。
本模块是「工具获取」的统一入口，但不负责所有工具来源：
MCP 工具由 McpManager 管理，sandbox 工具由 bootstrap 注入 CapabilityRegistry。

【组成】
1. 工具分组标记（模块级常量，白名单）：
   - CORE_TOOL_NAMES     ：core 组，基础工具，default + expert 都加载（省上下文）。
   - SANDBOX_TOOL_NAMES  ：sandbox 组，沙箱工具
                           （bash / read_file / write_file / list_dir / str_replace / present_files）。
   说明：不在上述两个集合中的工具名，一律归为 deferred（深度工具，仅 expert 加载）。
2. 分组判定：
   - _tool_group(name)   ：工具名 → group 的内部映射器，是过滤逻辑的核心判定。
3. 工具列表处理：
   - dedupe_by_name(tools)     ：按工具名去重，保留首次出现。
   - select_search_tool(tools) ：挑出第一个「搜索类」工具。
4. 对外主入口：
   - get_available_tools(groups, include_mcp)：加载 builtin 工具并按 group 过滤。

【职责边界】
- 本模块只加载 builtin 工具（如 ddg_search、read_snapshot）。
- MCP 工具由 McpManager 管理（bootstrap 通过 build_mcp_manager 加载），不在本模块加载。
- sandbox 工具由 bootstrap 注入 CapabilityRegistry，不在此加载；
  SANDBOX_TOOL_NAMES 在这里仅用于「分组判定」，不触发实际加载。
- include_mcp 为保留参数，仅为向后兼容，当前无任何 MCP 加载逻辑。

```
工具装配构建器（builtin 工具加载 + group 过滤）
│
├─ 模块级 docstring
│   ├─ 整体职责：加载 builtin 工具 + 按 group 白名单过滤
│   └─ 职责边界：不管 MCP（McpManager）、不管 sandbox（bootstrap 注入）
│
├─ imports
│   ├─ from __future__ import annotations
│   ├─ import logging
│   ├─ from langchain_core.tools import BaseTool
│   └─ from ...agent_tools.builtin import get_builtin_tools
│
├─ logger = logging.getLogger(__name__)
│
├─ 模块级常量（group 白名单）
│   ├─ CORE_TOOL_NAMES = {web_search, browse_page,
│   │                     read_snapshot, skill_search}      ← default + expert 都加载
│   └─ SANDBOX_TOOL_NAMES = {bash, read_file, write_file,
│                            list_dir, str_replace,
│                            present_files}                 ← 仅用于分类判定
│        （不在两个集合中的 → deferred，仅 expert 加载）
│
├─ _tool_group(name)                              ← 工具名 → group 判定
│   ├─ 命中 CORE_TOOL_NAMES    → "core"
│   ├─ 命中 SANDBOX_TOOL_NAMES → "sandbox"
│   └─ 其余                    → "deferred"
│
├─ dedupe_by_name(tools)                          ← 按 name 去重（保留首次）
│   ├─ seen: set[str] = set()
│   └─ for tool in tools:
│       └─ if tool.name not in seen:
│           ├─ seen.add(tool.name)
│           └─ result.append(tool)
│
├─ select_search_tool(tools)                      ← 挑第一个名含 "search" 的工具
│   └─ for tool in tools:
│       └─ if "search" in tool.name.lower(): return tool
│
└─ get_available_tools(groups=None, include_mcp=True)   ← 对外主入口
    ├─ tools = get_builtin_tools()                ← builtin 汇总
    ├─ all_tools = dedupe_by_name(tools)          ← 去重
    │
    ├─ if groups is None:
    │   └─ return all_tools                       ← 不过滤
    │
    └─ groups_set = set(groups)
        ├─ filtered = [t for t in all_tools
        │              if _tool_group(t.name) in groups_set]
        ├─ skipped  = [t.name for t in all_tools
        │              if _tool_group(t.name) not in groups_set]
        ├─ if skipped: logger.info(...)           ← 记录被过滤项
        └─ return filtered
```
