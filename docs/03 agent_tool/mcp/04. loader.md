---

name: MCP 连接生命周期 — eager 并行加载 + 按需 refresh + 安全层应用。

desvription: 

【整体职责】
管理 MCP server 的连接生命周期：启动时并行连接所有 enabled server、发现并注册工具
（经安全守卫过滤），运行时按需 refresh 重连，退出时清理连接。

【内容摘要】
- _SDK_TRANSPORT_MAP  : config transport → SDK transport 映射。
- _build_connection   : McpServerConfig → SDK connection dict。
- McpLoader.__init__  : 持有 config / registry / guards / clients。
- _get_env_guard / _get_description_guard : 按类型取 guard。
- _connect_server     : 连接单个 server，发现并注册工具。
- _register_tools     : 注册工具（include/exclude 过滤 + 描述扫描）。
- load_startup        : 并行连接所有 enabled server（单 server 失败不阻塞）。
- refresh             : 重连 server，增量更新 registry。
- shutdown            : 清理所有连接。
- sanitizer           : 暴露给 audit middleware 用。

【职责边界】
- 只负责：连接建立、工具发现与注册、连接清理、守卫应用。
- 不负责：配置加载（mcp/config）、工具条目定义（mcp/registry）、
  守卫实现（mcp/guards）、运行时熔断与审计（McpAuditMiddleware）。

## 0. 结构树

### 0.1. 静态结构树

```
loader.py — MCP 连接生命周期（eager 并行加载 + 按需 refresh + 安全层应用）
│
├─ 模块级常量
│   └─ _SDK_TRANSPORT_MAP = {"stdio":"stdio", "sse":"sse", "http":"streamable_http"}
│
├─ _build_connection(server, filtered_env) -> dict ← 配置 → SDK connection dict
│   ├─ transport 映射（config → SDK）
│   ├─ stdio → command / args / env（用过滤后 env）
│   └─ sse / http → url / headers
│
└─ McpLoader                                  ← 连接生命周期管理
    ├─ __init__(config, registry, guards=None) ← 初始化
    │   ├─ _config: McpConfig
    │   ├─ _registry: ToolRegistry
    │   ├─ _guards: list[SecurityGuard]（默认 [EnvFilter, DescriptionScanner]）
    │   ├─ _sanitizer: CredentialSanitizer
    │   ├─ _clients: dict[server_name, MultiServerMCPClient]
    │   └─ _lock: asyncio.Lock（refresh 串行）
    │
    ├─ _get_env_guard() -> EnvFilter | None    ← 按类型取 EnvFilter
    ├─ _get_description_guard() -> DescriptionScanner | None ← 按类型取 DescriptionScanner
    │
    ├─ _connect_server(server) -> list[BaseTool] ← 【单 server 连接】
    │   ├─ EnvFilter.check_env(server.env) → filtered_env
    │   ├─ _build_connection(server, filtered_env)
    │   ├─ MultiServerMCPClient({name: connection})
    │   ├─ asyncio.wait_for(client.get_tools(), timeout=connect_timeout)
    │   ├─ 超时 → RuntimeError
    │   ├─ _clients[name] = client
    │   └─ _register_tools(server, tools)
    │
    ├─ _register_tools(server, tools) -> list[BaseTool] ← 【注册（含过滤）】
    │   ├─ include 过滤（非白名单 → skip）
    │   ├─ exclude 过滤（黑名单 → skip）
    │   ├─ DescriptionScanner.scan_description → 可疑则 skip
    │   ├─ 构造 ToolEntry(tool, source="mcp", server_name, metadata)
    │   └─ registry.register(entry) → 成功加入 registered
    │
    ├─ load_startup() -> list[BaseTool]        ← 【启动：并行连接】
    │   ├─ 过滤 enabled server（无则返空）
    │   ├─ asyncio.gather(return_exceptions=True) 并行
    │   ├─ 逐 server 处理：
    │   │     ├─ 异常 → logger.error + mark_unhealthy + continue
    │   │     └─ 成功 → 合并工具
    │   └─ return all_tools
    │
    ├─ refresh() -> None                       ← 【重连（增量）】
    │   ├─ 持 _lock
    │   ├─ 重新连接所有 enabled server（gather）
    │   └─ 失败 → logger.warning / 成功 → logger.info
    │
    ├─ shutdown() -> None                      ← 【清理】
    │   ├─ 逐 client 调 __aexit__
    │   ├─ 失败 → logger.warning
    │   └─ _clients.clear()
    │
    └─ sanitizer (property) -> CredentialSanitizer ← 暴露给 audit middleware
```

### 0.2. 生命周期视图

```
【启动 load_startup】
    enabled servers
        │
        ▼
    asyncio.gather（并行）
        ├─ server A → _connect_server → EnvFilter → SDK → get_tools → _register_tools
        ├─ server B → ...
        └─ server C → ...
        │
        ├─ 单 server 失败 → mark_unhealthy（不阻塞其余）
        ▼
    all_tools（已注册工具）

【运行时 refresh】
    enabled servers
        │
        ▼
    _lock（串行）
        └─ 重新连接（gather）
              └─ registry.register 幂等（同名先入者保留）

【退出 shutdown】
    _clients
        │
        ▼
    逐 client.__aexit__（清理 SDK 连接）
        └─ _clients.clear()
```

### 0.3. 安全层应用顺序树

```
McpLoader 应用 guards（按顺序）：
│
├─ ① EnvFilter.check_env(server.env)
│     └─ 过滤环境变量（剔除敏感/危险变量）
│
└─ ② DescriptionScanner.scan_description(name, description)
      └─ 扫描工具描述（可疑 → skip 注册）
```

**注**：`CredentialSanitizer` 不做应用，只暴露给 `McpAuditMiddleware` 用（工具错误脱敏）。

### 0.4. 运行时调用树

```
① 装配（bootstrap）
bootstrap / build_mcp_manager
    ├─ load_mcp_config(...) → McpConfig
    ├─ ToolRegistry()
    └─ McpLoader(config, registry)
          └─ （等待 load_startup）

② 启动加载
McpLoader.load_startup()
    ├─ 过滤 enabled
    ├─ asyncio.gather(_connect_server × N, return_exceptions=True)
    │     └─ 每个 _connect_server：
    │           ├─ _get_env_guard() → EnvFilter.check_env
    │           ├─ _build_connection
    │           ├─ MultiServerMCPClient
    │           ├─ asyncio.wait_for(client.get_tools(), timeout)
    │           ├─ _clients[name] = client
    │           └─ _register_tools(server, tools)
    │                 ├─ include / exclude 过滤
    │                 ├─ DescriptionScanner.scan_description
    │                 └─ registry.register(ToolEntry)
    │
    ├─ 失败 server → mark_unhealthy
    └─ return all_tools

③ 运行（工具调用）
McpAuditMiddleware.awrap_tool_call
    ├─ registry.get(tool_name) → entry（含 breaker）
    ├─ entry.breaker.allow_call()
    ├─ handler(request)
    ├─ 成功 → record_success / 失败 → record_failure
    └─ 错误脱敏：loader.sanitizer.sanitize_error(...)

④ 刷新（CLI /mcp reload / 周期性）
McpLoader.refresh()
    ├─ _lock
    └─ 重连所有 server

⑤ 退出（bootstrap shutdown）
McpLoader.shutdown()
    └─ 逐 client.__aexit__
```

### 0.5. 补充

**`loader.py` 是 MCP 的连接生命周期管理器——启动时并行连接所有 enabled server（经安全守卫过滤后注册工具），运行时按需 refresh，退出时清理连接。**

几条主线：

- **eager 并行加载**：`load_startup` 用 `asyncio.gather` **并行连接**所有 server，**单 server 失败不阻塞**（`return_exceptions=True` + 逐个处理）——保证一个坏 server 不拖垮整个 MCP 加载。
- **安全守卫两件套**：连接前 `EnvFilter.check_env`（过滤环境变量），注册前 `DescriptionScanner.scan_description`（扫描可疑描述）——**两道防线**。
- **include/exclude 过滤**：`_register_tools` 按 server 配置的 `include_tools`（白名单优先）/ `exclude_tools`（黑名单）过滤工具——**按需裁剪工具集**。
- **连接超时保护**：`asyncio.wait_for(client.get_tools(), timeout=server.connect_timeout)`——避免单个 server 卡死。
- **失败传播有层次**：单 server 失败 → `logger.error` + `mark_unhealthy`（工具标记为不健康），其余继续；**不整体失败**。
- **refresh 是简化实现**：注释明确"重新连接所有 server"（`registry.register` 幂等）——生产级可优化为"仅重连 breaker 非 closed 的"。
- **幂等注册**：`registry.register` 同名先入者保留——refresh 时不会重复注册。
- **shutdown 用 SDK 的 `__aexit__`**：清理 `MultiServerMCPClient` 连接——SDK 负责实际断开。
- **sanitizer 外露**：`loader.sanitizer` 供 `McpAuditMiddleware` 用（错误脱敏），**不在加载阶段应用**——因为脱敏发生在工具调用时。
- **transport 映射**：config 层的 `http` → SDK 的 `streamable_http`（字段名适配）——这是 config 与 SDK 的接口对齐点。
- **与 McpAuditMiddleware 的分工**：本文件管**静态连接 + 注册**；`McpAuditMiddleware` 管**动态调用 + 熔断 + 审计**——一个"装载"，一个"运行"。
- **与 config.py 的分工**：`config.py` 读 YAML → `McpConfig`；本文件消费 `McpConfig` → 实际连接 server——配置与执行的分离。
