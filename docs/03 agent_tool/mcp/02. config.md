---

name: MCP 配置层 — YAML 加载 + ${ENV} 插值 + .env 开关。

desvription: 

【整体职责】
负责 MCP 配置的加载、解析与保存：从 YAML 读取 server 定义、对 ${VAR} 做宿主 env
插值、按 POIROT_MCP_ENABLED 开关决定是否启用，并把配置写回 YAML（敏感值转占位符）。

【内容摘要】
- _DEFAULT_CONFIG_PATH / _ENV_PATTERN / _CREDENTIAL_VALUE_PATTERNS : 常量与正则。
- McpServerConfig           : 单个 MCP server 配置（frozen 语义的数据类）。
- McpConfig                 : MCP 管理模块顶层配置。
- _interpolate_env / _interpolate_recursive : ${VAR} 插值。
- _parse_server             : dict → McpServerConfig（字段校验宽松）。
- load_mcp_config           : 从 YAML 加载 McpConfig。
- _is_credential_value / _to_env_placeholder / _sanitize_server_dict : 敏感值处理。
- save_mcp_config           : 写回 YAML（敏感值转 ${VAR} 占位符）。

【职责边界】
- 只负责：MCP 配置的加载、解析、插值、保存。
- 不负责：MCP server 的连接与工具加载（loader / registry）、
  MCP 工具的调用与审计（McpAuditMiddleware）、工具过滤的实际执行（registry）。

## 0. 结构树

### 0.1. 静态结构树

```
config.py — MCP 配置层（YAML 加载 + ${ENV} 插值 + .env 开关）
│
├─ 模块级常量
│   ├─ _DEFAULT_CONFIG_PATH = ".poirot/mcp_servers.yaml"   ← 缺省配置路径
│   ├─ _ENV_PATTERN = r"\$\{([A-Z_][A-Z0-9_]*)\}"          ← ${VAR} 匹配正则
│   └─ _CREDENTIAL_VALUE_PATTERNS: list[re.Pattern]         ← 凭证值模式
│       ├─ ^ghp_[A-Za-z0-9]{36}$                            ← GitHub token
│       ├─ ^sk-[A-Za-z0-9]{20,}$                            ← OpenAI key
│       ├─ ^Bearer\s+[A-Za-z0-9._\-]+$                      ← Bearer token
│       └─ ^token=[A-Za-z0-9]+$                             ← token= 形式
│
├─ McpServerConfig(dataclass)                ← 单个 MCP server 配置
│   ├─ name / transport                      ← 名 / 传输（stdio|sse|http）
│   ├─ command / args / env                  ← stdio 模式字段
│   ├─ url / headers                         ← sse / http 模式字段
│   ├─ enabled / timeout / connect_timeout   ← 开关 / 超时
│   └─ include_tools / exclude_tools         ← 工具过滤（include 优先）
│
├─ McpConfig(dataclass)                      ← 顶层配置
│   ├─ servers: dict[name, McpServerConfig]  ← 各 server 配置
│   ├─ fallback_chains: dict[tool, list]     ← 主→备链（熔断 fallback）
│   ├─ core_tools: list[str]                 ← 启动必加载工具
│   └─ tool_metadata: dict[tool, dict]       ← 工具元数据（供外化层调阈值）
│
├─ _interpolate_env(value) -> str            ← ${VAR} → env 值
│   └─ 未设则原样保留
│
├─ _interpolate_recursive(obj) -> object     ← 递归插值（str / list / dict）
│
├─ _parse_server(name, raw) -> McpServerConfig ← dict → 配置
│   ├─ transport 校验（非法 → stdio + warning）
│   ├─ tools.include / tools.exclude 解析
│   └─ 空值防御（YAML 空 `env:` → None，用 `or {}` 兜底）
│
├─ load_mcp_config(config_path=None) -> McpConfig ← 【主入口：加载】
│   ├─ 路径解析：参数 > env > 缺省（相对 cwd）
│   ├─ 文件不存在 → 空 McpConfig + warning
│   ├─ 解析失败 → 空 McpConfig + error
│   ├─ 根非 dict → 空 McpConfig + error
│   ├─ _interpolate_recursive(raw)（插值）
│   ├─ servers → _parse_server × N
│   ├─ fallback_chains / core_tools / tool_metadata
│   └─ return McpConfig
│
├─ _is_credential_value(value) -> bool       ← 值是否匹配凭证模式
│
├─ _to_env_placeholder(key) -> str           ← key → ${KEY}
│
├─ _sanitize_server_dict(server) -> dict     ← 配置 → dict（敏感值转占位符）
│   ├─ stdio：command / args / env（env 敏感值转 ${VAR}）
│   └─ sse/http：url / headers（headers 敏感值转 ${VAR}）
│
└─ save_mcp_config(config, config_path=None) -> None ← 【主入口：保存】
    ├─ 路径解析（同 load）
    ├─ _sanitize_server_dict × N（敏感值脱敏）
    ├─ mkdir(parents=True, exist_ok=True)
    ├─ yaml.safe_dump（覆盖写，丢注释）
    └─ 失败 logger.error（不抛）
```

### 0.2. 加载 / 保存流程树

```
【加载流程 load_mcp_config】
config_path（参数 | POIROT_MCP_CONFIG_PATH | .poirot/mcp_servers.yaml）
    │
    ▼
Path 解析（相对 → cwd 拼接）
    │
    ├─ 不存在 → McpConfig()（空）+ warning
    │
    ▼
yaml.safe_load
    ├─ YAMLError / OSError → McpConfig()（空）+ error
    ├─ 根非 dict → McpConfig()（空）+ error
    │
    ▼
_interpolate_recursive（${VAR} 插值）
    │
    ▼
解析各段：
    ├─ servers → _parse_server(name, spec) × N
    │     ├─ transport 校验（非法 → stdio + warning）
    │     ├─ tools.include / tools.exclude
    │     └─ 空值防御
    ├─ fallback_chains → dict[tool, list]
    ├─ core_tools → list
    └─ tool_metadata → dict
    │
    ▼
McpConfig(servers, fallback_chains, core_tools, tool_metadata)

【保存流程 save_mcp_config】
McpConfig
    │
    ▼
_sanitize_server_dict × N（敏感值 → ${VAR}）
    │
    ▼
组装 data：servers + fallback_chains + core_tools + tool_metadata
    │
    ▼
mkdir(parents=True, exist_ok=True)
    │
    ▼
yaml.safe_dump（allow_unicode=True, sort_keys=False）
    │
    ├─ OSError / YAMLError → logger.error（不抛）
    └─ 成功 → logger.info
```

### 0.3. 运行时调用树

```
① 装配阶段（bootstrap）
bootstrap / build_mcp_manager
    ├─ 检查 POIROT_MCP_ENABLED（false → 返 None，不加载）
    ├─ load_mcp_config(config_path)
    │     ├─ 路径解析 → yaml.safe_load → 插值 → 解析
    │     └─ return McpConfig
    │
    └─ 用 McpConfig 构造 McpManager（连接 server、加载工具）

② 运行阶段（MCP 工具被调用）
McpAuditMiddleware.awrap_tool_call
    ├─ registry 取 entry（含 breaker / source）
    ├─ 熔断检查 → 调工具 → 审计
    └─ 写 journal "tool.call"（args_summary / status / duration_ms / ...）
          └─ 凭证脱敏：CredentialSanitizer.sanitize_error

③ 配置修改（CLI / TUI）
    └─ save_mcp_config(config)
          ├─ 敏感值转 ${VAR} 占位符
          └─ yaml.safe_dump（覆盖写）

④ 插值时机
load_mcp_config 内 _interpolate_recursive
    └─ ${VAR} → os.environ[VAR]（未设则原样保留）
```

### 0.4. 补充

**`config.py` 是 MCP 的配置层——从 YAML 加载 server 定义、对 `${VAR}` 做宿主 env 插值、按开关决定是否启用，并把配置写回 YAML（敏感值转占位符）。**

几条主线：

- **开关优先**：`POIROT_MCP_ENABLED=false`（缺省）→ 不加载 MCP，`build_mcp_manager` 返 None——MCP 是 opt-in 能力。
- **加载永不抛**：文件不存在 / 解析失败 / 根非 dict，一律返**空 `McpConfig`** + logger 降级——保证缺件不影响主流程。
- **`${VAR}` 插值**：YAML 内 `${VAR}` 从宿主 env 取值（未设则原样保留）——避免把凭证硬编码进 YAML。
- **transport 三分支**：`stdio`（command/args/env）、`sse` / `http`（url/headers）；非法 transport 回退 `stdio` + warning。
- **空值防御**：YAML 的 `env:`（空值）解析为 `None`，代码用 `or {}` / `or []` 兜底——应对 YAML 的宽松语法。
- **敏感值脱敏（保存时）**：`save_mcp_config` 用 `_CREDENTIAL_VALUE_PATTERNS` 匹配凭证值（GitHub token / OpenAI key / Bearer / token=），命中则转 `${KEY}` 占位符——**防止凭证落盘**。
- **两入口对称**：`load_mcp_config`（读）与 `save_mcp_config`（写）路径解析逻辑一致；写用 `yaml.safe_dump` 覆盖（丢注释），失败只 log 不抛。
- **配置三块扩展**：`servers`（server 定义）+ `fallback_chains`（熔断 fallback）+ `core_tools`（启动必加载）+ `tool_metadata`（供外化层调阈值）。
- **与 McpAuditMiddleware 的分工**：本文件管**配置**（YAML 读写 / 插值 / 脱敏）；`McpAuditMiddleware` 管**运行时**（熔断 / 审计 / 凭证脱敏回 LLM）——一个静态配置，一个动态执行。
