---

name: MCP 管理模块层 — 配置化注册、熔断器、fallback、安全层、审计。

desvription: 

【整体职责】
作为 MCP 子系统的对外门面与公共 API 聚合点：把 config（YAML 配置）、registry
（工具注册表）、loader（连接生命周期）、audit（审计中间件）聚合成 McpManager，
并提供 build_mcp_manager 工厂（读开关 + 加载配置）。

【内容摘要】
- McpManager.__init__          : 聚合 config / registry / loader / audit。
- McpManager.load_startup      : eager 并行连接所有 enabled server。
- McpManager.add_server        : 运行时加载单个 server（串行加锁）。
- McpManager._persist_server   : 持久化 server 配置到 YAML。
- McpManager.list_servers      : 返回 server 列表 + 状态（供 TUI）。
- McpManager.get_tools         : 按 group 返回工具列表（供 agent 注入）。
- McpManager.get_audit_middleware : 供 middleware 链注入。
- McpManager.registry / loader : 暴露内部组件（供外化层 / reload）。
- McpManager.shutdown          : 清理所有连接。
- build_mcp_manager            : 从 .env 开关 + YAML 构建 McpManager。

【职责边界】
- 只负责：聚合各组件、提供对外 API、编排加载/清理。
- 不负责：各组件内部实现（config / registry / loader / audit 各模块）、
  工具的运行时调用与熔断（McpAuditMiddleware + CircuitBreaker）。

### 0.2. 装配与加载树

```
【装配（bootstrap）】
build_mcp_manager(config_path=None)
    ├─ 读 POIROT_MCP_ENABLED（false → None）
    ├─ 读 POIROT_MCP_CONFIG_PATH
    └─ McpManager(config)
          ├─ ToolRegistry(config)                        ← registry.py
          ├─ McpLoader(config, registry)                 ← loader.py
          │     └─ guards 默认 [EnvFilter, DescriptionScanner]
          │     └─ _sanitizer = CredentialSanitizer
          └─ McpAuditMiddleware(registry, loader.sanitizer) ← audit.py
                └─ _add_lock = asyncio.Lock

【加载（load_startup）】
McpManager.load_startup()
    └─ McpLoader.load_startup()
          ├─ 过滤 enabled server
          └─ asyncio.gather(_connect_server × N, return_exceptions=True)
                └─ 每个 server：
                      ├─ _get_env_guard() → EnvFilter
                      ├─ EnvFilter.check_env(server.env)     ← 安全①：env 过滤
                      ├─ _build_connection(server, filtered_env)
                      ├─ MultiServerMCPClient({name: connection})
                      ├─ asyncio.wait_for(get_tools, timeout)
                      ├─ _clients[name] = client
                      └─ _register_tools(server, tools)
                            ├─ include / exclude 过滤
                            ├─ _get_description_guard() → DescriptionScanner
                            ├─ DescriptionScanner.scan_description ← 安全②：描述扫描
                            └─ registry.register(ToolEntry(breaker=CircuitBreaker())) ← health.py
```

### 0.3. 运行时调用树（工具调用）

```
【工具调用】
Agent 调 MCP 工具
    │
    ▼
McpAuditMiddleware.awrap_tool_call(request, handler)
    ├─ tool_call / tool_name / runtime ← 从 request 取
    ├─ entry = registry.get(tool_name)
    ├─ start = time.time()
    │
    ├─【熔断检查】
    │     └─ entry.breaker.allow_call()
    │           ├─ False → _audit(status="circuit_open")
    │           │         + return ToolMessage(status="error")
    │           └─ True  → 继续
    │
    ├─【调工具】
    │     └─ await handler(request)
    │           ├─ 成功：
    │           │     ├─ entry.breaker.record_success()
    │           │     ├─ _audit(status="ok")
    │           │     │     └─ 外化联动：result 含 POIROT_EXTERNALIZED
    │           │     │           → event["externalized"] = True
    │           │     └─ return result
    │           │
    │           └─ 失败：
    │                 ├─ entry.breaker.record_failure()
    │                 ├─ sanitized = _sanitizer.sanitize_error(str(exc)) ← 安全③：错误脱敏
    │                 ├─ _audit(status="error", error=sanitized)
    │                 └─ re-raise（交 ToolCallMiddleware 转 ToolMessage）
    │
    └─ _audit → _emit(runtime, "tool.call", event)
          └─ journal.append("tool.call", {tool_name, source,
                                          args_summary, status,
                                          duration_ms, error?, externalized?})
```

### 0.8. 补充

**`mcp/` 是外部工具服务器的接入层——六个模块覆盖 MCP 全生命周期：配置 → 加载 → 注册 → 熔断 → 审计 → 安全。**

几条主线：

- **六层职责清晰**：
  - **配置层**（`config.py`）— YAML 加载 + 插值 + 保存；
  - **加载层**（`loader.py`）— eager 并行连接 + 工具发现 + 注册；
  - **注册层**（`registry.py`）— 工具条目 + 分组 + 健康标记；
  - **健康层**（`health.py`）— CircuitBreaker 熔断器；
  - **审计层**（`audit.py`）— McpAuditMiddleware（熔断 + 审计 + 脱敏）；
  - **安全层**（`guards/`）— 3 个 guard（EnvFilter / CredentialSanitizer / DescriptionScanner）。
- **门面聚合**：`McpManager` 把 config / registry / loader / audit 聚合成一个入口，`build_mcp_manager` 是工厂（opt-in）。
- **三条设计主线**：
  - **opt-in**：`POIROT_MCP_ENABLED=false`（缺省）→ 不加载；
  - **eager 并行 + 失败隔离**：`asyncio.gather` + 单 server 失败不阻塞；
  - **三层安全 + 双层熔断**：3 个 guard 覆盖 3 节点 + CircuitBreaker 工具级 + McpAuditMiddleware 调用级。
- **安全层是"一 guard 一接口"**：`EnvFilter`（env）/ `CredentialSanitizer`（错误）/ `DescriptionScanner`（描述）各管一段，其余 no-op——可组合、可扩展。
- **两个装载渠道**：`EnvFilter` / `DescriptionScanner` 在 `loader._guards`；`CredentialSanitizer` 在 `loader._sanitizer`（供 `McpAuditMiddleware`）。
- **与其他工具来源平行**：MCP 与 builtin（agent_tools）/ sandbox（sandbox）并列，最终都汇聚为 `list[BaseTool]` → `create_agent`。
- **与中间件链衔接**：`McpAuditMiddleware` 挂在 `wrap_tool_call` 洋葱上，与 `RunJournalMiddleware` / `SkillMetricsMiddleware` / `ToolCallMiddleware` 同链协作。
- **配置与执行分离**：`config.py` 管静态配置，`loader.py` 管实际连接，`audit.py` 管运行时——**三层各司其职**。

## 1. 概述

**MCP（Model Context Protocol）是 Poirot 接入"外部工具服务器"的标准协议层——让 Agent 能调用外部 MCP server 提供的工具（如 web_search_mcp、browser 等），并通过配置、连接生命周期、安全守卫、熔断审计四件套把这条外部工具链管住。**

```
├─ health.py                 ← 【健康层】CircuitBreaker 熔断器
├─ audit.py                  ← 【审计层】McpAuditMiddleware
├─ guards/                   ← 【安全层】EnvFilter / CredentialSanitizer / DescriptionScanner
└─ __init__.py               ← 【门面】McpManager + build_mcp_manager
```

**六层各管一段**——配置 → 加载 → 注册 → 熔断 → 审计 → 安全。

## 4. 逐层职责

### 4.1. `config.py` — 配置层

```
职责：从 YAML 读 server 定义、插值 ${VAR}、按开关决定启用

输入：.poirot/mcp_servers.yaml
输出：McpConfig（servers / fallback_chains / core_tools / tool_metadata）

关键点：
├─ POIROT_MCP_ENABLED=false（缺省）→ 不加载（opt-in）
├─ ${VAR} 从宿主 env 插值（避免凭证硬编码进 YAML）
├─ transport 三分支：stdio / sse / http
├─ 加载永不抛（文件不存在 / 解析失败 → 空 McpConfig）
└─ 保存时敏感值转 ${VAR} 占位符（防凭证落盘）
```

**YAML 结构**：
```yaml
servers:
  web_search:
    transport: stdio
    command: npx
    args: ["-y", "@modelcontextprotocol/server-web-search"]
    env:
      API_KEY: ${WEB_SEARCH_API_KEY}   # 插值
    tools:
      include: [search, fetch]          # 白名单
fallback_chains:
  web_search: [web_search_mcp:search]   # 熔断时备用
core_tools: [web_search]
tool_metadata:
  web_search:
    typical_output_tokens: 500
    source: mcp
```

### 4.2. `loader.py` — 加载层

```
职责：连接 server、发现工具、注册工具（经安全守卫）

流程：
├─ load_startup()  并行连接所有 enabled server（gather，单 server 失败不阻塞）
├─ refresh()        重连（简化实现：全部重连，registry 幂等）
└─ shutdown()       清理连接（client.__aexit__）

per server 流程：
├─ EnvFilter.check_env(server.env)        ← 安全①：env 过滤
├─ MultiServerMCPClient({name: connection})
├─ asyncio.wait_for(client.get_tools(), timeout)
├─ DescriptionScanner.scan_description    ← 安全②：描述扫描
└─ registry.register(ToolEntry)
```

**关键点**：
- **eager 并行**：`asyncio.gather` 并行连接，**单 server 失败不阻塞**；
- **安全守卫两个时机**：连接前（env）、注册前（描述）；
- **超时保护**：`connect_timeout` 限制单 server 连接。

### 4.3. `registry.py` — 注册层

```
职责：存储工具条目、按 group 分组、维护健康状态

ToolEntry（工具条目）：
├─ tool: BaseTool            ← 工具本体
├─ source: "mcp"             ← 来源标记
├─ server_name: str          ← 所属 server
├─ metadata: dict            ← tool_metadata（供外化层调阈值）
└─ breaker: CircuitBreaker   ← 每工具一个熔断器

ToolRegistry：
├─ register(entry) -> bool    ← 注册（幂等，同名先入者保留）
├─ get(tool_name) -> entry    ← 取条目（含 breaker）
├─ get_tools_by_group(groups) ← 按 group 返回工具
└─ mark_unhealthy(tool_name)  ← 标记不健康（server 连接失败时）
```

### 4.4. `health.py` — 健康层（熔断器）

```
职责：每个工具一个健康状态机（closed / open / half_open）

CircuitBreaker：
├─ allow_call() -> bool        ← 是否放行（含状态转换）
├─ record_success() -> None    ← 成功归零 + closed
└─ record_failure() -> None    ← 失败计数 + 触发 open

状态机：
├─ closed    连续失败 3 次 → open
├─ open      冷却 60s → half_open（放 1 次探针）
└─ half_open 探针成功 → closed；失败 → 重置 open

关键点：
├─ 被动触发（不主动 ping，调用时判定）
├─ 线程安全（_lock 保护）
└─ __slots__ 省内存（每工具一个实例）
```

### 4.5. `audit.py` — 审计层（McpAuditMiddleware）

```
职责：包住工具调用（wrap_tool_call）——熔断检查 + 审计 + 脱敏

流程：
├─ 熔断检查：breaker.allow_call()
│     ├─ False → 返回 error ToolMessage + 记 circuit_open
│     └─ True  → 继续
├─ handler(request) 调工具
│     ├─ 成功 → record_success + 记 ok
│     └─ 失败 → record_failure + sanitize_error（脱敏）+ 记 error + re-raise
└─ 写 journal "tool.call"（tool_name / source / args_summary /
                          status / duration_ms / error / externalized）
```

**关键点**：
- **统一拦截所有工具**（不限于 MCP）——但主要用于 MCP 工具的熔断 + 审计；
- **凭证脱敏**：错误信息经 `CredentialSanitizer` 清洗后才回 LLM；
- **外化联动**：工具结果含 `POIROT_EXTERNALIZED` 标记时，事件加 `externalized` 字段。

### 4.6. `guards/` — 安全层

```
契约：SecurityGuard Protocol（3 接口）
├─ check_env          → 过滤环境变量
├─ sanitize_error     → 脱敏错误信息
└─ scan_description   → 扫描工具描述

三个实现（各管一段）：
├─ EnvFilter            check_env（连接前）
├─ CredentialSanitizer  sanitize_error（出错时）
└─ DescriptionScanner   scan_description（注册前）
```

**关键点**：
- **一 guard 一接口**——各实现只关心自己那一个，其余 no-op；
- **三节点覆盖**：连接前 / 注册前 / 出错时；
- **可扩展**：新增 guard 实现 Protocol 即可。

### 4.7. `__init__.py` — 门面

```
McpManager（门面）：
├─ load_startup()             eager 并行连接
├─ add_server(config) -> bool 运行时加 server（串行加锁）
├─ list_servers() -> list     给 TUI 面板展示
├─ get_tools(groups) -> list  供 agent 注入
├─ get_audit_middleware()     供 middleware 链注入
├─ registry / loader          暴露内部组件
└─ shutdown()                 清理连接

build_mcp_manager(config_path=None) -> McpManager | None
├─ 读 POIROT_MCP_ENABLED（缺省 false）
├─ 读 POIROT_MCP_CONFIG_PATH
└─ enabled=false 或无配置 → None（opt-in）
```

## 5. 完整数据流

```
【装配阶段（bootstrap）】
build_mcp_manager()
    ├─ 读 POIROT_MCP_ENABLED（false → None）
    ├─ load_mcp_config() → McpConfig          ← config.py
    └─ McpManager(config)
          ├─ ToolRegistry(config)             ← registry.py
          ├─ McpLoader(config, registry)      ← loader.py
          └─ McpAuditMiddleware(registry, sanitizer)  ← audit.py

【加载阶段】
McpManager.load_startup()
    └─ McpLoader.load_startup()
          └─ asyncio.gather(_connect_server × N)
                └─ 每个 server：
                      ├─ EnvFilter.check_env              ← guards
                      ├─ MultiServerMCPClient + get_tools
                      ├─ DescriptionScanner.scan_description ← guards
                      └─ registry.register(ToolEntry)
                            └─ 每工具创建 CircuitBreaker   ← health.py

【运行阶段（工具调用）】
Agent 调 MCP 工具
    └─ McpAuditMiddleware.awrap_tool_call
          ├─ registry.get(tool_name) → entry
          ├─ entry.breaker.allow_call()
          │     ├─ False → error ToolMessage + circuit_open
          │     └─ True  → handler(request)
          ├─ 成功 → record_success + 记 ok
          └─ 失败 → record_failure + CredentialSanitizer + 记 error
                └─ re-raise → ToolCallMiddleware 转 ToolMessage

【清理阶段（shutdown）】
McpManager.shutdown()
    └─ McpLoader.shutdown()
          └─ client.__aexit__ × N
```

| 层 | 文件 | 职责 | 关键不变量 |
|---|---|---|---|
| **配置层** | `config.py` | YAML 加载 / 插值 / 保存 | opt-in、加载永不抛、敏感值转占位符 |
| **加载层** | `loader.py` | 连接 / 发现 / 注册 | eager 并行、单 server 失败不阻塞 |
| **注册层** | `registry.py` | 工具条目 / 分组 / 健康 | 幂等注册、每工具一个 breaker |

| **门面** | `__init__.py` | 聚合 + 对外 API | opt-in、生命周期管理 |

## 7. 三条设计主线

### 主线一：**opt-in（默认关闭）**

```
POIROT_MCP_ENABLED=false（缺省）
    → build_mcp_manager 返 None
    → 不加载 MCP，行为不变
```

**MCP 是可选能力**——没配置就走原有流程，不影响主链路。

### 主线二：**eager 并行 + 失败隔离**

```
load_startup
    └─ asyncio.gather(return_exceptions=True)
          ├─ server A 成功 → 注册工具
          ├─ server B 失败 → mark_unhealthy（不阻塞）
          └─ server C 成功 → 注册工具
```

**一个坏 server 不拖垮整个 MCP 加载**——保证健壮性。

### 主线三：**三层安全 + 双层熔断**

```
安全层（3 个 guard）：
├─ 连接前 → EnvFilter          （防 secrets 泄漏）
├─ 注册前 → DescriptionScanner （防 prompt injection）
└─ 出错时 → CredentialSanitizer（防密钥泄漏）

熔断层（双层）：
├─ 工具级 → CircuitBreaker      （每工具一个状态机）
└─ 调用级 → McpAuditMiddleware  （调用前检查 + 调用后联动）
```

**安全贯穿全程，熔断分两层**——静态安全 + 动态健康。

## 9. 总结

> **MCP 是 Poirot 接入外部工具服务器的协议层——六个模块覆盖全生命周期**：
> - **`config.py`** — 配置（YAML 加载 + `${VAR}` 插值 + 敏感值占位符）；
> - **`loader.py`** — 加载（eager 并行连接 + 工具发现 + 注册）；
> - **`registry.py`** — 注册（工具条目 + 分组 + 健康标记）；
> - **`health.py`** — 熔断（CircuitBreaker 三态状态机）；
> - **`audit.py`** — 审计（McpAuditMiddleware：熔断检查 + 审计 + 脱敏）；
> - **`guards/`** — 安全（EnvFilter / CredentialSanitizer / DescriptionScanner）；
> - **`__init__.py`** — 门面（McpManager + build_mcp_manager）。
>
> **三条设计主线**：**opt-in（默认关闭）** + **eager 并行 + 失败隔离** + **三层安全 + 双层熔断**。
>
> **数据流**：`build_mcp_manager` → `McpManager.load_startup` → `McpLoader._connect_server`（经 guards）→ `registry.register`（含 breaker）→ Agent 调用 → `McpAuditMiddleware.awrap_tool_call`（熔断 + 审计 + 脱敏）→ `shutdown` 清理。
