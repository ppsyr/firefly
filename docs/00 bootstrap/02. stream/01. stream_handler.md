---

name: stream_handler — StreamEvent → rich 渲染。

description:

【整体职责】
消费 PoirotStreamClient 产出的 StreamEvent，用 rich Console 实时渲染流式输出的
各类事件：thinking（折叠计时）、answer（累积后 Markdown 渲染）、tool_start/end
（spinner + 摘要）、error、done（分隔线 + 耗时尾行）、compaction 系列，
并把 budget_update 透传给 cli_state 供 bottom_toolbar 刷新。

【内容摘要】
- _truncate_args       : 截断工具参数为摘要字符串。
- _result_summary      : 截断工具结果为摘要。
- _tool_color          : 按工具名前缀分色。
- StreamRenderer       : 渲染器主类，render 分派各事件。
- StreamRenderer.render / render_user_input / expand_last_round
- 各 _render_* / _flush_thinking / _stop_spinner / _update_budget

【职责边界】
- 只负责：把 StreamEvent 渲染为 rich 输出、维护渲染态 state、透传 budget 到 cli_state。
- 不负责：事件的生产（stream_service）、cli_state 的初始化与生命周期（main）、
  状态栏渲染（status_bar）、流式驱动（PoirotStreamClient）。

## 0. 结构树

### 0.1. 静态结构树

```
stream_handler.py — StreamEvent → rich 渲染
│
├─ _truncate_args(args) -> str                ← 截断工具参数为摘要
│   └─ 去 type 字段，单值 ≤50，整体 ≤120
│
├─ _result_summary(result) -> str             ← 截断工具结果为摘要
│   └─ None → "ok"；≤80 原样；否则 [:77]+"..."
│
├─ _tool_color(tool_name) -> str              ← 按工具名前缀分色
│   ├─ search*    → "cyan"
│   ├─ fetch*     → "blue"
│   ├─ write*     → "yellow"
│   └─ 其他       → "dim"
│
└─ StreamRenderer                             ← 渲染器主类
    ├─ __init__(console, cli_state)           ← 初始化 + state 字典
    │   └─ state:
    │       ├─ full_answer / tool_results / thinking_enabled / _live
    │       ├─ thinking_log / _thinking_t0 / _thinking_buffer
    │       └─ round_t0 / model
    │
    ├─ render(event)                          ← 事件分派主入口
    │   ├─ budget_update → _update_budget（仅透传，不渲染）
    │   ├─ 新轮首个事件 → 清上一轮 state（保留 tool_results）
    │   ├─ thinking 切出 → _flush_thinking
    │   └─ 按 type 分派：
    │       ├─ thinking            → _render_thinking
    │       ├─ answer              → _render_answer
    │       ├─ tool_start          → _render_tool_start
    │       ├─ tool_end            → _render_tool_end
    │       ├─ done                → _render_done
    │       ├─ error               → _render_error
    │       ├─ compaction_start    → _render_compaction_start
    │       ├─ compaction_progress → _render_compaction_progress
    │       └─ compaction_end      → _render_compaction_end
    │
    ├─ 【thinking 段】
    │   ├─ _render_thinking(event)            ← 累积 token + 首个启动计时
    │   └─ _flush_thinking()                  ← 输出 "+ Thought: {ms}ms" + 存 log
    │
    ├─ 【answer 段】
    │   └─ _render_answer(event)              ← 仅累积 full_answer
    │
    ├─ 【工具段】
    │   ├─ _render_tool_start(event)          ← 停旧 spinner + 开新 spinner
    │   └─ _render_tool_end(event)            ← 停 spinner + ✓ 摘要 + 存全文
    │
    ├─ 【结束 / 错误】
    │   ├─ _render_done()                     ← Markdown 渲染 + 耗时尾行 + 分隔线 + 清理
    │   └─ _render_error(event)               ← 停 spinner + 红色错误
    │
    ├─ 【压缩段】
    │   ├─ _render_compaction_start(event)
    │   ├─ _render_compaction_progress(event)
    │   └─ _render_compaction_end(event)
    │
    ├─ render_user_input(text)                ← 用户输入卡片回显（Panel）
    ├─ expand_last_round()                    ← /expand：展开 Thought + 工具结果
    ├─ _stop_spinner()                        ← 停止 Live spinner
    └─ _update_budget(event)                  ← budget → cli_state（供 toolbar）
```

### 0.2. 事件 → 渲染行为 视图

```
StreamEvent.type          渲染行为                                      输出示例
─────────────────────────────────────────────────────────────────────────────────────
thinking            累积（不逐 token 输出）                         （暂不输出）
                    → 切出时 _flush_thinking                      + Thought: 1234ms
answer              累积 full_answer                              （暂不输出）
                    → done 时统一 Markdown                        （Markdown 渲染）
tool_start          开 Live spinner                              ⠋ web_search(...)...
tool_end            停 spinner + ✓ 摘要                             ✓ web_search → ...
done                停 spinner + Markdown + 耗时尾行 + 分隔线       ■ Build · model · 3.2s
error               停 spinner + 红色错误                          ✗ error
compaction_start    dim 提示                                    [compaction] 触发...
compaction_progress dim 进度                                    [compaction] 进度...
compaction_end      dim 完成 + saved                            [compaction] 完成 (saved=...)
budget_update       仅透传 cli_state（供 toolbar 刷新）              （不输出 console）
```

### 0.3. 运行时调用树

```
① 主循环绑定（main._run_chat_async）
main._run_chat_async
    ├─ renderer = StreamRenderer(console, cli_state)
    │     └─ state 初始化
    └─ renderer.state["round_t0"] = time.monotonic()   ← 注入轮次起始时间
    └─ renderer.state["model"] = _resolve_actual_model_name(...)

② 用户提交输入
    └─ renderer.render_user_input(prompt)              ← 卡片回显

③ 流式研究（async for）
    └─ async for event in client.stream(prompt):
          └─ renderer.render(event)
                ├─ budget_update → _update_budget → cli_state（供 status_bar）
                │     └─ status_bar.build_bottom_toolbar(cli_state) ← prompt_toolkit 轮询
                │
                ├─ thinking → _render_thinking（累积）
                │     └─ 切换时 _flush_thinking → console.print(+ Thought)
                │
                ├─ answer → _render_answer（累积）
                │
                ├─ tool_start → _render_tool_start
                │     └─ Live(Spinner).start()
                │
                ├─ tool_end → _render_tool_end
                │     ├─ _stop_spinner()
                │     └─ console.print(✓ 摘要)
                │
                ├─ done → _render_done
                │     ├─ _stop_spinner()
                │     ├─ console.print(Markdown(full_answer))
                │     ├─ console.print(■ Build · model · elapsed)
                │     └─ console.print(分隔线)
                │
                ├─ error → _render_error（红字）
                │
                └─ compaction_* → 对应 _render_compaction_*
                      └─ dim 提示

④ /expand 命令
main._run_chat_async → handle_command → renderer.expand_last_round()
    ├─ 展开 thinking_log（Panel）
    └─ 展开 tool_results（Panel）

⑤ /thinking off
handle_command → cli_state / renderer.state["thinking_enabled"] = False
    └─ 后续 thinking 事件被跳过
```

### 0.4. 补充

**`stream_handler.py` 是流式事件的 rich 渲染器——把 `StreamEvent` 分派到各 `_render_*`，用 rich 实时输出；`budget_update` 只透传给 `cli_state`（供 `status_bar`），其余渲染到 console。**

几条主线：

- **渲染策略：thinking/answer 延迟输出**：两者逐 token **只累积不输出**；thinking 在切出时 flush 为 `+ Thought: {ms}ms`，answer 在 `done` 时统一 Markdown 渲染——避免逐 token 刷屏，也让 Markdown 能整体渲染。
- **state 是渲染态核心**：`full_answer` / `tool_results` / `thinking_log` / `_thinking_t0` / `_round_active` / `round_t0` / `model` 全在 `self.state`，是渲染器的"记忆"。
- **轮次生命周期**：新轮首个事件清上一轮 state（保留 `tool_results` 供 `/expand`）；`done` 时清理并输出耗时尾行 + 分隔线。
- **spinner 生命周期**：`tool_start` 开 `Live(transient=True)`，`tool_end` / `done` / `error` 停——保证 spinner 不残留。
- **budget_update 是纯透传**：注释明确"renderer 不直接渲染 budget 信息，展示归 status_bar"——这是 renderer 与 status_bar 的职责分工点，也是你在 main 里看到的 `cli_state` 回填的落点。
- **`_render_done` 调用 `_strip_skills_leak`**：从 `stream_service` 导入，说明渲染前会对 answer 做一次"技能泄漏"清理（去掉模型误输出的技能标记）。
- **`/expand` 提供回溯**：`thinking_log` 与 `tool_results` 保留原文，`expand_last_round` 用 Panel 展开——这是"折叠显示 + 按需展开"的交互设计。
- **compaction 系列独立**：上下文压缩的 start/progress/end 三种事件单独渲染（dim），与主回答流区分。
- **与 `status_bar` 的分工**：renderer 负责"消息流"（滚动输出），status_bar 负责"常驻状态栏"（bottom_toolbar）——两者通过 `cli_state` 解耦，`budget_update` 是它们之间的数据桥。
- **`_tool_color` 是展示策略**：按工具名前缀给 spinner 与 ✓ 行分色，让工具调用在输出中更易辨识。
