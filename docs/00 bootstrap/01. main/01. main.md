---

name: CLI 入口 — 命令行参数解析、启动配置与主循环。

description:

【整体职责】
Poirot 的进程入口：加载 .env、解析命令行（chat / cli / run 三种模式）、引导首次配置，
启动后进入交互主循环（TUI 或传统 CLI）。主循环负责用户输入 → 命令处理 → 意图识别 →
流式研究 → 报告触发，并维护 cli_state（模式 / 模型 / token 展示）。

【内容摘要】
- main                 : 入口，解析参数并分发到 run / cli / 默认 chat 三种模式。
- run_chat             : 启动 bootstrap，进入 TUI 或传统 CLI。
- _build_stream_config : 构造 graph config（供 stream 使用）。
- _run_chat_async      : 传统 CLI 主循环（prompt_toolkit + rich）。
- run_chat 内嵌：_print_status / _print_welcome / _handle_report_intent / _trigger_report。

【职责边界】
- 只负责：参数解析、启动编排、交互主循环、呈现（banner / welcome / Markdown 渲染）。
- 不负责：运行时装配（bootstrap）、Agent 执行与图逻辑（leader/agent）、
  报告合成逻辑（agents/reporting）、命令实现细节（commands）。

【INVARIANT】
- .env 显式从项目根加载：load_dotenv(_PROJECT_ROOT / ".env")，避免从非项目根启动时
  POIROT_SKILL_* 等配置缺失导致 skill 模块被误跳过。
- 首次启动引导：.env 不存在时先跑 ensure_config，失败返回 1。
- bootstrap 在 asyncio.run 之前（同步阶段）：避免 MCP 的 asyncio.run 嵌套。
- 三种模式：
  - 无子命令 → 默认 TUI（textual）；
  - cli       → 传统 CLI（prompt_toolkit + rich）；
  - run       → 单次提问，直接输出报告与 run_id / events / artifact。
- run 模式默认 expert：--expert 默认 True，--no-expert 关闭。
- 意图先于 graph：intent_tree.detect_and_dispatch 命中则不进 graph。
- run 生命周期：create_run → mark_running → stream → mark_success / mark_failed。
- 模式/模型热切换复用 thread_id + checkpointer state。
- Ctrl+C / Ctrl+D 在输入时退出进程；/exit、/quit 退出。

### 0.1. 静态结构树（重点展开 main）

```
main.py — CLI 入口（参数解析 / 启动编排 / 主循环）
│
├─ _PROJECT_ROOT: Path                        ← 项目根（parents[4]）
├─ load_dotenv(_PROJECT_ROOT / ".env")        ← 模块级加载 .env（避免 CWD 相对路径）
│
├─ main(argv) -> int                          ← 【核心】入口，解析参数并分发
│   │
│   ├─ ① 首次配置引导
│   │   ├─ from ...cli.setup_wizard import ensure_config
│   │   ├─ ensure_config(_PROJECT_ROOT) → False → return 1
│   │   └─ load_dotenv(_PROJECT_ROOT / ".env", override=True)
│   │
│   ├─ ② 参数解析（argparse）
│   │   ├─ 全局：--provider / --model
│   │   ├─ 子命令 run：
│   │   │   ├─ question（位置参数）
│   │   │   ├─ --expert（默认 True）/ --no-expert（关）
│   │   │   ├─ --thread-id（默认 "default-thread"）
│   │   │   ├─ --run-id / --logs-root / --no-artifact
│   │   └─ 子命令 cli
│   │
│   ├─ ③ 分发（按 args.command）
│   │   ├─ command is None   → run_chat(legacy=False)   ← 默认 TUI
│   │   ├─ command == "cli"  → run_chat(legacy=True)    ← 传统 CLI
│   │   ├─ command == "run"  → 【单次运行路径】
│   │   │   ├─ overrides ← logs_root / save_artifact=False
│   │   │   ├─ runtime = bootstrap_runtime(expert_mode=args.expert,   ← *装配并拿到runtime
│   │   │   │                                  provider, model, cli_overrides)
│   │   │   ├─ result = runtime.run_question(question, thread_id, run_id)
│   │   │   └─ print(final_report / run_id / events_jsonl / artifact_path)
│   │   │   └─ return 0
│   │   └─ 其他              → return 1
│   │
│   └─ 返回退出码
│
├─ run_chat(provider, model, legacy) -> int   ← 启动 bootstrap，选 TUI 或 CLI
│   ├─ stdout.reconfigure(utf-8)               ← 容错处理编码
│   ├─ runtime = bootstrap_runtime(provider, model) ← 同步阶段（避免 asyncio 嵌套）
│   ├─ legacy=False → PoirotTUI(runtime).run() ← TUI 全屏应用
│   └─ legacy=True  → asyncio.run(_run_chat_async(runtime, ...))
│
├─ _build_stream_config(runtime, run_context) -> dict ← graph config（stream 用）
│   ├─ configurable: expert_mode / run_id / thread_id / journal / output_dir /
│   │                plan_enabled / timezone / model
│   └─ recursion_limit = max_loop_steps * graph_node_multiplier
│
└─ _run_chat_async(runtime, provider, model) -> int ← 传统 CLI 主循环
    ├─ console = Console()
    ├─ cli_state: dict                          ← 主循环共享状态
    │   ├─ pending_expert_mode / pending_mcp_reload / pending_model_switch
    │   ├─ pending_report
    │   ├─ skill_override
    │   ├─ mode / model                         ← bottom_toolbar 展示
    │   └─ current_tokens / current_fraction / current_window ← 预算展示
    │
    ├─ _skill_names_provider()                  ← 闭包，供 /skill 补全（读最新 runtime）
    ├─ session = PromptSession(...)             ← prompt_toolkit 会话
    │   └─ completer=SlashCommandCompleter(get_registry(), skill_provider)
    │   └─ bottom_toolbar=lambda: build_bottom_toolbar(cli_state)
    ├─ renderer = StreamRenderer(console, cli_state)
    │
    ├─ _print_status()                          ← 打印当前 mode/model/thread
    ├─ _print_welcome()                         ← 加载 prompts/system/cli/welcome.md
    ├─ _handle_report_intent(intent, rt)        ← 报告意图 handler
    ├─ _trigger_report(topic, rt, con)          ← 手动触发报告（default 模式）
    │   └─ generate_report_from_thread(runtime, topic) → Markdown 渲染
    │
    ├─ intent_tree = default_intent_tree(report_handler=_handle_report_intent)
    ├─ console.print(render_banner("POIROT"))
    ├─ MCP 工具徽标                              ← 统计已加载 MCP 工具数
    ├─ _print_welcome()
    │
    └─ while True:                              ← 【主循环】
        ├─ 读输入（prompt_async）
        │   └─ EOFError / KeyboardInterrupt → return 0
        ├─ prompt 为空 → continue
        ├─ prompt ∈ {/exit, /quit} → return 0
        │
        ├─ prompt 以 "/" 开头 → 命令分支
        │   ├─ handle_command(...) → should_exit → return 0
        │   ├─ pending_expert_mode → runtime.switch_expert_mode + 同步 cli_state
        │   ├─ pending_report      → _trigger_report
        │   ├─ pending_mcp_reload  → runtime.reload_mcp_tools
        │   ├─ pending_model_switch→ runtime.switch_model
        │   └─ continue
        │
        ├─ renderer.render_user_input(prompt)   ← 卡片化回显
        │
        ├─ 意图识别（graph 之前）
        │   └─ intent_tree.detect_and_dispatch(prompt, runtime)
        │         └─ True（已处理）→ continue（不进 graph）
        │
        └─ 流式研究
            ├─ ctx = runtime.run_manager.create_run(...)
            ├─ runtime.run_manager.mark_running(ctx.run_id)
            ├─ config = _build_stream_config(runtime, ctx)
            │   └─ config.configurable.skill_override ← cli_state
            ├─ client = PoirotStreamClient(graph, config)
            ├─ renderer.state["round_t0"] / ["model"] ← 注入耗时与模型
            ├─ async for event in client.stream(prompt) → renderer.render(event)
            ├─ runtime.run_manager.mark_success(ctx.run_id)
            └─ 异常分支：
                ├─ KeyboardInterrupt / CancelledError → mark_failed("interrupted")
                └─ Exception → _stop_spinner + mark_failed(str(exc))
```

### 0.3. 主循环状态机（_run_chat_async）

```
while True
    │
    ├─ 读输入 ──EOF/Ctrl+C──▶ return 0
    │
    ├─ 空输入 ──▶ continue
    │
    ├─ /exit | /quit ──▶ return 0
    │
    ├─ "/" 开头 ──▶ handle_command(...)
    │   ├─ should_exit ──▶ return 0
    │   └─ 消费 pending_* 标志：
    │       ├─ pending_expert_mode  → switch_expert_mode（复用 thread + checkpointer）

    │   └─ continue（本轮不跑研究）

    ├─ 普通输入
    │   ├─ render_user_input（卡片回显）
    │   ├─ intent_tree.detect_and_dispatch ──True──▶ continue（已处理）
    │   │
    │   └─ 流式研究
    │       ├─ create_run → mark_running
    │       ├─ _build_stream_config
    │       ├─ PoirotStreamClient.stream → renderer.render
    │       ├─ mark_success
    │       └─ 异常 → mark_failed（interrupted / str(exc)）→ continue
```

### 0.4. 补充

**`main.py` 是进程入口——`main` 负责"参数解析 + 模式分发"，`run_chat` 负责"启动 bootstrap + 选前端"，`_run_chat_async` 是传统 CLI 的主循环（读输入 → 命令/意图/研究三分支）。**

几条主线：

- **三种运行模式**：无子命令 → 默认 TUI；`cli` → 传统 CLI；`run` → 单次提问直出报告。`main` 在此处完成分发。
- **`.env` 显式从项目根加载**：模块级一次（防 CWD 相对路径）+ `main` 内 `override=True` 一次（配置向导后重载），保证 skill 等配置不缺失。
- **bootstrap 在 asyncio.run 之前**：注释明确"避免 MCP 的 asyncio.run 嵌套"——这是启动时序的关键约束。
- **主循环三分支**：`/命令`（走 `handle_command` + 消费 `pending_*` 标志）、意图命中（`detect_and_dispatch` 返回 True 即不进 graph）、普通研究（创建 run → 流式 → 标记成败）。
- **热切换复用 thread**：`switch_expert_mode` / `switch_model` / `reload_mcp_tools` 都重建 runtime 或 graph，但**复用 `thread_id` + checkpointer state**，所以模式切换不丢上下文。
- **run 生命周期由 CLI 驱动**：`create_run → mark_running → stream → mark_success / mark_failed` 四步全在 `_run_chat_async` 里——这是 runtime 模块在真实调用链中的落点。
- **职责分层清晰**：CLI 只做"呈现 + 驱动"，报告合成委托 `agents/reporting`（`_trigger_report` 里注释明确"报告生成逻辑在 agents/reporting 层，CLI 仅负责 presentation"）。
- **多处容错**：welcome.md 加载失败有 fallback、MCP 工具统计失败不阻塞启动、报告失败有 try/except——保证 CLI 启动与主循环不因单点失败而崩。
