---

name: 配置加载器 — 合并默认配置、叠加层与 CLI 覆盖，校验并构造 AppConfig。

description: 

【整体职责】
配置装载的唯一入口：以 DEFAULT_CONFIG 为基线，按 expert_mode 叠加 EXPERT_PROFILE，
再应用 CLI 覆盖，经校验后构造出不可变的 AppConfig。sandbox / memory 的配置从环境变量
懒加载并注入。

【内容摘要】
- ConfigError            : 配置加载或校验失败时抛出。
- load_config            : 主入口，合并 → 校验 → 构造 AppConfig。
- _apply_cli_overrides   : 应用 CLI 覆盖（expert_mode + 扁平字段映射）。
- _validate              : 校验必填字段与取值范围。
- _build_sandbox_config  : 从 POIROT_SANDBOX_* 环境变量构造 SandboxConfig。
- _build_memory_config   : 从 POIROT_MEMORY_* 环境变量构造 MemoryConfig。
- _build_config          : 把 raw dict 组装为 AppConfig。
- _deep_merge            : 递归深合并，dict 逐层覆盖，其他类型直接替换。

【职责边界】
- 只负责：配置的合并、覆盖、校验、组装，以及 sandbox / memory 的 env 懒加载。
- 不负责：默认值的定义（defaults）、配置结构定义（schema）、provider 配置解析
  （provider_config）、sandbox / memory 配置的内部语义（各自模块定义）。

## 0. 结构树

### 0.1. 静态结构树

```
loader.py — 配置加载器（合并 → 覆盖 → 校验 → 组装）
│
├─ ConfigError(ValueError)                     ← 配置加载或校验失败时抛出
│
├─ load_config(expert_mode, cli_overrides)     ← 主入口
│   ├─ selected_expert = cli_overrides > 参数 > False ← expert_mode 优先级
│   ├─ raw = deepcopy(DEFAULT_CONFIG)          ← 不污染全局默认
│   ├─ selected_expert 为真 → _deep_merge(raw, EXPERT_PROFILE)
│   ├─ _apply_cli_overrides(raw, overrides)    ← 应用 CLI 覆盖
│   ├─ _validate(raw)                          ← 校验必填与取值
│   └─ return _build_config(raw)               ← 组装 AppConfig
│
├─ _apply_cli_overrides(raw, overrides)        ← 应用 CLI 覆盖（原地修改）
│   ├─ expert_mode：类型校验 → 写 runtime；为 True → 叠加 EXPERT_PROFILE
│   └─ flat_targets 白名单：                     ← 扁平字段 → section 映射
│       ├─ logs_root        → (runtime, logs_root)
│       ├─ output_root      → (runtime, output_root)
│       ├─ researcher_model → (models, researcher_model)
│       ├─ reporter_model   → (models, reporter_model)
│       └─ save_artifact    → (reporting, save_artifact)
│
├─ _validate(raw)                              ← 校验必填与取值范围
│   ├─ researcher_model 非空                    ← 否则 ConfigError
│   ├─ reporter_model 非空
│   ├─ expert_mode 为 bool
│   ├─ max_loop_steps >= 1
│   └─ logs_root 非空
│
├─ _build_sandbox_config() -> SandboxConfig    ← 从 POIROT_SANDBOX_* env 懒加载
│   └─ use 为空 = 禁用
│
├─ _build_memory_config() -> MemoryConfig      ← 从 POIROT_MEMORY_* env 懒加载
│   ├─ use 为空 = 禁用
│   └─ phase2 子配置（enabled / trigger_every_n_turns / trigger_on_session_end）
│
├─ _build_config(raw) -> AppConfig             ← 把 raw dict 组装为 AppConfig
│   ├─ 逐段 ** 展开：runtime / models / tools / middleware / reporting / observability
│   ├─ context_governance ← raw.get("context_governance", {})
│   └─ sandbox / memory ← 由 _build_* 从 env 注入
│
└─ _deep_merge(target, patch)                  ← 递归深合并（原地修改）
    ├─ 双方均为 dict → 递归
    └─ 否则 → 直接替换
```

### 0.2. 运行时调用树

```
① 加载配置（主路径）
调用方（CLI / bootstrap）
    └─ load_config(expert_mode, cli_overrides)
          ├─ selected_expert ← cli_overrides > 参数 > False
          ├─ raw = deepcopy(DEFAULT_CONFIG)          ← 隔离全局
          ├─ selected_expert 为真
          │     └─ _deep_merge(raw, EXPERT_PROFILE)
          ├─ _apply_cli_overrides(raw, overrides)
          │     ├─ expert_mode 类型校验 → 写 runtime
          │     │     └─ 为 True → _deep_merge(raw, EXPERT_PROFILE)
          │     └─ flat_targets 逐项写 raw[section][field]
          ├─ _validate(raw)
          │     └─ 失败 → raise ConfigError
          ═══════════ 组装 ═══════════
          └─ _build_config(raw)
                ├─ RuntimeConfig / ModelConfig / ToolConfig / ...
                ├─ ContextGovernanceConfig(raw.get("context_governance", {}))
                ├─ _build_sandbox_config()
                │     └─ os.environ[POIROT_SANDBOX_*] → SandboxConfig
                └─ _build_memory_config()
                      └─ os.environ[POIROT_MEMORY_*] → MemoryConfig

② 深合并（被 load_config / _apply_cli_overrides 复用）
_deep_merge(target, patch)
    └─ 逐 key：双 dict 递归，否则替换
```

### 0.3. 补充

**`loader.py` 是配置装载的唯一入口——以 DEFAULT_CONFIG 为基线，按 expert_mode 叠加 EXPERT_PROFILE，应用 CLI 覆盖，校验后组装为不可变的 AppConfig。**

几点补充：

- **不污染全局**：先 `deepcopy(DEFAULT_CONFIG)` 再合并，保证多次 `load_config` 互不影响。
- **expert_mode 双通道**：既可由参数传入，也可由 `cli_overrides` 覆盖，后者优先；为 True 时叠加 `EXPERT_PROFILE`。
- **CLI 覆盖仅白名单**：`flat_targets` 限定支持 5 个扁平字段，映射到对应 section，避免任意键写入。
- **sandbox / memory 走 env 懒加载**：不走 raw dict，而在 `_build_config` 时从 `POIROT_SANDBOX_*` / `POIROT_MEMORY_*` 读取，`use` 为空即禁用。
- **校验与组装分离**：`_validate` 只做检查，`_build_config` 只做构造，职责清晰。
- **`_deep_merge` 是通用工具**：load_config 与 `_apply_cli_overrides` 共用同一套深合并语义。
