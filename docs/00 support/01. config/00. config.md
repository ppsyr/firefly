---

name: Configuration loading — 配置模块。

description: 

【整体职责】
负责应用配置的定义、加载与模型装配：从默认值出发，按模式叠加、应用 CLI 覆盖、
校验后装配为不可变的 AppConfig；同时提供 provider 声明、解析、角色路由与降级模型构造。

【内容摘要】
- schema                   : 配置数据结构（frozen dataclass），以 AppConfig 为根聚合。
- defaults                 : 默认配置（DEFAULT_CONFIG）与 expert 模式叠加层（EXPERT_PROFILE）。
- loader                   : 配置装载唯一入口（load_config），合并 → 覆盖 → 校验 → 组装。
- provider_profile         : 声明式 provider 定义（ProviderProfile 注册表）。
- provider_config          : provider 解析、选择、角色路由与 ChatModel 构造。
- fallback_model           : 运行时故障降级（FallbackChatModel）。
- model_router             : 角色化智能路由（ModelRouter），模型构造对外入口。

【职责边界】
- 只负责：配置结构定义、默认值、加载与校验、provider 声明与解析、模型构造与降级。
- 不负责：各子系统配置的内部语义（sandbox / skill / memory 由各自模块定义）、
  上下文治理策略实现（context_engineering）、模型调用后的业务处理（中间件 / summarizer）。

【两条装配线】
- 配置线：DEFAULT_CONFIG + EXPERT_PROFILE → CLI 覆盖 → 校验 → AppConfig
  （sandbox / memory 从 env 懒加载注入，skill 走默认工厂）。
- 模型线：discover_available_providers → route_chain_for → build_chat_model → FallbackChatModel。

## 0. 结构树

### 0.1. 静态结构树

```
config/ — Agent 配置模块
│
├─ __init__.py                              ← 配置包初始化（对外导出面）
├─ defaults.py                              ← 默认配置与叠加层
│   ├─ DEFAULT_CONFIG: dict                 ← 基线配置（runtime/models/tools/middleware/
│   │                                          reporting/observability/context_governance）
│   └─ EXPERT_PROFILE: dict                 ← expert 模式叠加层（deep_merge 到 DEFAULT）
│
├─ schema.py                                ← 配置数据结构（frozen dataclass）
│   ├─ RuntimeConfig                        ← 运行时参数
│   ├─ HitlConfig                           ← Human-in-the-loop 配置
│   ├─ ContextGovernanceConfig              ← 上下文治理配置（strategy + params）
│   ├─ ModelConfig                          ← 模型选择（researcher / reporter）
│   ├─ ToolConfig                           ← 工具配置
│   ├─ MiddlewareConfig                     ← 中间件开关
│   ├─ ReportingConfig                      ← 报告配置
│   ├─ ObservabilityConfig                  ← 可观测性配置
│   └─ AppConfig                            ← 配置根，聚合以上 + 子系统引用
│       ├─ sandbox: SandboxConfig           ← 引用 sandbox 模块
│       ├─ skill: SkillConfig               ← 引用 skill 模块
│       └─ memory: MemoryConfig             ← 引用 memory 模块
│
├─ provider_profile.py                      ← 声明式 provider 定义
│   ├─ ProviderKind (Literal)               ← kind 枚举（deepseek/openai_compat/.../fake）
│   ├─ ProviderProfile(frozen)              ← provider 声明模板
│   ├─ PROVIDER_PROFILES: list              ← 内置 provider 注册表（12 项）
│   ├─ _PROFILE_MAP                         ← name → profile 索引
│   ├─ get_provider_profile(name)           ← 按名查
│   └─ list_provider_profiles()             ← 返回全部
│
├─ provider_config.py                       ← provider 解析 + 选择 + 路由 + 构造
│   ├─ ProviderConfigError(ValueError)
│   ├─ ProviderConfig(frozen)               ← 解析后的 provider 配置
│   ├─ _resolve_profile(profile)            ← 读 env → ProviderConfig
│   ├─ _all_configs()                       ← 全部 profile 解析
│   ├─ select_provider_config(provider, model) ← 按名/默认选择
│   ├─ get_provider_config(provider)
│   ├─ _find_provider(candidates, provider)
│   ├─ MODEL_ROUTES: dict                   ← 角色 → provider 偏好链
│   ├─ discover_available_providers()       ← enabled + key 非空，按 priority 升序
│   ├─ _is_no_key(provider)                 ← 免 key 判定
│   ├─ route_chain_for(role, providers)     ← 角色路由链（deepseek 兜尾）
│   └─ build_chat_model(config)             ← 按 kind 构造 BaseChatModel
│
├─ fallback_model.py                        ← 运行时故障降级
│   ├─ _should_fallback(exc)                ← 瞬时错误判定
│   └─ FallbackChatModel(BaseChatModel)     ← 降级链模型
│       ├─ models / provider_names          ← 链与链名
│       ├─ _active: PrivateAttr             ← 活跃 provider 索引（记忆）
│       ├─ _generate / _agenerate           ← 按链轮转，瞬时失败降级
│       ├─ bind_tools                       ← 逐 model 绑定，返回新实例
│       └─ _llm_type / _identifying_params
│
├─ model_router.py                          ← 角色化智能路由（对外入口）
│   └─ ModelRouter
│       ├─ __init__(providers)              ← 未注入则 discover_available_providers()
│       ├─ build_model(role)                ← 按角色链构造 FallbackChatModel
│       ├─ build_single(provider, model)    ← 强制单 provider（测试/调试）
│       └─ chain_names(role)                ← 返回链名列表
│
├─ loader.py                                ← 配置加载器（装载唯一入口）
│   ├─ ConfigError(ValueError)
│   ├─ load_config(expert_mode, cli_overrides) ← 主入口
│   ├─ _apply_cli_overrides(raw, overrides)
│   ├─ _validate(raw)
│   ├─ _build_sandbox_config()              ← 从 POIROT_SANDBOX_* env
│   ├─ _build_memory_config()               ← 从 POIROT_MEMORY_* env
│   ├─ _build_config(raw)                   ← raw dict → AppConfig
│   └─ _deep_merge(target, patch)           ← 递归深合并
│
└─ profiles/                                ← 配置档案目录（已废弃）
    ├─ expert.yaml                          ← 原专家模式（现由 EXPERT_PROFILE 替代）
    ├─ fast.yaml                            ← 原快速模式
    └─ general.yaml                         ← 原通用模式
```

### 0.2. 运行时调用树（从 loader 开始，展开装配过程）

```
load_config(expert_mode, cli_overrides)          ← 装载唯一入口
│
├─ ① 决定 expert_mode
│   └─ selected_expert = cli_overrides["expert_mode"] > expert_mode 参数 > False
│
├─ ② 取基线并叠加
│   ├─ raw = deepcopy(DEFAULT_CONFIG)            ← 来自 defaults.py，隔离全局
│   └─ selected_expert 为真
│         └─ _deep_merge(raw, EXPERT_PROFILE)    ← 来自 defaults.py
│
├─ ③ 应用 CLI 覆盖
│   └─ _apply_cli_overrides(raw, overrides)
│       ├─ expert_mode：类型校验 → 写 raw["runtime"]["expert_mode"]
│       │     └─ 为 True → _deep_merge(raw, EXPERT_PROFILE)（再次叠加）
│       └─ flat_targets 白名单写入：
│             logs_root / output_root → raw["runtime"]
│             researcher_model / reporter_model → raw["models"]
│             save_artifact → raw["reporting"]
│
├─ ④ 校验
│   └─ _validate(raw)
│       ├─ researcher_model / reporter_model 非空
│       ├─ expert_mode 为 bool
│       ├─ max_loop_steps >= 1
│       └─ logs_root 非空
│       └─ 失败 → raise ConfigError
│
└─ ⑤ 组装 AppConfig
    └─ _build_config(raw)
        ├─ RuntimeConfig(**raw["runtime"])           ← schema.py
        ├─ ModelConfig(**raw["models"])              ← schema.py
        ├─ ToolConfig(**raw["tools"])                ← schema.py
        ├─ MiddlewareConfig(**raw["middleware"])     ← schema.py
        ├─ ReportingConfig(**raw["reporting"])       ← schema.py
        ├─ ObservabilityConfig(**raw["observability"]) ← schema.py
        ├─ ContextGovernanceConfig(**raw.get("context_governance", {})) ← schema.py
        ├─ sandbox = _build_sandbox_config()
        │     └─ os.environ["POIROT_SANDBOX_*"] → SandboxConfig   ← sandbox 模块
        ├─ memory = _build_memory_config()
        │     └─ os.environ["POIROT_MEMORY_*"] → MemoryConfig     ← memory 模块
        └─ return AppConfig(
               name, environment,
               runtime, models, tools, middleware, reporting, observability,
               context_governance, sandbox, skill, memory)
               │
               ├─ AppConfig.sandbox  ← SandboxConfig（env 注入）
               ├─ AppConfig.skill    ← SkillConfig（默认工厂，loader 未显式装配）
               └─ AppConfig.memory   ← MemoryConfig（env 注入）

═══════════ 模型构造路径（AppConfig 之外，独立入口） ═══════════

ModelRouter(providers)                            ← 角色化路由（对外入口）
│
├─ providers 为 None
│   └─ discover_available_providers()            ← provider_config.py
│       ├─ _all_configs()
│       │     └─ _resolve_profile(profile) × N   ← 读 env → ProviderConfig
│       └─ 过滤 enabled 且 key 非空（或 _is_no_key），按 priority 升序
│
├─ build_model(role)
│   ├─ route_chain_for(role, providers)          ← provider_config.py
│   │     ├─ MODEL_ROUTES[role] 筛 by_name
│   │     └─ 保证 deepseek 在链尾（若可用）
│   ├─ build_chat_model(p) × N                   ← provider_config.py
│   │     ├─ get_provider_profile(p.provider)    ← provider_profile.py
│   │     ├─ require_api_key()（非免 key 时）
│   │     └─ 按 kind 分发 → ChatDeepSeek / ChatOpenAI / ChatAnthropic / ...
│   └─ FallbackChatModel(models, provider_names) ← fallback_model.py
│         └─ 运行时按链降级（_should_fallback 判定）
│
├─ build_single(provider, model)
│   ├─ select_provider_config(provider, model)   ← provider_config.py
│   └─ build_chat_model(cfg)
│
└─ chain_names(role)
    └─ route_chain_for(role, providers) → [provider names]
```

### 0.3. 补充

**`config/` 是配置与模型装配的中心——`loader.py` 负责把默认值、叠加层、CLI 覆盖、env 装配为不可变的 `AppConfig`；`provider_*` / `fallback_model` / `model_router` 构成另一条独立的"模型构造链"，把 provider 声明装配为带降级的 ChatModel。**

几条主线：

- **配置装配线（loader）**：`DEFAULT_CONFIG` + `EXPERT_PROFILE` → CLI 覆盖 → 校验 → `AppConfig`，其中 `sandbox` / `memory` 从 env 懒加载注入，`skill` 走默认工厂。
- **模型构造线（router）**：`discover_available_providers` → `route_chain_for` → `build_chat_model` → `FallbackChatModel`，最终对上层表现为单个 `BaseChatModel`。
- **声明与实现分离**：`provider_profile.py` 只声明（不可变、不构造 client），`provider_config.py` 负责解析与构造（kind 分发）。
- **两层降级语义**：配置层（expert_mode 叠加）与运行时层（FallbackChatModel 按链降级）互不耦合，各司其职。
- **`profiles/` 已废弃**：原 fast/general/expert 三 yaml 档案被 `EXPERT_PROFILE` 单一叠加层 + `expert_mode: bool` 参数化替代，目录保留但不再参与装配。
