---

name: Thread state package — 线程状态模块。

description: 

【整体职责】
定义 Poirot 研究线程在 LangGraph 图中的状态：schema 与承载类型、字段合并规则、
以及初始状态工厂。是图内所有节点读写状态的统一契约来源。

【内容摘要】
- types          : 状态 schema 与承载类型（ThreadState + Observation/Source/Artifact 等 frozen dataclass）。
- reducers       : 字段合并规则（merge_thread_state 外层入口 + merge_xxx 字段级 reducer）。
- thread_state   : 初始状态工厂（create_initial_thread_state）。

【职责边界】
- 只负责：状态 schema、承载类型、合并规则、初始状态构造。
- 不负责：状态的持久化（runtime / checkpointer）、使用状态的业务逻辑
  （middleware / agent / tool）、状态变更的调度（graph）。

【三层结构】
- schema 层：types（ThreadState 字段以 Annotated[..., merge_xxx] 绑定 reducer）。
- 规则层  ：reducers（实现合并语义：追加 / 去重 / 覆盖 / deep-merge / fail-closed）。
- 工厂层  ：thread_state（产出初始 state，不参与 reducer 绑定）。

【两套 reducer 入口】
- 字段级：merge_xxx，供 Annotated 绑定，由 LangGraph 图内触发。
- 外层  ：merge_thread_state，供 LeaderAgent 手工调用，内部分派到规则。

## 0. 结构树

### 0.1. 静态结构树

```
state/ — 状态定义模块
│
├─ __init__.py                              ← 对外导出面
│
├─ reducers.py                              ← 【规则层】字段合并规则（无内部依赖）
│   ├─ CORE_FIELDS / MAX_ERRORS             ← 常量
│   ├─ ReducerConflictError                 ← 异常
│   ├─ merge_thread_state(state, patch)     ← 外层整体合并入口
│   ├─ _merge_sources / _merge_by_attr / _merge_metadata / _merge_final_report
│   ├─ _field / _update_same_type           ← 辅助
│   └─ merge_xxx（字段级 reducer 集合）      ← 被 types 引用
│       ├─ merge_observations / merge_sources / merge_citations / merge_artifacts
│       ├─ merge_reflection_items / merge_final_report / merge_errors / merge_metadata
│       ├─ merge_todos / merge_governance / merge_tagged_context / merge_sandbox
│       ├─ merge_orchestration
│       └─ merge_memory_recalled / merge_memory_updates
│
├─ types.py                                 ← 【schema 层】ThreadState + 承载类型
│   │                                          ⚠ 关键：import reducers 的 merge_xxx
│   │                                          ⚠ 在字段上以 Annotated[type, reducer] 绑定
│   ├─ GovernanceState / OrchestrationState
│   ├─ IntentState / PlanStep / ResearchPlan
│   ├─ Observation / Source / Citation / Artifact / ReflectionItem / AgentError
│   │
│   └─ ThreadState(AgentState)
│       ├─ 继承 → messages（add_messages reducer，LangGraph 内置）
│       │
│       ├─ 无 reducer 字段（NotRequired，直接覆盖）
│       │   └─ user_input / intent / research_question / plan / current_step_id
│       │      help_request_count / pending_help / skill_suggestion
│       │
│       └─ 有 reducer 字段（Annotated[..., merge_xxx]，绑定 reducers.py）
│           ├─ observations      ──绑定──▶ merge_observations      （追加）
│           ├─ sources           ──绑定──▶ merge_sources           （id/url 合并）
│           ├─ citations         ──绑定──▶ merge_citations         （id 合并）
│           ├─ artifacts         ──绑定──▶ merge_artifacts         （id 合并）
│           ├─ reflection_items  ──绑定──▶ merge_reflection_items  （id 合并）
│           ├─ final_report      ──绑定──▶ merge_final_report      （LWW）
│           ├─ errors            ──绑定──▶ merge_errors            （追加截断）
│           ├─ metadata          ──绑定──▶ merge_metadata          （禁核心字段）
│           ├─ todos             ──绑定──▶ merge_todos             （None保留/否则替换）
│           ├─ governance        ──绑定──▶ merge_governance        （deep-merge）
│           ├─ tagged_context    ──绑定──▶ merge_tagged_context    （LWW）
│           ├─ sandbox           ──绑定──▶ merge_sandbox           （fail-closed）
│           ├─ orchestration     ──绑定──▶ merge_orchestration     （去重追加）
│           ├─ recalled_memories ──绑定──▶ merge_memory_recalled   （id 去重）
│           └─ memory_updates    ──绑定──▶ merge_memory_updates    （追加）
│
└─ thread_state.py                          ← 【工厂层】初始状态构造（只消费 ThreadState）
    └─ create_initial_thread_state(user_input) → ThreadState
        └─ import types.ThreadState（不 import reducers）
```

### 0.2. 依赖 / 绑定关系树（核心）

```
        reducers.py                         types.py                      thread_state.py
   （规则层，无内部依赖）            （schema 层，绑定规则）              （工厂层）
             │                                │                              │
             │  merge_xxx 被 import             │                              │
             │◀───────────────────────────────│                              │
             │                                │                              │
             │                     ThreadState 字段                      create_initial_
             │                     Annotated[type, merge_xxx]            thread_state
             │                     ──▶ 运行时 LangGraph              ──▶ 返回 ThreadState
             │                         调用 merge_xxx                    （import types）
             │                                │                              │
             │                                │◀────── import ───────────────│
             │                                │
             ▼                                ▼                              ▼

   ┌─────────────────────────────────────────────────────────────────────────────┐
   │ 绑定关系（schema ↔ 规则）：                                                   │
   │   types.ThreadState 字段  ──Annotated──▶  reducers.merge_xxx                 │
   │   即：字段"用哪个 reducer"由 types.py 声明，reducer"怎么合并"由 reducers.py 实现 │
   ├─────────────────────────────────────────────────────────────────────────────┤
   │ 消费关系（工厂 → schema）：                                                   │
   │   thread_state.create_initial_thread_state  ──返回──▶  types.ThreadState       │
   │   工厂不碰 reducer，只产出一份符合 schema 的初始 dict                          │
   └─────────────────────────────────────────────────────────────────────────────┘
```

### 0.3. 运行时调用树（体现 reducer 如何被触发）

```
① 初始化（工厂层）
create_initial_thread_state(user_input)
    └─ 返回 ThreadState（user_input + 空容器 + None）
       └─ 注意：此时 reducer 未被调用，只是"字段声明里绑定了它"

② 图执行（LangGraph 驱动 → 触发绑定）
graph.invoke(state, config={thread_id})
    └─ 节点写增量 patch
          └─ LangGraph 读取 ThreadState 字段的 Annotated 元数据
                └─ 取出绑定的 merge_xxx
                      └─ reducers.merge_xxx(current, incoming) ← 规则层执行
                            ├─ 列表类 → 追加 / 去重追加
                            ├─ 覆盖类 → LWW
                            ├─ dict 类 → 浅合并 / deep-merge
                            └─ 特殊类 → fail-closed / 去重追加

③ 外层合并（LeaderAgent → 不经绑定，直接调）
LeaderAgent
    └─ merge_thread_state(state, patch)   ← reducers 的外层入口（手工分派，非 Annotated）

④ 异常传播
    ├─ ReducerConflictError（metadata 含核心字段）
    └─ ValueError（sandbox_id 冲突）
          └─ graph 外层捕获
```

### 0.4. 补充（重点：两类 reducer 入口的区别）

**这个模块最关键的一层关系是"绑定"：`types.ThreadState` 的字段用 `Annotated[type, merge_xxx]` 把"字段"与"合并规则"绑定起来，`reducers.py` 提供规则实现，`thread_state.py` 只产出初始值、不参与绑定。**


`types.py` 声明"字段用哪个 reducer"（绑定），`reducers.py` 实现"reducer 怎么合并"（规则），`thread_state.py` 只造初始值（消费 schema）。
