---

name: 线程状态与状态类型 — LangGraph 图的状态 schema 及承载类型。

description: 

【【整体职责】
定义 Poirot 研究线程的 LangGraph state schema（ThreadState）及状态中承载的全部
数据类型：意图、计划、观察、来源、引用、产物、反思项、错误、编排层状态等。
字段级 Annotated reducer 驱动图内部的状态合并。

【内容摘要】
- GovernanceState        : 治理层共享状态类型别名（策略 bundle 自管命名空间）。
- OrchestrationState     : Multi-Agent 编排层状态（specialist 产物 + 活跃 specialist）。
- IntentState            : 意图状态（任务类型、深度、目标、约束等）。
- PlanStep               : 计划步骤。
- ResearchPlan           : 研究计划。
- Observation            : 观察（证据条目）。
- Source                 : 来源。
- Citation               : 引用。
- Artifact               : 产物。
- ReflectionItem         : 反思项。
- AgentError             : 错误（兼工具调用账本）。
- ThreadState            : 线程状态 schema，继承 AgentState，含字段级 reducer。

【职责边界】
- 只负责：定义状态 schema、字段语义、承载的数据类型。
- 不负责：字段合并的具体实现（reducers 模块）、状态的读写与持久化
  （runtime / checkpointer）、使用状态的业务逻辑（middleware / agent）。

## 0. 结构树

### 0.1. 静态结构树

```
types.py — 线程状态与状态类型（LangGraph state schema + 承载类型）
│
├─ GovernanceState (类型别名)                  ← 治理层共享状态：dict[str, Any]
│   └─ 命名空间 governance.<strategy_name>.*    ← 策略 bundle 自管，不预设固定槽
│
├─ OrchestrationState(TypedDict, total=False)  ← Multi-Agent 编排层状态
│   ├─ specialist_artifacts: list              ← specialist 产物引用（list[ArtifactRef]）
│   └─ active_specialists: list[str]           ← 当前活跃 specialist 名
│
├─ IntentState(frozen)                         ← 意图状态
│   ├─ task_type / depth / objective           ← 任务类型 / 深度 / 目标
│   ├─ constraints: tuple = ()                 ← 约束集合

│
├─ PlanStep(frozen)                            ← 计划步骤
│   ├─ step_id / title                         ← 步骤 ID / 标题
│   ├─ description: str = ""                   ← 描述

│
├─ ResearchPlan(frozen)                        ← 研究计划
│   ├─ plan_id / goal                          ← 计划 ID / 目标
│   ├─ steps: tuple[PlanStep, ...] = ()        ← 步骤集合
│   └─ status: str = "pending"                 ← 状态
│
├─ Observation(frozen)                         ← 观察（证据条目）
│   ├─ observation_id / step_id                ← 观察 ID / 关联步骤 ID
│   ├─ content                                 ← 内容
│   ├─ source_refs: tuple = ()                 ← 来源引用集合
│   └─ created_at: str | None = None           ← 创建时间
│
├─ Source(frozen)                              ← 来源
│   ├─ source_id / url / title                 ← 来源 ID / URL / 标题
│   ├─ source_type: str = "web"                ← 来源类型
│   ├─ retrieved_at: str | None = None         ← 获取时间
│   └─ summary: str = ""                       ← 摘要
│
├─ Citation(frozen)                            ← 引用
│   ├─ citation_id / source_id                 ← 引用 ID / 关联来源 ID
│   ├─ quote / claim                           ← 引文 / 论断
│   └─ location: str | None = None             ← 位置
│
├─ Artifact(frozen)                            ← 产物
│   ├─ artifact_id / artifact_type             ← 产物 ID / 类型
│   ├─ title / path                            ← 标题 / 路径
│   ├─ summary: str = ""                       ← 摘要
│   ├─ source_refs: tuple = ()                 ← 来源引用集合
│   └─ created_at: str | None = None           ← 创建时间
│
├─ ReflectionItem(frozen)                      ← 反思项
│   ├─ item_id / scope / kind / question       ← 项 ID / 范围 / 种类 / 问题
│   ├─ status: str = "open"                    ← 状态
│   ├─ related_refs: tuple = ()                ← 关联引用集合
│   └─ created_at: str | None = None           ← 创建时间
│
├─ AgentError(frozen)                          ← 错误（兼工具调用账本）
│   ├─ error_id / stage / message              ← 错误 ID / 阶段 / 信息
│   ├─ related_refs: tuple = ()                ← 关联引用集合
│   ├─ created_at: str | None = None           ← 创建时间
│   ├─ kind: str = "failure"                   ← "failure" / "success"
│   ├─ tool_name: str = ""                     ← 工具名
│   ├─ attempt: int = 0                        ← 该 tool 连续失败次（成功归 0）
│   ├─ error_type: str = ""                    ← F5 分类
│   └─ reason: str = ""                        ← F8.2 原因模板

└─ ThreadState(AgentState)                     ← 线程状态 schema（图的核心 state）

    │
    └─ 有 reducer（Annotated，图内合并）

        ├─ artifacts: Annotated[list, merge_artifacts]

        ├─ recalled_memories: Annotated[list|None, merge_memory_recalled]
        └─ memory_updates: Annotated[list|None, merge_memory_updates]
```

### 0.2. 关系视图（状态字段 → reducer → 承载类型）

```
ThreadState（LangGraph schema）
│
├─ 叙事/控制类（无 reducer）
│   ├─ user_input / research_question / intent / plan / current_step_id
│   └─ help_request_count / pending_help / skill_suggestion
│
├─ 证据类（reducer 合并，元素为 frozen dataclass）
│   ├─ observations      → merge_observations   → Observation
│   ├─ sources           → merge_sources        → Source
│   ├─ citations         → merge_citations      → Citation
│   └─ artifacts         → merge_artifacts      → Artifact
│
├─ 反思/错误类（reducer 合并）
│   ├─ reflection_items  → merge_reflection_items → ReflectionItem
│   └─ errors            → merge_errors           → AgentError
│
├─ 输出类（reducer 合并）
│   └─ final_report      → merge_final_report
│
├─ 治理/上下文类（reducer 合并，dict 形态）
│   ├─ metadata          → merge_metadata
│   ├─ governance        → merge_governance      ← GovernanceState
│   ├─ tagged_context    → merge_tagged_context
│   └─ sandbox           → merge_sandbox
│
├─ 编排类（reducer 合并）
│   └─ orchestration     → merge_orchestration   ← OrchestrationState
│       ├─ specialist_artifacts（list[ArtifactRef]）
│       └─ active_specialists（list[str]）
│
├─ 待办类（reducer 合并）
│   └─ todos             → merge_todos
│
└─ 记忆类（reducer 合并）
    ├─ recalled_memories → merge_memory_recalled
    └─ memory_updates    → merge_memory_updates

═══════════ 继承 ═══════════
AgentState
└─ messages（add_messages reducer，LangGraph 内置）
    └─ ThreadState 继承 → 同时具备 messages 字段
```

### 0.3. 运行时调用树（状态在图中的流动）

```
① 图执行（LangGraph 驱动）
create_agent / graph.invoke(state, config={thread_id})
    │
    ├─ 输入 state → ThreadState 字段逐项按 reducer 合并
    │     ├─ 有 reducer 字段 → merge_xxx(old, new)
    │     │     ├─ observations → merge_observations（追加）
    │     │     ├─ final_report → merge_final_report（覆盖）
    │     │     ├─ governance → merge_governance（deep-merge, LWW per leaf）
    │     │     └─ orchestration → merge_orchestration（去重追加）
    │     └─ 无 reducer 字段 → 直接覆盖（NotRequired 可缺省）
    │
    ├─ 节点执行（middleware / agent / tool）
    │     ├─ 读取 thread_state（如 reporter 读 research_question / observations）
    │     └─ 写回增量（state 更新 → 触发 reducer 合并）
    │
    └─ state 持久化
          └─ checkpointer 按 thread_id 存取 state（runtime/checkpointer）

② reducer 合并（由 reducers.py 实现）
merge_xxx(existing, new) → merged
    ├─ 列表类：追加 / 去重追加（如 merge_observations / merge_orchestration）
    ├─ 覆盖类：新值覆盖旧值（如 merge_final_report）
    └─ dict 类：deep-merge（如 merge_governance, LWW per leaf）

③ 字段消费（跨模块）
    ├─ reporter 读 research_question / observations / sources / final_report
    ├─ reflection 写 reflection_items → merge_reflection_items
    ├─ todo 写 todos → merge_todos
    ├─ memory 写 recalled_memories / memory_updates → merge_memory_*
    └─ multiagent 写 orchestration → merge_orchestration
```

### 0.4. 补充

**`types.py` 是 Agent 状态的总 schema——`ThreadState` 定义 LangGraph 图携带的全部字段，其余 frozen dataclass 是字段的承载类型，reducer 决定字段如何合并。**

几条主线：

- **schema 即契约**：`ThreadState` 继承 `AgentState`（自带 `messages` + `add_messages`），是图内所有节点读写状态的统一契约。
- **两类字段**：无 reducer（`NotRequired`，图不强制提供，直接覆盖）与有 reducer（`Annotated[..., merge_xxx]`，按规则合并）。
- **reducer 驱动演进**：列表类多为追加/去重追加，`final_report` 为覆盖，`governance` 为 deep-merge——这解释了"observations 能不断累积、final_report 会被最后写入者覆盖"。
- **承载类型均为 frozen**：`Observation` / `Source` / `Artifact` 等不可变，元组字段用 `default_factory=tuple`，与项目"frozen dataclass"取向一致。
- **artifacts 分离**：`ThreadState.artifacts`（Lead 产物）与 `OrchestrationState.specialist_artifacts`（specialist 产物）分离，对应之前 multiagent 的 `ArtifactRef` 设计约束。
- **治理层命名空间化**：`governance` 为 `dict[str, Any]`，由策略 bundle 自管命名空间，不预设固定槽，全值可 JSON 序列化。
- **`AgentError` 兼账本**：`kind` / `tool_name` / `attempt` / `error_type` / `reason` 扩展字段，使其既是错误记录，也是工具调用账本（F8.1）。
- **带默认值兼容**：`AgentError` 扩展字段均有默认值，兼容既有构造（向后兼容）。
- **reducer 实现外置**：所有 `merge_xxx` 定义在 `reducers.py`，本文件只引用，职责分离。
