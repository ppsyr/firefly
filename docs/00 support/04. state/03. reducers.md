---

name: 状态 reducer — ThreadState 字段合并规则。

description: 

【整体职责】
定义 Poirot 状态合并的全部规则，分两套入口：
- merge_thread_state：外层的整体 patch 合并（LeaderAgent 用）。
- merge_xxx 系列：字段级 reducer，供 ThreadState 的 Annotated[..., reducer] 使用
  （LangGraph 图内部合并）。

【内容摘要】
- CORE_FIELDS            : 核心字段集合，metadata 不得包含。
- MAX_ERRORS             : errors 列表上限（截断保留最新）。
- ReducerConflictError   : 状态补丁会隐藏/破坏核心状态时抛出。
- merge_thread_state     : 外层整体 patch 合并（按字段分派到具体规则）。
- _merge_sources         : sources 按 source_id 覆盖 / url 去重。
- _merge_by_attr         : 通用按属性 ID 的覆盖或追加合并。
- _merge_metadata        : metadata 合并，禁止核心字段。
- _merge_final_report    : final_report last-write-wins 覆盖。
- _field / _update_same_type : 字段读取与同类型更新辅助。
- merge_sources / merge_citations / merge_artifacts / merge_reflection_items
- merge_observations / merge_errors / merge_metadata / merge_final_report
- merge_todos            : None 保留，否则整体替换。
- merge_governance       : deep-merge，叶子 last-write-wins。
- merge_tagged_context   : last-write-wins 替换。
- merge_sandbox          : 幂等合并 + fail-closed + 不清空。
- merge_orchestration    : specialist_artifacts / active_specialists 去重追加。
- _dedupe_orchestration_artifacts : 按 path 去重追加。
- merge_memory_recalled / merge_memory_updates : 记忆类合并。

【职责边界】
- 只负责：定义并实现状态字段的合并规则。
- 不负责：状态 schema 定义（state/types）、初始状态构造（thread_state）、
  state 的持久化（runtime / checkpointer）、消费状态的业务逻辑（middleware / agent）。

## 0. 结构树

### 0.1. 静态结构树

```
reducers.py — 状态 reducer（ThreadState 字段合并规则）
│
├─ CORE_FIELDS: set                            ← 核心字段集合，metadata 不得包含
├─ MAX_ERRORS: int = 100                       ← errors 列表上限
├─ ReducerConflictError(ValueError)            ← 状态补丁会隐藏/破坏核心状态时抛出
│
├─ 【外层入口】merge_thread_state(state, patch) ← LeaderAgent 用的整体 patch 合并
│   └─ 按字段分派：
│       ├─ sources          → _merge_sources
│       ├─ citations/artifacts → _merge_by_attr(…_id)
│       ├─ reflection_items → _merge_by_attr(item_id)
│       ├─ errors           → 追加 + 截断 MAX_ERRORS
│       ├─ metadata         → _merge_metadata
│       ├─ final_report     → _merge_final_report
│       └─ 其余             → 直接覆盖
│
├─ 【合并辅助】
│   ├─ _merge_sources(current, incoming)        ← 同 source_id 覆盖 / 同 url 去重
│   ├─ _merge_by_attr(current, incoming, attr)  ← 按属性 ID 覆盖或追加（同类型更新）
│   ├─ _merge_metadata(current, incoming)       ← 禁核心字段，浅合并覆盖
│   ├─ _merge_final_report(current, incoming)   ← last-write-wins
│   ├─ _field(item, name)                       ← 兼容 dict / 对象属性
│   └─ _update_same_type(existing, incoming)    ← 同类型 dataclass 用 replace 合并
│
├─ 【字段级 reducer】供 Annotated[..., reducer]（LangGraph 图内合并）
│   ├─ merge_sources             ← None 保留；按 source_id/url 合并
│   ├─ merge_citations           ← 按 citation_id 合并
│   ├─ merge_artifacts           ← 按 artifact_id 合并
│   ├─ merge_reflection_items    ← 按 item_id 合并
│   ├─ merge_observations        ← 追加（不去重）
│   ├─ merge_errors              ← 追加 + 截断
│   ├─ merge_metadata            ← 禁核心字段，浅合并
│   ├─ merge_final_report        ← last-write-wins
│   ├─ merge_todos               ← None 保留；否则整体替换
│   ├─ merge_governance          ← deep-merge，叶子 last-write-wins
│   ├─ merge_tagged_context      ← last-write-wins 替换
│   ├─ merge_sandbox             ← 幂等合并 + fail-closed + 不清空
│   └─ merge_orchestration       ← 去重追加（artifacts by path / specialists by name）
│
├─ 【编排辅助】
│   └─ _dedupe_orchestration_artifacts(existing, incoming) ← 按 path 去重追加
│
└─ 【记忆 reducer】
    ├─ merge_memory_recalled     ← 去重追加 by id
    └─ merge_memory_updates      ← 追加（不去重）
```

### 0.3. 运行时调用树

```
① 外层整体合并（LeaderAgent 用）
LeaderAgent
    └─ merge_thread_state(state, patch)
          └─ 逐 key 分派到具体规则 → 返回新 dict（不修改入参）

② 图内字段级合并（LangGraph 驱动）
graph 节点写 state
    └─ LangGraph 按 ThreadState 的 Annotated[..., reducer] 调用对应 merge_xxx
          ├─ 列表类 → 追加 / 去重追加
          ├─ 覆盖类 → final_report / tagged_context
          ├─ dict 类 → metadata（浅合并）/ governance（deep-merge）
          └─ 特殊类 → sandbox（fail-closed）/ orchestration（去重追加）

③ 辅助函数（被上述复用）
    ├─ _merge_sources → _field
    ├─ _merge_by_attr → _update_same_type → replace/asdict
    ├─ _merge_metadata → CORE_FIELDS 校验 → ReducerConflictError
    ├─ merge_governance → 递归自调用
    └─ merge_orchestration → _dedupe_orchestration_artifacts → _field

④ 异常传播
    ├─ ReducerConflictError：metadata 含核心字段
    └─ ValueError：sandbox_id 冲突（fail-closed）
          └─ graph 外层（LeaderAgent.run / stream_service）捕获转优雅提示
```

### 0.4. 补充

**`reducers.py` 是状态合并规则的唯一实现地——一套对外层 patch（`merge_thread_state`），一套对字段级 `Annotated` reducer（`merge_xxx`），共同决定 state 如何演进。**

几条主线：

- **两套入口分工**：`merge_thread_state` 服务 LeaderAgent 的外层 patch 合并（design D7）；`merge_xxx` 服务 LangGraph 图内字段级合并，由 `ThreadState` 的 `Annotated[..., reducer]` 引用。
- **None 语义统一**：多数 reducer 中 `incoming=None` 表示"本轮未触碰该字段"，保留 current、不清空——只有 `todos`（显式空列表视为替换）与 `merge_final_report`（None 保留）等少数有细微差别。
- **去重维度各异**：`sources` 双重（id + url）、`citations/artifacts/reflection_items` 按 id、`orchestration` 按 path/name、`recalled_memories` 按 id；`observations/memory_updates` 不去重。
- **两类覆盖**：`final_report` / `tagged_context` 为 last-write-wins；`governance` 为 deep-merge（叶子 LWW）；`metadata` 为浅合并。
- **fail-closed 的 sandbox**：不同 `sandbox_id` 抛 `ValueError` 而非静默选一——确定性 ID 排除合法 race，冲突即 bug，应暴露。
- **核心字段保护**：`metadata` 含 `CORE_FIELDS` 抛 `ReducerConflictError`，防止 patch 覆盖核心状态。
- **容量控制**：`errors` 截断至 `MAX_ERRORS`（保留最新），防止无限增长。
- **记忆只存索引**：`recalled_memories` 只存 id + score + strength，全量内容走 per-call 注入，保护 prompt caching。
- **兼容两种形态**：`_field` 同时支持 dataclass 与 dict，`_update_same_type` 对 dataclass 用 `replace` 做同类型字段级更新。
