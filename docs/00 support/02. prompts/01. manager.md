---

name: Prompt 管理系统 — 统一加载 / 渲染 / 切换 prompt。

description: 

【整体职责】
提供提示词的统一加载、变量渲染与切换能力，是唯一直接访问 prompt 文件（.md）的层。
按三层架构组织：本模块为 low-level（唯一碰文件），模块 accessor 为 mid-level
（知道 category/name + vars），外部调用方为 high-level（只调 accessor）。

【内容摘要】
- PromptManager          : 统一 prompt 加载 / 渲染 / 切换管理（唯一碰文件的层）。
- PromptManager.load     : 加载并渲染 prompt（user/ 优先 system/）。
- PromptManager.load_raw : 加载原始文本（不渲染），返回 (text, source)。
- PromptManager.list_prompts : 列出可用 prompt（category/name 格式）。
- PromptManager.clear_cache  : 清空缓存。
- get_prompt_manager     : 全局单例访问器。

【职责边界】
- 只负责：读 .md 文件、缓存、变量渲染、列出与切换（user/ 覆盖 system/）。
- 不负责：知道具体 category/name 与变量语义（模块 accessor 层）、业务级 prompt 组合
  （外部调用方）、prompt 内容的编写（.md 文件本身）。

## 0. 结构树

### 0.1. 静态结构树

```
manager.py — Prompt 管理系统（统一加载 / 渲染 / 切换）
│
├─ PromptManager                                   ← 唯一碰文件的 low-level 层
│   ├─ __init__(base_dir)                           ← 初始化，_base + _cache
│   │   ├─ _base: Path                              ← prompt 根目录（含 system/ 与 user/）
│   │   └─ _cache: dict[str, str]                   ← 文件路径 → 文本内容
│   │
│   ├─ load(category, name, **vars) -> str          ← 加载 + ${var} 渲染
│   │   ├─ _read(category, name)                    ← 取模板（user/ 优先 system/）
│   │   └─ _render(template, vars)                  ← 变量替换
│   │
│   ├─ load_raw(category, name) -> (text, source)   ← 加载原始文本，不渲染
│   │   └─ _read(category, name)
│   │
│   ├─ list_prompts(category=None) -> list[str]     ← 列出可用 prompt（category/name）
│   │   ├─ 遍历 ("system", "user") 两层              ← 合并去重
│   │   ├─ category 过滤（可选）
│   │   └─ glob("*.md") → "{cat}/{stem}"
│   │
│   ├─ clear_cache() -> None                        ← 清空缓存
│   │
│   ├─ _read(category, name) -> (text, source)      ← 读 .md，user/ 优先
│   │   ├─ user/{category}/{name}.md 存在 → ("user")
│   │   ├─ system/{category}/{name}.md 存在 → ("system")
│   │   └─ 均不存在 → raise FileNotFoundError
│   │
│   ├─ _cached_read(path) -> str                    ← 按路径缓存读取
│   │   └─ 未命中 → read_text(utf-8) 并写入 _cache
│   │
│   └─ _render(template, vars) -> str (staticmethod) ← ${variable} regex 替换
│       ├─ 命中 vars → 替换为 str(vars[key])
│       └─ 未命中 → 保留原样 + stderr warning
│
├─ _pm: PromptManager | None                       ← 模块级单例
│
└─ get_prompt_manager() -> PromptManager           ← 单例访问器
    └─ _pm 为 None → PromptManager(Path(__file__).parent)
```

### 0.2. 运行时调用树

```
① 外部调用（high-level）
调用方（accessor / 中间件 / Leader）
    └─ get_prompt_manager()
          └─ 首次调用 → PromptManager(Path(__file__).parent)   ← 单例初始化
    ═══════════ 加载与渲染 ═══════════
    └─ pm.load(category, name, **vars)
          ├─ _read(category, name)
          │     ├─ user/{category}/{name}.md 存在？
          │     │     └─ 是 → _cached_read(user_path) → ("...", "user")
          │     ├─ system/{category}/{name}.md 存在？
          │     │     └─ 是 → _cached_read(sys_path) → ("...", "system")
          │     └─ 均不存在 → raise FileNotFoundError
          └─ _render(template, vars)
                ├─ 匹配 ${(\w+)}
                ├─ key ∈ vars → str(vars[key])
                └─ key ∉ vars → 保留原样 + stderr warning

② 原始加载（不渲染）
pm.load_raw(category, name)
    └─ _read(category, name) → (text, source)

③ 列出可用 prompt
pm.list_prompts(category=None)
    ├─ 遍历 layer ∈ ("system", "user")
    │     └─ base 存在 → 遍历子目录
    │           ├─ category 过滤（可选）
    │           └─ glob("*.md") → "{cat}/{stem}" 加入 set
    └─ return sorted(result)

④ 缓存失效
pm.clear_cache()
    └─ _cache.clear()
```

### 0.3. 补充

**`manager.py` 是提示词系统的唯一文件访问层——把 .md 的读取、缓存、变量渲染与 user/system 覆盖规则收敛到一个类，上层只通过 accessor 与单例访问。**

几点补充：

- **三层架构的底层**：本模块 low-level（唯一碰文件）→ 模块 accessor（mid-level，知道 category/name + vars）→ 外部调用方（high-level，只调 accessor）。
- **user/ 覆盖 system/**：同名 prompt 存在 `user/` 时优先，实现用户自定义覆盖内置提示词，无需改动 system/ 目录。
- **渲染容错**：`${var}` 未绑定不报错、保留原样并打 stderr warning，避免缺变量导致运行中断。
- **缓存以路径为键**：`_cached_read` 按文件路径缓存，同一 prompt 多次加载只读一次盘；`clear_cache` 手动失效（不支持自动感知文件变更）。
- **单例 + 固定 base_dir**：`get_prompt_manager` 全局唯一，base_dir 锁定为本文件所在目录，即 `prompts/`。
- **`load` vs `load_raw`**：前者渲染、后者返回原文与来源层，`source` 可用于调试"到底用的是 user 还是 system"。
- **正则仅匹配 `\w+`**：变量名限定为字母/数字/下划线，不含点、连字符等，命名需遵守此约定。
