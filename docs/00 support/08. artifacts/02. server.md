---

name: 产物下载/预览的轻量 HTTP 服务。

description: 

【整体职责】
绑定 127.0.0.1，把经 register() 登记的产物文件以 /artifacts/{sandbox_id}/{filename}
对外提供下载/预览。由 bootstrap 启动、退出时停止。无第三方依赖（stdlib http.server）。

【内容摘要】
- _DEFAULT_PORT / _MAX_PORT_RETRIES : 默认端口与端口重试次数。
- ArtifactServer                     : 本地 HTTP 产物服务。
- ArtifactServer.start / stop        : 启动 / 停止服务。
- ArtifactServer.register            : 登记产物，返回可下载 URL。
- ArtifactServer._resolve            : 按 sandbox_id + filename 查宿主路径。
- ArtifactServer._make_handler       : 构造请求处理器（GET 下载）。

【职责边界】
- 只负责：登记产物路径、按 URL 提供文件下载/预览、端口占用时自动重试。
- 不负责：产物内容的生成（reporter）、产物写盘（local_store）、服务的启动时机与
  生命周期编排（bootstrap）、访问控制与鉴权（当前实现无）。

## 0. 结构树

### 0.1. 静态结构树

```
server.py — 产物下载/预览的轻量 HTTP 服务
│
├─ _DEFAULT_PORT: int = 18080                 ← 默认端口
├─ _MAX_PORT_RETRIES: int = 10                ← 端口重试次数
├─ logger: Logger                             ← 模块日志器
│
└─ ArtifactServer                             ← 本地 HTTP 产物服务
    ├─ __init__(host="127.0.0.1", port=18080)  ← 初始化
    │   ├─ _host: str                          ← 绑定地址
    │   ├─ _port: int                          ← 绑定端口（可递增）
    │   ├─ _registry: dict[str, str]           ← {sandbox_id}/{filename} → 宿主路径
    │   ├─ _lock: threading.Lock               ← 保护 _registry
    │   ├─ _server: ThreadingHTTPServer | None ← HTTP 服务实例
    │   └─ _thread: threading.Thread | None    ← 服务后台线程
    │
    ├─ base_url (property) -> str              ← http://host:port
    │
    ├─ start() -> None                         ← 启动服务（后台线程）
    │   ├─ 端口占用时逐次 +1 重试（最多 _MAX_PORT_RETRIES 次）
    │   ├─ ThreadingHTTPServer((host, port), _make_handler())
    │   ├─ threading.Thread(serve_forever, daemon=True).start()
    │   └─ 仍失败 → raise RuntimeError
    │
    ├─ stop() -> None                          ← 停止服务
    │   ├─ _server.shutdown()
    │   └─ _thread.join(timeout=2)
    │
    ├─ register(sandbox_id, filename, host_path) -> str ← 登记产物
    │   ├─ _registry[key] = host_path          ← 加锁写入
    │   └─ return "{base_url}/artifacts/{sandbox_id}/{quote(filename)}"
    │
    ├─ _resolve(sandbox_id, filename) -> str | None ← 查宿主路径（加锁）
    │
    └─ _make_handler() -> type[BaseHTTPRequestHandler] ← 构造请求处理器
        └─ _Handler（内嵌类）
            ├─ log_message            ← 转发到 logger.debug
            └─ do_GET                 ← 处理 GET 下载
                ├─ 非 /artifacts/ 前缀 → 404
                ├─ 含 ".." 或格式非法 → 403（路径穿越防护）
                ├─ _resolve 未命中 → 404（未登记）
                ├─ 文件不存在/非文件 → 404
                └─ 命中 → 200 + 文件字节
                      ├─ Content-Type: application/octet-stream
                      ├─ Content-Disposition: inline; filename="{basename}"
                      └─ Content-Length
```

### 0.2. 请求处理流程树（do_GET）

```
GET /artifacts/{sandbox_id}/{filename}
│
├─ unquote(path)
│
├─ 校验 1：前缀 /artifacts/ ？
│   └─ 否 → 404
│
├─ 拆分：rest = path[11:] → parts = rest.split("/", 1)
│
├─ 校验 2：parts 为 2 段 且 rest 不含 ".." ？
│   └─ 否 → 403 "path traversal blocked"
│
├─ _resolve(sandbox_id, filename)
│   ├─ 查 _registry（加锁）
│   └─ 未命中 → 404 "artifact not registered"
│
├─ 校验 3：宿主路径存在且为文件？
│   └─ 否 → 404 "file not found"
│
└─ 命中 → 200
    ├─ Content-Type: application/octet-stream
    ├─ Content-Disposition: inline; filename="{basename}"
    ├─ Content-Length: {len}
    └─ 写文件字节
```

### 0.3. 运行时调用树

```
① 启动（bootstrap 阶段）
bootstrap
    └─ ArtifactServer(host, port)
          └─ server.start()
                ├─ 端口重试绑定
                ├─ ThreadingHTTPServer(...)
                └─ 后台 daemon 线程 serve_forever
        ═══════════ 服务就绪 ═══════════
    └─ base_url → 后续 register 返回的 URL 前缀

② 登记产物（产物生成后）
调用方（沙箱 / 工具 / 产物流程）
    └─ server.register(sandbox_id, filename, host_path)
          ├─ _registry[key] = host_path（加锁）
          └─ return 可下载 URL

③ 下载（外部请求）
浏览器 / 客户端
    └─ GET /artifacts/{sandbox_id}/{filename}
          └─ _Handler.do_GET
                ├─ 前缀校验 → 穿越校验 → _resolve → 文件校验
                └─ 200 + 文件字节

④ 停止（退出时）
bootstrap / 退出钩子
    └─ server.stop()
          ├─ _server.shutdown()
          └─ _thread.join(timeout=2)
```

### 0.4. 补充

**`server.py` 是产物的对外 HTTP 出口——把经 `register()` 登记的宿主文件以 `/artifacts/{sandbox_id}/{filename}` 提供下载/预览，由 bootstrap 启停，零第三方依赖。**

几条主线：

- **登记制访问**：只有 `register` 过的 `{sandbox_id}/{filename}` 才可下载——`_registry` 是白名单，未登记一律 404。
- **零第三方依赖**：仅用 stdlib `http.server` + `ThreadingHTTPServer`，后台 daemon 线程运行，`stop` 时 shutdown + join。
- **端口自动重试**：端口被占用时逐次 +1，最多 `_MAX_PORT_RETRIES`（10）次；仍失败抛 `RuntimeError`，避免静默失败。
- **两道安全校验**：前缀必须为 `/artifacts/`（否则 404）；`rest` 含 `..` 或格式非法则 403（路径穿越防护）。
- **filename 可含子目录**：如 `workspace/x.pptx`；下载名取 `basename`（`display_name`），避免暴露完整路径。
- **线程安全**：`_registry` 读写由 `_lock` 保护，适应多请求并发。
- **仅本机可达**：默认绑定 `127.0.0.1`，无鉴权——定位是本地预览/下载，非公网服务。
- **与 local_store 的关系**：`local_store` 负责**写盘**（`save_artifact`），`server` 负责**对外提供**（`register` + HTTP）——两者分工，前者产、后者发。
- **生命周期由 bootstrap 编排**：本文件只实现"启/停/登记/服务"，何时启动、何时停止由上层决定。
