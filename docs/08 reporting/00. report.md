---

name: Reporting package — 报告生成模块。

description: 

【整体职责】
负责 Leader 收尾阶段的报告产出：从 thread 累积 state 提取证据，按优先级渲染为
Markdown 报告，可选保存为 artifact。对上层提供渠道无关的统一入口，
CLI / API / IM 各自负责呈现。

【内容摘要】
- MarkdownReporter            : 报告渲染器，三级 fallback 产出报告文本。
- ReportResult                : 报告结果数据结构（文本 + 产物 + 警告）。
- thread_report               : 渠道无关的报告生成服务（取 state → 合成 → 保存）。
- ReportArtifact              : 报告生成结果（渠道无关），对外导出。
- generate_report_from_thread : 报告生成服务主入口，对外导出。

【职责边界】
- 只负责：报告文本渲染（markdown_reporter）、报告结果结构（result）、
  渠道无关的生成服务编排（thread_report）。
- 不负责：证据收集（middleware / tool）、report.generated 事件发送（LeaderAgent.run）、
  交互呈现（console / HTTP / IM，由调用渠道负责）、artifact 存储实现（artifact_store）。

【依赖方向】
agents 层不 import app 层，thread_report 用 Protocol 描述 runtime 形状，
AppRuntime 结构性满足，避免反向依赖。
