---

name: LoopDetectionMiddleware — ReAct 死循环熔断器。

description:

【要解决的问题】
default 模式没有 Todo 完成度强制时，模型可能陷入死循环：
反复用同一个工具、同一组参数调用，白白烧 token，直到 recursion_limit 耗尽
才被迫停下。本中间件在 after_model 检测这种重复调用，超阈时熔断：

1. 清掉最后一条 AIMessage 的 tool_calls；
2. 注入一条终止引导（隐藏 HumanMessage）；
3. jump_to="model"，强制模型基于已有信息收尾。

【启用范围】
全模式挂载（default + expert）。

【思路来源】
借鉴 deer-flow LoopDetectionMiddleware 的思路。

---

## 0. 结构树

### 0.1. 静态结构树（模块 → 函数/类 → 方法）

```
LoopDetectionMiddleware — ReAct 死循环熔断器
│
├─ class LoopDetectionConfig(frozen dataclass)   ← 检测配置
│   ├─ enabled: bool = True                      ← 是否启用
│   ├─ window: int = 10                          ← 扫描最近 N 条消息
│   └─ threshold: int = 3                        ← 同 (tool, args) 出现 M 次触发
│
├─ 模块级工具函数
│   ├─ _hash_args(args)                          ← 参数哈希（sort_keys 截断 100）
│   ├─ _detect_loop(messages, window, threshold) ← 找重复 (tool_name, args_hash)
│   └─ _build_guidance(loop_tool)                ← 终止引导文本
│
└─ class LoopDetectionMiddleware(AgentMiddleware)
    ├─ state_schema = ThreadState
    ├─ __init__(config=None)                     ← 默认 LoopDetectionConfig()
    ├─ after_model(state, runtime)               ← 检测 → 清 tool_calls → 注入引导 → jump
    └─ aafter_model(state, runtime)              ← 转调同步版
```

---

### 0.2. 运行时调用树（after_model 主流程）

```
LangGraph 进入 after_model 阶段
│
└─ LoopDetectionMiddleware.after_model(state, runtime)
    │
    ├─ if not config.enabled: return None
    │
    ├─ messages = state["messages"]
    ├─ loop_tool = _detect_loop(messages, window=10, threshold=3)
    │   ├─ recent = messages[-window:]
    │   ├─ for AIMessage.tool_calls:
    │   │   ├─ name = tc["name"]
    │   │   ├─ args = tc["args"]
    │   │   └─ call_counts[(name, _hash_args(args))] += 1
    │   └─ 任一 key count >= threshold → return name
    │
    ├─ if loop_tool is None: return None
    │
    ├─ last_ai = 最后一条 AIMessage
    ├─ if not last_ai or not last_ai.tool_calls: return None
    │
    ├─ new_kwargs = 剥掉 tool_calls / function_call
    │                + 加 loop_detected = loop_tool
    │
    ├─ cleared = AIMessage(
    │       id=last_ai.id,               ← 复用 id，让 add_messages 替换而非追加
    │       content=last_ai.content,
    │       tool_calls=[],               ← 清空
    │       additional_kwargs=new_kwargs)
    │
    ├─ guidance = HumanMessage(
    │       name="loop_detection",
    │       hide_from_ui=True,
    │       content=_build_guidance(loop_tool))
    │
    └─ return {"messages": [cleared, guidance], "jump_to": "model"}
```
