---

name: SkillActivationMiddleware — before_model 主动建议相关 skill。

desvription: 

【整体职责】
在每次进入 model 之前，分析最后一条 user message 的关键词，主动给出
「本次任务可能相关的 skill」建议，写入 ThreadState.skill_suggestion
（旁路存档）。lead agent 看到建议后，自己决定是否进一步调 skill_search
或读 SKILL.md —— 建议是提示性的，不强制。

【内容摘要】
- _KEYWORD_MAP                         : 关键词 → 候选 skill name 映射表。
- SkillActivationMiddleware.before_model: 从最后一条 user message 提取关键词并产出建议。
- SkillActivationMiddleware._match_keywords : 关键词匹配 → 去重后的建议列表。

【职责边界】
- 只负责：关键词匹配、产出建议、写 ThreadState.skill_suggestion（旁路字段）。
- 不负责：实际的 skill 选择与注入（SkillInjectionMiddleware）、skill 的存储
  与检索（skill 子系统）、agent 是否采纳建议（agent 自行决定）、
  skill_search 的执行（由 agent 调工具触发）。

## 0. 结构树

---

### 0.1. 静态结构树（模块 → 类 → 方法）

```
SkillActivationMiddleware — before_model 主动建议相关 skill
│
├─ 模块级常量
│   └─ _KEYWORD_MAP: {关键词: [候选 skill name, ...]}
│       ← 与 find-skills SKILL.md 的 keyword 表一致
│       （frontend/ui/react/vue → frontend-design；
│         chart/graph/visualization → chart-visualization；
│         diagram → architecture-diagram / concept-diagrams；
│         github/pr/code review → github-*；
│         debug/bug → systematic-debugging / python-debugpy；
│         test/tdd → test-driven-development；
│         plan/spike → plan / spike；
│         refactor/simplify → simplify-code）
│
└─ class SkillActivationMiddleware(AgentMiddleware)
    ├─ before_model(state, runtime)      ← 核心：取末条 user message → 匹配 → 写 skill_suggestion
    │   ├─ messages = state["messages"]
    │   ├─ last_msg = messages[-1]
    │   ├─ content  = last_msg.content（非 str → return None）
    │   ├─ suggestions = _match_keywords(content.lower())
    │   └─ return {"skill_suggestion": suggestions} | None
    │
    └─ _match_keywords(text)             ← 关键词子串匹配 + skill 去重
        ├─ for keyword, skill_names in _KEYWORD_MAP
        │   └─ if keyword in text:
        │       └─ for skill_name in skill_names:
        │           └─ seen_skills 去重后 append {"keyword", "skill"}
        └─ return suggestions
```

---

### 0.2. 运行时调用树（按执行阶段分：取消息 → 匹配 → 写建议）

```
LangGraph 进入 before_model 阶段
│
└─ SkillActivationMiddleware.before_model(state, runtime)
    │
    ├─ 【阶段 1：取最后一条消息】
    │   ├─ messages = state.get("messages") or []
    │   │   └─ if not messages: return None              ← 短路：无消息
    │   ├─ last_msg = messages[-1]
    │   ├─ content  = getattr(last_msg, "content", "")
    │   │   └─ if not isinstance(content, str): return None  ← 短路：非纯文本
    │   │
    ├─ 【阶段 2：关键词匹配】
    │   └─ suggestions = _match_keywords(content.lower())
    │       ├─ for keyword, skill_names in _KEYWORD_MAP:
    │       │   └─ if keyword in text:
    │       │       └─ for skill_name in skill_names:
    │       │           ├─ if skill_name in seen_skills: skip
    │       │           └─ seen_skills.add + append {"keyword", "skill"}
    │       │
    │       └─ if not suggestions: return None           ← 短路：无命中
    │
    └─ 【阶段 3：写旁路建议】
        └─ return {"skill_suggestion": suggestions}       ← 写 ThreadState.skill_suggestion
                                                             不注入 SystemMessage
                                                             不改 messages
```

### 0.3. 与上下游的衔接（本文件之外，仅示意）

```
用户发消息
    │
    ▼
SkillActivationMiddleware.before_model（本文件）
│
├─ 只读 state.messages[-1].content
├─ 纯关键词匹配（零 LLM 调用）
└─ 写 ThreadState.skill_suggestion（旁路存档）
      │
      ▼
lead agent 看到建议（建议非强制）
│
└─ 自行决定是否调 skill_search / 读 SKILL.md
      │
      ▼
SkillInjectionMiddleware.before_model（下游，另一条路径）
│
└─ 真正决定 active skills → 注入 SystemMessage + 写 provenance
```
