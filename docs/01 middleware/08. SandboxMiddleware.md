---

name: SandboxMiddleware — Sandbox 生命周期中间件（只 async，Grill #9）。

description:

【整体职责】
管理 sandbox 的「按需获取（lazy acquire）→ 跨轮复用 → 结束释放」生命周期，
并把 present_files 的虚拟路径落成真实产出物 + 注册到 ArtifactServer。

【INVARIANT（必须保持的不变量）】
- lazy_init 硬编码 True：没有 before_agent hook；sandbox 只有在
  sandbox 工具真正被调用时才 acquire。
- abefore_model：从 state["sandbox"] 恢复 ContextVar。
  subagent 共享父 sandbox_id（块 D1）：父已设 state["sandbox"]，
  子进程/子 agent 在这里恢复 ContextVar，awrap_tool_call 看到已设就跳过 acquire。
- awrap_tool_call：sandbox 工具首次调用时执行 acquire + set_sandbox_id，
  并用 Command 把 sandbox_id 持久化进 state。
- present_files 调用后：把 virtual path 解析成 host path，复制到
  .poirot/outputs/，写入 state.artifacts 并向 ArtifactServer 注册。
- aafter_agent release：release 不销毁（LocalSandboxProvider 为 no-op）。
- Sandbox 中间件在中间件列表外层；ToolCall 在内层 catch SandboxError（Grill #9）。
- 非 sandbox 工具（web_search 等）不触发 acquire。

## 0. 结构树

### 0.1. 静态结构树（模块 → 类 → 方法）

```
SandboxMiddleware — Sandbox 生命周期中间件（只 async，Grill #9）
│
├─ 模块级常量
│   ├─ _VIRTUAL_PREFIX = "/mnt/poirot/user-data/"
│   └─ logger
│
└─ class SandboxMiddleware(AgentMiddleware)
    ├─ __init__(provider, artifact_server=None, sandbox_root=None)
    │   ← 持有 provider + artifact_server + sandbox_root
    │
    ├─ abefore_model(state, runtime)              ← 从 state["sandbox"] 恢复 ContextVar
    │   ├─ if get_sandbox_id() is not None: return None    ← 已设不覆盖
    │   └─ sandbox_state.sandbox_id → set_sandbox_id(...)
    │
    ├─ _emit_sandbox_acquired(sandbox_id) [static] ← 推 sandbox_update custom 事件
	│	                         					    (推送到UI界面、失败只记录)
    │   └─ get_stream_writer()({"type": "sandbox_update", "content": sandbox_id})
    │
    ├─ awrap_tool_call(request, handler)          ← 核心：按需 acquire + present_files 落产出物
    │   ├─ tool_name ∉ SANDBOX_TOOL_NAMES → 直接 handler(request)
    │   ├─ first_acquire = (get_sandbox_id() is None)
    │   ├─ [first_acquire] 取 thread_id → provider.acquire
    │   │                  → set_sandbox_id → _emit_sandbox_acquired
    │   ├─ result = await handler(request)
    │   ├─ [present_files + artifact_server] _register_artifacts → 追加 Download 链接
    │   └─ [first_acquire + ToolMessage] return Command(update={sandbox, messages})
    │
    ├─ _register_artifacts(request, sandbox_id)   ← 解析/复制/注册产出物
    │   ├─ 取 args.paths（dict / str / list）
    │   ├─ sandbox = provider.get(sandbox_id)
    │   ├─ outputs_dir = _PROJECT_ROOT / ".poirot" / "outputs"
    │   └─ for vp in paths:
    │       ├─ 前缀校验（_VIRTUAL_PREFIX）
    │       ├─ 解析 host_path（sandbox.get_host_path / sandbox_root 回退）
    │       ├─ copy2 → outputs_dir（固定产出物目录）
    │       ├─ artifact_server.register → urls
    │       └─ 复制失败时再用原始 host_path 注册（去重）
    │
    └─ aafter_agent(state, runtime)               ← 释放 sandbox（release 不销毁）
        └─ provider.release(state["sandbox"]["sandbox_id"])
```

### 0.2. 运行时调用树（按 hook 分）

```
【阶段 A：模型调用前 — abefore_model】

abefore_model(state, runtime)
│
├─ if get_sandbox_id() is not None: return None         ← 已设（lead 同进程多轮）
├─ sandbox_state = state["sandbox"]
└─ if sandbox_state.sandbox_id:
      set_sandbox_id(sandbox_state.sandbox_id)          ← subagent 共享父 sandbox_id

【阶段 B：工具调用 — awrap_tool_call】

awrap_tool_call(request, handler)
│
├─ tool_name = request.tool_call["name"]
├─ if tool_name not in SANDBOX_TOOL_NAMES:
│     return await handler(request)                     ← 非 sandbox 工具，不 acquire
│
├─ sandbox_id = get_sandbox_id()
├─ first_acquire = sandbox_id is None
│
├─ if first_acquire:
│   ├─ thread_id = request.runtime.config.configurable.thread_id
│   │   └─ 缺失 → raise SandboxRuntimeError
│   ├─ sandbox_id = provider.acquire(thread_id)
│   ├─ set_sandbox_id(sandbox_id)
│   └─ _emit_sandbox_acquired(sandbox_id)
│
├─ result = await handler(request)
│
├─ if tool_name == "present_files" and artifact_server is not None:
│   ├─ urls = _register_artifacts(request, sandbox_id)
│   └─ if urls and result is ToolMessage:
│         result = ToolMessage(content + "\n\nDownload:\n  url...")
│
└─ if first_acquire and result is ToolMessage:
      return Command(update={"sandbox": {"sandbox_id": ...}, "messages": [result]})
   else:
      return result

【阶段 C：run 结束 — aafter_agent】

aafter_agent(state, runtime)
│
└─ if state["sandbox"].sandbox_id:
      provider.release(sandbox_id)                      ← release 不销毁（Local no-op）
```



---

| 存储位 | 生命周期 | 作用 |
|---|---|---|
| `ContextVar`（`get/set_sandbox_id`） | 单次执行上下文 | 「当前正在用哪个 sandbox」的即时指针 |
| `state["sandbox"]` | 跨轮、可持久化（checkpoint） | sandbox_id 的**持久档案**，重启/换轮后靠它恢复 |
| `Command(update=...)` | 图状态更新 | 把 ContextVar 的值**写回 state** 的通道 |

三者关系：`ContextVar` 是快指针，`state` 是慢档案，`Command` 是把快指针落成慢档案的动作。

## 1. lazy acquire —— 按需获取

**触发点**：`awrap_tool_call`，且只在 sandbox 工具被调用时才走。

```python
tool_name = request.tool_call.get("name", "")
if tool_name not in SANDBOX_TOOL_NAMES:
    return await handler(request)        # 非 sandbox 工具：直接透传，不 acquire
```

**判定"要不要 acquire"**：

```python
sandbox_id = get_sandbox_id()            # 读 ContextVar
first_acquire = sandbox_id is None       # ContextVar 没设 = 本轮首次
```

**首次 acquire 做三件事**：

```python
if first_acquire:
    thread_id = ...runtime.config.configurable["thread_id"]   # ① 拿 thread_id
    sandbox_id = self._provider.acquire(thread_id)            # ② 真正起 sandbox
    set_sandbox_id(sandbox_id)                                # ③ 写 ContextVar
    self._emit_sandbox_acquired(sandbox_id)                   # 推 custom 事件给 UI
```

- `thread_id` 从 `runtime.config.configurable` 取，缺失直接 `raise SandboxRuntimeError`——因为 acquire 必须有归属，不能凭空起。
- `provider.acquire(thread_id)` 是真正干活的一步（起容器/进程/目录）。
- `set_sandbox_id` 写 ContextVar，让**同一执行上下文里后续的工具调用**立刻能读到，不用再 acquire。

为什么叫 lazy：**没有 `before_agent`**，不提前建；只有第一个 sandbox 工具真的来了才建。



注意：`acquire` 给你的是一个 **sandbox_id（字符串句柄）**，代表"这个 thread 的 sandbox 实例"；  
真正要操作 sandbox 时，用 id 找 `provider.get()` 换回 **sandbox 对象**（能翻译路径、能执行）；  
中间件层只流转 id，因为它轻量、可持久化、能进 ContextVar 和 state；  
对象本身由 provider 集中持有和管理，不进 state、不进 checkpoint。

## 2. 跨轮复用 —— 两层复用

复用分两种场景，分别靠 ContextVar 和 state 配合。

### 2.1. 同一轮 / 同一进程内复用（靠 ContextVar）

首次 acquire 后 ContextVar 已设，后面同一上下文里的 sandbox 工具调用：

```python
sandbox_id = get_sandbox_id()      # 非 None
first_acquire = False              # 跳过 acquire
...
result = await handler(request)    # 直接用现成的
```

不需要重新 acquire，直接复用。

### 2.2. 跨轮 / subagent 复用（靠 state + abefore_model）

新一轮开始时 ContextVar 是空的，但 `state["sandbox"]` 里存着上一轮 acquire 的 sandbox_id。`abefore_model` 负责把它恢复到 ContextVar：

```python
async def abefore_model(self, state, runtime):
    if get_sandbox_id() is not None:
        return None                                # 已设（同进程多轮），不覆盖
    sandbox_state = state.get("sandbox")
    if isinstance(sandbox_state, dict) and sandbox_state.get("sandbox_id"):
        set_sandbox_id(sandbox_state["sandbox_id"]) # 从 state 恢复 ContextVar
    return None
```

两条路都能复用：

- **lead 同进程多轮**：ContextVar 可能还没清，`get_sandbox_id() is not None` 直接 return，不覆盖。
- **subagent 继承父 sandbox**：subagent 的 state 里带着父的 `sandbox.sandbox_id`，这里恢复 ContextVar 后，`awrap_tool_call` 看到已设 → 跳过 acquire → 复用父 sandbox。

这就是"跨轮复用"的完整闭环：**ContextVar 管即时，state 管持久，abefore_model 管恢复**。

### 2.3. 首次 acquire 时把 sandbox_id 落进 state（靠 Command）

光有 ContextVar 不够——ContextVar 进程内有效，checkpoint 不认它。所以首次 acquire 且结果是 ToolMessage 时，用 `Command` 把 sandbox_id 写回 state：

```python
if first_acquire and isinstance(result, ToolMessage):
    return Command(
        update={
            "sandbox": {"sandbox_id": sandbox_id},   # ← 持久化到 state
            "messages": [result],
        }
    )
return result
```

这一步让"跨轮复用"成立：下一轮 `abefore_model` 才有 `state["sandbox"]` 可恢复。

## 3. 结束释放 —— aafter_agent

run 结束时释放：

```python
async def aafter_agent(self, state, runtime):
    sandbox_state = state.get("sandbox")
    if sandbox_state and sandbox_state.get("sandbox_id"):
        self._provider.release(sandbox_state["sandbox_id"])
```

注意注释里的语义：**release 不销毁**。`LocalSandboxProvider` 的 release 是 no-op；远端 provider 可据此真正回收。也就是说 release 的"释放力度"由 provider 决定，中间件只管在正确时机调它。

## 4. present_files → 真实产出物 + ArtifactServer

这条链路在 `awrap_tool_call` 里，只对 `present_files` 触发：

```python
if tool_name == "present_files" and self._artifact_server is not None:
    urls = self._register_artifacts(request, sandbox_id)
    if urls and isinstance(result, ToolMessage):
        url_text = "\n".join(f"  {u}" for u in urls)
        content = ...
        result = ToolMessage(
            content=f"{content}\n\nDownload:\n{url_text}",   # 追加下载链接
            tool_call_id=result.tool_call_id,
            name=result.name,
        )
```

`_register_artifacts` 是真正干活的四步：

### 4.1. 解析 paths

```python
args = request.tool_call.get("args", {})
paths = args.get("paths", []) if isinstance(args, dict) else ...
```

兼容 dict / str / list 三种入参形态。

### 4.2. 前缀校验

```python
if not isinstance(vp, str) or not vp.startswith(_VIRTUAL_PREFIX):
    logger.warning(...)
    continue
```

只接受 `/mnt/poirot/user-data/` 下的虚拟路径，防止越权读任意 host 路径。

### 4.3. 解析 host 路径

```python
sandbox = self._provider.get(sandbox_id)
try:
    if sandbox is not None:
        host_path = sandbox.get_host_path(vp)       # 优先用 sandbox translator
    else:
        host_path = f"{self._sandbox_root}/{sandbox_id}/{filename}"  # 回退拼接
except Exception:
    host_path = f"{self._sandbox_root}/{sandbox_id}/{filename}"      # 再回退
```

优先让 sandbox 自己把虚拟路径翻译成 host 路径；拿不到就按 `sandbox_root/sandbox_id/filename` 拼。

### 4.4. 复制 + 注册

```python
dest = outputs_dir / filename
shutil.copy2(host_path, dest)                       # 复制到 .poirot/outputs/
url = self._artifact_server.register(sandbox_id, filename, str(dest))
urls.append(url)
```

- 复制到**固定目录** `.poirot/outputs/`，用户总知道去哪找产出物。
- 注册到 `ArtifactServer` 得到 HTTP 下载 URL。
- 复制失败时再用**原始 host_path** 注册一次（去重），保证至少原始路径可下载。

最后把 urls 拼成 "Download:\n  url..." 追加到 ToolMessage.content，回给 LLM / 用户。

## 5. 整体串联

```
第一次 sandbox 工具调用
│
├─ ContextVar 空 → first_acquire=True
├─ thread_id → provider.acquire → sandbox_id
├─ set_sandbox_id(sandbox_id)          ← ContextVar 记住
├─ _emit_sandbox_acquired(...)          ← 推 custom 事件给 UI
├─ handler(request)                     ← 执行工具
│
└─ first_acquire + ToolMessage
   └─ Command(update={"sandbox": {"sandbox_id": ...}})
        ← 把 sandbox_id 持久化进 state

同一上下文后续 sandbox 工具
└─ get_sandbox_id() 非 None → 跳过 acquire，直接复用

下一轮 / subagent
└─ abefore_model 从 state["sandbox"] 恢复 ContextVar → 复用

present_files 调用
└─ _register_artifacts：解析 → 前缀校验 → host 路径 → 复制到 .poirot/outputs/ → 注册 ArtifactServer

run 结束
└─ aafter_agent → provider.release(sandbox_id)（释放力度由 provider 决定）
```

**ContextVar 管即时复用，state 管跨轮档案，Command 把前者落成后者，abefore_model 把后者恢复成前者；present_files 走一套"翻译→复制→注册"把虚拟路径变成可下载产出物；aafter_agent 在正确时机把释放动作交给 provider。**
