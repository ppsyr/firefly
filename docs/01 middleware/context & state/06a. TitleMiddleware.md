---

name: TitleMiddleware — after_agent 设置 metadata.title。

description:

【整体职责】
在 run 结束时，为本次运行生成一个简短标题，写入 state.metadata.title。
标题来源按优先级取：
1. state["research_question"]（研究型任务的正式问题）；
2. state["user_input"]（普通对话的用户输入）；
3. 兜底字面量 "Untitled"。  
标题统一截断到 60 个字符，避免过长污染 metadata / UI 展示。

【只写 metadata】
本中间件只往 metadata 里塞 title，不改 messages、不改其他 state 字段，属于轻量、幂等的元数据写入。

---

## 0. 结构树

---

### 0.1. 静态结构树（模块 → 类 → 方法）

```
TitleMiddleware — after_agent 设置 metadata.title
│
└─ class TitleMiddleware(AgentMiddleware)
    ├─ after_agent(state, runtime)       ← 核心：取标题来源 → 截断 60 → 写 metadata.title
    │   └─ source = research_question or user_input or "Untitled"
    │
    └─ aafter_agent(state, runtime)      ← 异步：直接转调同步版
```

---

### 0.2. 运行时调用树（按执行阶段分：取来源 → 截断 → 写 metadata）

```
LangGraph 进入 after_agent 阶段
│
└─ TitleMiddleware.after_agent(state, runtime)
    │
    ├─ 【阶段 1：按优先级取标题来源】
    │   ├─ source = state.get("research_question")
    │   ├─ if not source: source = state.get("user_input")
    │   └─ if not source: source = "Untitled"            ← 兜底
    │
    ├─ 【阶段 2：强转字符串 + 截断】
    │   └─ str(source)[:60]                              ← 最多 60 字符
    │
    └─ 【阶段 3：写 metadata】
        └─ return {"metadata": {"title": ...}}           ← 合并进 state.metadata
                                                            不改 messages
                                                            不改其他 state 字段
```
