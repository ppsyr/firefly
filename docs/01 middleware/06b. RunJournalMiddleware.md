---

name: RunJournalMiddleware — 把 agent / model / tool 生命周期事件记入 RunJournal。

description:

【整体职责】
以 AgentMiddleware 形式（取代旧 BaseMiddleware 体系）监听 agent / model / tool 的生命周期 hook，把关键事件追加写入 RunJournal，供审计、回放、UI 活动展示使用。

【依赖获取方式】
journal / run_id / activity_tracker / model 等依赖都从 runtime configurable 读取，统一走模块级函数 _get_runtime_value（它内部走三到四条路径，兼容 LangGraph ≥1.1.9 与测试用的 SimpleNamespace）。

【模块级函数的复用】
_get_runtime_value 为模块级函数，除本文件外，TodoMiddleware / _jump_budget等也复用同一套取值逻辑，避免各处重复实现。

【无 journal 时的行为】
任何 hook 里 journal 为 None 都静默跳过，不报错（容忍运行环境缺件）。
---

## 0. 结构树

### 0.1. 静态结构树（模块 → 函数/类 → 方法）

```
RunJournalMiddleware — 把 agent/model/tool 生命周期事件记入 RunJournal
│
├─ _get_runtime_value(runtime, key, default=None)     ← 多路径取 runtime configurable
│   ├─ Path 1: runtime.context（dict / 对象）
│   ├─ Path 2: langgraph.config.get_config()["configurable"]
│   ├─ Path 3: runtime.get_configurable()
│   ├─ Path 4: runtime.config["configurable"]
│   └─ 全失败 → default
│
├─ _tool_text(result)                                 ← tool 结果压平成字符串
│   ├─ ToolMessage: content str → 原样
│   │                content list → 拼接（dict 取 "text"）
│   │                其他 → str(content)
│   └─ 其他对象 → str(result)
│
├─ _result_status(result)                             ← 从结果识别 error / ok
│   ├─ ToolMessage(status="error") → "error"
│   ├─ Command.update.errors 含 kind="failure" → "error"
│   ├─ Command.update.messages 含 ToolMessage(status="error") → "error"
│   └─ 其他 → "ok"
│
├─ _truncate_tool_input(tool_input)                   ← tool input 短摘要（≤80）
│   ├─ dict: command → path → str(tool_input)
│   └─ 其他: str(tool_input)
│
└─ class RunJournalMiddleware(AgentMiddleware)
    ├─ _journal(runtime)              ← runtime → journal（无则 None）
    ├─ _run_id(runtime)               ← runtime → run_id（无则 None）
    ├─ _activity_tracker(runtime)     ← runtime → activity_tracker（无则 None）
    ├─ _model_name(runtime)           ← runtime → model（str，无则 ""）
    │
    ├─ before_agent(state, runtime)   ← journal "agent.started"
    │   └─ journal.append("agent.started", {run_id})
    │
    ├─ after_agent(state, runtime)    ← journal "agent.finished"
    │   └─ journal.append("agent.finished", {run_id})
    │
    ├─ before_model(state, runtime)   ← journal "llm.request"
    │   └─ journal.append("llm.request", {run_id, model})
    │
    ├─ after_model(state, runtime)    ← journal "llm.response"
    │   └─ journal.append("llm.response", {run_id, model})
    │
    ├─ wrap_tool_call(request, handler)                ← 同步工具包装
    │   │
    │   ├─ 【取依赖】
    │   │   ├─ runtime   = request.runtime
    │   │   ├─ journal   = _journal(runtime)
    │   │   ├─ run_id    = _run_id(runtime)
    │   │   ├─ tool_call = request.tool_call
    │   │   ├─ tool_name = tool_call["name"]
    │   │   └─ tool_input= tool_call["args"]
    │   │
    │   ├─ 【调用前打点】
    │   │   ├─ journal.append("tool.called", {run_id, tool_name, tool_input})
    │   │   ├─ tracker = _activity_tracker(runtime)
    │   │   ├─ activity_id = "tool_name:tool_call_id"
    │   │   └─ tracker.start(activity_id, "tool", "tool_name: 摘要")
    │   │
    │   ├─ 【调 handler】
    │   │   ├─ result = handler(request)
    │   │   └─ status = _result_status(result)        ← ok / error
    │   │
    │   ├─ 【异常分支】
    │   │   ├─ status = "error"
    │   │   ├─ tracker.finish(activity_id, status="error", error=str(exc))
    │   │   ├─ journal.append("tool.finished", {..., status="error"})
    │   │   └─ raise                                  ← 异常继续上抛
    │   │
    │   ├─ 【成功分支打点】
    │   │   ├─ tracker.finish(activity_id, status, output_size=len(_tool_text(result)))
    │   │   └─ journal.append("tool.finished", {..., output: _tool_text(result)[:2000], status})
    │   │
    │   └─ return result
    │
    └─ awrap_tool_call(request, handler)               ← 异步工具包装（逻辑同同步）
        │
        ├─ 【取依赖】同同步版
        │
        ├─ 【调用前打点】journal.append("tool.called", ...) + tracker.start(...)
        │
        ├─ 【调 handler】result = await handler(request)
        │                 status = _result_status(result)
        │
        ├─ 【异常分支】tracker.finish(status="error", error=str(exc))
        │              journal.append("tool.finished", {..., status="error"})
        │              raise
        │
        ├─ 【成功分支打点】tracker.finish(status, output_size=len(_tool_text(result)))
        │                  journal.append("tool.finished", {..., output: _tool_text(result)[:2000], status})
        │
        └─ return result
```

### 0.2. 运行时调用树（按 hook 分）

```
【agent 生命周期】
before_agent → journal.append("agent.started", {run_id})
after_agent  → journal.append("agent.finished", {run_id})

【model 生命周期】
before_model → journal.append("llm.request",  {run_id, model})
after_model  → journal.append("llm.response", {run_id, model})

【tool 生命周期】wrap_tool_call / awrap_tool_call
│
├─ runtime   = request.runtime
├─ journal   = _journal(runtime)
├─ run_id    = _run_id(runtime)
├─ tool_call = request.tool_call
├─ tool_name / tool_input
│
├─ journal.append("tool.called", {run_id, tool_name, tool_input})
├─ tracker.start(activity_id, "tool", "tool_name: 摘要")
│
├─ try:
│   ├─ result = handler(request)                 ← await 版为 await handler(request)
│   └─ status = _result_status(result)
│
├─ except Exception as exc:
│   ├─ status = "error"
│   ├─ tracker.finish(activity_id, status="error", error=str(exc))
│   ├─ journal.append("tool.finished", {..., status="error"})
│   └─ raise
│
├─ tracker.finish(activity_id, status, output_size=len(_tool_text(result)))
├─ journal.append("tool.finished", {..., output: _tool_text(result)[:2000], status})
└─ return result
```
