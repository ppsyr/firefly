
## 1. Subagent 最小可用流程

### 1.1. 4 个组件的角色

| 文件 | 角色 | 一句话职责 |
|---|---|---|
| `subagent_runtime.py` | 执行器 | 进程内调 lead factory，建隔离 state，跑 leaf-role 子 Agent |
| `subagent_specialist.py` | 适配器 | 把 runtime 包装成 `SpecialistAgent` 契约（name / capabilities / invoke） |
| `self_copy_context_summarizer.py` | 输入端闸门 | 把父 ThreadState 压成 context_summary |
| `self_copy_result_summarizer.py` | 输出端闸门 | 把子 Agent 原始输出压成 SpecialistResult + 校验成功标准 |

**关系**：Specialist 持有 Runtime；两个 Summarizer 被 tool 闭包捕获。**四者构成"一进一出 + 一适配一执行"的最小闭环。**

---

### 1.2. 组件装配关系图

```
                    SubagentSpecialist
                    ├─ name = "subagent"
                    ├─ capabilities = (RESEARCH,)
                    ├─ invoke() → 转发
                    └─ _runtime: SubagentRuntime
                            └─ _agent_factory: Callable   ← 外部注入

                    SelfCopyContextSummarizer      SelfCopyResultSummarizer
                    （无状态，规则路径）              （继承 BaseResultSummarizer）

                    ┌──────────────────────────────────────┐
                    │  三者被 make_specialist_tool 闭包捕获  │
                    │  → 绑定到 delegate_to_subagent tool    │
                    └──────────────────────────────────────┘
```

---

### 1.3. 完整流程（装配 → 运行）

#### 阶段 A：装配（启动时一次）

```
① bootstrap._load_specialist("subagent", config, agent_factory)
   │
   ├─ runtime = SubagentRuntime(agent_factory=agent_factory)
   │   └─ 用途：造执行器，持有 agent_factory
   │
   └─ return (
          SubagentSpecialist(runtime=runtime),          # ②
          SelfCopyContextSummarizer(),                  # ③
          SelfCopyResultSummarizer(),                   # ④
      )
   │
   ▼
② registry.register(specialist)
   └─ 用途：✅ 唯一注册点——SubagentSpecialist 进 SpecialistRegistry
   │
   ▼
③ make_specialist_tool(
       "subagent", specialist,
       ctx_summarizer,        ← SelfCopyContextSummarizer 闭包捕获
       result_summarizer,     ← SelfCopyResultSummarizer 闭包捕获
       max_steps=..., timeout_seconds=...
   )
   └─ 产出：delegate_to_subagent (BaseTool)
   │
   ▼
④ 工具进 Leader 的 tools 列表 → LLM 可见
```

**装配后状态**：
- registry 里：`{"subagent": SubagentSpecialist}`
- tool 闭包里：`SubagentSpecialist` + `SelfCopyContextSummarizer` + `SelfCopyResultSummarizer`
- `SubagentRuntime` 藏在 Specialist 里，`agent_factory` 藏在 Runtime 里

---

#### 阶段 B：运行（每次派活）

```
① LLM 决定派活
   └─ tool_call("delegate_to_subagent", {goal, success_criteria})
   │
   ▼
② OrchestrationMiddleware.wrap_tool_call
   ├─ set_current_state(state)                  ← 把 ThreadState 写进 ContextVar
   └─ metrics 打点（selection / invoked）
   │
   ▼
③ delegate_to_subagent handler（闭包）
   │
   ├─ state = get_current_state()               ← 读 ContextVar
   │
   ├─ context_summary = ctx_summarizer.summarize(state, goal, criteria)
   │   │  用途：输入端闸门——压父上下文
   │   │
   │   └─ SelfCopyContextSummarizer.summarize
   │       ├─ _llm 为 None → 规则路径
   │       │   ├─ "Goal: ..." / "Success criteria: ..."
   │       │   ├─ user_input → "Original request: ..."
   │       │   ├─ observations[-5:] → "Finding: ..."
   │       │   └─ 截断到 3000 字符
   │       └─ 返回 context_summary 字符串
   │
   ├─ request = SpecialistRequest(
   │       goal, success_criteria, context_summary, sandbox_id, ...
   │   )
   │
   ├─ raw = specialist.invoke(request)
   │   │  用途：适配层转发
   │   │
   │   └─ SubagentSpecialist.invoke(request)
   │       └─ self._runtime.invoke(request)
   │           │  用途：执行器——进程内跑子 Agent
   │           │
   │           ├─ _get_agent() → agent_factory()
   │           │  用途：造 leaf-role 子 Agent（防递归）
   │           ├─ _create_isolated_state(request)
   │           │  用途：隔离上下文 + 共享沙箱
   │           │   ├─ create_initial_thread_state(goal)  ← 全新 state
   │           │   ├─ context_summary → metadata         ← 只传摘要
   │           │   └─ sandbox_id → state["sandbox"]      ← 复用父沙箱
   │           ├─ agent.invoke(state, recursion_limit=max_steps*2)
   │           │  用途：真正跑子 Agent
   │           │   ├─ RecursionError → SubagentMaxStepsError
   │           │   └─ 其他异常 → SpecialistCrashError
   │           ├─ _extract_output(result)     ← 抽最后一条消息文本
   │           └─ return SpecialistRawResult(raw_output, duration)
   │
   ├─ result = result_summarizer.summarize(raw.raw_output, raw.artifacts, goal, criteria)
   │   │  用途：输出端闸门——压结果 + 程序化评估
   │   │
   │   └─ SelfCopyResultSummarizer.summarize（继承自 BaseResultSummarizer）
   │       ├─ 校验 success_criteria
   │       ├─ 压缩 raw_output → summary
   │       ├─ success=False → 填 gap_analysis
   │       └─ return SpecialistResult(specialist_name="subagent")
   │
   └─ return json.dumps({success, summary, specialist, gap_analysis, artifacts})
   │
   ▼
④ OrchestrationMiddleware.wrap_tool_call（返回后）
   ├─ metrics 打点（completion / fallback）
   ├─ _build_orchestration_update → ArtifactRef 列表
   └─ return Command{update: {messages, orchestration}}
   │
   ▼
⑤ ThreadState 更新 → LLM 看到 ToolMessage → 继续推理
```

### 1.4. 每个文件在流程里的"出场点"

| 文件 | 装配期出场 | 运行期出场 | 具体动作 |
|---|---|---|---|
| `subagent_runtime.py` | ② 被构造 | ③ 被 invoke | 建隔离 state → 调 agent → 抽输出 |
| `subagent_specialist.py` | ② 被构造 + ③ 进 registry | ③ 被 invoke | 转发给 runtime |
| `self_copy_context_summarizer.py` | ② 被构造 + ③ 闭包捕获 | ③ 被 summarize | 压父上下文成字符串 |
| `self_copy_result_summarizer.py` | ② 被构造 + ③ 闭包捕获 | ③ 被 summarize | 压结果 + 校验成功标准 |

---

### 1.5. 最小可用的"数据流"

```
父 ThreadState
    │
    │ ① SelfCopyContextSummarizer 压
    ▼
context_summary: str
    │
    │ ② SubagentRuntime._create_isolated_state 装进新 state
    ▼
子 ThreadState（全新）
    │
    │ ③ agent.invoke 跑
    ▼
agent result
    │
    │ ④ SubagentRuntime._extract_output 抽
    ▼
raw_output: str
    │
    │ ⑤ SelfCopyResultSummarizer 压 + 校验
    ▼
SpecialistResult
    │
    │ ⑥ json.dumps 转 ToolMessage
    ▼
回 Leader
```

---

### 1.6. 总结

> **subagent 的最小闭环：`SubagentSpecialist` 是"外壳"（适配契约），`SubagentRuntime` 是"发动机"（进程内执行），两个 Summarizer 是"进出的闸门"（压上下文、压结果）。装配时三者被绑定到 `delegate_to_subagent` 工具上，运行时按"压进 → 执行 → 压出"三步走完一次派活。**
