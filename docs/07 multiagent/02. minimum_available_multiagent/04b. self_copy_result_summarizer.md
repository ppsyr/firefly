---

name: SelfCopyResultSummarizer — self-copy subagent 的输出端转换器。

description: 

【整体职责】
为 self-copy subagent 提供输出端转换：直接继承 BaseResultSummarizer，
复用其通用校验（programmatic eval floor），不做任何 self-copy 专属扩展。

【内容摘要】
- SelfCopyResultSummarizer : 继承 BaseResultSummarizer，仅传入 specialist_name="subagent"。

【职责边界】
- 只负责：通过继承复用 BaseResultSummarizer 的 summarize 逻辑。
- 不负责：定义新的校验规则、压缩策略（都由基类提供）。
- 不持有状态：仅一个固定的 specialist_name。

---

## 0. 结构树 — SelfCopyResultSummarizer（含 Base 视角）

### 0.1. 静态结构树

```
self_copy_result_summarizer.py — SelfCopyResultSummarizer（纯继承，零覆写）
│
└─ SelfCopyResultSummarizer(BaseResultSummarizer)
    │                                            ← 纯继承，不覆写任何基类方法
    │                                            复用 BaseResultSummarizer 的完整逻辑
    │                                            specialist_name 固定 "subagent"
    │
    ├─ __init__()                             ← 调 super().__init__(specialist_name="subagent")
    │
    └─ 其余成员全部继承自 BaseResultSummarizer：
        │
        ├─ summarize(raw_output, artifacts, goal, success_criteria) -> SpecialistResult
        │   │                                        ← 对外唯一入口（模板方法）
        │   ├─ ① _evaluate_success(...)           ← 走基类版
        │   ├─ ② _extract_gap(...)（仅失败时）    ← 走基类版
        │   ├─ ③ _compress(...)                   ← 走基类版
        │   ├─ ④ _classify_failure(...)           ← 走基类版
        │   └─ ⑤ return SpecialistResult(...)
        │
        ├─ _evaluate_success(...) -> bool         ← 基类版（self_copy 未覆写）
        │   ├─ raw_output 空白 → False
        │   ├─ 有敏感改动 → False
        │   ├─ artifacts 为空（非 None） → False
        │   └─ 否则 → True
        │
        ├─ _has_sensitive_changes(...) -> bool    ← 基类版
        │   └─ 遍历 _SENSITIVE_PATTERNS（rm -rf / 等 5 条）
        │
        ├─ _compress(...) -> str                  ← 基类版
        │   └─ 超 2000 字符 → 截断 + "...(truncated)"
        │
        ├─ _extract_gap(...) -> str               ← 基类版（self_copy 未覆写）
        │   └─ "Criteria not met: <criteria>. Output tail: <最后 5 行，最多 200 字符>"
        │
        └─ _classify_failure(...) -> str | None   ← 基类版
            ├─ success=True → None
            └─ success=False → context/ability/goal/sandbox 四类启发式

   继承链：
    BaseResultSummarizer（通用校验 + 压缩 + gap + 分类）
        └─ SelfCopyResultSummarizer（本文件，零覆写）

   对照：同基类的另一个子类
    BaseResultSummarizer
        └─ ClaudeCodeResultSummarizer（覆写 2 个钩子）
            ├─ _evaluate_success（覆写，+ suggestion 检查）
            └─ _extract_gap（覆写，+ 缺失说明）
```

### 0.2. 模板方法调用链（self_copy 视角）

```
外部调用（delegate_to_subagent tool handler）
    │
    ▼
summarizer.summarize(raw_output, artifacts, goal, success_criteria)
    │
    │  ← summarizer 是 SelfCopyResultSummarizer
    │    它没覆写 summarize，调的是「继承来的」基类版本
    │
    ▼
BaseResultSummarizer.summarize（模板方法，流程固定）
    │
    ├─ ① self._evaluate_success(raw_output, artifacts, success_criteria)
    │   │
    │   │  ← self 是 SelfCopyResultSummarizer，但它没覆写此方法
    │   │    所以走「基类版」：
    │   │    ├─ raw_output 空白 → False
    │   │    ├─ 有敏感改动 → False
    │   │    ├─ artifacts 为空（非 None） → False
    │   │    └─ 否则 → True
    │   │
    │   └─ success = 上述结果
    │
    ├─ ② success=False → self._extract_gap(...)
    │   │  ← 走基类版："Criteria not met: ... Output tail: ..."
    │   └─ success=True → gap_analysis = ""
    │
    ├─ ③ self._compress(raw_output)
    │   └─ 走基类版：超 2000 字符截断
    │
    ├─ ④ self._classify_failure(success, raw_output)
    │   └─ 走基类版：启发式分类
    │
    └─ ⑤ return SpecialistResult(
           specialist_name="subagent",     ← 唯一的 self_copy 特征
           summary, artifacts, success, gap_analysis, failure_category
       )
```

**与 ClaudeCodeResultSummarizer 的对照：**

| 步骤 | SelfCopyResultSummarizer | ClaudeCodeResultSummarizer |
|---|---|---|
| ① `_evaluate_success` | **基类版**（空白/敏感/artifacts） | **覆写版**（基类 + suggestion 检查） |
| ② `_extract_gap` | **基类版** | **覆写版**（base_gap + 缺失说明） |
| ③ `_compress` | 基类版 | 基类版 |
| ④ `_classify_failure` | 基类版 | 基类版 |
| ⑤ `specialist_name` | `"subagent"` | `"claude"` |

**差异只在两处**：`_evaluate_success` 和 `_extract_gap`。self_copy **不覆写**，完全复用基类。

### 0.3. 补充

**`self_copy_result_summarizer.py` 是输出端最"薄"的一个实现——只有一行 `__init__`，其余全部继承基类。它的存在只为固定 `specialist_name="subagent"`。**

几点补充：

- **零覆写 = 完全复用基类行为**：self_copy 场景下，子 Agent 的输出格式和 Leader 一致，**不需要任何专属校验**。基类的"空白/敏感/artifacts"三规则已经够用。
- **和 `SelfCopyContextSummarizer` 不对称**：输入端摘要器有 LLM + 规则双路径（自己写），输出端摘要器纯继承（不写）。原因是**输入端要"选择传什么"（场景化），输出端只需"按统一标准校验"（标准化）**。
- **`specialist_name` 是唯一差异点**：对比 `ClaudeCodeResultSummarizer` 覆写了两个方法，`SelfCopyResultSummarizer` 什么都不覆写——**唯一的"身份"就是 `specialist_name="subagent"`**。
- **依赖基类 `BaseResultSummarizer`**：本文件是"薄壳"，真正行为在 `base.py`。要理解 self_copy 的输出端逻辑，看基类即可。
- **为什么不做专属校验**：subagent 是 Leader 的复制品，它的产出质量应当按 Leader 自己的标准衡量。**给它加专属校验反而会引入"双重标准"。** 这是刻意的设计。
