---

name: SubagentRuntime — 进程内调用 lead factory 实现（Poirot self-copy subagent）。

description: 

【整体职责】
实现 SpecialistRuntime 契约：在进程内调用 lead agent factory 创建一个 leaf-role 子 Agent，
用隔离的 ThreadState 执行任务，返回 SpecialistRawResult。
是 Poirot self-copy subagent 的底层执行器。

【内容摘要】
- SubagentRuntime              : runtime 主类，实现 invoke()。
- invoke()                     : 执行入口：取 agent → 建隔离 state → invoke → 抽输出。
- _get_agent()                 : 从 agent_factory 取子 Agent；未配置时抛 StartupError。
- _create_isolated_state()     : 构造全新 ThreadState（只带 goal + context_summary）。
- _extract_output()            : 从 agent 结果中抽取最后一条消息的文本。

【职责边界】
- 只负责：取 agent、建隔离 state、调 agent.invoke、抽取输出、异常归一化。
- 不负责：agent 的构造（agent_factory 提供）、上下文摘要（ContextSummarizer 负责）、
  结果摘要（ResultSummarizer 负责）、沙箱管理（sandbox 层负责）。
- 不持有运行时状态：每次 invoke 都新建 state，不跨调用累积。

## 0. 结构树

### 0.1. 静态结构树

```
subagent_runtime.py — SubagentRuntime（进程内调用 lead factory 的 self-copy subagent runtime）
│
└─ SubagentRuntime                            ← 实现 SpecialistRuntime 契约
    │                                           传入的 agent_factory 构造逻辑就是 lead_agent 
    │                                           的构造逻辑
    │
    ├─ _agent_factory: Callable[[], Any] | None ← 返回 leaf-role agent 的工厂
    │                                             None → _get_agent 抛 StartupError
    │
    ├─ __init__(agent_factory=None)           ← 注入工厂（bootstrap 负责）
    │
    ├─ invoke(request) -> SpecialistRawResult ← 执行入口
    │   ├─ ① _get_agent()                     ← 取子 Agent
    │   ├─ ② _create_isolated_state(request)  ← 建隔离 ThreadState
    │   ├─ ③ agent.invoke(state, config={recursion_limit: max_steps*2})
    │   │   ├─ RecursionError → SubagentMaxStepsError
    │   │   └─ 其他异常 → SpecialistCrashError
    │   ├─ ④ _extract_output(result)          ← 抽最后一条消息文本
    │   └─ ⑤ return SpecialistRawResult(raw_output, duration_seconds)
    │
    ├─ _get_agent() -> Any                    ← 从 agent_factory 取子 Agent
    │   └─ agent_factory 为 None → raise SpecialistStartupError
    │
    ├─ _create_isolated_state(request) -> dict ← 构造隔离 ThreadState
    │   ├─ create_initial_thread_state(goal)  ← 全新 state
    │   ├─ context_summary → state["metadata"]["context_summary"]
    │   └─ sandbox_id → state["sandbox"] = {"sandbox_id": ...}
    │
    └─ _extract_output(result) -> str         ← 抽输出文本
        ├─ dict + messages → 最后一条 content（无 content → str(last)）
        ├─ dict 无 messages → ""
        └─ 其他 → str(result)
```

### 0.2. 运行时调用树

```
① 装配期（bootstrap._load_specialist 的 subagent 分支）
_load_specialist("subagent", config, agent_factory)
    └─ SubagentRuntime(agent_factory=agent_factory)   ← 构造 runtime
        → 注入 SubagentSpecialist
        ═══════════ 进入 Agent 循环 ═══════════

② 运行期（Leader 派活给 subagent）
Leader → delegate_to_subagent tool
    │
    ▼
SubagentSpecialist.invoke(request)
    │
    └─ SubagentRuntime.invoke(request)          ← 本文件
        │
        ├─ ① _get_agent()
        │     └─ agent_factory() → leaf-role agent
        │
        ├─ ② _create_isolated_state(request)
        │     ├─ create_initial_thread_state(goal)   ← 全新 ThreadState
        │     ├─ state["metadata"]["context_summary"] = context_summary
        │     └─ state["sandbox"] = {"sandbox_id": sandbox_id}   ← 复用父沙箱
        │
        ├─ ③ agent.invoke(state, config={"recursion_limit": max_steps*2})
        │     ├─ 成功 → result
        │     ├─ RecursionError → raise SubagentMaxStepsError
        │     └─ 其他异常 → raise SpecialistCrashError
        │
        ├─ ④ _extract_output(result)
        │     └─ 最后一条消息的 content
        │
        └─ ⑤ return SpecialistRawResult(raw_output, duration_seconds)
        │
        ▼
（回到 tool handler，交给 ResultSummarizer 压缩为 SpecialistResult）
```

### 0.3. 补充

**`subagent_runtime.py` 是 multiagent 的"自复制执行器"——在进程内调 lead factory 造一个 leaf-role 子 Agent，用隔离的 state 跑任务，返回原始输出。**

几点补充：

- **进程内执行，不是子进程**：不像 Codex / Claude 走外部进程，SubagentRuntime 直接在当前进程内调 `agent.invoke`。这是"自复制"的本质——复用同一套代码。
- **isolated context 只靠两样东西**：`goal` + `context_summary`。父 Agent 的 messages / observations / sources 完全不继承，避免上下文污染。
- **shared sandbox 是唯一共享**：`sandbox_id` 被写进新 state，让子 Agent 能用父的沙箱。一个隔离（context）、一个共享（sandbox），是刻意设计。
- **leaf role 靠 agent_factory 保证**：本文件不强制 tool_groups，它信任 `agent_factory()` 返回的是一个不含 multiagent 工具的子 Agent。**递归安全的责任在工厂，不在 runtime。**
- **`recursion_limit` 取 `max_steps * 2`**：因为 LangGraph 的一次"步"可能消耗多个 recursion 单位，留 2 倍余量。超限触发 `RecursionError`，再转成 `SubagentMaxStepsError`。
- **异常归一化到 SpecialistError 层次**：`SubagentRuntime` 虽属 subagent 体系，但 `invoke` 抛的却是 `SpecialistCrashError` / `SpecialistStartupError`（而非 `SubagentError`）——因为它的契约是 `SpecialistRuntime`。只有 `SubagentMaxStepsError` 走 `SubagentError` 分支。**这是两套异常层次交叉的地方，容易看漏。**
