---

name: VersionDAG — 演化产物 version DAG + is_active 单指针 + 回滚 + hash 防环。

description: 

【整体职责】
持久化 L2 演化产物与实验记录：commit 写入 evolution_artifacts +
evolution_experiments 两张表，accept 时更新 is_active 单指针；
提供 get_active / get_history / rollback / hash_exists_in_recent 四个查询。

【内容摘要】
- _VERSION_DAG_SCHEMA_SQL : 两张表建表 SQL（幂等）。
- ArtifactRow(frozen)     : evolution_artifacts 表行。
- _artifact_type_name()   : 从 artifact 实例推断 artifact_type 名。
- _serialize_payload()    : 序列化 artifact 为 JSON。
- _deserialize_payload()  : 从 ArtifactRow 反序列化 artifact。
- _DummySelector          : 反序列化 placeholder。
- VersionDAG              : 主类（commit / get_active / get_history / rollback / hash_exists_in_recent）。

【职责边界】
- 只负责：持久化 artifact + experiment、is_active 单指针维护、回滚、hash 防环查询。
- 不负责：变异（mutator 负责）、评估（PromotionGate 负责）、
  晋升决策（PromotionGate.decide 负责）。
- 不持有重状态：只持有 db_path + 锁。

### 0.2. 运行时调用树

```
① 装配期（L2 启用时）
setup_l2（evolution/bootstrap.py）
    │
    └─ version_dag = VersionDAG(db_path=config.metrics_db_path)
        │
        ├─ 建父目录
        └─ _init_schema()（幂等建两张表）
        │
        ├─ 注入 PromotionGate（hash 检查 + commit）
        └─ 注入 L2EvolutionWorker
        ═══════════ 进入 Agent 循环 ═══════════

② 运行期：L2 演化提交（worker 消费后）
L2EvolutionWorker
    │
    ├─ focuser.analyze(...)
    ├─ mutator.evolve_* (...) → EvolutionResult（candidate）
    ├─ gate.evaluate(candidate, baseline, task_sample) → EvalResult
    ├─ gate.decide(candidate, baseline, eval_result) → PromotionDecision
    │
    └─ version_dag.commit(candidate, eval_result,               ← 本文件
                          from_artifact_id=...,
                          trigger_source=...,
                          decision="accept" / "reject")
        │
        ├─ ① artifact_id = f"art_{uuid4().hex[:12]}"
        ├─ ② payload_json = _serialize_payload(candidate)
        ├─ ③ INSERT INTO evolution_artifacts（is_active=0）
        ├─ ④ decision == "accept"?
        │     ├─ UPDATE is_active=0 WHERE type+template_id
        │     └─ UPDATE is_active=1 WHERE artifact_id
        ├─ ⑤ eval_json = {...}
        ├─ ⑥ INSERT INTO evolution_experiments（exp_...）
        └─ ⑦ return artifact_id

③ 运行期：L1 读活跃版本（每次派活时）
L1 / ContextSummarizer
    │
    └─ version_dag.get_active(ContextSummaryTemplate)          ← 本文件
        │
        ├─ SELECT ... WHERE artifact_type='context_summary'
        │   AND is_active=1 ORDER BY created_at DESC LIMIT 1
        │
        ├─ None → 返回 None（无活跃版本）
        └─ 非 None → _deserialize_payload(row)
            ├─ extractors=() / filters=()（hot swap 时重构造）
            └─ 返回 ContextSummaryTemplate

④ 运行期：防环检查（PromotionGate.decide 内）
PromotionGate.decide(...)
    │
    └─ version_dag.hash_exists_in_recent(candidate.artifact_hash, window=5)  ← 本文件
        │
        ├─ SELECT artifact_hash ORDER BY created_at DESC LIMIT 5
        ├─ 命中 → REJECT（防环）
        └─ 未命中 → 继续 CI 比较

⑤ 运行期：手动回滚（运维）
CLI / 运维
    │
    └─ version_dag.rollback(artifact_id)                       ← 本文件
        │
        ├─ 查目标 artifact 的 type + template_id
        ├─ 同 type + template_id 全部 is_active=0
        └─ 指定 artifact is_active=1
        │
        └─ 下次 get_active 返回回滚后的版本
```

### 0.3. 补充

**`version_dag.py` 是 L2 的"版本账本"——持久化演化产物与实验记录，维护 is_active 单指针，支持回滚与 hash 防环。**

几点补充：

- **`is_active` 单指针**：同 `artifact_type` + `template_id` 只有一行 `is_active=1`——**这是"当前活跃版本"的标识**。
- **`get_active` 不缓存**：注释说"每次查 DB，保 hot swap"——**L1 每次派活时都从 DB 读最新活跃版本**，保证"演化后立即生效"。
- **`reject` candidate 也存**：注释说"防重复尝试"——**即使被拒绝的 candidate 也写库**，这样 `hash_exists_in_recent` 能检测到"这个版本试过了"。
- **`hash_exists_in_recent` 是防环机制**：检查近 5 版的 hash——**如果 candidate 的 hash 和最近某版相同，说明"绕回来了"**，PromotionGate 会 REJECT。
- **`commit` 双写**：同时写 `evolution_artifacts`（产物）和 `evolution_experiments`（实验记录）——**前者是"结果"，后者是"过程"**。
- **`_serialize_payload` 只存类名**：`extractors` / `filters` / `skill_selector` 的**实际对象不序列化**，只存类名——**反序列化时用空 tuple / `_DummySelector` 占位**。真正的对象在 L1 hot swap 时重新构造。
- **`rollback` 是手动干预**：把 `is_active` 指针回退到指定版本——**这是"演化出错时的人工兜底"**。
- **`ArtifactRow` 是"表行"映射**：字段与表列一一对应——**`get_active` / `get_history` 返回它，而不是直接返回 artifact**。`get_active` 内部再转成 `EvolutionArtifact`。
- **ID 格式有前缀**：`art_<12 位 hex>` / `exp_<12 位 hex>`——**方便识别类型**。
- **和其他组件的关系**：

| 组件                 | 谁调它                                                   | 它调谁                                       |
| ------------------ | ----------------------------------------------------- | ----------------------------------------- |
| `TriggerManager`   | `L2TriggerMiddleware`                                 | `metrics_view`                            |
| `FailureFocuser`   | `L2EvolutionWorker`                                   | `metrics_view`                            |
| `EvolutionMutator` | `L2EvolutionWorker`                                   | `LLMCaller`                               |
| `PromotionGate`    | `L2EvolutionWorker`                                   | `bridge` / `evaluator` + **`VersionDAG`** |
| **`VersionDAG`**   | **`PromotionGate`（commit / hash 检查）+ L1（get_active）** | **DB**                                    |
