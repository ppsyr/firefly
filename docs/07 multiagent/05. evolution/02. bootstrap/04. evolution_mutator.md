---

name: EvolutionMutator — LLM 演化执行。

description: 

【整体职责】
用 LLM 对当前活跃模板做单次变异：调用 LLM 生成结构化 JSON，解析并校验后
产出新的 candidate（ContextSummaryTemplate 或 SkillInjectionTemplate）。
失败时最多重试 max_retries 次，全部失败则保持旧 is_active。

【内容摘要】
- _EVOLUTION_FAILURE_TYPES      : 演化失败类型常量（4 类）。
- LLMCaller(Protocol)           : LLM 调用抽象。
- EvolutionResult(dataclass)    : 单次演化结果。
- EvolutionMutator              : 变异主类（evolve_context_summary / evolve_skill_injection）。
- _SchemaMismatchError / _IllegalFieldError : 内部重试异常。
- _DummySelector                : selector 占位（L1 hot swap 时重构造）。
- 5 个模块级辅助函数              : 序列化 current / 失败统计 / 失败样本 / lessons；校验 extractors / filters。
- _CONTEXT_SUMMARY_SCHEMA / _SKILL_INJECTION_SCHEMA : LLM prompt schema。

【职责边界】
- 只负责：构造 prompt、调 LLM、解析 JSON、schema 校验、构造 candidate。
- 不负责：触发（TriggerManager 负责）、失败聚类（FailureFocuser 负责）、
  评估与晋升（PromotionGate 负责）、持久化（VersionDAG 负责）。
- 不持有运行时状态：llm_caller / evolution_model 由构造注入。

## 0. 结构树

### 0.1. 静态结构树

```
evolution_mutator.py — EvolutionMutator（LLM 演化执行）
│
├─ 外部 import
│   ├─ ContextSummaryTemplate / SkillInjectionTemplate
│   │                          ← from evolution/types.py
│   ├─ EvolutionArtifact       ← from evolution/types.py
│   └─ FailureStats            ← from evolution/types.py
│
├─ 常量
│   └─ _EVOLUTION_FAILURE_TYPES = (          ← 演化失败类型
│       "llm_timeout", "json_parse",
│       "schema_mismatch", "illegal_field"
│     )
│
├─ LLMCaller(Protocol)                       ← LLM 调用抽象
│   └─ call(prompt) -> str                   ← 返回原始文本（期望 JSON）
│
├─ EvolutionResult(dataclass)                ← 单次演化结果
│   ├─ success: bool
│   ├─ candidate: EvolutionArtifact | None
│   ├─ rationale: str
│   ├─ failure_type: str                     ← 失败类型（成功时为空）
│   ├─ retries: int                          ← 实际重试次数
│   ├─ llm_model: str
│   ├─ input_tokens: int
│   ├─ output_tokens: int
│   └─ latency_ms: float
│
├─ EvolutionMutator                          ← ★ 变异主类
│   │   用途：单次 LLM 变异 + 结构化 JSON + 重试
│   │
│   ├─ _llm_caller: LLMCaller | None
│   ├─ _evolution_model: str | None
│   ├─ _max_retries: int = 2
│   │
│   ├─ __init__(llm_caller, evolution_model, max_retries=2)
│   │
│   ├─ evolve_context_summary(current, failures, lessons=()) -> EvolutionResult
│   │   └─ 用途：演化 ContextSummaryTemplate（CONTEXT_INSUFFICIENT 主导时）
│   │
│   ├─ evolve_skill_injection(current, failures, lessons=()) -> EvolutionResult
│   │   └─ 用途：演化 SkillInjectionTemplate（ABILITY_INSUFFICIENT 主导时）
│   │
│   ├─ _evolve(current, failures, artifact_type, schema, lessons=()) -> EvolutionResult
│   │   │   ★ 核心：单次 LLM + 重试
│   │   │
│   │   ├─ ① llm_caller is None?
│   │   │     └─ 是 → 返回失败（failure_type="llm_timeout"）
│   │   ├─ ② prompt = _build_prompt(...)
│   │   ├─ ③ for attempt in range(max_retries + 1):
│   │   │     ├─ raw = llm_caller.call(prompt)
│   │   │     ├─ candidate = _parse_and_validate(...)
│   │   │     ├─ 成功 → return EvolutionResult(success=True, ...)
│   │   │     └─ 异常分类处理：
│   │   │         ├─ JSONDecodeError    → last_error="json_parse" + 重写 prompt
│   │   │         ├─ _SchemaMismatchError→ last_error="schema_mismatch" + 重写 prompt
│   │   │         ├─ _IllegalFieldError → last_error="illegal_field" + 重写 prompt
│   │   │         └─ 其他 Exception     → last_error="llm_timeout" + 重写 prompt
│   │   └─ ④ 全部失败 → return EvolutionResult(success=False, failure_type=last_error)
│   │
│   ├─ _build_prompt(current, failures, artifact_type, schema, *, error_hint="", lessons=()) -> str
│   │   │   用途：构造 LLM prompt
│   │   └─ 包含：当前模板 JSON / 失败统计 / 代表失败样本 /
│   │            available 列表 / 输出 schema / error_hint
│   │
│   └─ _parse_and_validate(raw_output, current, artifact_type, schema) -> EvolutionArtifact
│       │   用途：解析 JSON + schema 校验 + 构造 candidate
│       ├─ ① 清理 markdown fence
│       ├─ ② json.loads
│       ├─ ③ 校验 required 字段（缺 → _SchemaMismatchError）
│       ├─ ④ next_version = f"v{int(current.version[1:]) + 1}"
│       └─ ⑤ 按 artifact_type 构造：
│           ├─ context_summary → _validate_extractors + _validate_filters
│           │   → ContextSummaryTemplate
│           └─ skill_injection → 校验 selector → SkillInjectionTemplate
│
├─ 内部异常类
│   ├─ _SchemaMismatchError(Exception)       ← LLM 输出 schema 不匹配
│   └─ _IllegalFieldError(Exception)         ← LLM 输出字段值非法
│
├─ _DummySelector                            ← selector 占位（L1 hot swap 时重构造）
│   └─ select(goal, available_skills) -> tuple
│
├─ 模块级辅助函数
│   ├─ _serialize_current(current, artifact_type) -> str
│   │   └─ 用途：序列化当前 active 模板为 JSON
│   ├─ _serialize_failure_categories(failures) -> str
│   │   └─ 用途：序列化 failure_category 统计
│   ├─ _serialize_failure_samples(failures) -> str
│   │   └─ 用途：序列化失败样本（每类 top 2，上限 5）
│   ├─ _serialize_lessons(lessons) -> str
│   │   └─ 用途：序列化 L3 DecisionLog lessons
│   ├─ _validate_extractors(names, available) -> tuple
│   │   └─ 用途：校验 extractor 名是否在 available 列表
│   └─ _validate_filters(names, available) -> tuple
│       └─ 用途：校验 filter 名是否在 available 列表
│
└─ LLM prompt schema
    ├─ _CONTEXT_SUMMARY_SCHEMA               ← ContextSummaryTemplate 的 schema
    │   ├─ available_extractors: [LastNMessages / CodeSnippets... / ErrorLogs...]
    │   ├─ available_filters: [TruncateAtTokens / DeduplicateByHash / PrioritizeRecent]
    │   └─ output_schema: {required: [...], properties: {...}}
    └─ _SKILL_INJECTION_SCHEMA               ← SkillInjectionTemplate 的 schema
        ├─ available_selectors: [KeywordMatch / LLMClassify / SemanticMatch]
        └─ output_schema: {required: [...], properties: {...}}
```

### 0.2. 运行时调用树

```
① 装配期（L2 启用时）
setup_l2（evolution/bootstrap.py）
    │
    └─ mutator = EvolutionMutator(
           llm_caller=None,                    ← MVP 未配置 LLM
           evolution_model=config.l2.evolution_model,
           max_retries=2,
       )
       │
       └─ 注入 L2EvolutionWorker
        ═══════════ 进入 Agent 循环 ═══════════

② 运行期：L2EvolutionWorker 消费任务后变异
L2EvolutionWorker（daemon 线程）
    │
    ├─ 从 task_queue 取 EvolutionTask
    ├─ focuser.analyze(...) → FailureStats
    │
    ├─ 根据 dominant_category 选择变异方法：
    │   ├─ CONTEXT_INSUFFICIENT → mutator.evolve_context_summary(...)
    │   └─ ABILITY_INSUFFICIENT → mutator.evolve_skill_injection(...)
    │
    └─ _evolve(...)                                ← 本文件
        │
        ├─ ① llm_caller is None?
        │   ├─ MVP：是 → 返回失败（不实际演化）
        │   └─ 生产：否 → 继续
        │
        ├─ ② prompt = _build_prompt(...)
        │   ├─ _serialize_current(current)          ← 当前模板 JSON
        │   ├─ _serialize_failure_categories(...)   ← 失败统计
        │   ├─ _serialize_failure_samples(...)      ← 代表样本
        │   └─ _serialize_lessons(lessons)          ← L3 lessons（可选）
        │
        ├─ ③ 尝试循环（max_retries + 1 次）：
        │   │
        │   ├─ raw = llm_caller.call(prompt)
        │   │   └─ LLM 返回 JSON 文本
        │   │
        │   ├─ candidate = _parse_and_validate(raw, current, ...)
        │   │   ├─ ① 清理 markdown fence
        │   │   ├─ ② json.loads
        │   │   ├─ ③ 校验 required 字段
        │   │   ├─ ④ 版本号递增
        │   │   └─ ⑤ 构造 ContextSummaryTemplate / SkillInjectionTemplate
        │   │       └─ 校验 extractors / filters / skill_selector
        │   │
        │   ├─ 成功 → return EvolutionResult(success=True, candidate)
        │   │
        │   └─ 异常 → 分类：
        │       ├─ JSONDecodeError      → last_error="json_parse"
        │       ├─ _SchemaMismatchError → last_error="schema_mismatch"
        │       ├─ _IllegalFieldError   → last_error="illegal_field"
        │       └─ Exception            → last_error="llm_timeout"
        │       └─ 重写 prompt（带 error_hint）+ 继续
        │
        └─ ④ 全部失败 → return EvolutionResult(
        │        success=False,
        │        candidate=None,
        │        failure_type=last_error,
        │    )
        │
        ▼
    worker 收到 EvolutionResult
        ├─ success=True → gate.decide(candidate, baseline, ...)
        └─ success=False → metrics_l2.record_evolution_failed(failure_type)

③ 运行期：lessons 来源（L3 → L2 回流）
L3 DecisionLog
    │
    └─ reader.get_recent_lessons(specialist_name, failure_category, limit)
        └─ worker 传给 mutator.evolve_context_summary(..., lessons=...)
            └─ _serialize_lessons 拼进 prompt
```

### 0.3. 补充

**`evolution_mutator.py` 是 L2 的"变异执行器"——用 LLM 对当前模板做单次变异，产出 candidate 供晋升门决策。**

几点补充：

- **单次 LLM + 结构化 JSON**：不搞多轮对话，**一次 prompt 期望一次 JSON 输出**——简单直接。
- **重试是"改写 prompt"而非"重复相同 prompt"**：每次重试都把 `error_hint` 拼进去——**告诉 LLM 上次错在哪**。这比"重复相同请求"更可能成功。
- **失败类型与重试提示对应**：
  - `json_parse` → "Strict JSON required. Output ONLY JSON, no markdown."
  - `schema_mismatch` → "Schema error: {e}. Fix and retry."
  - `illegal_field` → "Illegal field: {e}. Valid extractors/filters listed in schema."
  - `llm_timeout` → "LLM call failed: {e}. Retry."
- **`llm_caller=None` 直接返回失败**：MVP 阶段不配置 LLM——**演化不会真的发生，但也不会崩**。
- **markdown fence 清理**：LLM 经常把 JSON 包在 ```json ... ``` 里——**代码主动 strip 掉**。
- **`_validate_extractors` / `_validate_filters` 返回空 tuple**：注释说"L1 hot swap 时重新构造"——**演化产物只记录"名字"，实际对象在 hot swap 时重建**。
- **`_DummySelector` 是占位**：`SkillInjectionTemplate` 需要一个 `SkillSelector` 对象，但演化产物只有"名字"——**用 `_DummySelector` 占位，hot swap 时替换**。
- **`lessons` 来自 L3 DecisionLog**：`_serialize_lessons` 把它拼进 prompt——**L3 的决策日志成为 L2 变异的输入样本**。这是 **L3 → L2 的信息回流**。
- **版本号强制递增**：`v{int(current.version[1:]) + 1}`——**不信任 LLM 输出的 version，代码强制生成**。LLM 输出里的 `version` 字段被忽略。
- **`rationale` 来自代码而非 LLM**：`candidate.__class__.__name__ + "_evolved"`——**LLM 输出的 `rationale` 字段被忽略**（虽然在 schema 里 required）。这是一个"schema 要求但实际不用"的字段。
- **在 L2 流程里的位置**：

```
L2 演化流程
    ├─ ① 触发（TriggerManager）
    ├─ ② 聚焦（FailureFocuser）→ FailureStats
    ├─ ③ 变异（EvolutionMutator）← ★ 本文件
    │   ├─ evolve_context_summary（CONTEXT_INSUFFICIENT 主导）
    │   └─ evolve_skill_injection（ABILITY_INSUFFICIENT 主导）
    ├─ ④ 评估（PromotionGate → L3）
    └─ ⑤ 晋升（PromotionGate → VersionDAG）
```

- **它产出的是 "candidate（新版本模板）"**，不是"最终产物"——最终是否采纳由 `PromotionGate` 决定。**变异和晋升分离**：变异只管"造出候选"，晋升管"要不要用"。
