---

name: PromotionGate — longitudinal pairs eval + Wilson 95% CI + hash 防环。

description: 

【整体职责】
L2 的晋升门：先评估 candidate vs baseline（longitudinal pairs，或经 L3 bridge 分发），
再根据评估结果与 hash 防环规则决定 ACCEPT / REJECT / FAILED。
是"变异 → 评估 → 晋升"链条的最后一环。

【内容摘要】
- EvalTask(frozen)          : 单个评估任务（一条历史 specialist 调用记录）。
- EvalResult(frozen)        : 评估结果（candidate / baseline 分数 + CI + 元信息）。
- Evaluator(Protocol)       : 评估器抽象（evaluate(artifact, task) -> bool）。
- PromotionGate             : 晋升门主类（evaluate / decide）。
- _wilson_ci()              : Wilson score interval 计算（小样本友好）。

【职责边界】
- 只负责：评估 candidate vs baseline、按 hash + CI 规则决策。
- 不负责：变异（mutator 负责）、版本持久化（version_dag 负责）、
  L3 内部评估实现（bridge / adapter 负责）。
- 不持有重状态：只持有 evaluator / version_dag / bridge / _task_use_count。

## 0. 结构树

### 0.1. 静态结构树

```
promotion_gate.py — PromotionGate（longitudinal pairs eval + Wilson 95% CI + hash 防环）
│
├─ 外部 import
│   ├─ EvolutionArtifact / PromotionDecision ← from evolution/types.py
│   └─ TYPE_CHECKING: EvalBridge / EvalContext ← 仅类型标注用（避免循环 import）
│
├─ EvalTask(frozen)                          ← 单个评估任务
│   ├─ task_id: str                          ← 任务唯一 ID（累计使用次数用）
│   ├─ goal: str
│   ├─ success_criteria: str
│   ├─ sandbox_id: str | None = None
│   ├─ context_snapshot_ref: str | None = None
│   └─ expected_outcome: str | None = None
│
├─ EvalResult(frozen)                        ← 评估结果（L2 自建同构）
│   ├─ candidate_score: float                ← candidate 平均分
│   ├─ baseline_score: float                 ← baseline 平均分
│   ├─ ci_low: float                         ← candidate CI 下界
│   ├─ ci_high: float                        ← candidate CI 上界
│   ├─ sample_size: int                      ← 样本数
│   ├─ method_used: str                      ← 评估方法名
│   ├─ raw_data_ref: str | None = None
│   ├─ success: bool = True
│   └─ failure_reason: str | None = None
│
├─ Evaluator(Protocol)                       ← 评估器抽象
│   └─ evaluate(artifact, task) -> bool      ← 跑 artifact 在 task 上
│
├─ PromotionGate                             ← ★ 晋升门主类
│   │   用途：评估 candidate vs baseline + 决策 ACCEPT/REJECT/FAILED
│   │
│   ├─ _evaluator: Evaluator | None
│   ├─ _version_dag: Any | None              ← 提供 hash_exists_in_recent
│   ├─ _eval_timeout: float = 1800.0         ← 评估整体超时（30min）
│   ├─ _sample_min: int = 10                 ← 样本数下限（预留）
│   ├─ _sample_max: int = 15                 ← 样本数上限（预留）
│   ├─ _task_max_reuse: int = 3              ← 单 task 累计最大使用次数
│   ├─ _z: float = 1.96                      ← Wilson CI 的 z 值
│   ├─ _bridge: EvalBridge | None            ← L3 bridge（非 None 时优先走 L3）
│   └─ _task_use_count: dict[str, int]       ← task 累计使用次数（防过拟合）
│
│   ├─ __init__(evaluator, version_dag, eval_timeout_seconds,
│   │           eval_sample_min, eval_sample_max, eval_task_max_reuse,
│   │           z_score, bridge)
│   │
│   ├─ evaluate(candidate, baseline, task_sample) -> EvalResult
│   │   │   ★ 评估：candidate vs baseline
│   │   │
│   │   ├─ ① bridge 非 None?
│   │   │     └─ 是 → 构造 EvalContext → bridge.evaluate(ctx)（L3 分发）
│   │   ├─ ② evaluator is None?
│   │   │     └─ 是 → 返回失败（no evaluator configured）
│   │   ├─ ③ 过滤累计超 _task_max_reuse 的 task
│   │   │     └─ filtered 为空 → 返回失败（insufficient_tasks）
│   │   ├─ ④ 遍历 filtered：
│   │   │     ├─ 超时检查（执行前）
│   │   │     │   └─ 超时 → 返回失败（overall_timeout）
│   │   │     ├─ _task_use_count[task_id] += 1
│   │   │     ├─ c_met = evaluator.evaluate(candidate, task)
│   │   │     ├─ b_met = evaluator.evaluate(baseline, task)
│   │   │     └─ 异常 → continue（跳过）
│   │   ├─ ⑤ candidate_scores 为空?
│   │   │     └─ 是 → 返回失败（all_tasks_failed）
│   │   ├─ ⑥ 算平均分 + Wilson CI
│   │   └─ ⑦ 返回 EvalResult
│   │
│   └─ decide(candidate, baseline, eval_result) -> PromotionDecision
│       │   ★ 决策：ACCEPT / REJECT / FAILED
│       │
│       ├─ ① version_dag.hash_exists_in_recent(candidate.artifact_hash, window=5)?
│       │     └─ 是 → REJECT（hash 防环）
│       ├─ ② not eval_result.success?
│       │     └─ 是 → FAILED（保持旧 is_active）
│       ├─ ③ 重算 baseline CI（b_low, b_high = _wilson_ci(...)）
│       ├─ ④ eval_result.ci_low > b_high?
│       │     ├─ 是 → ACCEPT
│       │     └─ 否 → REJECT
│       └─ ⑤ 返回 PromotionDecision
│
└─ _wilson_ci(score, sample_size, z=1.96) -> tuple[float, float]
    │   用途：Wilson score interval 计算（小样本友好）
    ├─ sample_size == 0 → (0.0, 0.0)
    ├─ p_hat = clamp(score, 0, 1)
    ├─ denom = 1 + z²/n
    ├─ center = (p_hat + z²/(2n)) / denom
    ├─ margin = z·√(p_hat(1-p_hat)/n + z²/(4n²)) / denom
    └─ return (max(0, center-margin), min(1, center+margin))
```

### 0.3. 补充

**`promotion_gate.py` 是 L2 的"晋升门"——评估 candidate vs baseline，并根据 hash 防环 + CI 比较决定是否晋升。**

几点补充：

- **`evaluate` 有两条路径**：
  1. **L3 启用**：`bridge.evaluate(ctx)` → L3 的 `OrchestrationBridge` 选 adapter 评估
  2. **L3 未启用**：直接用 `evaluator`（floor eval）
  - **`bridge` 优先**——L3 启用后，L2 的 `evaluate` 变成"L3 的转发器"。
- **`decide` 有三条规则（顺序）**：
  1. **hash 防环**：candidate hash 命中近 5 版 → REJECT——**避免"绕了一圈又变回旧版本"**
  2. **eval 失败**：`eval_result.success=False` → FAILED——**保持旧 is_active**
  3. **CI 比较**：candidate CI 下界 > baseline CI 上界 → ACCEPT——**统计显著**
  4. 否则 → REJECT
- **Wilson CI 而非简单比例**：用小样本友好的 Wilson 区间——**避免"3 次里 2 次成功 = 66%"这类不靠谱结论**。**p=0/1 时不退化**（普通正态近似会退化）。
- **`_task_use_count` 是"防过拟合"**：每个 task 累计使用 ≤ 3 次——**避免反复用同一批 task 评估**，导致候选"记住"了这些 task。
- **`EvalResult` 只存 candidate CI**：`decide` 里**重新算 baseline CI**——因为 `EvalResult` 字段有限。**这是一个可优化点**（可以同时存两者）。
- **`bridge` 是 L2→L3 的连接点**：`PromotionGate` 的 `bridge` 参数类型是 `EvalBridge`——**L2 通过它调 L3**。
- **超时检查在执行前**：每次循环开始检查 `time.time() - start > self._eval_timeout`——**不在评估中途打断**，只阻止"开始下一个 task"。
- **`_wilson_ci` 是模块级函数**：不在类里——**可以被独立调用/测试**。多个地方用它（`evaluate` 算 candidate CI，`decide` 算 baseline CI，L3 的 adapter 也 import 它）。
- **`_task_max_reuse` / `_sample_min` / `_sample_max` 的配置来源**：

| PromotionGate 字段 | L2Config 字段 | 默认值 |
|---|---|---|
| `eval_timeout_seconds` | `eval_timeout_seconds` | 1800.0 |
| `eval_sample_min` | `eval_sample_min` | 10 |
| `eval_sample_max` | `eval_sample_max` | 15 |
| `eval_task_max_reuse` | `eval_task_max_reuse` | 3 |

- **和其他组件的关系**：

| 组件                  | 谁调它                     | 它调谁                                        |
| ------------------- | ----------------------- | ------------------------------------------ |
| `TriggerManager`    | `L2TriggerMiddleware`   | `metrics_view`                             |
| `FailureFocuser`    | `L2EvolutionWorker`     | `metrics_view`                             |

| `VersionDAG`        | `PromotionGate`         | DB                                         |
