---

name: ClaudeCodeContextSummarizer — 规则提取（代码 + review 标准，零 LLM）。

description: 

【整体职责】
为 Claude Code specialist 生成 context_summary：从父 ThreadState 中提取代码块和
review 相关的关键词，拼成一段精简上下文。零 LLM，纯规则提取，控制 token 成本。

【内容摘要】
- _CODE_BLOCK_RE / _REVIEW_KEYWORDS / _MAX_CODE_BLOCKS / _MAX_SUMMARY_CHARS : 规则常量。
- _field()                          : 从 dict 或对象中统一取字段。
- ClaudeCodeContextSummarizer      : 输入端转换器主类。
- summarize()                       : 入口，拼装 goal + 代码块 + review 提示。
- _extract_code_blocks()            : 从 messages 中提取代码块（最多 2 个）。
- _extract_review_hints()           : 从 messages 中提取 review 关键词（最多 5 个）。

【职责边界】
- 只负责：从 ThreadState 规则提取代码块与 review 关键词，拼成 context_summary 字符串。
- 不负责：结果压缩（ResultSummarizer 负责）、specialist 执行、LLM 调用。
- 不持有运行时状态：纯函数式读取，不写回 state。

## 0. 结构树

### 0.1. 静态结构树

```
claude_code_context_summarizer.py — ClaudeCodeContextSummarizer（规则提取：代码 + review 标准）
│
├─ 常量
│   ├─ _CODE_BLOCK_RE                         ← 代码块正则：``` ... ```（含跨行）
│   ├─ _REVIEW_KEYWORDS = (                   ← review 相关关键词
│   │     "review", "check", "verify", "test",
│   │     "lint", "security", "performance"
│   │   )
│   ├─ _MAX_CODE_BLOCKS: int = 2              ← 最多提取的代码块数量
│   └─ _MAX_SUMMARY_CHARS: int = 3000         ← 总摘要最大字符数，超出截断
│
├─ _field(item, name) -> Any                  ← 统一字段访问
│   ├─ dict → item.get(name)
│   └─ 对象 → getattr(item, name, None)
│
└─ ClaudeCodeContextSummarizer               ← 输入端转换器主类（零 LLM，纯规则）
    │
    ├─ summarize(state, goal, success_criteria, template=None) -> str
    │   │                                        ← 入口：拼装 context_summary
    │   ├─ ① 拼 "Goal: ..." / "Success criteria: ..."
    │   ├─ ② _extract_code_blocks(state)
    │   │     └─ 非空 → 拼 "Code to review:" + 各代码块
    │   ├─ ③ _extract_review_hints(state)
    │   │     └─ 非空 → 拼 "Review focus: kw1, kw2, ..."
    │   ├─ ④ 总长 > 3000 → 截断 + "...(truncated)"
    │   └─ ⑤ 返回 summary
    │
    ├─ _extract_code_blocks(state) -> list[str] ← 从 messages 提取代码块
    │   ├─ 遍历 messages → _field(msg, "content")
    │   ├─ 非 str → 跳过
    │   ├─ _CODE_BLOCK_RE.findall(content)
    │   ├─ 找够 _MAX_CODE_BLOCKS=2 → break
    │   └─ 返回 blocks[:2]
    │
    └─ _extract_review_hints(state) -> list[str] ← 从 messages 提取 review 关键词
        ├─ 遍历 messages → _field(msg, "content")
        ├─ 非 str → 跳过
        ├─ content.lower() 匹配 _REVIEW_KEYWORDS
        ├─ 去重追加
        └─ 返回 hints[:5]
```

### 0.3. 补充

**`claude_code_context_summarizer.py` 是 Claude specialist 的"输入端闸门"——从父 ThreadState 里挑出"代码块 + review 关键词"，压成一段精准上下文，零 LLM。**

几点补充：

- **零 LLM，纯规则**：与 `SelfCopyContextSummarizer` 不同，这里没有任何 LLM 路径。**完全靠正则和关键词匹配**，速度快、成本零、行为确定。
- **专为 review 场景定制**：`_REVIEW_KEYWORDS` 里是 `review / check / verify / test / lint / security / performance`——这是"代码审查"场景的典型关注点。**这就是 per-specialist summarizer 的意义**：不同 specialist 提取不同内容。
- **代码块提取是"最近优先"**：遍历 `messages` 顺序提取，遇到第 2 个就 `break`。**先出现的先被取到**——通常最近的代码在 messages 末尾，但这里没做"从后往前"的优化，是个可注意点。
- **review hint 是"全 messages 扫描"**：不像代码块有上限截断，hint 提取会扫描所有 messages 才去重取前 5。**代价是遍历完整 history**。
- **截断是最后一道保险**：无论提取多少内容，总长超 3000 字符就砍。**保证输出可控**。
- **`template` 参数全程未用**：与 `SelfCopyContextSummarizer` 一样，是 L2 扩展预留位。
