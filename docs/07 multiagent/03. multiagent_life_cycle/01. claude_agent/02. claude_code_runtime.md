---

name: ClaudeCodeRuntime — CLI 直接调实现（claude --print 子进程 + stdout 解析）。

description: 

【整体职责】
实现 SpecialistRuntime 契约：每次 invoke 启动一个 claude CLI 子进程，
通过 `claude --print <goal>` 执行任务，从 stdout 取原始输出，组装成 SpecialistRawResult。

【内容摘要】
- ClaudeCodeRuntime          : runtime 主类，实现 invoke()。
- invoke()                   : 构建命令 + env → subprocess.run → 解析输出 / 归一化异常。
- _build_command()           : 构造 `claude --print <goal>` 命令。
- _build_env()               : 透传 auth 相关环境变量给子进程。
- _build_mcp_add_command()   : 构造 `claude mcp add` 命令注册 SpecialistMcpServer。
- configure_mcp()            : 执行 mcp add，注册 Poirot MCP server。

【职责边界】
- 只负责：构造命令、构造 env、启动子进程、解析 stdout、异常归一化。
- 不负责：上下文摘要（ContextSummarizer 负责）、结果摘要（ResultSummarizer 负责）、
  凭证发现（CredentialProvider 负责）、沙箱生命周期（sandbox 层负责）。
- 不持有运行时状态：每次 invoke 启动新进程，不跨调用复用。

## 0. 结构树

### 0.1. 静态结构树

```
claude_code_runtime.py — ClaudeCodeRuntime（CLI 直接调实现）
│
└─ ClaudeCodeRuntime                         ← 实现 SpecialistRuntime 契约
    │                                            sync only；每次 invoke 启动新进程
    │                                            黑盒：claude CLI 自带 model + 自管 ReAct loop
    │
    ├─ _command: str = "claude"              ← claude CLI 命令名 / 路径
    ├─ _sandbox_provider                      ← 沙箱 provider，用于构造 sandbox URL 参数
    │
    ├─ __init__(command="claude", sandbox_provider=None)
    │
    ├─ invoke(request) -> SpecialistRawResult ← 执行入口
    │   ├─ ① _build_command(request)          ← 构造 claude --print <goal>
    │   ├─ ② _build_env()                     ← 构造子进程 env
    │   ├─ ③ subprocess.run(cmd, ...)         ← ★ 启动 claude 子进程（见下方详解）
    │   └─ ④ return SpecialistRawResult(stdout, duration_seconds)
    │
    ├─ _build_command(request) -> list[str]   ← [command, "--print", goal]
    │   └─ 等价于终端执行: claude --print "<goal>"
    │
    ├─ _build_env() -> dict | None            ← 透传 auth 相关环境变量
    │   ├─ 读取: CLAUDE_CODE_OAUTH_TOKEN / ANTHROPIC_AUTH_TOKEN /
    │   │        ANTHROPIC_API_KEY / CLAUDE_CODE_CREDENTIALS_PATH
    │   ├─ 无 auth 变量 → return None（子进程继承父 env）
    │   └─ 有 auth 变量 → return {**os.environ, **auth_env}
    │
    ├─ _build_mcp_add_command(sandbox_id) -> list[str]
    │   │                                        ← 构造 claude mcp add 命令
    │   ├─ [command, "mcp", "add", "poirot_sandbox", "--",
    │   │   "python", "-m", "...specialist_mcp_server", "--sandbox-id", id]
    │   └─ append_sandbox_url_args(cmd, provider, sandbox_id)
    │
    └─ configure_mcp(sandbox_id) -> None      ← 执行 mcp add（超时 30s）
        └─ subprocess.run(self._build_mcp_add_command(...), timeout=30)
```

### 0.2. `subprocess.run` 内部逻辑详解（★★ 核心步骤）

```
invoke() 第 ③ 步：subprocess.run(...)
│
│  调用形式：
│  subprocess.run(
│      cmd,                          # ["claude", "--print", goal]
│      capture_output=True,          # 捕获 stdout + stderr 到内存
│      text=True,                    # 输出按文本解码（str，非 bytes）
│      timeout=request.timeout_seconds,  # 超时上限，超时 kill
│      env=env,                      # 子进程环境变量（None = 继承父 env）
│  )
│
└─ 操作系统级动作序列：
    │
    ├─ ① 查找程序
    │     在 PATH 环境变量里找名为 "claude" 的可执行文件
    │     └─ 找不到 → FileNotFoundError
    │
    ├─ ② 创建子进程
    │     fork 当前进程 → 新进程
    │     exec 执行 claude，argv = ["claude", "--print", goal]
    │
    ├─ ③ 传递参数
    │     命令行参数（goal）通过 argv 传给 claude
    │
    ├─ ④ 传递环境变量
    │     env=None → 子进程继承父进程全部 env
    │     env={...} → 子进程用指定 env（含 PATH/HOME + auth）
    │
    ├─ ⑤ 子进程内部执行（Poirot 不介入）
    │     claude 进程启动
    │       ├─ 读取 auth（env 或 ~/.claude/.credentials.json）
    │       ├─ 解析 --print 与 goal
    │       ├─ 调用 Anthropic API
    │       ├─ 跑自己的 ReAct loop（多轮推理、工具调用）
    │       ├─ 最终结果打到 stdout
    │       └─ 退出（exit code 0）
    │
    ├─ ⑥ 捕获输出
    │     stdout → result.stdout（str）
    │     stderr → result.stderr（str）
    │
    ├─ ⑦ 等待结束 / 超时
    │     ├─ 正常退出 → 返回 CompletedProcess
    │     └─ 超时 → 抛 TimeoutExpired + kill 子进程
    │
    └─ ⑧ 返回 CompletedProcess
          ├─ result.returncode → 退出码
          ├─ result.stdout     → 标准输出
          └─ result.stderr     → 标准错误
```

**参数作用速查：**

| 参数 | 作用 | 缺失后果 |
|---|---|---|
| `cmd` | 命令 + 参数列表，`argv[0]` = `"claude"` | — |
| `capture_output=True` | stdout/stderr 装进 result，不打印到终端 | 输出直接喷到控制台，无法回收 |
| `text=True` | 输出按 UTF-8 解码成 `str` | 得到 `bytes`，需手动 `.decode()` |
| `timeout=...` | 超时上限；超时抛 `TimeoutExpired` 并 kill | 卡死无上限 |
| `env=env` | 子进程 env；`None` = 继承父进程 env | — |

**env 两种情况：**

| env 值 | 子进程环境 | 为什么 |
|---|---|---|
| `None` | 继承父进程全部 env | 无 auth 变量时最简单，保证 PATH / HOME 可用 |
| `{**os.environ, **auth_env}` | 父 env + auth 覆盖 | 有 auth 时显式注入，同时不丢基础 env |

**异常来源：**

| 情况 | 触发点 | 转换 |
|---|---|---|
| 超时 | `subprocess.run` 抛 `TimeoutExpired` | → `SpecialistTimeoutError` |
| 找不到 `claude` | `subprocess.run` 抛 `FileNotFoundError` | → `SpecialistStartupError` |
| `claude` 退出码非 0 | `result.returncode != 0`（正常返回） | → `SpecialistCrashError(exit_code)` |

**与"调用 API"的本质区别：**

| 维度 | 调用 API | `subprocess.run(["claude", ...])` |
|---|---|---|
| 调用对象 | HTTP 接口 | 操作系统进程 |
| 通信方式 | 网络请求 / 响应 | argv + stdin/stdout |
| 谁跑 LLM | Poirot 自己 | `claude` 程序自己 |
| 认证 | Poirot 传 API key | `claude` 读自己的登录态 |
| 返回 | JSON 响应 | stdout 文本 |
| Poirot 角色 | 调用方 | 启动器 + 收件人 |

### 0.3. 运行时调用树

```
① 装配期（bootstrap._load_specialist 的 claude 分支）
_load_specialist("claude", config)
    ├─ ClaudeCredentialProvider().get_credential()      ← 凭证检测
    ├─ ClaudeCodeSpecialist()                           ← 内部构造 ClaudeCodeRuntime()
    ├─ ClaudeCodeContextSummarizer()
    └─ ClaudeCodeResultSummarizer()
        → registry.register(specialist)
        → make_specialist_tool(...)
        ═══════════ 进入 Agent 循环 ═══════════

② 运行期（Leader 派活给 claude）
delegate_to_claude tool handler
    │
    ├─ context_summarizer.summarize(...)                ← 压父上下文
    ├─ SpecialistRequest(goal, criteria, context_summary, ...)
    │
    ▼
ClaudeCodeSpecialist.invoke(request)
    │  转发
    ▼
ClaudeCodeRuntime.invoke(request)                       ← 本文件
    │
    ├─ ① _build_command(request)
    │     └─ ["claude", "--print", goal]
    │
    ├─ ② _build_env()
    │     ├─ 遍历 4 个 auth 变量
    │     ├─ 无 auth → None
    │     └─ 有 auth → {**os.environ, **auth_env}
    │
    ├─ ③ subprocess.run(cmd, capture_output=True, text=True,
    │                   timeout=request.timeout_seconds, env=env)
    │     │
    │     │  ┌─────── 操作系统级：启动 claude 子进程 ───────┐
    │     │  │ PATH 查找 → fork/exec → 传 argv+env          │
    │     │  │ claude 内部：读 auth → 调 API → ReAct loop   │
    │     │  │              → stdout → exit                 │
    │     │  │ 回收 stdout/stderr → 等退出 / 超时 kill       │
    │     │  └──────────────────────────────────────────────┘
    │     │
    │     ├─ TimeoutExpired   → raise SpecialistTimeoutError
    │     ├─ FileNotFoundError→ raise SpecialistStartupError
    │     └─ returncode != 0  → raise SpecialistCrashError(exit_code)
    │
    └─ ④ return SpecialistRawResult(raw_output=stdout, duration_seconds=...)
    │
    ▼
（回到 tool handler，交给 ResultSummarizer 压缩）

③ MCP 配置（可选路径，bootstrap 或 specialist 调）
configure_mcp(sandbox_id)
    ├─ _build_mcp_add_command(sandbox_id)
    │   └─ append_sandbox_url_args(...)                 ← 附加沙箱 URL 参数
    └─ subprocess.run(cmd, timeout=30)                  ← 注册 SpecialistMcpServer
```

### 0.4. 补充

**`claude_code_runtime.py` 是 Claude Code specialist 的"外部进程执行器"——通过 `subprocess.run` 启动 `claude` CLI 子进程，用其 stdout 作为原始输出。**

几点补充：

- **走"进程"不走"网络"**：`subprocess.run(["claude", ...])` 是操作系统级进程调用，不是 HTTP 调用。**Poirot 只当启动器和收件人，不参与 claude 内部怎么调 LLM。**
- **`--print` 是"非交互一次性执行"模式**：claude 跑完一次就把结果打到 stdout 并退出，不会进入 REPL。Poirot 因此能用"启动-等待-收输出"的简单模型。
- **`env` 的两种情况都有必要**：`None`（继承父 env）适合无 auth 场景；`{**os.environ, **auth_env}` 适合有 auth 场景——**只传 auth 会让子进程丢 PATH/HOME，只传父 env 又注入不了 auth**。
- **异常分工明确**：超时和命令缺失是 `subprocess.run` 主动抛；退出码非 0 是"正常返回但结果失败"，需自己判断。
- **`configure_mcp` 是独立路径**：不在 `invoke` 里调，而是由 bootstrap 或 specialist 在 invoke 前单独调。作用是**把 Poirot 的 MCP server 注册给 claude CLI**，让 claude 能通过 MCP 访问沙箱工具。
- **每次 invoke 新进程**：不复用、不做长连接。简单直接，代价是启动开销。
