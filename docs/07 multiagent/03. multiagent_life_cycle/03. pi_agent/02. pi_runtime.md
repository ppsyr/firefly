---

name: PiRuntime — RPC mode 协议实现（pi --mode rpc 子进程 + stdio JSON-RPC）。

description: 

【整体职责】
实现 SpecialistRuntime 契约：每次 invoke 启动一个 `pi --mode rpc` 子进程，
通过 stdin 发 prompt、从 stdout 读 JSON 事件流，收集文本增量与 token 用量，
返回 SpecialistRawResult。强制走 Poirot SpecialistMcpServer（禁用 pi 自带工具）。

【内容摘要】
- PiRuntimeConfig             : runtime 配置（命令 / mode 参数 / provider / model / thinking）。
- PiRuntime                   : runtime 主类，实现 invoke()。
- invoke()                    : 同步入口：起进程 → 发 prompt → 收事件 → 归一化异常。
- _run_rpc_session()          : 启动子进程 + 读写 stdio 的 JSON-RPC 会话。
- _build_command()            : 组装 pi CLI 命令（含 --no-builtin-tools + -e extension）。
- _build_env()                : 透传凭证 env（国内 provider 优先）+ MCP endpoint。
- _build_prompt()             : 构造 prompt（goal + context + criteria + 三段输出格式）。
- _extract_usage()            : 从 agent_end 事件提取 TokenUsage。
- _resolve_mcp_endpoint()     : 解析 SpecialistMcpServer 的 stdio 启动命令。
- _poirot_extension_path()    : 返回 Poirot sandbox bridge extension 的路径。

【职责边界】
- 只负责：启动 pi 子进程、发 prompt、收事件、抽输出与 usage、异常归一化。
- 不负责：上下文摘要（ContextSummarizer 负责）、结果摘要（ResultSummarizer 负责）、
  凭证发现（CredentialProvider 负责）、沙箱生命周期（sandbox 层负责）。
- 不持有运行时状态：每次 invoke 启动新进程 + 完成关闭，不做 pool。

## 0. 结构树

### 0.1. 静态结构树

```
pi_runtime.py — PiRuntime（RPC mode 实现：pi --mode rpc 子进程 + stdio JSON-RPC）
│
├─ PiRuntimeConfig(frozen)                   ← runtime 配置
│   ├─ command: str = "pi"                   ← 启动命令
│   ├─ mode_args: tuple = ("--mode", "rpc", "--no-session")
│   ├─ provider: str | None = None           ← provider（留空用 pi 默认）
│   ├─ model: str | None = None              ← 模型（留空用 pi 默认）
│   ├─ thinking_level: str = "medium"        ← 思考等级
│   └─ extra_args: tuple = ()                ← 额外参数
│
└─ PiRuntime                                 ← 实现 SpecialistRuntime 契约
    │                                            sync only；每次 invoke 启动新进程 + 完成关闭
    │                                            强制走 Poirot SpecialistMcpServer
    │                                            黑盒：pi CLI 自带 model + 自管 ReAct loop
    │
    ├─ _config: PiRuntimeConfig              ← runtime 配置
    ├─ _sandbox_provider                      ← 沙箱 provider
    │
    ├─ __init__(config, sandbox_provider)
    │
    ├─ invoke(request) -> SpecialistRawResult ← 同步入口
    │   ├─ raw_output, usage = _run_rpc_session(request)
    │   │   ├─ subprocess.TimeoutExpired → SpecialistTimeoutError
    │   │   ├─ FileNotFoundError         → SpecialistStartupError
    │   │   ├─ SpecialistError 子类       → 原样抛出
    │   │   └─ 其他异常                  → SpecialistCrashError
    │   └─ return SpecialistRawResult(raw_output, usage, duration_seconds)
    │
    ├─ _run_rpc_session(request) -> (str, TokenUsage | None)
    │   │                                        ← 启动子进程 + 读写 stdio
    │   ├─ ① cmd = _build_command(request)
    │   ├─ ② env = _build_env(request)
    │   ├─ ③ subprocess.Popen(cmd, stdin/stdout/stderr=PIPE, text=True, env=env)
    │   ├─ ④ 写一行 JSON 到 stdin：
    │   │     {"type": "prompt", "message": prompt, "id": "req-1"}
    │   ├─ ⑤ 逐行读 stdout，解析 JSON 事件：
    │   │     ├─ message_update + text_delta → chunks.append(delta)
    │   │     ├─ agent_end → 抽最后一条 assistant message 的 usage；break
    │   │     └─ extension_error → raise SpecialistCrashError
    │   ├─ ⑥ raw_output = "".join(chunks)
    │   ├─ ⑦ usage = _extract_usage(usage_data)
    │   ├─ ⑧ return (raw_output, usage)
    │   └─ finally：proc.stdin.close() → proc.terminate() → wait(5s) → 超时 kill
    │
    ├─ _build_command(request) -> list[str]
    │   │                                        ← 组装 pi CLI 命令
    │   ├─ [command, *mode_args]
    │   ├─ --provider <provider>（若配置）
    │   ├─ --model <model>（若配置）
    │   ├─ --thinking <level>（若配置）
    │   ├─ --no-builtin-tools               ← 禁用 pi 自带工具
    │   ├─ -e <pi-sandbox-bridge/index.ts>  ← 加载 Poirot extension
    │   └─ *extra_args
    │
    ├─ _build_env(request) -> dict | None
    │   │                                        ← 透传凭证 env + MCP endpoint
    │   ├─ 凭证 env（13 个，国内 provider 优先）：
    │   │   DEEPSEEK_API_KEY / KIMI_API_KEY / MINIMAX_API_KEY /
    │   │   XIAOMI_API_KEY / ZAI_API_KEY /
    │   │   ANTHROPIC_API_KEY / OPENAI_API_KEY / GEMINI_API_KEY /
    │   │   OPENROUTER_API_KEY / GROQ_API_KEY / XAI_API_KEY /
    │   │   MISTRAL_API_KEY / TOGETHER_API_KEY
    │   ├─ PI_CODING_AGENT_DIR（若设置）
    │   ├─ POIROT_SANDBOX_MCP_ENDPOINT（sandbox_id 非 None 时）
    │   ├─ 无命中 → None
    │   └─ 有命中 → {**os.environ, **auth_env}
    │
    ├─ _build_prompt(request) -> str         ← 构造 prompt
    │   ├─ goal
    │   ├─ "## Context\n<context_summary>"（若非空）
    │   ├─ "## Success Criteria\n<criteria>"（若非空）
    │   └─ "## Output Format\n..."（三段式：What You Did / Success / Gaps）
    │
    ├─ _extract_usage(usage_data) -> TokenUsage | None
    │   ├─ 空 → None
    │   └─ tokens = usage_data["tokens"]
    │       → TokenUsage(input, output, total)
    │
    ├─ _resolve_mcp_endpoint(sandbox_id) -> str
    │   │                                        ← 解析 SpecialistMcpServer 启动命令
    │   ├─ "python -m ...specialist_mcp_server --sandbox-id <id>"
    │   └─ append_sandbox_url_args(...)         ← 附加 sandbox URL 参数
    │
    └─ _poirot_extension_path() -> str        ← 返回 sandbox bridge extension 路径
        └─ <pkg_path>/extensions/pi-sandbox-bridge/index.ts
```

### 0.3. 补充

**`pi_runtime.py` 是 Pi specialist 的"RPC 协议执行器"——启动 `pi --mode rpc` 子进程，通过 stdin/stdout 做 JSON-RPC，流式收事件、抽 token 用量。**

几点补充：

- **唯一返回 token 用量的 runtime**：从 `agent_end` 事件的 `usage.tokens` 里抽 `input` / `output` / `total`。Claude / Codex 的 runtime 都不返回 usage。
- **唯一强制走 Poirot MCP**：`--no-builtin-tools` 禁掉 pi 自带 read/write/edit/bash；`-e pi-sandbox-bridge/index.ts` 加载 Poirot 的 TypeScript 扩展。**所有文件操作必须经 Poirot MCP → 过 PathTranslator + SecurityGuard。**
- **不传 system prompt**：MVP 不定制 pi 的 system prompt，靠 `_build_prompt` 在 user message 里塞 context + 三段式输出格式要求（What You Did / Success / Gaps）。
- **env 白名单最长（13 个凭证）**：且**国内 provider 优先**（DeepSeek / Kimi / MiniMax / Xiaomi / ZAI 在前），国外大厂在后。**这是"便宜优先"的显式排序。**
- **`POIROT_SANDBOX_MCP_ENDPOINT` 是桥接关键**：`sandbox_id` 非 None 时，把 MCP server 的启动命令字符串（含 `--sandbox-id` + sandbox URL 参数）传进 env；pi extension 读这个 env 来连接 Poirot MCP。
- **事件处理三分支**：
  - `message_update` + `text_delta` → 累积输出（流式）
  - `agent_end` → 抽 usage 并结束
  - `extension_error` → 转 `SpecialistCrashError`
- **进程清理在 finally**：`stdin.close → terminate → wait(5s) → kill`。**即便读取过程中抛异常，也能保证子进程不泄漏。**
- **`_poirot_extension_path` 是动态解析**：基于 `poirot.backend.agents.multiagent.__path__` 找 `extensions/pi-sandbox-bridge/index.ts`。**安装位置变化时不需要改代码。**
- **与其他两个 runtime 的定位差异**：

| 维度 | ClaudeCodeRuntime | CodexRuntime | PiRuntime |
|---|---|---|---|
| 通信 | CLI + stdout | ACP 协议 | stdio JSON-RPC |
| token 用量 | ❌ | ❌ | ✅ |
| 强制 MCP | ❌ | ❌ | ✅ |
| 扩展加载 | ❌ | ❌ | ✅ TypeScript extension |
| env 白名单 | 4 | 3 | 13 + PI_DIR + MCP endpoint |
