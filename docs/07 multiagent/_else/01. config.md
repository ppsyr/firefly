---

name: MultiAgentConfig — 多 Agent 编排配置。

description: 

【整体职责】
定义 multiagent 层的全部配置结构，并从环境变量（POIROT_MULTIAGENT_*）加载。
配置覆盖四个层面：编排主配置（MultiAgentConfig）、L2 进化层（L2Config）、
L3 评估层（L3Config）、预算控制（BudgetConfig / SpecialistBudgetLimit）。

【内容摘要】
- L2Config                  : L2 进化层配置（触发周期、冷却、退化阈值、成本/延迟告警等）。
- L3Config                  : L3 评估层配置（评估方法、LLM 评判权重、健康检查窗口等）。
- SpecialistBudgetLimit     : 单个 specialist 的每日预算上限。
- BudgetConfig              : 各 specialist 的预算上限集合 + 全局告警阈值。
- MultiAgentConfig          : 编排主配置（启用开关、specialist 列表、并发/超时、Pi 专属配置）。
- STARTUP_ONLY_FIELDS       : 标记启动时确定、不可热切换的字段集合。
- load_multiagent_config()  : 从环境变量构造 MultiAgentConfig 的唯一入口。

【职责边界】
- 只负责：定义配置结构、字段默认值、从 env 加载、标记 startup-only 字段。
- 不负责：配置校验（由 loader 层负责）、配置热更新、运行时状态管理。
- 不持有运行时状态：全部为 frozen dataclass，构造后不可变。

## 0. 结构树

### 0.1. 静态结构树

```
config.py — MultiAgentConfig 多 Agent 编排配置（定义结构 + 从 env 加载）
│
├─ L2Config(frozen)                           ← L2 进化层配置；作用：控制进化触发周期、
│   │                                            冷却、退化检测、成本/延迟告警、意图识别等
│   ├─ enabled: bool = False                  ← 是否启用 L2（默认关闭，数据驱动触发）
│   ├─ cron_interval_hours: float = 6.0       ← 进化任务周期（小时）
│   ├─ cooldown_seconds: float = 3600.0       ← 两次触发之间的冷却时间（秒）
│   ├─ anti_loop_window: int = 5              ← 反循环窗口（防止反复触发）
│   ├─ failure_window_hours: float = 24.0     ← 失败统计时间窗口（小时）
│   ├─ failure_threshold: int = 5             ← 失败次数阈值（超过则触发进化）
│   ├─ degradation_min_invoked: int = 5       ← 判定退化所需的最小调用次数
│   ├─ degradation_threshold: float = 0.4     ← 退化判定阈值
│   ├─ cost_alert_usd: float = 1.0            ← 成本告警阈值（美元）
│   ├─ latency_alert_seconds: float = 300.0   ← 延迟告警阈值（秒）
│   ├─ blocked_auto_release_hours: float = 24.0 ← 阻塞自动释放时间（小时）
│   ├─ evolution_model: str | None = None     ← 进化所用模型（None 表示用默认）
│   ├─ eval_timeout_seconds: float = 1800.0   ← 评估超时（秒）
│   ├─ eval_sample_min: int = 10              ← 评估采样下限
│   ├─ eval_sample_max: int = 15              ← 评估采样上限
│   ├─ eval_task_max_reuse: int = 3           ← 单个评估任务最大复用次数
│   ├─ intent_llm_enabled: bool = False       ← 是否用 LLM 做意图识别
│   ├─ intent_model: str | None = None        ← 意图识别模型
│   ├─ intent_confidence_threshold: float = 0.7    ← 意图置信度阈值
│   ├─ intent_delegate_rate_threshold: float = 0.2 ← 委派率阈值
│   ├─ intent_ability_failure_threshold: float = 0.5 ← 能力失败率阈值
│   ├─ intent_metadata_sample_size: int = 20  ← 意图元数据采样大小
│   └─ l3_enabled: bool = False               ← L3 联动开关（L2 内部持有）
│
├─ L3Config(frozen)                           ← L3 评估层配置；作用：控制评估方法、
│   │                                            LLM 评判权重、健康检查窗口、决策日志保留
│   ├─ enabled: bool = False                  ← 是否启用 L3（默认关闭，数据驱动触发）
│   ├─ default_eval_method: str = "programmatic" ← 默认评估方法
│   ├─ llm_judge_model: str | None = None     ← LLM 评判所用模型

│   │   └─ task_completion / response_quality / efficiency / tool_usage
│   ├─ health_check_window: int = 20          ← 健康检查滑动窗口
│   ├─ degradation_threshold: float = 0.4     ← 退化判定阈值
│   ├─ degradation_delta: float = 0.15        ← 退化增量阈值
│   ├─ decision_log_retention_days: int = 90  ← 决策日志保留天数
│   └─ decision_log_archive_enabled: bool = True ← 是否归档决策日志

├─ SpecialistBudgetLimit(frozen)              ← 单个 specialist 每日预算上限
│   ├─ per_day_tokens: int = 200000           ← 每日 token 上限

│   ├─ max_steps: int = 50                    ← 最大步数

│   ├─ subagent_timeout_seconds: int = 300    ← subagent 超时（秒）
│   ├─ metrics_db_path: str = ".poirot/multiagent.db" ← 指标数据库路径
│   ├─ metrics_health_threshold: float = 0.4  ← 健康度阈值
│   ├─ metrics_min_invoked: int = 5           ← 指标统计最小调用次数
│   ├─ specialists_pi_provider: str = ""      ← Pi provider（空=未配置）
│   ├─ specialists_pi_api_key: str = ""       ← Pi API key（空=未配置）

│   ├─ specialists_pi_thinking_level: str = "medium" ← Pi 思考等级
│   ├─ l2: L2Config = ...                     ← L2 进化层配置
│   ├─ budget: BudgetConfig = ...             ← 预算配置
│   └─ l3: L3Config = ...                     ← L3 评估层配置
│
├─ STARTUP_ONLY_FIELDS(frozenset)             ← 启动时确定、不可热切换的字段集合
│   └─ {"enabled", "specialists_use", "metrics_db_path", "l2.enabled", "l3.enabled"}
│
├─ _env_bool(name, default) -> bool           ← 读布尔环境变量；未设/不在白名单 → 默认
├─ _env_int(name, default) -> int             ← 读整型环境变量；转换失败 → 默认
├─ _env_float(name, default) -> float         ← 读浮点环境变量；转换失败 → 默认
├─ _env_tuple(name, default) -> tuple         ← 读逗号分隔元组；空/全空白 → 默认
│
└─ load_multiagent_config() -> MultiAgentConfig ← 唯一入口：从 POIROT_MULTIAGENT_* 加载配置
    ├─ 主配置字段 ← _env_bool / _env_int / _env_float / _env_tuple
    ├─ Pi 配置 ← os.getenv 直读（字符串型）
    ├─ l2 = L2Config(...)                     ← 嵌套构造
    └─ l3 = L3Config(...)                     ← 嵌套构造
```

### 0.2. 运行时调用树

```
① 装配期（启动时一次）
bootstrap_runtime()
    └─ load_multiagent_config()
          ├─ _env_bool("POIROT_MULTIAGENT_ENABLED", True)      ← 主开关
          ├─ _env_tuple("POIROT_MULTIAGENT_SPECIALISTS", ...)  ← 启用哪些 specialist
          ├─ _env_int / _env_float(...)                        ← 并发/超时/阈值
          ├─ os.getenv("POIROT_MULTIAGENT_PI_*", "")           ← Pi 专属（字符串直读）
          ├─ L2Config(...)                                     ← 嵌套构造 L2
          └─ L3Config(...)                                     ← 嵌套构造 L3
    → 得到 MultiAgentConfig
    → 按 specialists_use 注册 specialist 到 registry
    → STARTUP_ONLY_FIELDS 之外的字段可参与后续热更新
        ═══════════ 进入 Agent 循环 ═══════════

② 运行期 —— 配置被读取（只读，不修改）
Leader 派活 / middleware / budget guard / metrics
    ├─ config.max_concurrent        → 并发控制
    ├─ config.timeout_seconds       → 超时控制
    ├─ config.budget.<specialist>   → 预算检查
    ├─ config.metrics_*             → 健康度判定
    └─ config.l2 / config.l3        → 决定是否触发进化/评估

③ 热更新（若有）
配置热更新入口
    ├─ 过滤 STARTUP_ONLY_FIELDS            ← 这些字段一律忽略
    └─ 其余字段允许覆盖

（本模块不参与：实际派活、runtime 执行、摘要、eval 执行）
```

### 0.3. 补充

**`config.py` 是 multiagent 层的"配置总入口"——定义所有配置结构，并统一从环境变量加载；运行期只读、frozen、可安全跨线程共享。**

几点补充：

- **纯配置、无行为**：本文件只有 frozen dataclass + env 读取函数，没有业务逻辑。唯一的"动作"是 `load_multiagent_config()` 把 env 组装成配置对象。
- **`frozen=True` 是并发前提**：配置在装配期构造一次，运行期被多个 Agent / 线程读取；不可变才能安全共享。
- **默认值以代码为准**：`MultiAgentConfig.enabled` 实际是 `True`（原注释里"enabled=false 默认"是过时描述）；`L2Config.enabled` / `L3Config.enabled` 才是 `False`。判断"默认开还是关"时，直接看字段值。
- **`STARTUP_ONLY_FIELDS` 的语义**：这些字段启动时确定，热更新时必须忽略；`l2.enabled` / `l3.enabled` 用点号表示"嵌套字段"。
- **env 读取全部 fail-safe**：`_env_int` / `_env_float` 在 `ValueError` 时回退默认，不抛异常；`_env_bool` 只认 `true/1/yes`；`_env_tuple` 过滤空段。目的是**配置错误不致命**。
- **字符串型配置不过 helper**：Pi 的 provider / api_key / model 直接 `os.getenv(..., "")`，空串表示"未配置"，由下游判空。
- **嵌套配置在 loader 内构造**：`l2` / `l3` 不在 `MultiAgentConfig` 默认工厂里加载，而是在 `load_multiagent_config()` 里显式构造，便于后续扩展 env 映射。
- **未覆盖的 env 字段**：`load_multiagent_config()` 只映射了部分 L2 / L3 字段（其余字段保持 dataclass 默认值），说明这些字段当前不支持 env 覆盖，只能靠代码默认。
