---

name: L3 DecisionLog — 跨 run specialist 协作 lessons 累积。

description: 

【整体职责】
定义决策日志的读写门面：DecisionLogWriter 提供异步写入（fire-and-forget，不阻塞
L1 turn）；DecisionLogReader 提供读取最近 N 条 lesson 与归档过期记录。
持久化由 _DecisionLogStore 契约承担（L1 MultiAgentMetricsStore 实现）。

【内容摘要】
- _DecisionLogStore(Protocol) : 持久化契约（save_decision_log / get_decision_logs / archive_decision_logs）。
- DecisionLogWriter           : 异步写入口（ThreadPoolExecutor max_workers=1）。
- DecisionLogReader           : 读入口（最近 N 条 lesson + 归档）。

【职责边界】
- 只负责：定义持久化契约、提供异步写与读门面。
- 不负责：实际 SQLite 读写（L1 MultiAgentMetricsStore 负责）、
  lesson 如何被消费（L2 EvolutionMutator 负责）。
- Writer 持有 executor（用于异步），Reader 无状态。

## 0. 结构树

### 0.1. 静态结构树

```
decision_log.py — L3 DecisionLog（跨 run specialist 协作 lessons 累积）
│
├─ 外部 import
│   ├─ DecisionLogRecord      ← from eval/types.py（复用，不重复定义）
│   └─ FailureCategory        ← from evolution/types.py（复用 L2 enum）
│
├─ _DecisionLogStore(Protocol)              ← ★ 持久化契约
│   │   用途：抽象决策日志的存/取/归档
│   │   实现方：L1 MultiAgentMetricsStore
│   │
│   ├─ save_decision_log(record) -> None
│   │   用途：写一条决策日志
│   ├─ get_decision_logs(specialist_name, failure_category, limit) -> list[DecisionLogRecord]
│   │   用途：按 specialist + 分类过滤查 N 条
│   └─ archive_decision_logs(retention_days) -> int
│       用途：归档超期记录，返回归档条数
│
├─ DecisionLogWriter                        ← ★ 异步写门面
│   │   用途：fire-and-forget 写决策日志，不阻塞 L1 turn
│   │
│   ├─ _store: _DecisionLogStore           ← 注入的持久化 store
│   ├─ _executor: ThreadPoolExecutor(max_workers=1)  ← 单线程池（串行写）
│   │
│   ├─ __init__(store)                     ← 注入 store + 建 executor
│   │
│   ├─ write_async(record) -> None         ← 提交异步写（立即返回）
│   │   └─ executor.submit(store.save_decision_log, record)
│   │
│   └─ shutdown() -> None                  ← 关闭 executor（等 pending 写完成）
│       └─ executor.shutdown(wait=True)
│
└─ DecisionLogReader                        ← ★ 读门面
    │   用途：供 L2 EvolutionMutator 读 lesson / 供归档调度调用
    │
    ├─ _store: _DecisionLogStore           ← 注入的持久化 store
    │
    ├─ __init__(store)
    │
    ├─ get_recent_lessons(specialist_name, failure_category, limit=5) -> list[DecisionLogRecord]
    │   │   用途：查最近 N 条 lesson（作 L2 输入样本，不进 prompt）
    │   └─ store.get_decision_logs(...)
    │
    └─ archive_expired(retention_days=90) -> int
        │   用途：归档超期记录（移到 archive 表 + 删主表）
        └─ store.archive_decision_logs(...)
```

### 0.2. 运行时调用树

```
① 装配期（L3 启用时）
bootstrap / setup_l3
    │
    ├─ store = MultiAgentMetricsStore(...)       ← L1 实现 _DecisionLogStore
    │
    ├─ writer = DecisionLogWriter(store)         ← 建写门面
    │   └─ executor = ThreadPoolExecutor(max_workers=1)
    │
    └─ reader = DecisionLogReader(store)         ← 建读门面
        ═══════════ 进入 Agent 循环 ═══════════

② 运行期：L1 写入（每次派活后）
delegate_to_* tool handler
    │
    └─ _write_decision_log_async(writer, ...)    ← tools.py 里的辅助函数
        │
        ├─ 构造 DecisionLogRecord
        │   ├─ log_id / specialist_name / task_id
        │   ├─ goal / success_criteria
        │   ├─ failure_category（从 SpecialistResult 取）
        │   ├─ success_criteria_met（0/1）
        │   └─ timestamp=utc_now_iso()
        │
        └─ writer.write_async(record)            ← 本文件
            │
            └─ executor.submit(store.save_decision_log, record)
                │
                └─ （后台线程执行，不阻塞 L1）
                    └─ MultiAgentMetricsStore.save_decision_log
                        └─ INSERT INTO specialist_decision_log

③ 运行期：L2 读取（进化时）
L2 EvolutionMutator（cron 周期触发）
    │
    └─ reader.get_recent_lessons(specialist_name, failure_category, limit=5)
        │
        └─ store.get_decision_logs(...)
            └─ SELECT ... FROM specialist_decision_log
                WHERE specialist_name=? AND failure_category=?
                ORDER BY timestamp DESC LIMIT ?
        │
        └─ 返回 list[DecisionLogRecord]
            └─ 作为变异输入样本（不进 prompt）

④ 运行期：归档（周期任务 / L2 cron）
归档调度
    │
    └─ reader.archive_expired(retention_days=90)
        │
        └─ store.archive_decision_logs(90)
            ├─ INSERT INTO archive SELECT ...（复制到归档表）
            └─ DELETE FROM specialist_decision_log（删主表）
        │
        └─ 返回归档条数

⑤ 进程退出
atexit / 关闭流程
    └─ writer.shutdown()
        └─ executor.shutdown(wait=True)          ← 等 pending 写完成
```

### 0.3. 补充

**`decision_log.py` 是决策日志的"读写门面"——Writer 给 L1 异步写，Reader 给 L2 读 lesson；持久化由 `_DecisionLogStore` 契约承担（`MultiAgentMetricsStore` 实现）。**

几点补充：

- **写读分离**：`DecisionLogWriter` 只用于写（L1 每次派活后），`DecisionLogReader` 只用于读（L2 进化时 + 归档调度）。**两个类职责单一，不混合。**
- **fire-and-forget 是核心设计**：`write_async` 提交后立即返回——**不阻塞 L1 的派活流程**。L1 不需要等日志写完就能继续下一步。
- **单线程池（max_workers=1）而非多线程**：串行写，避免 SQLite 并发写冲突。**简单优先于性能。**
- **`shutdown(wait=True)` 保证不丢数据**：进程退出时等 pending 写完成。**这是 `atexit` 或关闭流程该调的方法。**
- **`_DecisionLogStore` 是 Protocol**：`MultiAgentMetricsStore` **无需显式继承**——只要实现三个方法（`save_decision_log` / `get_decision_logs` / `archive_decision_logs`）就满足契约。**这是 Poirot 表达契约的统一方式。**
- **lesson 不进 prompt**：`get_recent_lessons` 的结果作为 **L2 EvolutionMutator 的输入样本**，不注入当前对话的 prompt。**历史失败经验是给"进化"用的，不是给"当前 LLM"看的。**
- **归档是"移"不是"删"**：`archive_expired` 把超期记录移到 archive 表——**数据保留，只是不在主表**。这是 `L3Config.decision_log_archive_enabled` 的语义。
- **与 L1/L2 接口关系**：

| 组件 | 角色 | 谁调 |
|---|---|---|
| `DecisionLogWriter` | L1 写入门面 | `tools.py` 的 `_write_decision_log_async` |
| `DecisionLogReader` | L2 读取门面 | L2 EvolutionMutator + 归档调度 |
| `_DecisionLogStore` | 持久化契约 | 由 `MultiAgentMetricsStore` 实现 |
| `MultiAgentMetricsStore` | SQLite 实际读写 | 实现契约三方法 |
