---

name: L3 SpecialistEvalRegistry + EvalAdapter Protocol。

description: 

【整体职责】
定义 L3 评估器的契约与注册表：EvalAdapter Protocol 规定评估器必须实现的方法；
SpecialistEvalRegistry 以实例级 dict 管理多个评估器，供 Bridge 按 method 名取用。

【内容摘要】
- EvalAdapter(Protocol, runtime_checkable) : 评估器契约（evaluate + health_check）。
- SpecialistEvalRegistry                  : 实例级注册表（register / get / list_methods）。

【职责边界】
- 只负责：定义评估器契约、注册与查询评估器。
- 不负责：评估逻辑实现（3 个 adapter 负责）、评估触发（Bridge 负责）、
  装配（bootstrap 负责）。
- 不持有状态：registry 持有 dict，但本身不做全局注册。

## 0. 结构树

### 0.1. 静态结构树

```
registry.py — L3 SpecialistEvalRegistry + EvalAdapter Protocol
│
├─ 外部 import
│   ├─ EvalContext           ← from eval/types.py
│   └─ EvalResult            ← from evolution/promotion_gate.py（复用 L2）
│
├─ EvalAdapter(Protocol, runtime_checkable)  ← ★ 评估器契约
│   │                                            结构化契约：实现方无需继承
│   │                                            runtime_checkable：支持 isinstance 检查
│   │
│   ├─ evaluate(ctx: EvalContext) -> EvalResult
│   │   │   用途：评估 candidate vs baseline，返 EvalResult（含 CI + success + method_used）
│   │   └─ 实现方：ProgrammaticAdapter / LLMJudgeAdapter / LongitudinalPairsAdapter
│   │
│   └─ health_check() -> bool
│       │   用途：评估器健康检查
│       └─ 示例：LLM-judge 检查 model 可用；programmatic 检查 ResultSummarizer 可用
│
└─ SpecialistEvalRegistry                    ← ★ 实例级注册表
    │                                            不做 class-level 全局注册
    │                                            由 bootstrap 装配，OrchestrationBridge 接收
    │
    ├─ _adapters: dict[str, EvalAdapter]      ← method 名 → adapter 实例
    │
    ├─ __init__()                             ← 初始化空 dict
    │
    ├─ register(method, adapter) -> None      ← 注册 adapter
    │   │   用途：把 adapter 挂到 method 名下
    │   ├─ method 名："programmatic" / "llm_judge" / "longitudinal_pairs"
    │   └─ 重复注册覆盖（后注册生效）
    │
    ├─ get(method) -> EvalAdapter | None      ← 按 method 名取 adapter
    │   └─ 未注册 → None（不抛异常）
    │
    └─ list_methods() -> tuple[str, ...]      ← 已注册 method 名 tuple
        └─ 按注册顺序返回
```

### 0.2. 运行时调用树

```
① 装配期（bootstrap）
bootstrap_runtime / setup_l3
    │
    ├─ registry = SpecialistEvalRegistry()    ← 建实例级注册表
    │
    ├─ registry.register("programmatic", ProgrammaticAdapter(...))
    ├─ registry.register("llm_judge", LLMJudgeAdapter(...))         ← 按配置决定
    ├─ registry.register("longitudinal_pairs", LongitudinalPairsAdapter(...))
    │
    └─ 把 registry 注入 OrchestrationBridge
        ═══════════ 进入 Agent 循环 ═══════════

② 运行期（L2 触发评估）
L2 Evolution（cron 周期）
    └─ OrchestrationBridge.evaluate(ctx: EvalContext)
        │
        ├─ ① 决定用哪个 method
        │     ├─ ctx.eval_method_hint 非空 → 用它
        │     └─ 否则用默认 method
        │
        ├─ ② registry.get(method)
        │     ├─ 命中 → 拿到 EvalAdapter
        │     └─ 未命中 → None（Bridge 处理回退）
        │
        ├─ ③ adapter.health_check()
        │     ├─ True → 继续
        │     └─ False → Bridge 可能换 adapter / 报错
        │
        └─ ④ adapter.evaluate(ctx)
            └─ return EvalResult
                │
                ▼
            L2 消费 EvalResult（决定是否晋升新版本）
```

### 0.3. 补充

**`registry.py` 是 L3 的"评估器花名册"——定义评估器契约（EvalAdapter Protocol）+ 实例级注册表（SpecialistEvalRegistry），供 Bridge 按 method 名取用。**

几点补充：

- **`EvalAdapter` 是 Protocol，不是 ABC**：实现方（3 个 adapter）**无需显式继承**——只要方法签名对得上（`evaluate` + `health_check`），运行时 `isinstance` 就认。**这是 Poirot 表达契约的统一方式。**
- **`@runtime_checkable` 是必要的**：没有它，`isinstance(x, EvalAdapter)` 会在运行时抛错。**它只检查"方法名是否存在"，不检查签名。**
- **实例级而非全局单例**：`_adapters` 是实例属性，不是类属性。**遵循 Poirot 禁全局单例原则**——避免跨测试 / 跨 thread 污染。
- **重复注册覆盖（不报错）**：`register` 用 dict 赋值——后注册的覆盖先注册的。**这给了 bootstrap 灵活性**：可以先注册默认实现，再用配置覆盖。
- **`get` 未命中返回 None**：不抛异常——**调用方（Bridge）负责决定"未命中怎么办"**（回退、报错、跳过）。
- **`list_methods` 返回 tuple**：不可变、有序（按注册顺序）。**比返回 list 更安全。**
- **复用 L2 的 `EvalResult`**：`evaluate` 的返回类型来自 `evolution/promotion_gate.py`——**不重复定义**。这保证 L2 和 L3 对"评估结果"的理解一致。
- **和 `SpecialistRegistry` 的对称性**：

| 维度     | SpecialistRegistry     | SpecialistEvalRegistry      |
| ------ | ---------------------- | --------------------------- |
| 存什么    | `SpecialistAgent` 实例   | `EvalAdapter` 实例            |
| key    | specialist 名           | method 名                    |
| 查方法    | `get(name)`            | `get(method)`               |
| 列方法    | `list_specialists()`   | `list_methods()`            |
| 注册方法   | `register(specialist)` | `register(method, adapter)` |
| 是否全局单例 | ❌ 实例级                  | ❌ 实例级                       |
| 契约类型   | Protocol               | Protocol                    |
