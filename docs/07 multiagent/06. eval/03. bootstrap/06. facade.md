---

name: L3 MultiagentProgrammaticFacade — L3 未启用时 L2 用的 facade。

description: 

【整体职责】
实现 EvalBridge 契约：当 L3 评估层未启用时，为 L2 PromotionGate 提供一个"退化的"
评估门面——只用 programmatic 方法（调 L1 ResultSummarizer 的 success_criteria_met），
接口与 L3 启用时的 OrchestrationBridge 完全一致，保证 L2 调用方式不变。

【内容摘要】
- MultiagentProgrammaticFacade : facade 主类，实现 evaluate / list_available_methods / health_check。

【职责边界】
- 只负责：委托 evaluator 做 programmatic 评估，返回 EvalResult。
- 不负责：LLM 评判（llm_judge adapter 负责）、纵向配对（longitudinal_pairs 负责）、
  评估器管理（registry 负责）。
- 不持有运行时状态：evaluator 由构造注入，可为 None。

---

```
① L2 检测到指标退化 / 失败超阈值
        │
        ▼
② L2 触发进化
        │
        ├─ ② -1 抽取历史样本（task_sample）
        ├─ ② -2 用 mutator 变异出 candidate（新版本）
        │
        ▼
③ L2 调 L3 评估 ★ ← 评估在这里
        │
        └─ L3.evaluate(EvalContext)
            ├─ candidate vs baseline
            ├─ programmatic / llm_judge
            └─ 返回 EvalResult
        │
        ▼
④ L2 根据评估结果决定是否晋升
        │
        └─ promotion_gate(EvalResult)
            ├─ 新版本更好 → 晋升
            └─ 没变好 / 更差 → 丢弃f
```

## 0. 结构树

### 0.1. 静态结构树

```
facade.py — MultiagentProgrammaticFacade（L3 未启用时 L2 用的 facade）
│
├─ 外部 import
│   ├─ EvalContext           ← from eval/types.py
│   └─ EvalResult / Evaluator / _wilson_ci   ← from evolution/promotion_gate.py（复用 L2）
│
└─ MultiagentProgrammaticFacade              ← ★ facade 主类
    │                                            实现 EvalBridge 契约
    │                                            内部调 L1 ResultSummarizer.success_criteria_met
    │                                            L3 未启用时 L2 PromotionGate 用它（floor eval）
    │
    ├─ _evaluator: Evaluator | None          ← 评估单个任务的 callable（构造注入）
    ├─ _z: float = 1.96                      ← Wilson CI 的 z 值（95% 置信度）
    │
    ├─ __init__(evaluator=None, z_score=1.96)
    │   │   用途：注入 evaluator 与 z 值
    │   └─ evaluator 为 None 时 evaluate 直接返回失败
    │
    ├─ evaluate(ctx) -> EvalResult            ← ★ 核心方法
    │   │   用途：对 task_sample 逐个评估 candidate / baseline，聚合返回
    │   │
    │   ├─ ① evaluator is None?
    │   │     └─ 是 → 返回 success=False, failure_reason="no evaluator configured"
    │   │
    │   ├─ ② 遍历 ctx.task_sample
    │   │     ├─ c_met = evaluator.evaluate(ctx.candidate, task)
    │   │     ├─ b_met = evaluator.evaluate(ctx.baseline, task)
    │   │     ├─ 异常 → continue（跳过）
    │   │     └─ 累积 candidate_scores / baseline_scores（1.0 / 0.0）
    │   │
    │   ├─ ③ candidate_scores 为空?
    │   │     └─ 是 → 返回 success=False, failure_reason="all_tasks_failed"
    │   │
    │   ├─ ④ c_score = 平均分；b_score = 平均分
    │   ├─ ⑤ c_low, c_high = _wilson_ci(c_score, n, z)
    │   │
    │   └─ ⑥ 返回 EvalResult(
    │          candidate_score, baseline_score,
    │          ci_low, ci_high, sample_size,
    │          method_used="programmatic", success=True
    │       )
    │
    ├─ list_available_methods() -> tuple[str, ...]
    │   │   用途：返回支持的评估方法
    │   └─ 固定返回 ("programmatic",)  ← 不支持 llm_judge / longitudinal_pairs
    │
    └─ health_check() -> bool                 ← 健康检查
        └─ evaluator is not None（已配置即可用）
```

### 0.2. 运行时调用树

```
① 装配期（bootstrap，L3 未启用时）
bootstrap_runtime / setup_l2
    │
    ├─ L3 未启用（l3.enabled=false）
    │   └─ 构造 MultiagentProgrammaticFacade(evaluator=...)
    │       └─ 注入 L2 PromotionGate.bridge
    │
    └─ L3 启用（l3.enabled=true）
        └─ 构造 OrchestrationBridge（另一个 facade）
            └─ 注入 L2 PromotionGate.bridge
        ═══════════ 进入 Agent 循环 ═══════════

② 运行期（L2 触发进化 → 调 L3 评估）
L2 Evolution（cron 周期触发）
    │
    ├─ ① 检测退化 / 失败超阈值
    ├─ ② 变异出 candidate
    │
    ├─ ③ PromotionGate 调 bridge.evaluate(ctx)
    │   │
    │   └─ MultiagentProgrammaticFacade.evaluate(ctx)   ← 本文件
    │       │
    │       ├─ ① evaluator is None?
    │       │     └─ 是 → 返回失败（no evaluator configured）
    │       │
    │       ├─ ② 遍历 task_sample：
    │       │     ├─ candidate 评估 → c_met
    │       │     ├─ baseline 评估 → b_met
    │       │     └─ 累积分数
    │       │
    │       ├─ ③ 全部失败 → 返回失败（all_tasks_failed）
    │       │
    │       ├─ ④ 算平均分
    │       ├─ ⑤ _wilson_ci(c_score, n, 1.96) → (c_low, c_high)
    │       │
    │       └─ ⑥ 返回 EvalResult
    │
    ├─ ④ PromotionGate 读 EvalResult
    │     ├─ candidate_score > baseline_score（+ CI 支持）→ 晋升
    │     └─ 否则 → 丢弃
    │
    └─ ⑤ 更新 version_dag / evolution_experiments
```

### 0.3. 补充

**`facade.py` 是 L3 未启用时的"降级评估门面"——只提供 programmatic 方法，接口与 L3 启用时的 `OrchestrationBridge` 完全一致，保证 L2 调用方式不变。**

几点补充：

- **它是 EvalBridge 契约的一个实现**：L2 的 `PromotionGate.bridge` 参数类型是 `EvalBridge` Protocol——`MultiagentProgrammaticFacade` 和 `OrchestrationBridge` 都满足，**L2 代码不需要知道用的是哪个**。
- **"floor eval"的含义**：只有 programmatic 一种方法（`list_available_methods` 固定返回 `("programmatic",)`）——这是**最低限度**的评估：只用 L1 的 `success_criteria_met` 做二值判定。
- **两种失败返回**：
  - `evaluator=None` → `failure_reason="no evaluator configured"`（配置问题）
  - 任务全失败 → `failure_reason="all_tasks_failed"`（数据问题）
- **单任务异常跳过**：`try / except: continue`——**不因单个任务失败中断整体评估**。这是容错设计。
- **Wilson CI 而非简单比例**：用 `_wilson_ci` 算置信区间，而非直接用平均分。**小样本时更保守**（避免"3 次里 2 次成功 = 66%"这类不靠谱结论）。
- **复用 L2 的 `EvalResult` / `Evaluator` / `_wilson_ci`**：**不重复定义**——L2 和 L3 对"评估结果"的理解必须一致。
- **和 `OrchestrationBridge` 的对照**：

| 维度 | MultiagentProgrammaticFacade | OrchestrationBridge |
|---|---|---|
| 启用条件 | L3 未启用（默认） | L3 启用 |
| 方法数 | 1（programmatic） | 3（programmatic + llm_judge + longitudinal_pairs） |
| 实现方式 | 直接调 evaluator callable | 通过 SpecialistEvalRegistry 取 adapter |
| 依赖 | L1 ResultSummarizer | L3 的 3 个 adapter |
| 接口 | EvalBridge Protocol | EvalBridge Protocol（同一个） |

**关键：两者实现同一契约，L2 调用方式不变——这是"渐进迁移"的设计。**
