## 0. 结构树

### 0.1. 静态结构树

```
local/ — Sandbox 本地实现目录（本地无隔离场景的 provider）
│
└─ local_sandbox_provider.py — LocalSandboxProvider（LRU 缓存 + 确定性 ID）
    │
    ├─ _DEFAULT_LRU_SIZE = 256               ← LRU 缓存默认容量
    │
    ├─ _deterministic_sandbox_id(user_id, thread_id) -> str
    │   ← 确定性 sandbox_id = sha256(user:thread)[:8]
    │
    └─ LocalSandboxProvider(SandboxProvider)
        ├─ 类属性
        │   ├─ uses_thread_data_mounts = True
        │   └─ needs_upload_permission_adjustment = False
        │
        ├─ __init__(path_mappings=None, lru_size=256, sandbox_config=None)
        │   ├─ _path_mappings: list[PathMapping]
        │   ├─ _lru_size: int
        │   ├─ _sandboxes: OrderedDict[str, Sandbox]   ← LRU 缓存
        │   ├─ _lock: threading.Lock
        │   └─ _allow_host_bash: bool
        │
        ├─ acquire(thread_id=None, *, user_id=None) -> str
        │   ← 取或建 sandbox；命中刷新 LRU，未命中构造 + 驱逐
        │
        ├─ get(sandbox_id) -> Sandbox | None
        │   ← 纯内存查找
        │
        ├─ release(sandbox_id) -> None
        │   ← no-op（保留缓存）
        │
        ├─ reset() -> None
        │   ← 清空缓存（不 close）
        │
        └─ shutdown() -> None
            ← 清空缓存 + 锁外逐个 close
```

### 0.3. 运行时调用树

```
① 装配期
LocalSandboxProvider(path_mappings, lru_size, sandbox_config)
    └─ 初始化空 LRU 缓存 + 锁 + allow_host_bash

        ═══════════ 进入 Agent 循环 ═══════════

② 取或建 sandbox —— acquire(thread_id, user_id)
SandboxMiddleware.wrap_tool_call
    └─ provider.acquire(thread_id, user_id=...)
          ├─ thread_id is None → raise ValueError（Grill #6）
          ├─ sandbox_id = sha256("{user}:{thread}")[:8]
          └─ with _lock:
                ├─ [命中缓存]
                │     ├─ move_to_end(sandbox_id)    ← 刷新 LRU
                │     └─ return sandbox_id
                └─ [未命中]
                      ├─ LocalRuntime(allow_host_bash=...)
                      ├─ LocalPathTranslator(_path_mappings)
                      ├─ AuditGuard(LocalSecurityGuard(_path_mappings))
                      ├─ Sandbox(sandbox_id, runtime, translator, guard)
                      ├─ _sandboxes[sandbox_id] = sandbox
                      └─ 超容量 → popitem(last=False) 取出 evicted
            （锁外）evicted.close()

③ 一次 bash 调用
tools.py bash_tool(cmd)
    └─ _ensure_sandbox(provider)
          ├─ get_sandbox_id()                       ← ContextVar
          └─ provider.get(sandbox_id)               ← 纯内存查找
                └─ Sandbox.execute_command(cmd)
                      ├─ ① guard.validate_command(cmd)
                      │     └─ AuditGuard → LocalSecurityGuard
                      ├─ ② guard.validate_path(path)
                      │     └─ AuditGuard 透传 → LocalSecurityGuard
                      ├─ ③ translator.translate_command(cmd)
                      │     └─ LocalPathTranslator：虚拟 → 物理
                      ├─ ④ runtime.exec_command(cmd)
                      │     └─ LocalRuntime：subprocess.run(shell=True)
                      └─ ⑤ translator.mask_output(output)
                            └─ LocalPathTranslator：物理 → 虚拟（脱敏）

④ 进程退出兜底
integration/bootstrap_sandbox.py
    _shutdown_all_providers()（atexit）
        └─ provider.shutdown()
              ├─ with _lock: 取出全部 sandbox + 清空缓存
              └─ 锁外逐个 sandbox.close()
                    └─ runtime.close() → no-op
```

## 1. Local 总览

`local/` 是 sandbox 层的**本地实现目录**——提供本地（无容器隔离）场景下的 provider 实现。它本身只放一个文件（`local_sandbox_provider.py`），但它组合了本地版的 runtime / translator / guard 三件套，是"本地沙箱"的装配点。

---

## 2. 本地沙箱的组成

本地沙箱 = `LocalSandboxProvider` 组合以下四个组件：

| 组件 | 实现 | 文件 |
|---|---|---|
| **Provider** | `LocalSandboxProvider` | `local/local_sandbox_provider.py` |
| **Runtime** | `LocalRuntime` | `runtimes/local_runtime.py` |
| **Translator** | `LocalPathTranslator` | `translators/local_path_translator.py` |
| **Guard** | `AuditGuard(LocalSecurityGuard)` | `guards/audit_guard.py` + `guards/local_security_guard.py` |

组合发生在 `LocalSandboxProvider.acquire()` 里：

```
runtime    = LocalRuntime(allow_host_bash=...)
translator = LocalPathTranslator(path_mappings)
guard      = AuditGuard(LocalSecurityGuard(path_mappings))
sandbox    = Sandbox(sandbox_id, runtime, translator, guard)
```

---

## 3. LocalSandboxProvider — 本地 provider

**职责：按 `thread_id` 创建 / 复用本地沙箱实例，用 LRU 缓存控制常驻数量。**

- **确定性 ID**：`sha256(user:thread)[:8]`——同一 `(user, thread)` 跨进程可推导。
- **`thread_id` 必传**：`None` 抛 `ValueError`（Grill #6，已去 legacy 单例）。
- **LRU 缓存**：默认 256 条，命中 `move_to_end` 刷新，超容量 `popitem(last=False)` 驱逐。
- **锁外 close**：驱逐在锁内 `pop`，`close()` 在锁外调——避免持锁阻塞 I/O。
- **`release` 是 no-op**：保留缓存，下次 `acquire` 复用。
- **`_lock` 是 `threading.Lock`**：说明 provider 设计为多线程共享，非 asyncio 专用。

---

## 4. LocalRuntime — 本地裸执行引擎

**职责：用 `subprocess` 跑命令、用 `pathlib`/`os` 操作文件。只做裸执行，不知路径翻译、不做安全校验。**

- **命令执行**：`subprocess.run(shell=True)` + 600 秒超时；超时 / 非零退出 → `SandboxCommandError`。
- **文件操作**：读写 / 列目录 / glob / grep / 二进制下载上传。
- **异常统一包装**：`FileNotFoundError` → `SandboxFileNotFoundError`，`PermissionError` → `SandboxPermissionError`（Grill #5）。
- **三处安全加固**：
  - **S2**：`allow_host_bash=False` 时拒绝 `exec_command`。
  - **S9**：`list_dir` 用 BFS 剪枝，防大目录 DoS。
  - **S10**：`grep` 非 literal 模式过 ReDoS 校验。
- **`close` 是 no-op**：`subprocess` 无持久连接，无需清理。

---

## 5. LocalPathTranslator — 本地双向路径翻译

**职责：基于 `PathMapping` 在虚拟 ↔ 物理路径之间双向翻译。**

- **正向**：`translate_path` / `translate_command` —— 虚拟 → 物理。
- **反向**：`mask_output` —— 物理 → 虚拟（脱敏，防泄漏宿主目录结构）。
- **规则**：最长前缀优先（防 `/mnt/poirot/skills` 误匹配 `/mnt/poirot/skills-extra`）。
- **防穿越**：`resolve()` 跟随 symlink 后做越界检测。
- **缓存**：四个 `cached_property` 缓存排序 / `resolve` / 正则编译。

---

## 6. 本地 Guard 组合 — AuditGuard(LocalSecurityGuard)

**职责：外层 `AuditGuard` 做三档分级 + 审计，底层 `LocalSecurityGuard` 做严格校验。**

- **`AuditGuard`**：三档分级（`block` / `warn` / `pass`）+ 审计日志。
- **`LocalSecurityGuard`**：本地严格规则——白名单 + 黑名单 + 路径穿越拒绝 + shlex fail-closed。
- **为什么本地 Guard 复杂**：本地无容器隔离，**Guard 是唯一防线**，必须独自承担全部安全责任。

---

## 7. 本地沙箱的调用流程（一次 `bash` 调用）

```
① 工具层 tools.py
bash_tool(command)
    └─ _ensure_sandbox(provider)
          ├─ get_sandbox_id()          ← ContextVar
          └─ provider.get(sandbox_id)  ← LocalSandboxProvider.get（纯内存查找）

② Sandbox 门面 sandbox.py
sandbox.execute_command(cmd)
    ├─ ① guard.validate_command(cmd)         ← AuditGuard → LocalSecurityGuard
    ├─ ② guard.validate_path(path)           ← AuditGuard 透传 LocalSecurityGuard
    ├─ ③ translator.translate_command(cmd)   ← LocalPathTranslator：虚拟 → 物理
    ├─ ④ runtime.exec_command(cmd)           ← LocalRuntime：subprocess.run
    └─ ⑤ translator.mask_output(output)      ← LocalPathTranslator：物理 → 虚拟（脱敏）
```

**本地链路关键点**：
- **没有 Docker 的"专属分层"**——没有 cross_process_lock、readiness、executor。
- **正向翻译是必须的**——虚拟路径 ≠ 宿主物理路径，靠 `PathMapping` 翻。
- **反向脱敏是必须的**——输出里的宿主路径必须换回虚拟路径。

---

## 8. 本地 vs Docker 的核心差异

| 维度 | 本地 | Docker |
|---|---|---|
| 隔离级别 | **软约束**（靠 guard 拦） | **硬隔离**（namespace + cgroup） |
| 安全边界 | Guard（软件层） | 容器（内核层） |
| Guard 角色 | 唯一防线 → 复杂 | 补漏层 → 简单 |
| 路径翻译 | 双向都复杂（PathMapping） | 正向直传、反向一处 |
| 命令执行 | `subprocess.run` 直接在宿主 | `docker exec` 进容器 |
| 锁 | `file_operation_lock`（进程内） | `cross_process_lock`（跨进程） |
| 生命周期 | runtime 几乎 no-op | runtime 管容器启停 |
| 容器专属分层 | 无 | cross_process_lock / readiness / executor |

---

## 9. 总结

**`local/` 是本地沙箱的 provider 实现——它组合 `LocalRuntime`（裸执行）+ `LocalPathTranslator`（双向翻译）+ `AuditGuard(LocalSecurityGuard)`（唯一安全防线），用 LRU + 确定性 ID 管理沙箱实例。本地无容器隔离，所以三件套都比 Docker 版复杂：guard 是唯一防线、translator 要双向翻译、runtime 直接在宿主执行。**
