---

name: LocalRuntime — 本地运行时（subprocess 裸执行 + Python 标准库文件操作）。

description: 

【整体职责】
实现 sandbox_runtime 契约的"本地版本"：用 subprocess 执行命令，用 pathlib / os
做文件读写、列目录、glob、grep 等操作。只负责"裸执行"——不知道路径翻译、
不做安全检查；这些由 translator / guard 在 Sandbox 门面层完成。
所有异常统一包装成 SandboxError 子类（Grill #5），不向调用方泄漏内置异常。

【内容摘要】
- 模块常量：
    _EXEC_TIMEOUT_SECONDS      : 命令执行超时（600 秒）。
    _MAX_REGEX_PATTERN_LENGTH  : grep 正则最大长度（200 字符，S10 ReDoS 防护）。
    _NESTED_QUANTIFIER_RE      : 嵌套量词检测正则（如 (a+)+，ReDoS 经典模式）。
- 模块函数：
    _validate_regex_pattern    : ReDoS 防护；拒绝超长 pattern + 嵌套量词。
    _is_path_ignored           : 路径任一段命中 IGNORE_PATTERNS 即忽略。
- LocalRuntime                 : 本地运行时类。
    ├─ __init__      : 持有 allow_host_bash 开关。
    ├─ exec_command  : subprocess 执行命令（shell=True + 超时 + 异常包装）。
    ├─ read_file     : 读文本文件。
    ├─ write_file    : 写 / 追加文本文件（自动建父目录）。
    ├─ list_dir      : BFS 剪枝列目录（S9，防大目录 DoS）。
    ├─ _scan_bfs     : BFS 递归扫描（list_dir 内部用）。
    ├─ glob          : 按 pattern 递归匹配（带 max_results 截断）。
    ├─ grep          : 正则搜索文件内容（带 ReDoS 防护 + 忽略过滤 + 大小限制）。
    ├─ download_file : 读二进制文件（供 artifact 下载）。
    ├─ update_file   : 写二进制文件（自动建父目录）。
    └─ close         : no-op（subprocess 无持久连接）。

【职责边界】
- 只负责：命令的裸执行 + 本地文件系统操作。
- 不负责：路径翻译（translator）、安全检查（guard）、沙箱创建 / 销毁
  （provider）、写入大小限制（Grill #7：Stage 3 工具层加，不在本层）。
- 持有状态：仅 allow_host_bash 开关，无持久连接 / 无缓存。

## 0. 结构树

### 0.1. 静态结构树

```
local_runtime.py — LocalRuntime（subprocess 裸执行 + Python 标准库文件操作）
│
├─ _EXEC_TIMEOUT_SECONDS = 600                 ← 命令执行超时（秒）
│
├─ _MAX_REGEX_PATTERN_LENGTH = 200             ← grep 正则最大长度（S10 ReDoS 防护）
├─ _NESTED_QUANTIFIER_RE: Pattern              ← 嵌套量词检测正则（(a+)+ 类）
│
├─ _validate_regex_pattern(pattern)            ← ReDoS 防护
│   ├─ len > 200      → raise ValueError
│   └─ 命中嵌套量词   → raise ValueError
│
├─ _is_path_ignored(file_path, root) -> bool   ← 路径忽略判定
│   ├─ file_path 不在 root 下 → False
│   └─ 任一段命中 IGNORE_PATTERNS → True
│
└─ LocalRuntime
    ├─ _allow_host_bash: bool                 ← host bash 开关
    ├─ __init__(allow_host_bash=True)
    │
    ├─ exec_command(command) -> str           ← subprocess 执行命令
    │   ├─ allow_host_bash=False → raise SandboxRuntimeError（S2）
    │   ├─ subprocess.run(shell=True, timeout=600)
    │   ├─ TimeoutExpired        → raise SandboxCommandError
    │   └─ returncode != 0       → raise SandboxCommandError
    │
    ├─ read_file(path) -> str                 ← 读文本文件
    │   ├─ FileNotFoundError → SandboxFileNotFoundError
    │   └─ PermissionError   → SandboxPermissionError
    │
    ├─ write_file(path, content, append=False) ← 写/追加文本，自动建父目录
    │   └─ PermissionError → SandboxPermissionError
    │
    ├─ list_dir(path, max_depth=2, max_entries=1000) -> list[str]
    │   ← BFS 剪枝列目录（S9）
    │   ├─ root 不存在 → SandboxFileNotFoundError
    │   └─ _scan_bfs(...) → sorted(entries)
    │
    ├─ _scan_bfs(root, current, depth, max_depth, max_entries, entries)
    │   ← BFS 递归扫描（list_dir 内部用）
    │   ├─ depth > max_depth 或 len(entries) >= max_entries → return
    │   ├─ os.scandir(current)，按 name 排序
    │   ├─ 每个 entry 加入 entries
    │   └─ entry.is_dir() 且 depth < max_depth → 递归下一层
    │         （PermissionError / OSError 静默跳过）
    │
    ├─ glob(path, pattern, *, include_dirs=False, max_results=200)
    │   -> (list[str], bool)                  ← 递归匹配，返回 (matches, truncated)
    │   ├─ rglob(pattern)，跳过目录（除非 include_dirs）
    │   ├─ len >= max_results → return (matches, True)
    │   └─ PermissionError → SandboxPermissionError
    │
    ├─ grep(path, pattern, *, glob=None, literal=False,
    │        case_sensitive=False, max_results=100)
    │   -> (list[GrepMatch], bool)             ← 正则搜索文件内容
    │   ├─ literal=True  → re.escape（跳过 ReDoS 校验）
    │   ├─ literal=False → _validate_regex_pattern（S10）
    │   ├─ rglob 遍历：
    │   │     ├─ 跳过目录
    │   │     ├─ _is_path_ignored → 跳过
    │   │     ├─ st_size > DEFAULT_MAX_FILE_SIZE_BYTES → 跳过
    │   │     └─ 逐行 regex.search → GrepMatch（截断到 200）
    │   └─ PermissionError → SandboxPermissionError
    │
    ├─ download_file(path) -> bytes            ← 读二进制（artifact 下载）
    │   └─ FileNotFoundError → SandboxFileNotFoundError
    │
    ├─ update_file(path, content: bytes)       ← 写二进制，自动建父目录
    │   └─ PermissionError → SandboxPermissionError
    │
    └─ close() -> None                         ← no-op（subprocess 无持久连接）
```

### 0.2. 运行时调用树

```
① 装配期
LocalRuntime(allow_host_bash=...)
    └─ 持有 allow_host_bash 开关

        ═══════════ 进入命令执行 ═══════════

② Sandbox.execute_command(cmd)
    └─ runtime.exec_command(cmd)
          ├─ allow_host_bash=False → raise SandboxRuntimeError
          ├─ subprocess.run(cmd, shell=True, timeout=600)
          ├─ TimeoutExpired        → raise SandboxCommandError
          └─ returncode != 0       → raise SandboxCommandError
    → 返回 stdout 给 Sandbox 门面

③ Sandbox.read_file / write_file / list_dir / glob / grep
    └─ runtime.<method>(...)
          ├─ 文件操作异常统一包装为 SandboxFileNotFoundError /
          │  SandboxPermissionError / SandboxCommandError
          └─ grep：
                ├─ literal=False → _validate_regex_pattern(pattern)（S10）
                ├─ 遍历文件 → _is_path_ignored 过滤
                └─ 逐行匹配 → GrepMatch（截断）

④ 进程退出 / 销毁
provider.shutdown()
    └─ sandbox.close()
          └─ runtime.close()
                └─ no-op（subprocess 无持久连接）

（本模块不介入路径翻译、安全校验、沙箱创建/销毁）
```

## 1. 补充

**`local_runtime.py` 是本地沙箱的"裸执行引擎"——它只做两件事：用 `subprocess` 跑命令、用 `pathlib`/`os` 操作文件。它不知道路径翻译、不做安全检查，所有异常统一包装成 `SandboxError` 子类。**

几点补充：

- **"裸执行"是它的核心定位**：`exec_command` 拿到的命令是**已翻译过的物理路径**，直接 `subprocess.run(shell=True)`；文件操作直接 `Path(path).read_text()`。路径转换在 translator，安全校验在 guard——**runtime 不参与**。

- **异常包装是统一的对外契约（Grill #5）**：
  - `subprocess.TimeoutExpired` → `SandboxCommandError`
  - 非零退出 → `SandboxCommandError`
  - `FileNotFoundError` → `SandboxFileNotFoundError`
  - `PermissionError` → `SandboxPermissionError`
  - `allow_host_bash=False` → `SandboxRuntimeError`
  **调用方只需 catch `SandboxError` 即可**，不用关心底层是什么异常。

- **三处安全加固（S2 / S9 / S10）**：
  - **S2**：`allow_host_bash=False` 时 `exec_command` 直接拒绝——不给 LLM 执行任意命令的能力。
  - **S9**：`list_dir` 用 BFS 剪枝替代 `rglob("*")` 先全遍历再过滤——避免 `node_modules` 十万文件 DoS。
  - **S10**：`grep` 非 literal 模式必须过 `_validate_regex_pattern`——拒绝超长 pattern + 嵌套量词（`(a+)+` 类灾难回溯）。

- **`grep` 的 literal 分支跳过 ReDoS 校验**：`literal=True` 时走 `re.escape`，pattern 是字面量、不可能触发灾难回溯——**跳过校验是合理的**，不是漏洞。

- **`grep` 的三重过滤**：路径忽略（`_is_path_ignored`）+ 文件大小限制（`DEFAULT_MAX_FILE_SIZE_BYTES`）+ 结果数量上限（`max_results`）——保证大仓库搜索不失控。

- **`glob` / `grep` 返回 `(matches, truncated)`**：第二个布尔表示"是否被 `max_results` 截断"——调用方据此提示用户"结果不完整"。

- **`close` 是 no-op**：`subprocess` 无持久连接，无需清理。这和 `DockerRuntime` 的 `close`（停容器）形成对比——**本地无生命周期，容器有**。

- **无 `write_file` 80KB 限制（Grill #7）**：本层是裸执行，不关心 LLM chunk 大小；该限制在 Stage 3 工具层加（`integration/tools.py` 的 `WRITE_FILE_MAX_BYTES`）。
