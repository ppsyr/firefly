---

name: LocalSecurityGuard — 本地严格守卫（白名单 + 路径穿越拒绝 + 命令扫描）。

description: 

【整体职责】
实现 security_guard 契约的"本地严格"版本：对路径做白名单前缀校验、拒绝路径穿越，
对命令做危险模式黑名单 + 绝对路径白名单扫描。用于本地沙箱场景——
本地无容器隔离，安全完全依赖本 guard 的校验，故规则从严。
Docker / E2B 场景改用 PermissiveGuard（容器已隔离）。

【内容摘要】
- _SYSTEM_PATH_PREFIXES : 命令中允许出现的系统路径前缀白名单（/bin/ /usr/ /lib/）。
- _DANGEROUS_PATTERNS   : 危险命令黑名单（(regex, description)），S4 defense-in-depth。
- LocalSecurityGuard    : 本地严格守卫类。
    ├─ __init__                 : 持有 PathMapping 列表（白名单映射表）。
    ├─ _reject_path_traversal   : 拒绝含 ".." 段的路径（路径穿越）。
    ├─ _find_mapping            : 按最长前缀匹配查找 PathMapping。
    ├─ validate_path            : 路径校验（穿越 + 白名单 + 只读）。
    └─ validate_command         : 命令校验（危险模式 + shlex + 绝对路径白名单）。

【职责边界】
- 只负责：路径白名单校验、路径穿越拒绝、命令危险模式扫描、命令绝对路径白名单。
- 不负责：路径转换（translator）、命令执行（backend）、输出脱敏
  （本 guard 只做 validate，不做 mask_output）。
- 持有 PathMapping 列表：白名单规则的来源，由装配层注入。

## 0. 结构树

### 0.1. 静态结构树

```
local_security_guard.py — LocalSecurityGuard（本地严格守卫：白名单 + 路径穿越拒绝 + 命令扫描）
│
├─ _SYSTEM_PATH_PREFIXES: tuple[str, ...]      ← 系统路径白名单；作用：命令中出现的绝对路径
│   ├─ "/bin/"                                    若命中这些前缀则直接放行
│   ├─ "/usr/"
│   └─ "/lib/"
│
├─ _DANGEROUS_PATTERNS: list[(Pattern, str)]   ← 危险命令黑名单（S4 defense-in-depth）
│   │                                            每项 (regex, description)
│   ├─ [破坏性命令]
│   │   ├─ rm -rf /          ← rm -rf /（排除 /word）
│   │   ├─ rm -rf ~          ← rm -rf ~
│   │   ├─ rm -rf $HOME      ← rm -rf $HOME
│   │   ├─ rm -rf /*         ← rm -rf /*
│   │   ├─ mkfs filesystem format ← mkfs.xxx
│   │   ├─ dd to device      ← dd ... of=/dev/
│   │   └─ fork bomb         ← :(){:|:&};: 类
│   ├─ [远程代码执行]
│   │   ├─ curl pipe to shell ← curl ... | bash/sh
│   │   └─ wget pipe to shell ← wget ... | bash/sh
│   └─ [危险内置命令]
│       ├─ eval builtin      ← eval
│       ├─ exec builtin      ← exec（排除 exec *.py）
│       └─ source builtin    ← source
│
└─ LocalSecurityGuard                         ← 本地严格守卫类
    ├─ _mappings: list[PathMapping]           ← 白名单映射表（由装配层注入）
    │
    ├─ __init__(path_mappings)                ← 初始化；持有 PathMapping 列表
    │
    ├─ _reject_path_traversal(path)           ← 路径穿越检查；作用：含 ".." 段则拒绝
    │   └─ raise SandboxPermissionError
    │
    ├─ _find_mapping(path) -> PathMapping|None ← 白名单查找；作用：按最长前缀优先
    │   └─ 对 _mappings 按 container_path 长度降序，匹配 path == container
    │      或 path.startswith(container + "/")
    │
    ├─ validate_path(path, *, write=False)    ← 路径校验；作用：穿越 → 白名单 → 只读
    │   ├─ _reject_path_traversal(path)
    │   ├─ _find_mapping(path) 为 None → raise SandboxPermissionError（不在白名单）
    │   └─ write=True 且 mapping.read_only → raise SandboxPermissionError（只读）
    │
    └─ validate_command(command)              ← 命令校验；作用：黑名单 → shlex → 绝对路径
        ├─ 扫 _DANGEROUS_PATTERNS：
        │     命中 → raise SandboxPermissionError（危险命令）
        ├─ shlex.split(command)：
        │     ValueError → raise SandboxPermissionError（fail-closed，畸形引号）
        └─ 遍历 tokens，以 "/" 开头者：
              ├─ 命中 _SYSTEM_PATH_PREFIXES → 放行
              ├─ _find_mapping(token) 命中 → 放行
              └─ 否则 → raise SandboxPermissionError（不在白名单）
```

### 0.2. 运行时调用树

```
① 装配期
LocalSecurityGuard(path_mappings)
    └─ 注入 PathMapping 列表（白名单来源，由装配层提供）
    → 产出 guard 实例（本地模式下可能再被 AuditGuard 包装）

        ═══════════ 进入命令执行 ═══════════

② 路径校验 —— validate_path(path, write)
sandbox.execute_command(cmd) 内部 / 或上游 guard 透传
    └─ guard.validate_path(path, write=...)
          ├─ _reject_path_traversal(path)
          │     ├─ PurePosixPath(path).parts 含 ".." → raise SandboxPermissionError
          │     └─ 通过
          ├─ _find_mapping(path)
          │     ├─ 按 container_path 长度降序匹配
          │     ├─ 命中 → 返回 mapping
          │     └─ 未命中 → raise SandboxPermissionError（path not in whitelist）
          └─ write and mapping.read_only
                └─ raise SandboxPermissionError（write to read-only path）

③ 命令校验 —— validate_command(command)
sandbox.execute_command(cmd) 前
    └─ guard.validate_command(command)
          ├─ 危险模式黑名单（先于 shlex，整条命令 pattern match）
          │     └─ 命中 → raise SandboxPermissionError（dangerous command blocked）
          ├─ shlex.split(command)
          │     └─ ValueError → raise SandboxPermissionError
          │                     （unparseable quoting，fail-closed）
          └─ 遍历 tokens：
                ├─ token.startswith("/") 为 False → 继续下一个
                ├─ 命中 _SYSTEM_PATH_PREFIXES → continue（放行）
                ├─ _find_mapping(token) 命中 → continue（放行）
                └─ 否则 → raise SandboxPermissionError
                          （command references path not in whitelist）

（本模块不介入路径转换、命令执行、输出脱敏）
```
