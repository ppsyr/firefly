---

name: Sandbox 搜索工具 — 忽略路径判定 + 行截断（供 grep / 搜索类工具复用）。

description: 

【整体职责】
为搜索类工具（grep 等）提供两个公共能力：
① 判断路径是否应被忽略（版本控制目录、依赖目录、缓存、编辑器临时文件等）；
② 把命中行截断到固定长度，避免超长行撑爆输出。
两者都是纯函数，无状态，供工具层直接调用。

【内容摘要】
- IGNORE_PATTERNS           : 忽略模式列表（目录名 / 文件名 glob 模式）。
- DEFAULT_MAX_FILE_SIZE_BYTES : 默认单文件大小上限（1_000_000 字节）。
- DEFAULT_LINE_SUMMARY_LENGTH: 默认单行截断长度（200 字符）。
- should_ignore_path        : 判断路径是否命中忽略模式（逐段匹配）。
- truncate_line             : 截断单行到指定长度，超出加 "..." 后缀。

【职责边界】
- 只负责：忽略判定（纯字符串匹配）、行截断（纯字符串处理）。
- 不负责：实际文件遍历 / 搜索（由调用方负责）、文件大小校验
  （DEFAULT_MAX_FILE_SIZE_BYTES 只是常量声明，判定由调用方使用）。
- 无状态：两个函数都是纯函数，不持有任何字段。

## 0. 结构树

### 0.1. 静态结构树

```
search.py — Sandbox 搜索工具（忽略路径判定 + 行截断）
│
├─ IGNORE_PATTERNS: list[str]                  ← 忽略模式列表（目录名 / 文件名 glob）
│   ├─ 版本控制：.git .svn .hg .bzr
│   ├─ 依赖：node_modules site-packages
│   ├─ Python 缓存：__pycache__ .venv venv .tox .nox .eggs *.egg-info
│   ├─ 构建产物：dist build .next .nuxt .output .turbo target out
│   ├─ 编辑器：.idea .vscode *.swp *.swo *~
│   ├─ 系统文件：.DS_Store Thumbs.db desktop.ini *.lnk
│   ├─ 临时文件：*.log *.tmp *.temp *.bak *.cache
│   └─ 工具缓存：.coverage coverage .nyc_output htmlcov
│                .pytest_cache .mypy_cache .ruff_cache
│
├─ DEFAULT_MAX_FILE_SIZE_BYTES = 1_000_000     ← 默认单文件大小上限（字节）
├─ DEFAULT_LINE_SUMMARY_LENGTH = 200           ← 默认单行截断长度（字符）
│
├─ should_ignore_path(path) -> bool            ← 忽略判定
│   └─ 统一分隔符（\\ → /）→ 按 "/" 分段 → 逐段 fnmatch
│         └─ 任一段命中 → True；否则 False
│
└─ truncate_line(line, max_chars=200) -> str   ← 行截断
    ├─ rstrip("\n\r") 去行尾换行
    ├─ len ≤ max_chars → 原样返回
    └─ 否则 → line[:max_chars - 3] + "..."
```

### 0.2. 运行时调用树

```
① 调用方（搜索类工具，如 grep）
grep 工具遍历文件
    ├─ should_ignore_path(path)
    │     └─ 命中 → 跳过该路径
    └─ 命中行 → truncate_line(line)
          └─ 超长行截断后返回

（本模块为纯函数，无装配、无生命周期、无状态）
```
