## 1. Utils 总览

`utils/` 是 sandbox 层的**公共工具集**——提供不依赖具体隔离实现（local / docker）的通用能力，供工具层（`integration/tools.py`）、translator、provider 等复用。三个文件各自独立，没有相互依赖。

---

## 2. 三个工具

### 2.1 `file_operation_lock.py` — 文件操作锁

**按 `(sandbox_id, virtual_path)` 分配进程内互斥锁，让同一沙箱同一文件的"读—改—写"复合操作串行化。**

- **锁的维度**：`(sandbox_id, virtual_path)` 二维——不同沙箱、不同文件互不阻塞。
- **key 用虚拟路径**：工具层拿到的是虚拟路径（Agent 视角）。
- **WeakValueDictionary**：锁无引用时自动 GC，防长跑进程内存泄漏。
- **元锁**：`_FILE_OPERATION_LOCKS_GUARD` 只保护字典读写（get-or-create 原子），不保护文件操作本身。
- **已知限制（S11）**：锁**只进程内，不跨进程**。Docker 模式下 `read_file` + `write_file` 是两次独立 HTTP 调用，存在 TOCTOU 风险；当前单进程可接受，多 worker 需引入容器内 `flock`。
- **唯一已知调用方**：`integration/tools.py` 的 `str_replace_tool`。

### 2.2 `sandbox_id.py` — sandbox_id 格式校验

**校验 sandbox_id 是否符合约定格式（8 位小写十六进制，来自 sha256[:8]），防不可信值引发路径穿越。**

- **威胁模型**：正常来源安全，但反序列化（`SandboxInfo.from_dict` 从文件恢复）可能引入不可信值——若直接用于 `Path(root) / sandbox_id` 且含 `../`，会造成路径穿越。
- **校验规则**：恰好 8 位，`[a-f0-9]`；非 `str` 也判非法。
- **失败策略**：抛 `ValueError`，不静默修复、不截断、不转大小写。
- **定位**：S6 defense-in-depth——即使上游信任链被破坏，也能在路径拼接前挡住。

### 2.3 `search.py` — 搜索工具

**为搜索类工具（grep 等）提供忽略判定 + 行截断两个纯函数。**

- **`IGNORE_PATTERNS`**：模块级常量，覆盖版本控制 / 依赖 / 缓存 / 构建产物 / 编辑器临时文件 / 系统文件等。
- **`should_ignore_path(path)`**：先统一分隔符（`\\` → `/`），再按 `/` 分段，逐段 `fnmatch`——**任一段命中即忽略**。
- **`truncate_line(line, max_chars=200)`**：先去行尾换行，超长则 `line[:max_chars - 3] + "..."`（总长恰好 `max_chars`）。
- **两个常量**：`DEFAULT_MAX_FILE_SIZE_BYTES`（1 MB）、`DEFAULT_LINE_SUMMARY_LENGTH`（200）——前者在本文件里只是声明，判定由调用方使用。

## 3. 三个工具对照表

| 工具 | 类型 | 状态 | 主要用途 | 关键约束 |
|---|---|---|---|---|
| `file_operation_lock` | 有状态（锁字典） | 进程内单例 | 文件操作串行化 | 不跨进程（S11 限制） |
| `sandbox_id` | 纯函数 | 无 | sandbox_id 格式校验 | 只接受 8 位小写十六进制 |
| `search` | 纯函数 | 无 | 忽略判定 + 行截断 | 按段匹配、硬编码模式 |

---

## 4. 三个工具的共性与差异

### 共性

- **不依赖具体隔离实现**：三个工具在 local / docker 下**行为一致**——它们处理的是"字符串 / 锁 / 格式"，不碰"路径翻译""容器执行"。
- **职责单一**：每个文件只做一件事，没有交叉依赖。

### 差异

| 维度 | `file_operation_lock` | `sandbox_id` | `search` |
|---|---|---|---|
| 是否有状态 | 有（锁字典 + 元锁） | 无 | 无 |
| 是否跨进程 | ❌ 仅进程内 | — | — |
| 是否有已知限制 | ✅（S11） | — | — |
| 调用方 | `tools.py`（`str_replace`） | provider / `from_dict` 路径 | 搜索类工具（grep） |

---

## 5. 总结

**`utils/` 是 sandbox 的公共工具箱：`file_operation_lock` 管并发串行化（进程内、有状态）、`sandbox_id` 管输入安全（防路径穿越）、`search` 管搜索辅助（忽略判定 + 行截断）。三者不依赖隔离实现，是 local / docker 共用的基础设施。**
