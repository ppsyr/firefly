---

name: Sandbox 类型定义 — 跨实现统一的数据结构。

description: 

【整体职责】
定义 sandbox 层在各实现（Local / Docker / K8s）之间共享的数据类型，
供 provider / backend / guard / translator / middleware 等模块引用，
避免各实现各自定义、导致跨实现不兼容。

【内容摘要】
- PathMapping            : 虚拟路径 → 宿主路径的映射（LocalSandbox 专属）。
- ResolvedPath           : 路径解析结果（路径 + 命中的映射），NamedTuple。
- GrepMatch              : grep 工具的单条匹配结果，跨实现统一。
- SandboxInfo            : 跨进程可恢复的沙箱元数据，含序列化/反序列化。

【职责边界】
- 只负责：定义数据结构、字段语义、序列化/反序列化。
- 不负责：沙箱创建/销毁（provider）、命令执行（backend）、路径转换逻辑（translator）、安全校验（guard）。
- 不持有状态：纯数据定义，无副作用（SandboxInfo.created_at 默认值除外）。

## 0. 结构树

### 0.1. 静态结构树

```
types.py — Sandbox 类型定义（跨实现统一的数据结构）
│
├─ PathMapping                                ← 虚拟路径→宿主路径映射；LocalSandbox 专属
│   │                                            作用：记录一条「虚拟路径 ↔ 宿主路径」的绑定关系
│   │                                            以及是否只读；供路径解析时按最长前缀匹配
│   ├─ container_path: str                    ← 虚拟侧路径（Agent 视角）
│   ├─ local_path: str                        ← 宿主侧真实路径
│   └─ read_only: bool = False                ← 该映射是否只读
│
├─ ResolvedPath(NamedTuple)                   ← 路径解析返回值；作用：把「解析出的路径」和
│   │                                            「命中的哪条映射」一起返回，避免调用方二次查找
│   ├─ path: str                              ← 解析后的路径
│   └─ mapping: PathMapping | None            ← 命中的映射；未命中为 None
│
├─ GrepMatch                                  ← grep 单条匹配结果；作用：统一各实现的返回结构
│   ├─ path: str                              ← 命中文件路径
│   ├─ line_number: int                       ← 命中行号
│   └─ line: str                              ← 命中行内容
│
└─ SandboxInfo                                ← 跨进程可恢复的沙箱元数据
    │                                            作用：把沙箱的身份 + 访问入口 + 归属容器
    │                                            序列化成可持久化的结构，供跨进程恢复
    ├─ sandbox_id: str                        ← 沙箱唯一标识
    ├─ sandbox_url: str                       ← 沙箱访问入口
    ├─ container_name: str | None = None      ← 容器名；仅 LocalContainerBackend 有
    ├─ container_id: str | None = None        ← 容器 ID；仅 LocalContainerBackend 有
    ├─ created_at: str = utc_now_iso()        ← 创建时间；与 journal 格式一致
    │
    ├─ to_dict() -> dict                      ← 序列化；作用：给持久化/日志提供纯 dict 形式
    │   └─ 返回 5 字段的 dict
    │
    └─ from_dict(data) -> SandboxInfo         ← 反序列化；作用：从持久化数据恢复 SandboxInfo
        │                                        （classmethod，跨进程恢复的唯一入口）
        ├─ sandbox_url = data["sandbox_url"] or data["base_url"]   ← 兼容旧字段名
        ├─ created_at 缺省 → utc_now_iso()
        └─ 返回 cls(...)
```

### 0.2. 运行时调用树

```
① 装配期
（本模块不介入；纯数据定义，无初始化、无副作用）
        ═══════════ 进入 Agent 循环 ═══════════

② Sandbox 创建 —— 产出 SandboxInfo
SandboxProvider.create()
    └─ 构造 SandboxInfo(sandbox_id, sandbox_url, ...)
          └─ created_at = utc_now_iso()        ← 默认工厂
    → 写入 state["sandbox"]                    ← 供 middleware / stream_service 读

③ 路径解析 —— 产出 ResolvedPath
_resolve_path_with_mapping(path, mappings)
    ├─ 按 container_path 长度降序匹配          ← 最长前缀优先
    └─ return ResolvedPath(path=..., mapping=PathMapping(...))

④ grep 工具 —— 产出 GrepMatch 列表
grep(...)
    └─ 每条匹配 → GrepMatch(path, line_number, line)

⑤ 持久化 / 恢复 —— SandboxInfo 序列化往返
state["sandbox"] → SandboxInfo.to_dict()       ← 持久化 / 日志
持久化数据 → SandboxInfo.from_dict(data)       ← 跨进程恢复
    └─ base_url 旧字段 → sandbox_url           ← 向后兼容

（其余 hook 与本模块无关）
```

### 0.3. 补充

**`types.py` 是 sandbox 层的"公共词汇表"——provider / backend / guard / translator / middleware 都引用同一套类型，保证跨实现（Local / Docker / K8s）语义一致。**

几点补充：

- **纯数据、无行为**：本文件只有 dataclass / NamedTuple，没有业务逻辑。每个类的作用都是"承载某一类信息"，唯一带逻辑的是 `SandboxInfo` 的 `to_dict` / `from_dict`——它是跨进程恢复沙箱的唯一入口。
- **`frozen=True` 是并发前提**：`PathMapping` 不可变，才能在多线程 / 多 Agent 场景下安全共享映射表。
- **"最长前缀优先"不在本文件实现**：注释只是约定，真正的排序逻辑在解析路径的调用方（`_resolve_path_with_mapping` 所在模块）。
- **字段差异是设计而不是缺陷**：`container_name` / `container_id` 只有 LocalContainerBackend 有，K8s（Remote）只有 `sandbox_url`；用 `None` 默认值把差异压平，调用方按需判空。
- **向后兼容点**：`from_dict` 里 `base_url → sandbox_url` 是唯一的兼容分支，改字段名时别删。
