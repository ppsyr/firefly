---

name: DockerPathGuard — Docker 路径白名单守卫（写入必须落挂载区）。

description: 

【整体职责】
实现 security_guard 契约的"Docker 路径"版本：约束**写入**操作只能落在挂载区
（/mnt/poirot/user-data/），包括两条路径——
① validate_path(write=True)：直接写入的路径；
② validate_command：bash 重定向目标（> / >>）的绝对路径。
读操作不限制——容器边界本身已提供隔离，读越界危害有限。

【内容摘要】
- _VIRTUAL_PREFIX   : 唯一允许写入的虚拟路径前缀（/mnt/poirot/user-data/）。
- _REDIRECT_PATTERN : 捕获 bash 重定向目标绝对路径的正则（> 或 >>）。
- DockerPathGuard   : Docker 路径守卫类。
    ├─ validate_path    : 写入路径校验（write=True 时才查前缀）。
    └─ validate_command : 命令中重定向目标校验。

【职责边界】
- 只负责：写入路径的前缀白名单校验（直接路径 + 重定向目标）。
- 不负责：读路径校验（读不限制）、路径转换（translator）、
  相对路径解析 / cd 后路径解析（容器隔离兜底）。
- 无状态：不持有任何字段，规则全在模块级常量里。

## 0. 结构树

### 0.1. 静态结构树

```
docker_path_guard.py — DockerPathGuard（Docker 路径白名单守卫：写入必须落挂载区）
│
├─ _VIRTUAL_PREFIX: str                        ← 唯一允许写入的虚拟路径前缀
│   └─ "/mnt/poirot/user-data/"
│
├─ _REDIRECT_PATTERN: Pattern                  ← 捕获 bash 重定向目标（绝对路径）的正则
│   └─ r'>{1,2}\s*(/[^\s;|&]*)'
│         ├─ > 或 >>（重定向符）
│         ├─ \s*（可含空白）
│         └─ (/[^\s;|&]*)（以 / 开头，遇空白/; | & 停 → 仅绝对路径）
│
└─ DockerPathGuard                             ← Docker 路径守卫类（无状态）
    │
    ├─ validate_path(path, *, write=False)     ← 写入路径校验
    │   ├─ not write → return（读不限制，直接放行）
    │   └─ not path.startswith(_VIRTUAL_PREFIX)
    │         → raise SandboxPermissionError
    │           (operation="validate")
    │
    └─ validate_command(command)               ← 命令校验：扫重定向目标
        └─ _REDIRECT_PATTERN.finditer(command)
              └─ 每个 target：
                    ├─ startswith(_VIRTUAL_PREFIX) → 放行
                    └─ 否则 → raise SandboxPermissionError
                              (operation="validate_command")
```

### 0.2. 运行时调用树

```
① 装配期
DockerPathGuard()
    └─ 无参构造，无状态；规则全部来自模块级常量
    → 产出 guard 实例（Docker 场景下按需叠加）

        ═══════════ 进入命令执行 ═══════════

② 路径校验 —— validate_path(path, write)
sandbox.execute_command(cmd) 内部对涉及的写入路径
    └─ guard.validate_path(path, write=...)
          ├─ write=False → return（读不限制）
          └─ write=True
                ├─ path.startswith("/mnt/poirot/user-data/") → 放行
                └─ 否则 → raise SandboxPermissionError
                          （write path must be under ...）

③ 命令校验 —— validate_command(command)
sandbox.execute_command(cmd) 前
    └─ guard.validate_command(command)
          └─ _REDIRECT_PATTERN.finditer(command)
                ├─ 匹配 "> /abs/path" 或 ">> /abs/path"
                │     ├─ target.startswith("/mnt/poirot/user-data/") → 放行
                │     └─ 否则 → raise SandboxPermissionError
                │               （redirect target must be under ...）
                └─ 不匹配（相对路径、2>&1、tee 等）→ 跳过（容器隔离兜底）

（本模块不介入路径转换、命令执行、读路径校验、cd 解析）
```
