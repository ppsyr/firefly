---

name: DefaultStrategy — 默认上下文治理策略。

description:

【整体职责】
实现 contract.GovernanceStrategy 的 6 个 hook，按 token 占用 fraction 分阶段
（P1/P2/P3/P4/P5）触发上下文压缩动作。策略内部把具体执行委托给 4 个 Executor：
    - BudgetTrackerExecutor ：算 token / fraction / pending 阶段
    - ExternalizerExecutor  ：外化超长 tool result 到磁盘
    - SnapshotExecutor      ：P4 压缩前存快照
    - SummarizerExecutor    ：P4 用 LLM 全量摘要旧消息

【注册】
@register_strategy("default") 装饰，供 registry.get_strategy_class("default") 查表。

【阈值（_DEFAULT_THRESHOLDS，可被 params.thresholds 覆盖）】
    p1_externalize   0.40  → P1 外化
    p2_thinking      0.50  → P2（标记 thinking，当前主要由 _mark_thinking 承担）
    p3_observations  0.60  → P3 设 p3_obs_limit（当前渲染层未消费，no-op）
    p4_summarize     0.80  → P4 摘要
    p5_stop_toolcall 0.90  → P5 剥 tool_calls + 收尾提示 + jump model
    hard_stop        0.99  → 硬停（P5 分支用文案区分）

【hook 编排概览】
    before_agent  → init_budget
    after_agent   → clear_run_state
    before_model  → pairing 补全 + P3/P4/P1 按 pending 顺序执行
    after_model   → track + _mark_thinking + P5 剥 tool_calls
    wrap_model_call  → no-op
    wrap_tool_call   → 单条 tool result 外化（externalize_if_needed）

strategies/default/ — DefaultStrategy 默认策略（@register_strategy("default")）
│
├─ _constants.py
│   └─ CST = timezone(timedelta(hours=8))        ← 中国标准时间 UTC+8
│
├─ budget.py — BudgetTrackerExecutor
│   ├─ __init__(thresholds: dict[str, float])
│   ├─ init_budget(governance) → dict            ← 初始化 budget / seen_msgs / pending / 标志位
│   ├─ track(governance, messages, token_counter, window) → dict
│   │   ├─ 增量累计 usage_metadata（seen_msgs diff）
│   │   ├─ current = token_counter(messages)
│   │   ├─ fraction = current / window
│   │   └─ 按阈值标 pending（P1/P2/P4/P5）
│   └─ clear_run_state(governance) → dict        ← 清 budget/seen_msgs/pending/warned/...
│
├─ externalizer.py — ExternalizerExecutor
│   ├─ __init__(externalize_dir, min_chars, preview_chars, exempt_rounds, tool_metadata)
│   ├─ _get_threshold(tool_name) → int           ← max(min_chars, typical_tokens*4)
│   ├─ externalize_if_needed(tool_result) → ToolMessage | None   ← 单条外化
│   ├─ externalize_history(messages) → list[ToolMessage] | None  ← 批量 FIFO 外化
│   │   └─ 近 exempt_rounds 轮豁免 + 每轮保 1 + 幂等
│   ├─ _partition_turns(messages) → list[list[tuple[int, Any]]]  ← 按 HumanMessage 分 turn
│   ├─ _is_externalizable(msg) → bool            ← 当前未被调用（保留工具方法）
│   ├─ _extract_text(content) → str              ← str / list[dict] / list[str] 抽文本
│   └─ _write_to_disk(content, tool_call_id, tool_name) → str | None
│       └─ JSON 可解析存 .json，否则存 .txt
│
├─ snapshot.py — SnapshotExecutor
│   ├─ __init__(snapshot_dir=".poirot/snapshots")
│   ├─ snapshot_if_pending(governance, messages, state) → dict | None
│   │   └─ 仅 "P4" in pending；写 default.snapshot_path + metrics.snapshot_count
│   ├─ _build_snapshot(messages, state) → dict
│   │   └─ created_at / messages / research_question / todos /

│   ├─ _serialize_list(items) → list             ← dataclass → asdict，其它 str 兜底
│   ├─ _serialize_msg(msg) → dict                ← {type, content, id, tool_calls, ...}

│

│   ├─ __init__(model, preserve_recent=6)
│   ├─ summarize_if_pending(governance, messages, externalizer) → GovernanceResult | None
│   │   └─ 仅 "P4" in pending；无模型返 None
│   │      messages_patch = [RemoveAll, summary_msg, *preserved]
│   ├─ _partition(messages) → (to_summarize, preserved)
│   ├─ _strip_orphan_tools(preserved) → (clean, orphans)
│   ├─ _snap_to_pairing(messages, cut) → int     ← 切分点前移到 pairing 完整处
│   ├─ _externalize_orphans(messages, externalizer) → list[str]
│   ├─ _call_llm(messages) → str | None          ← prompts 加载 summarize 提示词
│   │   └─ config.tags=["internal_llm"] 防 stream 泄漏
│   ├─ _format_history(messages) → str           ← "[类型] 内容前 500 字"
│   └─ _update_summary(governance, summary_text) → dict
│       └─ default.summary / summary_id / metrics.summarize_count
│
└─ strategy.py — DefaultStrategy（实现 GovernanceStrategy 6 hook）
    ├─ _DEFAULT_THRESHOLDS: dict[str, float]     ← p1/p2/p3/p4/p5/hard_stop
    │
    ├─ __init__(params, model, summarize_model)
    │   ├─ 阈值合并（默认 + params.thresholds）
    │   └─ 实例化 4 个 Executor：
    │       BudgetTrackerExecutor / ExternalizerExecutor /
    │       SummarizerExecutor / SnapshotExecutor
    │
    ├─ before_agent(ctx) / abefore_agent(ctx)
    │   └─ budget.init_budget → GovernanceResult(state_patch.governance)
    ├─ after_agent(ctx) / aafter_agent(ctx)
    │   └─ budget.clear_run_state → GovernanceResult(state_patch.governance)
    │
    ├─ before_model(ctx) / abefore_model(ctx)     ← 压缩主入口
    │   ├─ _ensure_pairing(messages) → pairing_patch
    │   ├─ P3 分支 → p3_obs_limit（当前 no-op）
    │   ├─ P4 分支 → snapshot.snapshot_if_pending
    │   │            → summarizer.summarize_if_pending
    │   ├─ P1 分支 → externalizer.externalize_history（间隔抑制）
    │   └─ 合并 pairing_patch → GovernanceResult
    │
    ├─ after_model(ctx) / aafter_model(ctx)
    │   ├─ 解析 window（config.window 优先 → resolve_window_size）
    │   ├─ budget.track → governance
    │   ├─ _mark_thinking(messages) → messages_patch
    │   └─ P5 分支 → _strip_tool_calls + _build_stop_message
    │                → jump_to="model"（warned 防重复）
    │
    ├─ wrap_model_call(ctx) / awrap_model_call(ctx)
    │   └─ no-op → GovernanceResult()
    │
    ├─ wrap_tool_call(ctx) / awrap_tool_call(ctx)
    │   └─ externalizer.externalize_if_needed(tool_result)
    │       → GovernanceResult(request_override=替换版) 或 GovernanceResult()
    │
    ├─ _ensure_pairing(messages) → list | None    ← 补缺失 ToolMessage
    ├─ _strip_tool_calls(last_ai, fraction) → AIMessage   ← 同 id 替换，剥 tool_calls
    ├─ _build_stop_message(fraction) → str        ← 90% / 99% 两档文案
    ├─ _mark_thinking(messages) → list | None     ← 打 POIROT_THINKING 标记
    ├─ _emit_compaction_event(event_type, **fields) → None
    ├─ _emit_trace(ctx, event, stage, **fields) → None
    │   ├─ 写 compaction.jsonl
    │   ├─ 关键事件入 journal
    │   └─ 发 stream 事件
    └─ _get_run_dir(runtime) → str | None         ← .poirot/logs/threads/<tid>/runs/<rid>
