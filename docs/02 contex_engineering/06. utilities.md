---

name: token utility：token_counter + resolve_window_size + resolve_model_name。

description:

【整体职责】
为上下文治理层提供「token 计数」与「模型窗口/模型名解析」两类工具：
    1. token_counter(messages, model_name=None) → int
       算 messages 的总 token 数。tiktoken 优先；tiktoken 不可用时退化到
       CJK-aware 字符估算（CJK 字符 ~1 token，非 CJK ~4 字符/token）。
    2. resolve_window_size(model) → int
       取模型上下文窗口大小。支持穿透 FallbackChatModel 拿到内层真实模型，
       再按属性 / _identifying_params / model_name 前缀映射逐级解析。
    3. resolve_model_name(model) → str | None
       取当前活跃 provider 的真实模型名（如 "deepseek-v4-flash"），
       与 resolve_window_size 共用穿透逻辑。

【被谁用】
    - StrategyMiddleware._ctx 把 token_counter 注入 GovernanceContext；
    - DefaultStrategy.after_model 调 resolve_window_size 解析 window；
    - DefaultStrategy.budget.track 用 ctx.token_counter 算 current/fraction；
    - TUI 的 Build 信息行用 resolve_model_name 展示真实模型名。

【关键设计】
    - tiktoken 懒加载 + 失败 cooldown（600s）+ 并发 LOADING sentinel 缓存；
    - CJK-aware char fallback：中文场景下比"字符数/4"更接近真实 token；
    - FallbackChatModel 穿透：本身只含 providers/active，必须进 .models[active]
      才能拿到真实容量与模型名；bind_tools 后的 RunnableBinding 需剥 .bound。

```text
utilities.py — token utility（token 计数 + 模型窗口/模型名解析）
│
├─ 模块级常量
│   ├─ logger = logging.getLogger(__name__)
│   ├─ _TIKTOKEN_RETRY_COOLDOWN_S = 600        ← tiktoken 失败冷却期（秒）
│   ├─ _DEFAULT_WINDOW = 128_000               ← 无法解析时的默认窗口
│   ├─ _MODEL_WINDOW_MAP: dict[str, int]       ← model_name 前缀 → 窗口大小（长前缀优先）
│   ├─ _ENCODING_CACHE: dict[str, Any]         ← model_name → encoding 或 sentinel
│   ├─ _last_failure_ts: float = 0.0           ← 上次 tiktoken 失败时间戳
│   ├─ _loading_sentinel = object()            ← 并发占位 sentinel
│   └─ _CJK_RANGES: tuple[tuple[int, int], ...]← CJK 字符区间
│
├─ _is_cjk(ch) → bool                          ← CJK 字符判定
│   └─ 用途：char 估算时 CJK ~1 token，非 CJK ~4 字符/token
│
├─ _extract_text(message) → str                ← 从 str / BaseMessage / dict 抽纯文本
│   └─ 支持：str / .content / dict["content"] / list[str|dict] 拼接
│
├─ _char_estimate(messages) → int              ← CJK-aware char 估算
│   └─ 返回 cjk 字符数 + 非 cjk 字符数 // 4
│
├─ _get_encoding(model_name) → encoding | None ← tiktoken 懒加载 + 失败冷却 + sentinel
│   ├─ key = model_name or "default"
│   ├─ 缓存命中且非 sentinel → 返回 encoding
│   ├─ 缓存命中且是 sentinel → 返回 None
│   ├─ 距上次失败 < cooldown → 返回 None（不重试）
│   ├─ 尝试 import tiktoken：
│   │   ├─ 成功 → 缓存 encoding + 返回
│   │   └─ 失败 → 记 _last_failure_ts + 缓存 sentinel + 返回 None
│   └─ 无 model_name 时用 cl100k_base
│
├─ token_counter(messages, model_name=None) → int   ★ 对外主接口
│   ├─ enc = _get_encoding(model_name)
│   ├─ enc 为 None → _char_estimate(messages)
│   ├─ 否则逐条 len(enc.encode(_extract_text(msg))) 累加
│   └─ 单条 encode 异常 → 该条退化为 _char_estimate([msg])
│   └─ 被谁用：StrategyMiddleware._ctx 注入 GovernanceContext；
│              DefaultStrategy.budget.track 算 current/fraction
│
├─ resolve_window_size(model) → int            ★ 对外主接口
│   ├─ 1. FallbackChatModel 穿透：.models[active] → 剥 .bound → 递归
│   ├─ 2. model 属性：max_input_tokens / model_max_tokens / max_tokens
│   ├─ 3. _identifying_params dict（可能是 callable）
│   ├─ 4. model_name / model 前缀匹配 _MODEL_WINDOW_MAP
│   └─ 5. 全部失败 → _DEFAULT_WINDOW
│   └─ 被谁用：DefaultStrategy.after_model 解析 window
│
└─ resolve_model_name(model) → str | None      ★ 对外主接口
    ├─ 1. FallbackChatModel 穿透：.models[active] → 剥 .bound → 递归
    ├─ 2. model.model_name / model.model
    ├─ 3. _identifying_params 的 model_name / model
    └─ 4. 都没有 → None
    └─ 被谁用：TUI Build 信息行展示真实模型名（非 provider 链）
```

### 关系速览

```
DefaultStrategy.after_model
  ├─ resolve_window_size(self._model)         → window
  └─ budget.track(..., ctx.token_counter, window)
        └─ token_counter(messages)            → current
              └─ _get_encoding(model_name)
                    ├─ 命中 → enc.encode
                    └─ 未命中 → _char_estimate
                          └─ _is_cjk / _extract_text

TUI Build 信息行
  └─ resolve_model_name(model)                → "deepseek-v4-flash"

StrategyMiddleware._ctx
  └─ GovernanceContext(token_counter=token_counter)   ← 注入
```
