---

name: registry - 策略 bundle 注册表。

description:

【整体职责】
维护一张全局映射表 ``name -> bundle_cls``，用于「按名字查找策略 bundle 类」。
策略 bundle 通过 ``@register_strategy(name)`` 装饰器被动注册；
装配器（builder）通过 ``get_strategy_class(name)`` 查表拿到类再实例化。

【使用方式】
新增一个策略 bundle，只需：
    1. 在新文件里定义 bundle 类；
    2. 在类上加 ``@register_strategy("策略名")``；
    3. 在某个会被 import 的地方 import 该文件，触发注册（import 副作用）。

【设计要点】
- 注册表是模块级全局变量，进程内共享。
- 重注册（同名不同类）不报错，仅打 warning，后注册的覆盖先注册的，
  方便排查策略被意外覆盖。
- ``clear_strategies()`` 用于测试隔离，避免用例间互相污染。

---

```
registry.py — 策略 bundle 注册表
│
├─ 模块级
│   ├─ logger = logging.getLogger(__name__)
│   └─ _STRATEGY_BUNDLES: dict[str, type]        ← 全局注册表 name -> bundle_cls
│
├─ register_strategy(name) → Callable[[type], type]     ← 装饰器工厂
│   └─ decorator(cls) → type
│       ├─ 重注册（同名不同类）→ logger.warning + 覆盖
│       ├─ 幂等（同名同类）→ 不告警
│       ├─ _STRATEGY_BUNDLES[name] = cls
│       └─ return cls
│
├─ get_strategy_class(name) → type               ← 查表，未注册抛 KeyError
│   └─ KeyError 信息含 Available: sorted(_STRATEGY_BUNDLES)
│
├─ list_strategies() → list[str]                 ← 列出已注册名（sorted）
│
└─ clear_strategies() → None                     ← 清空注册表（测试隔离）
```
