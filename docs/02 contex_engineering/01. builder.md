---

name: builder - 治理 middleware 装配构建器。

description:

【职责】：
    把「上下文治理」相关的 middleware 组装成一个有序列表，交给上层 Agent 挂载。
    组装结果 = 公共 2 个固定 middleware + 1 个策略 middleware（可选）。

【组成】：
    1. 公共 2 固定（永远挂载，与所选策略无关）：
       - TaggedContextMiddleware        ：给消息上下文渲染标签（如 <date>）。
                                          DateInjector 的逻辑已并入此中间件，
                                          不再单独存在 DateInjector。
       - MessageNormalizerMiddleware    ：规范化消息结构（统一消息形态）。
    2. StrategyMiddleware（按 config.strategy 选定的策略 bundle）：
       - 内部持有策略 bundle，负责路由 6 个 hook。
       - 若 config.strategy 对应的 bundle 未注册，则跳过该中间件并打 warning，
         仅挂载公共 2 个，不抛异常。
       - 过渡期兼容：像 "minimal" 这类尚未注册为 bundle 的策略名，只会挂公共 2 个，
         不会导致崩溃。

【挂载顺序（固定）】：
    公共 TaggedContextMiddleware
    → 公共 MessageNormalizerMiddleware
    → StrategyMiddleware（策略 bundle 的 6 个 hook）

【职责边界】：
    - token 预算 + 硬停：由策略 bundle 内部负责
      （DefaultStrategy 的 BudgetTrackerExecutor 计算 fraction + P5/P99 分段），
      公共层不再重复实现硬停逻辑。
    - 公共层只负责：标签渲染、消息规范化、以及把策略 bundle 适配进 middleware 链。
---

## 0. 结构树

```
build_governance_middlewares(config, model, summarize_model) → list
│   【触发顺序：装配入口，最先被上层 Agent 组装代码调用】
│   来源：builder.py
│
├─ 步骤 1：固定挂公共 2 个 middleware（顺序不可调换）
│   │
│   ├─ TaggedContextMiddleware()
│   │   └─ 来源：middlewares/tagged_context_middleware.py
│   │       └─ 渲染 <date> 等标签（DateInjector 逻辑已并入）
│   │
│   └─ MessageNormalizerMiddleware()
│       └─ 来源：middlewares/message_normalizer_middleware.py
│           └─ 规范化消息结构（统一消息形态）
│
├─ 步骤 2：查策略 bundle 类
│   │
│   └─ get_strategy_class(config.strategy)
│       └─ 来源：registry.py
│           ├─ _STRATEGY_BUNDLES: dict[str, type]   ← 全局 name -> bundle_cls
│           ├─ 命中 → 继续步骤 3
│           └─ KeyError → logger.warning + return（仅公共 2，降级不崩）
│
├─ 步骤 3：在查策略 bundle 类之前，已经实例化策略 bundle
│   │     在 strategy.py 中，通过 @register_strategy("default") 注册了一个实例策略
│   │
│   └─ bundle_cls(config.params, model=model, summarize_model=summarize_model)
│       │   ← bundle_cls 来源：strategies/ 目录
│       │      （通过 @register_strategy(name) 装饰器注册进 registry）
│       │
│       └─ 必须实现 contract.py 的 GovernanceStrategy Protocol 6 hook：
│           │   来源：contract.py
│           │
│           ├─ before_agent(ctx) / abefore_agent(ctx)
│           ├─ after_agent(ctx) / aafter_agent(ctx)
│           ├─ before_model(ctx) / abefore_model(ctx)
│           ├─ after_model(ctx) / aafter_model(ctx)
│           ├─ wrap_model_call(ctx) / awrap_model_call(ctx)
│           └─ wrap_tool_call(ctx) / awrap_tool_call(ctx)
│
├─ 步骤 4：包成 StrategyMiddleware 追加到链尾
│   │
│   └─ StrategyMiddleware(bundle, config.params)
│       └─ 来源：strategy_middleware.py
│           │
│           └─ class StrategyMiddleware(AgentMiddleware)   【运行期触发顺序】
│               │
│               ├─ state_schema = ThreadState
│               │   └─ 来源：state/types.py
│               │
│               ├─ __init__(bundle, config=None)
│               │   └─ 持有 bundle + config
│               │
│               ├─ _ctx(state, runtime, hook, **hook_specific) → GovernanceContext
│               │   │   来源：contract.py → GovernanceContext
│               │   │
│               │   └─ 注入字段：
│               │       ├─ state          ← 入参
│               │       ├─ governance     ← state.get("governance")
│               │       ├─ config         ← self._config
│               │       ├─ token_counter  ← utilities.token_counter
│               │       ├─ runtime        ← 入参
│               │       ├─ hook           ← hook 名
│               │       └─ hook-specific  ← messages/tools/model_request/
│               │                           tool_call_request/tool_result
│               │
│               ├─ 【state-channel hooks：返回 dict，走 apply_governance_result】
│               │   │   （来源：contract.apply_governance_result）
│               │   │
│               │   ├─ before_agent(state, runtime)      ← bundle.before_agent
│               │   ├─ abefore_agent(state, runtime)     ← bundle.abefore_agent
│               │   ├─ after_agent(state, runtime)       ← bundle.after_agent
│               │   ├─ aafter_agent(state, runtime)      ← bundle.aafter_agent
│               │   ├─ before_model(state, runtime)      ← @hook_config(can_jump_to=["model"])
│               │   ├─ abefore_model(state, runtime)     ← @hook_config(can_jump_to=["model"])
│               │   ├─ after_model(state, runtime)       ← @hook_config(can_jump_to=["model"])
│               │   └─ aafter_model(state, runtime)      ← @hook_config(can_jump_to=["model"])
│               │       │
│               │       └─ apply_governance_result(state, result) → dict | None
│               │           └─ GovernanceResult → dict patch
│               │               ├─ state_patch
│               │               ├─ messages_patch
│               │               ├─ governance.metrics（merge_metrics_into_governance）
│               │               └─ jump_to
│               │
│               └─ 【wrap hooks：adapter 包 handler，仅消费 request_override】
│                   │
│                   ├─ wrap_model_call(request, handler)     ← PRE：bundle 改 request → handler
│                   ├─ awrap_model_call(request, handler)    ← PRE async
│                   ├─ wrap_tool_call(request, handler)      ← POST：handler 取 result → bundle 改 result
│                   └─ awrap_tool_call(request, handler)     ← POST async
│
└─ 返回：list = [TaggedContextMiddleware, MessageNormalizerMiddleware, (StrategyMiddleware)]
```

## 2. 触发时序总览（从上层组装到运行期）

```
上层 Agent 组装代码
    │
    ▼
① builder.build_governance_middlewares(config, model, summarize_model)
    │
    ├─ import strategies（副作用：触发所有 @register_strategy 注册）
    ├─ 挂 TaggedContextMiddleware
    ├─ 挂 MessageNormalizerMiddleware
    ├─ registry.get_strategy_class(config.strategy)
    │       └─ 未注册 → warning + return（仅公共 2）
    ├─ bundle = bundle_cls(config.params, model, summarize_model)
    └─ append StrategyMiddleware(bundle, config.params)
    │
    ▼
② 返回 list[AgentMiddleware] 交给 Agent 挂载
    │
    ▼
③ 运行期：AgentMiddleware 链依次触发
    │
    TaggedContextMiddleware
        → MessageNormalizerMiddleware
        → StrategyMiddleware
              │
              ├─ _ctx() 构造 GovernanceContext
              │       └─ utilities.token_counter 注入
              │
              ├─ state-channel hook
              │   └─ bundle.<hook>(ctx)
              │       └─ apply_governance_result → dict patch
              │
              └─ wrap hook
                  ├─ wrap_model_call（PRE）：bundle 改 request → handler
                  └─ wrap_tool_call（POST）：handler 取 result → bundle 改 result
```

## 3. contract.py 内部结构（被 strategy_middleware 消费）

```
contract.py
│
├─ class GovernanceContext(dataclass, frozen)         ← hook 级统一入参
│   └─ state / governance / config / token_counter / runtime / hook
│      + messages / tools / model_request / tool_call_request / tool_result
│
├─ class GovernanceResult(dataclass, frozen)          ← hook 级统出参
│   └─ state_patch / request_override / messages_patch / metrics / jump_to
│
├─ class GovernanceMetric(dataclass, frozen)          ← 策略级 metric
│   └─ strategy_name / metric_key / value / run_id / thread_id
│
├─ class GovernanceStrategy(Protocol, runtime_checkable)   ← 策略接入契约
│   └─ 6 hook（sync + a 前缀 async 对）
│
├─ class MemorySink(Protocol, runtime_checkable)      ← 短期治理 ↔ 长期记忆边界
│   └─ flush / aflush(messages_to_drop)
│
├─ merge_metrics_into_governance(governance, metrics) → dict
│   └─ 按 {strategy_name}.{metric_key} 前缀写 governance.metrics
│
└─ apply_governance_result(state, result) → dict | None
    └─ 把 GovernanceResult 转成 state-channel hook 的 dict patch
        （state_patch / messages / governance.metrics / jump_to）
```

## 4. utilities.py 内部结构（被 strategy_middleware 消费）

```

│
├─ _is_cjk(ch) → bool                            ← CJK 字符判定

├─ _char_estimate(messages) → int                ← CJK-aware char 估算
├─ _get_encoding(model_name) → encoding | None   ← tiktoken 懒加载 + 失败冷却

                                                   与 resolve_window_size 同一穿透逻辑
```

## 5. registry.py 内部结构（被 builder 消费）

```
registry.py
│
├─ _STRATEGY_BUNDLES: dict[str, type]            ← 全局注册表 name -> bundle_cls
│
├─ register_strategy(name) → decorator           ← 装饰器工厂
│   └─ decorator(cls) → cls
│       ├─ 重注册（同名不同类）→ warning + 覆盖
│       └─ 幂等（同名同类）→ 不告警
│
├─ get_strategy_class(name) → type               ← 查表，未注册抛 KeyError
│                                                  ★ 被 builder 调用
│
├─ list_strategies() → list[str]                 ← 列出已注册名（排序）
└─ clear_strategies() → None                     ← 清空（测试隔离）
```
